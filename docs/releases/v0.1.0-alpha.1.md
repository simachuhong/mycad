# MyCAD v0.1.0-alpha.1 — Windows x64 测试预览

面向 Windows 10/11 x64 测试用户的首个安装器预览。安装器文件版本为 `0.1.0.1`。
无需预装 Python 或 uv；默认仅为当前用户安装。

## 下载与安装

下载 `MyCAD-0.1.0.1-x64-Setup.exe`，核对 `SHA256SUMS` 后启动安装向导。
支持中文向导、开始菜单、可选桌面快捷方式、文档打开方式登记和卸载入口。
完整操作见随附的 Windows 安装包测试指南。

## 本版内容

- 现有二维绘图、文字与尺寸、GROUP/BLOCK 和本地/共享块库流程。
- 现有三维零件建模和工程图流程；包含草图约束求解依赖。
- Windows 安装/卸载日志、启动故障日志，以及冻结后的工程图和 DXF 辅助进程入口。
- 可在 Windows 本机重复执行的构建脚本。

## 测试范围与已知边界

- 这是 Alpha 预览，Windows 实际人工验收和第三方 CAD 兼容检查仍需按清单执行。
- 安装包未做数字签名；品牌图标使用打包器默认图标。
- 不含自动更新；覆盖升级和卸载后数据保留须在用户主机继续验证。
- 不承诺与 AutoCAD / Solid Edge 完全兼容，不承诺未验证的平台。
- Windows 10 支持仍需 Windows 10 实机证据，Windows runner 的结果不能代替。

## 反馈

请附 Windows 版本、显卡与驱动、安装器校验值、最短复现步骤和相关日志。
安装日志默认位于 `%LOCALAPPDATA%\MyCAD\installer-logs`，
运行日志位于 `%LOCALAPPDATA%\MyCAD\logs\进程号`。
直接双击安装器的默认日志通常位于 `%TEMP%` 的 `Setup Log*.txt`。

本软件采用 Apache-2.0；随附原生库和第三方组件保留各自许可证。
