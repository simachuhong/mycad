# U09 矩形阵列方向角

目标：ARRAYRECT 的 AN/ANGLE 让列轴按工作平面内角度旋转，行轴保持正交；独立和关联阵列的预览、确认、源联动、间距及数量编辑、保存重开和撤销重做保持同一几何语义。

1. 为独立阵列实现有限角度和正交位移，保留零角行为。
2. 为关联阵列引入带方向角的版本化记录；旧记录按零角重放，禁止旧命令版本静默接受新字段。传播、间距与数量修改使用相同位移计算，保持成员身份和现有关联保护。
3. 接入 ARRAYRECT 预览角度选项，非法输入不破坏预览，确认时独立和关联使用同一角度；支持数值和方向点输入。
4. 覆盖负角、负间距、单行列、多源、不同工作平面、约束与锁层拒绝、旧档重放、撤销重做、保存重开及窗口交互。录像未覆盖的行为保留待实机核对。

版本迁移需覆盖 `sketch.create` v14、`drawing.sketch.revise` v11 及 `drawing.array.add/resize` 的新版本，选择版本时同时考虑已有端点、推断重绑定和混合历史；不修改旧版严格 schema。间距更新命令只携带阵列 ID 和新间距，可沿用原有格式；其重放须从既有阵列记录取得角度。零角旧记录维持旧字段集合，新记录仅由新版本创建。数量修改不得借机篡改方向角。

参考：[Autodesk ARRAYRECT 命令说明](https://help.autodesk.com/cloudhelp/2016/ENU/AutoCAD-MAC-Core/files/GUID-BB3DA888-0C3A-4C68-A3ED-E0E528781205.htm)。
