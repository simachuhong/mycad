# 二维绘图人工验收整改

**依据**：用户人工验收四项不通过：独立窗口、缺 UCS、缺绘图/修改面板、直线不能连续与自动闭合。
**状态**：整改与工程验证完成，用户复验待执行；此前 P2 G 工程完成不代表本轮人工验收通过。
**方案**：复用现有 PySide6 草稿/Bus，在主窗口中央堆叠工作区嵌入编辑器；左侧可滚动绘图/修改工具面板，右侧画布、底部坐标/命令控制。兼容已有独立编辑器调用，但产品入口全部内嵌。绘图模式默认连续直线。绘制 UCS 与真实工作平面/原点一致，不宣称支持任意旋转 UCS。
**约束**：保留共享工作树全部改动；只经 Bus 提交；用户限定已提交草图不做自由几何编辑；不改变存档协议。授权来自既有继续开发/质量自检要求与本轮明确验收反馈，不另设审批。

- [x] 连续线/闭合：鼠标和数值输入共用；Enter结束，C闭合，首点捕捉闭合，Esc保留已完成线；退回上一段，零长拒绝；闭合多段线。
- [x] 内嵌工作区：开始/取消/提交/失败恢复/文档切换；绘图文档新建直接入画布；保存和关闭保护草稿。
- [x] 面板/UCS：常驻图元与修改按钮、清晰参数组、坐标箭头/原点/平面名、缩放平移后仍可辨识。
- [x] 范围测试/静态检查/实际Qt渲染截图；复核布局及连续绘图事件；更新验收与ledger，人工验收仍待用户。

## 验证重点
小屏幕下按钮不能挤出窗口；非XY平面轴标签必须正确；连画撤销后继续必须接在正确端点；不完整圆弧禁止提交；提交失败保留草稿；Esc不得丢弃整张草稿。
