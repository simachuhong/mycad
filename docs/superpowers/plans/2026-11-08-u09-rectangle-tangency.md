# U09 矩形边不修剪圆角相切

目标：不改变矩形身份的前提下，让不修剪圆角可引用矩形的有限边；同草稿和跨草图关系均可求解、保存、撤销和重放，禁止用多段线替换源矩形。

1. [x] 建立矩形四边稳定索引，验证几何解析、有限相切和非法索引；复用既有 segment 引用结构。
2. [x] 将矩形边接入草稿相切求解和不修剪圆角，覆盖线、圆、圆弧、多段线和矩形来源；验证来源和关联的撤销重做。
3. [ ] 跨草图求解通过投影临时路径及方向约束保持矩形，已覆盖旋转/反向平面、固定目标、移动及尺寸驱动；矩形角点方向反转时保护性拒绝，退化和更多依赖组合仍需验证。
4. [x] 新增 `sketch.create` v27、`drawing.sketch.revise` v27 和 `drawing.tangency.add` v6；旧版本拒绝新引用，覆盖存档重开和撤销重做。
5. [ ] 路径级测试、格式、类型及分层已执行；真实设备验收仍待进行。
