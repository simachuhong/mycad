# 二维曲线与鼠标修改整改

用户验收反馈：缺样条；穿过两个边界的线连续修剪失败；复制原地重叠；移动没有鼠标放置。

根因：直线修剪对全部剩余交点分段，后续片段无内部交点；移动/复制工具直接用默认零位移执行。

实现顺序：
1. 保留修剪区域两侧各自连续的剩余线，只在实际删除区间处分开；验证两端连续修剪和两个对象连续修剪。
2. 原生鼠标选择—基点—预览—目标点状态；支持预选和命令先行，右键/Enter结束选择，Esc取消，确认一次写入草稿撤销历史。显式数值按钮保留ΔU/ΔV方式，拒绝零位移。锁定/隐藏层及用户约束保护继续生效。
3. 新增开放均匀夹持三次B样条中立DTO（控制点方式，至少4点），UI同一数据采样显示；OCCT原生BSpline构建准确几何、ezdxf原生SPLINE读写，保存重放及变换/控制点编辑。首尾控制点在曲线上，中间点控制形状，不宣称拟合点/周期/有理权重样条已支持。暂不支持样条修剪/延伸/偏移，明确拒绝，不离散成折线冒充。
4. scoped自动化（真实交互状态、撤销、保存重放、DXF/OCCT一致性、既有几何约束不退化）、静态四门及隔离XCB鼠标检查；留证与人工步骤。

用户正在运行的GUI不因编辑自动重启。所有模型提交保持Bus，直接几何编辑范围仍为未提交草稿。
