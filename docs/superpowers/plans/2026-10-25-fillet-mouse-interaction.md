# 圆角鼠标交互实施计划

状态：核心实现和针对性验证已完成；GUI 已启动，等待人工验收。

## 目标

按已确认的 `docs/superpowers/specs/2026-10-25-fillet-mouse-interaction-design.md` 落地圆角主流程：视口外的固定命令条、连续选边、半径自动预览、预览中继续选边/导航、显式确认并以 CommandBus 写入。

## 步骤

1. 添加紧凑圆角命令条和单输入状态测试；命令条位于视口外，不绘制在模型上。
2. 增加圆角专用视口交互：左键选择/切换原模型边，中键导航，短右键松开确认，Enter/R/Escape 服从输入焦点优先级。
3. 令候选预览保留相机、选边身份和高亮；在计算新参数时清掉旧候选，避免过期几何伪装成当前结果。
4. 在 MainWindow 编排自动防抖预览、无效半径反馈、每组单独确认与连续建模；命令仍走 PlanDraftController + CommandBus。
5. 运行改动路径的 lint、类型与 UI 测试，然后启动 GUI 供人工验收。

## 验收重点

- 视口上方独立命令条，不遮挡几何；模型变大或窗口变窄也不覆盖。
- 预览存在时点击源模型边仍能累加/移除；中键旋转/平移和滚轮缩放不丢参数。
- 半径有效时自动生成最新预览；无效时保留输入和选边并给出简短说明。
- 半径输入 Enter 只接受输入；视口 Enter/有效短右键/“完成此组”才通过 GUI 确认路径提交。
- 成功后每组选边形成独立可撤销命令，可接着操作；取消不撤销已提交组。
