# U09 多段线段跨草图相切

跨草图引用增加可选的多段线段索引；旧关系映射和旧命令版本保持原样。引用解析必须确认实体、索引和真实有限曲线；投影求解使用原多段线及共享顶点，逆投影后验证弧段、相切分支和所有本地约束，禁止以弦替代圆弧。新增命令版本保存段引用，预览和提交继续使用候选及 Bus。

1. 测试关系映射、旧版本兼容、无效索引、线/圆弧段的有限相切和法向映射。
2. 测试并实现跨草图分量求解、已有约束、段关联拖动及固定锚点；覆盖外切、内切、失败回滚。
3. 增加命令版本与创建入口，覆盖完整保存重开、撤销重做、过期预览和版本隔离。
4. 接通画布创建和拾取、混合草稿、编辑与命令选项，按需增加版本化草图创建和修订；验证不同来源、取消及重放。
