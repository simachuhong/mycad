# U05 零件草图动态输入实施计划

**目标：** 零件草图直线、矩形和圆的动态尺寸可见、可输入和锁定；预览与落点遵守同一解析结果，精确输入不被捕捉或自动关系覆盖。

**依据：** `docs/design/2026-11-04-unified-ui-todo.md` U05、统一 UI 设计 §5.3 和 ST10-S05–S07。真实 ST10 操作与 GPU 证据缺失项继续待核对，不把自动测试标为人工验收。

**边界：** 动态输入属于零件草图 UI，不改 Bus、持久化 schema、求解器或独立二维工作台；失败和取消不能产生图元或污染既有草稿。输入数据在未完成图元、完成图元、整张草图三层之间隔离。

## 1. 尺寸解析与生命周期

- [ ] 对直线长度/角度、矩形宽/高和圆半径/直径编写可重复的解析测试：只锁一个字段、两个字段同时锁定、方向和象限、零值/无效值、切换单位模式。
- [ ] 实现零件草图 UI 内的单一解析器；捕捉与自动关系先解析未锁定的鼠标位置，再应用精确锁定约束，预览和最终落点复用同一结果。无法同时满足关系时不创建错误关系。
- [ ] 测试清除与生命周期：Esc 取消当前图元、撤销、切工具、完成和取消整张草图均释放临时输入；连续线每段继承方式需明确并由测试锁定。

## 2. 交互控件与键盘

- [ ] 为活动工具提供带单位的输入、键盘切换字段和锁定/解锁；支持直线长度/角度、矩形宽/高、圆半径/直径。
- [ ] 数值字段获得焦点时不触发画布绘图快捷键；无效文本保留可修正状态，不能误完成图元或污染草稿。
- [ ] 在鼠标移动、捕捉及输入变更时刷新同一候选；严格测试输入锁定后鼠标和自动关系不能覆盖精确值，解锁后可继续跟随。

## 3. 实际几何和适配验证

- [ ] 对各工具通过绘制、精确输入、预览、最终放置、测量及撤销测试几何，不仅断言字段存在；分别覆盖连续绘制、取消、无效输入及已有草图编辑。
- [ ] 跑 scoped lint、格式、类型、草图回归、分层测试；在 X11 虚拟窗口覆盖窄窗口和 DPI。记录当前源码哈希、自动结果、参考和用户验收缺口。
