# U09 圆弧多段线顶点拖动

未被任何约束引用的 bulge 多段线允许拖动顶点，保留实体身份、图层和各段 bulge；几何退化、锁定、过期版本及已有约束不允许部分提交。同草图其他约束及跨草图相切若与该多段线无关联，应保持不变。对多段线自身的直接约束仍须单独实现，不能把弧作为弦线求解。

1. 覆盖求解预览的有效拖动、无效目标、相邻点重合、锁层、其他约束及既有关联保护。
2. 接入草稿和已保存对象的真实鼠标拖动；已保存对象的同面投影保留镜像时的弧方向，预览与提交沿用修订候选和 Bus。
3. 验证草稿、保存对象和有关联但不涉及目标的草图的拖动、取消、过期、撤销重做与保存重开；记录混合暂存及参考录像未覆盖的边界。
