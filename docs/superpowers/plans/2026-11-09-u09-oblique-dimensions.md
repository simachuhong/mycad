# 异轴草图的画布方向尺寸

目标：在任意旋转、同向或反向法向的共面草图上创建画布水平、竖直及坐标尺寸，尺寸按创建时的画布方向测量并持久化，原有方向尺寸和历史重放语义不变。

1. 在中立尺寸记录中加入可选的单位投影方向，以来源草图坐标表达；严格校验、缺省不改变旧序列化。
2. 让本地求解、跨草图求解、参考值刷新、几何校验及约束锚定均使用该方向；覆盖负坐标、反向法向与零投影。
3. 为所有承载新字段的命令、草图创建、修订和关联阵列快照增加新版本；旧版本拒绝新字段，新版本允许重放，避免覆盖已有命令语义。
4. 二维尺寸工具以当前画布轴转换出来源坐标中的单位方向；候选、预览、保存及布局均使用该方向，智能尺寸与 Shift 切换共用同一转换。
5. 增量验证核心编解码和求解、旧版本拒绝、窗口鼠标创建、驱动/参考、跨草图关联、撤销重做、存档及 DXF 输出提示。方向创建在上述链路闭合前保持现有保护。
