# U09 跨草图尺寸联动

目标：尺寸的新增或更新与相切连通分量的几何变化通过一次版本化命令原子重放，尺寸预览和提交使用同一联动求解语义。

1. 在隔离求解中将尺寸加入目标草图，并与相切分量及原有局部约束一起求解；保留相切分支、锁定图层和固定约束，失败不改变文档。
2. 新增版本化批量修订命令，明确携带唯一确认的尺寸变更、求解器元数据、基准摘要与所有关联草图的结果；重放验证尺寸身份、其余约束、所有几何以及跨草图关系后一次安装，重建下游特征。
3. 接入画布尺寸预览与提交，防止文档、会话或尺寸在异步求解期间变化；预览和提交共用求解逻辑。
4. 覆盖新增和更新、无解、锁定、过期候选、撤销重做、保存重开和下游重建；对修改范围运行分层、格式、类型及相关测试。

进展：画布已接入连通分量预览与原子提交，显示目标和关联草图，提交前核对预览结果及会话状态。长度、距离、角度、半径、直径和弧长可走该路径；线性投影及端点锚定由原有求解语义处理。版本化命令记录求解器版本并校验唯一尺寸变更，参考标注可按几何重新测量。已有半径界面的鼠标操作、取消、更新、撤销，重放、保存重开和下游拉伸专项；更多图元、约束组合与窗口路径仍需覆盖。
