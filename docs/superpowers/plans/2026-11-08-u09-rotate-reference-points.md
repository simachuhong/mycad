# U09 ROTATE 参考目标两点

参考 Autodesk 2023 ROTATE 操作说明，参考角确定后提供 P / Points 选项，以任意起点及终点确定目标绝对方向。继续复用现有旋转、拾取、命令行、复制与事务路径；零长度方向保持等待并提示，Esc 取消，坐标和鼠标均可用。覆盖草稿、已保存及混选、坐标和鼠标、预览、重复/撤销及保存重开。参考：https://www.autodesk.com/support/technical/article/caas/sfdcarticles/sfdcarticles/How-to-rotate-an-object-based-on-an-existing-angle.html
