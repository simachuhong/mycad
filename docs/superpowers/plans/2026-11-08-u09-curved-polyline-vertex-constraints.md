# U09 曲线多段线顶点约束

圆弧多段线的端点、顶点按真实点接入求解；固定、重合与点间距离只作用于点坐标，弧段 bulge 精确保留。其他直接涉及弧段的约束继续拒绝，直到有真实圆弧求解模型。已有约束必须在拖动、相切联动、重放及参考尺寸刷新中保持有效。

1. 先覆盖固定、重合、距离、自由度、约束拖动、锁层和退化等局部求解；测试先失败再实现。
2. 扩展跨草图复合求解的投影、锚点和逆投影，测试曲线顶点通过本地关系与跨草图相切连接、反法向、冲突和无部分修改。
3. 检查 UI 选择及提交的版本模式，验证实际交互、保存重开、撤销重做、参考尺寸和过期候选；按项目规则做 scoped 检查并更新证据。
