# U09 录像中双切点直线

本地 AutoCAD 2023 录像约 02:05–02:20 使用直线与切点捕捉连接左下圆和右圆。当前切点捕捉需要已有直线起点，尚缺先选第一圆并延迟确定切点的路径。

1. 核心计算两圆或有限圆弧的外/内公切线，按两个拾取位置选择，检查有限弧、退化及等分歧义。
2. 二维 LINE 命令接受 TAN / TANGENT：第一切点选择来源后暂存，第二次 TAN 选另一来源后计算并生成一条线；Esc/来源变化/锁层不留部分几何；复用撤销、保存、跨草图相切约束路径。
3. 以录像尺寸及两个拾取位置验证公共外切线；单独覆盖圆弧有限范围、内切、无法求解、取消、已保存和草稿混用、保存重开与撤销。录像未证明的输入焦点和设置不作推断。

补充：同一 TAN 状态也支持“已有点 → 圆/弧切点”和“圆/弧切点 → 普通点”，普通终点保留对象捕捉和自动重合关系；预览与提交使用同一有限曲线求解。来源快照、图层、撤销与跨草图相切关系沿用已有草图事务。
