# U09 关联矩形阵列基点

## 语义与约束

- 矩形阵列基点控制阵列夹点及定位参考；更改基点不应默默移动现有成员。普通基点和源对象关键点是两种不同定义，关键点必须随所引用的源几何变化。参考：[ARRAYEDIT](https://help.autodesk.com/cloudhelp/2026/ENU/AutoCAD-LT-MAC/files/GUID-1D0F6016-F4DC-44BA-A517-B116D8CFC141.htm)、[源基点 API](https://help.autodesk.com/cloudhelp/2019/ENU/OARX-RefGuide/files/OREF-__MEMBERTYPE_Methods_AcDbAssocArrayActionBody.html)。
- 拖动基点夹点的移动操作需要移动整个关联阵列，与重新指定基点是不同操作；应覆盖多个源、共享源、下游阵列、约束和锁层。参考：[AutoCAD Civil Engineering Applications，矩形阵列夹点](https://studylib.net/doc/27619960/intro-to-autocad-2025-textbook)。具体操作细节仍需与可用的视频和设备核对。
- 保持旧数组记录缺字段时的既有默认夹点和旧命令的严格 schema。不可把普通点简单实现成源首点的固定偏移，冒充关键点绑定。
- 源关键点以源草图及实体的稳定引用、点类型与索引标识；实体修改或拓扑变更后引用失效时显式拒绝，不能悄然绑定到其他顶点。普通基点坐标和工作平面之间的转换须覆盖非 XY 平面。

## 推进顺序

1. 明确点引用的解析、实体类型及无效引用行为，覆盖点、线、多段线、矩形、圆弧、圆和样条的可选关键点。
2. 在核心增加可重放的普通点或源关键点定义，验证源归属、坐标有效性、源修改及引用失效；确保更新间距、角度、数量时不丢失基点。
3. 为创建、修订、添加及调整基点引入新版本命令 schema；旧版本继续拒绝新字段，核对混合时间线、存档和重放。
4. 接入 ARRAYRECT 基点选项和已保存阵列的基点编辑、夹点显示及交互；预览隔离、取消、陈旧状态和失败不写历史。
5. 验证源修改、成员几何保持、不同工作平面、撤销重做和保存重开；对照已下载视频，记录视频未覆盖的行为并保留实机验收项。

## 下游阵列源是上游副本时的移动

上游成员现可保存相对于阵列网格的工作平面偏移；`drawing.array.move` v2 原子更新上游成员偏移、下游几何及所选阵列固定基点。源与其派生副本同时参与移动时不重复施加偏移。旧 v1 保留对上游副本源的拒绝行为。上游修改、保存重开及撤销重做已覆盖。`drawing.array.offset` 和窗口菜单支持成员位置偏移编辑及全部位置偏移重置；参考软件的完整重置还涉及擦除、旋转和替换覆盖，这些类型尚未实现，需继续核对并开发。
