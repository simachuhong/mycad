# U09 二维 SCALE

目标：按 [Autodesk SCALE 文档](https://help.autodesk.com/cloudhelp/2016/ENU/AutoCAD-Core/files/GUID-D4E17E51-5000-4AB6-8D6A-6D2AB4863C75.htm)支持选取、固定基点、正比例因子、Copy 和 Reference；保留草稿/已保存/混选事务、约束及存档历史。

1. [x] 先实现纯二维等比缩放，覆盖点、线、矩形、多段线（含弧段）、圆、弧和样条，保持身份、层与构造属性；无效/非有限因子和退化几何拒绝。
2. [ ] 明确草图约束、尺寸位置、跨草图相切及关联阵列的保护与求解边界，建立失败回滚探针。
3. [ ] 打通草稿、已保存和混选的预览、提交、取消、撤销重做、保存重开；新增命令历史只经既有 Bus 路径。
4. [ ] 命令栏增加 SCALE/SC、数值和点选基点与比例，接入 Copy/Reference；覆盖无效输入和连续状态。（基本命令、复制和参考长度已实现；继续核对完整交互。）
5. [ ] 对照录像中可见内容及官方文档验证，运行增量测试、静态与分层检查；真实设备及录像未覆盖项保持待验。
