# U09 多段线与其他图元的圆角

普通 FILLET 现支持同一多段线内的两段直线，尚不能处理多段线段与直线、圆、圆弧或另一多段线段。已保存来源通过 `committed_drag_trim_requested` 提交多来源替换和删除；同草稿和跨草图相切分别使用 `SketchGeometryReference(segment)` 与 `DraftTangentPair`。

1. 为多段线段与外部直线/圆/圆弧/多段线段建立相同几何候选，严格校验有限段上的切点和目标图层；不修剪时原对象保持、创建独立圆角，并按自动关系设置建立本地或跨草图相切。
2. 修剪时按拾取侧裁剪多段线，保留其余连续路径；涉及两条可连接路径时把线、圆角和多段线连接成可重放的路径，处理开放、闭合、起点/终点及反向选择。圆保持完整；不明确或无效路径不得静默修改。
3. 草稿、已保存及混合来源统一走原子候选，旧身份、约束和图层的变更明确验证；覆盖取消、锁层、来源失效、无解、撤销/重做和保存重开。先增量测试内核，再测试真实窗口。

参考：[Autodesk 关于线和多段线圆角](https://help.autodesk.com/view/ACDLT/2026/ENU/?caas=caas%2Fdocumentation%2FACD%2F2014%2FENU%2Ffiles%2FGUID-357499AE-7EF5-4228-BE9D-7FA6A8F11C27-htm.html)。本地录像不覆盖此组合；拾取和路径保留细节需参考软件及用户设备验收。


## 实施状态与剩余事项

多段线直线段与直线、圆、圆弧及其他多段线直线段的修剪和不修剪候选已实现，覆盖草稿、已保存及混合来源；不同路径连接时保留第一个多段线的身份。不修剪自动关系支持线段引用；内核提交时也校验这类推断相切。开放路径从拾取侧保留一支，另一断开的部分丢弃；录像未覆盖该选择语义，须人工对照。

圆角弧两端跨草图相切时来源圆半径联动此前因固定扫角被拒绝。新版本关系可记录圆角端点及修剪来源端点，求解时允许圆角扫角变化并保留有限曲线和相切分支校验；旧关系保持原有语义。完整组合、局部关系与参考软件行为仍须继续覆盖。
