# U09 独立二维交互命令行与环境整理计划

**边界：** 只作用于独立二维工作台；不能把底栏批处理 CLI 改名充数，也不能改普通尺寸/参数化尺寸的持久语义。对照 AutoCAD 2025 文档及用户截图；实机工作区、更新号和用户验收仍待核对。

1. 先建立二维交互命令栏的解析器和状态契约：支持明确的绝对坐标 `x,y`、相对坐标 `@dx,dy` 和相对极坐标 `@距离<角度`，拒绝无基点的相对输入、非有限数和格式错误，保持原草稿。为命令、别名、重复命令、取消、完成以及坐标输入编写独立测试。
2. 将命令栏接入现有 `SketchCanvas` 的真实 `set_tool`、坐标输入和完成/取消动作；按钮和键盘共享工作台状态，活动草稿守卫与锁定图层仍由画布执行。只公开已真正实现的命令，未支持项给明确提示；不能静默冒充完整 AutoCAD 命令。
3. 明确动态输入与命令行的焦点、Enter/空格、Esc、中文输入法和相对基点；测试从鼠标切换到键盘、图元完成后继续绘制、错误恢复和撤销/重开。
4. 按绘图、修改、图层、标注等整理现有入口，状态栏分别控制真实网格、栅格捕捉、正交和对象捕捉；极轴追踪等未实现项应明确标记。二维与零件、工程图的布局和状态隔离。
5. 单独验证普通与驱动尺寸、图层状态、保存重开和 DXF 报告；人工对照及用户接受另行留痕。

## 二维动态输入增量

先覆盖直线、矩形和圆：复用尺寸解析控件，鼠标预览和点击提交经同一解析路径；锁定尺寸错误时保留草稿并给出提示。显式命令坐标保持精确，不被捕捉或动态尺寸改写；切换工具、连续线和 Esc 需清理旧锁定。以真实画布点击、锁定尺寸、错误恢复、关闭动态输入和文档隔离作定向回归。其他工具与光标旁浮动样式留作后续扩展，不能宣称完整 AutoCAD 动态输入。

## 二维尺寸语义决定

沿用现有文档语义：新建标注初始为驱动尺寸，用户可显式切换为参考尺寸；同一编辑会话记住用户选择。驱动尺寸改值可能求解并改变几何，参考尺寸显示测量结果。旧档的 driving 属性及已有数值不作隐式迁移，也不把参考尺寸重新解释成独立 CAD 注释；AutoCAD 普通标注的完整等价行为仍待专项设计和参考核对。对应现有 `test_driving_dimensions.py` 与 `test_drafting_acceptance_round2.py` 作回归依据。
