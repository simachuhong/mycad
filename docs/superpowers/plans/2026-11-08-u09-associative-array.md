# U09 关联矩形阵列计划

目标：提供真正的独立二维关联阵列；源图元改变后，已有副本按固定行列偏移联动，保存、重放、撤销和重做一致。不能把仅带标签的独立副本称为关联。

1. 定义不依赖 CAD 后端的持久关系：阵列 id、工作平面、行列数和间距、源草图/图元引用、每个格位稳定的目标草图/图元引用。严格校验身份唯一、位置映射完整、范围与非退化间距，禁止副本作为本阵列或传递链中的源以产生环；依赖缺失与面不兼容明确拒绝。
2. 增加版本化 drawing.array.add/update/remove 命令及 drawing2d 白名单；阵列创建使用显式副本 id 和原子批事务，禁止重放时生成随机身份。旧存档和旧命令不变；移除关联只解除关系，几何保留。
3. 在统一草图修订路径里根据源变化计算受影响的副本快照，校验锁定/隐藏图层、草图约束及跨草图依赖；不能安全联动的依赖必须事务整体拒绝，不能部分修改。保护关联副本的直接编辑和删除，提供先移除关联的明确提示。
4. 将候选重放预览、创建、修改参数、解除关联、独立/关联切换接入 ARRAYRECT；不同来源和当前草稿共同参与时必须保证同一事务，不在预览阶段写入。
5. 覆盖约束、跨草图、源/副本删除、身份冲突、事务回滚、复制和编辑、保存重开、撤销/重做、旧版兼容及 DXF 几何导出边界；每一层先加 scoped 验证。真实软件视频未覆盖该功能，设备验收仍需人工执行。

## 行列数量编辑增量

- 修改数量必须在命令参数中携带完整的新成员身份映射；已有格位保留身份，新格位由界面生成一次并持久化，重放不得生成随机身份。
- 增加格位时生成目标图元；减少格位前检查被移除副本的局部约束、跨草图相切及下游阵列依赖，不能安全删除时整体拒绝。锁定/隐藏图层和跨平面规则与现有关联更新一致。
- 候选几何及关系网络通过完整校验后才走 Bus 提交，撤销/重做、保存重开保持一次事务；编辑窗口取消或文档过期不得写入。
