# U09 阵列单元额外替换图元

目标：替换集合大于单元原有副本数时，为额外图元保存稳定身份、来源与共同锚点；一次替换、撤销、重做、存档重开和重置均保持原副本身份。

设计草案：在阵列记录中增加逐单元额外输出记录，包含单元行列、替换来源引用、生成目标引用、共同锚点及基点偏移。每个额外输出参与全局依赖图和拓扑排序，坐标推导复用单元替换变换；目标身份不与其他图元或阵列成员冲突。原有副本仍按共同锚点替换，额外输出通过同一命令创建。重置前必须检查额外输出的约束、跨草图关系和下游引用；安全时删除额外输出并恢复原副本。数量缩减不能静默移除有依赖的输出。

1. [x] 编写记录序列化、非法身份、单元范围和循环依赖探针，新增纯数据模型，旧记录字节结构保持不变。
2. [x] 将额外输出纳入候选创建、全局拓扑传播、来源图层及只读约束检查；覆盖锚点、来源形状变化及下游依赖。
3. [x] 实现原子替换、删除与重置，覆盖冲突回滚、来源/目标身份及数量扩展。
4. [x] 对携带新记录的命令与草稿时间线进行版本化，验证旧版本拒绝、新版保存重开与撤销重做。
5. [x] 接入窗口数量选择和多来源输入，覆盖单源和多源窗口操作。
6. [ ] 扩大额外输出的跨草图、多层依赖及约束组合验证；混合草稿删除、数量缩减、下游引用和跨草图相切拒绝已有专项覆盖。
