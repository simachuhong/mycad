# U09 修剪围栏选项

1. 在二维 TRIM 命令中接受 F/Fence，收集两点以上的折线围栏；Enter/右键结束，Esc 回滚草稿和已保存对象预览。
2. 复用现有拖动修剪的原子候选和来源版本保护，仅在确认围栏点时采样每一段；保留既有显式边界和锁定保护，失败不能部分提交。
3. 覆盖草稿、已保存及混合对象，撤销、取消、失效和命令栏交互；确认旧拖动与单击不回归。
4. 记录与参考软件围栏行为的差异；二维 EXTEND 支持及 Project/Edge 等其余选项另行收口。

## EXTEND 围栏

采用同一条折线收集横穿的有限目标。对每个目标按围栏交点选择唯一较近端点，候选沿其已有方向延至所选边界；端点等距、无可延伸端点或延伸无解时保持原图并提示。草稿与已保存对象复用原子预览和撤销，重复采样不得对同一目标多次延伸；覆盖圆弧、多段线、锁定、来源变化、边界筛选及保存重开。
