# 二维 MIRROR 删除源对象确认增量计划

**目标：** 命令栏 `MI` / `MIRROR` 在指定镜像轴第二点后保留预览，询问是否删除源对象；默认 Enter / N 保留，Y 删除，Esc 取消。原参数面板及工具按钮行为保持现有可配置路径。

**依据：** [二维修改差异](../../design/2026-11-04-autocad-2d-modify-audit.md)及 [AutoCAD 2025 MIRROR](https://help.autodesk.com/cloudhelp/2025/ENG/AutoCAD-Core/files/GUID-595277C8-9B87-4CFB-A3AF-769537A22F3D.htm)。

1. 真实 Qt 测试草稿预选和命令先行：两点后文档和草稿不变、预览可见；N/Enter 保留源并添加副本，Y 替换源，Esc 不改变；非法输入可更正。分别验证来源修订变化、隐藏/锁定、轴退化、鼠标右键和未完成图元阻挡。
2. 在画布活动变换内保存待确认轴，复用现有镜像计算、过滤和草稿历史。命令栏与画布用同一确认状态，只有命令栏启动的 MIRROR 启用询问，现有面板按其复选框执行。确认前重新核对源修订和对象；失败不能写入。
3. 真实文档测试已保存/草稿混选的两种选择、源模型隔离、撤销/重做及保存重开；对受约束或锁定对象拒绝危险操作。验证相关静态检查及局部回归，明确文字镜像等剩余行为。

## 2026-11-06 进度

命令栏与画布的 Y/N、默认保留、右键、Esc、无效输入、命令先行/预选已实现；草稿及已保存混选的保留/删除源、撤销/重做、保存重开与来源失效有定向回归。图层或选择变化会拒绝旧候选，约束不允许删除源时不提交。参数面板原有偏好在命令结束后恢复。后续仍需文字及其他对象类型、真实 AutoCAD 行为与用户验收。
