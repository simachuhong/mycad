# 二维 GROUP / BLOCK 实施计划

目标：独立二维文档先交付 GROUP，再交付 BLOCK 和 DXF 联合交换。验收以本聊天中用户提供的完整《GROUP / BLOCK 剩余开发路线与 terra 实施交接》为准；本文件为可恢复的执行索引，不缩减该范围。

## 不变量

- GROUP 覆盖几何、文字、尺寸、公差、基准、图片、块实例；不接入关联阵列来源及成员。组选择按原始选择的一层成员扩展。
- BLOCK 定义仅含几何和文字；实例支持移动、复制、旋转、正等比缩放和删除。块内可捕捉但不提供持久关联。嵌套、属性、动态块、镜像、非等比及外部块库不在首期。
- 所有变更经 Command Bus；复合操作以 `drawing.objects.batch@1` 单条 v8 命令记录，子命令版本固定、白名单校验、不嵌套；重开后仍一次撤销。新身份事先生成并记录。
- 草稿相关操作在同一隔离时间线暂存；源文档未提交前不变化，撤销/重做/取消恢复完整对象状态。
- DXF 用原生 GROUP、BLOCK/INSERT；基准和尺寸专用处理优先。无法完整导入的块整体拒绝并报告；图片缺失及不完整组明确报告。
- 仅按改动运行增量测试；不重复运行未受影响且已通过的测试。保留当前未提交的公差工作区。

## 顺序与验收出口

1. G0：不可变组/引用、目录验证、一对多成员映射和完整组复制；定向领域测试。
2. G1：组状态和命令、二维文档门控、受限持久复合命令、重放和优化重建；跨对象失败回滚及保存重开后一次撤销。
3. G2：草稿与已提交对象的暂存、候选提交、逐步撤销和取消；A+B 编组、移动、复制、取消/重开的场景。
4. G3：GROUP / UNGROUP / GROUPEDIT、按钮和命令栏、异类选择、整体操作及锁层保护。
5. B0：块值对象与确定性展开；比例、方向、字体、图层和身份测试。
6. B1：BLOCK / INSERT、实例显示选择捕捉、依赖保护及组内实例操作。
7. B2：隔离 BEDIT / BSAVE / BCLOSE、EXPLODE、版本化剪贴板与身份重映射。
8. X0：DXF 对象/handle 映射，原生组和块交换、重复导入和损失报告；编写人工验收清单及样图。

跨项验收：已提交 A＋草稿 B → GROUP → COPY → BLOCK → INSERT → 编辑共享定义 → EXPLODE → 逐步撤销/重做 → 完成草稿 → 保存重开 → 再次逐步撤销/重做；取消草稿分支应恢复原文档。

## 代码入口

`core/drawing_groups.py`、`core/bus.py`、`geom/kernel.py`、`app.py`、`ui/sketch_editor.py`、`ui/main_window.py`、`ui/drawing2d_command_bar.py`、`ui/drawing_clipboard.py`、`formats/providers/dxf_provider.py`。新增具体模块与单项验收详见本聊天用户提供的完整计划。

## 必须保留的实施细节

- 二维组独立于三维 `NamedGroup`。成员引用包含对象类型、稳定 ID 和必要的草图 ID；支持多组重叠、不允许嵌套。扩展选择只从用户的原始选择出发一次，不能将扩展结果重新作为种子；编辑或解散重叠组要明确目标。关闭组选择后可独立编辑，成员删除或确定的身份替换同步维护引用，空组删除。
- `DrawingCollectionState` 管理组、块定义、块实例；对象目录由当前视图构造，不另行持久化。块定义保存以基点为原点的几何和文字、不携带求解约束或嵌套引用；实例保存位置、角度、正比例及图层。展开仅用于显示、拾取、捕捉和输出，派生身份由实例和定义成员决定。
- 复合命令只允许本工作包所需的二维内置子命令，固定子命令版本和参数，禁止嵌套、插件、三维或外部副作用；子命令保留原有校验，父命令是唯一历史和审计记录。普通重放执行父事务一次；优化重建正确处理子操作，不重复执行或跳过。候选、安装、reset、回滚和重建都必须覆盖全部集合状态。
- 同一暂存时间线保存草稿、组、块、相关文字、图片、标注和确定的身份映射。每次用户动作保留步骤；保存前按依赖构造隔离候选，经授权一次提交；撤销、重做、取消、失败和文档切换恢复完整状态。源文档不得引用草稿，读界面使用合并视图。尚未接入暂存的写入必须事先拒绝，不能先改文档再依靠检查点补救。
- 整体操作先验证所有成员的图层可见、未冻结、未锁定且操作受支持，避免附着标注既自动跟随又重复变换。完整复制才创建新组和新对象，部分复制不加入原组。普通编辑只能按确定映射继承组关系，不确定时清理并报告。
- `BLOCK` 默认转为块，也可保留源对象；同向共面来源先转到统一图纸坐标再减基点。转换遇到尺寸、约束、公差附着或阵列依赖须整体拒绝；组内来源只有组归属一致时才能用实例替换。手工创建、改名的名称冲突拒绝。
- 块实例的整体拾取、可见包围盒、捕捉、适应窗口和输出共用确定性展开；内部关键点只返回坐标，不能成为块外持久约束/标注引用。文字高度与框宽随比例变化，0 层继承实例层，权限考虑实例层与成员有效层。分解生成新的实体及曲线点 ID，保留定义并替换组引用。
- `BEDIT` 需要隔离本地会话、独立撤销、几何文字工具以及非主文档写入回调；`BSAVE` 校验版本和受影响图层后一次更新全部实例，失败保留编辑内容。`BCLOSE` 支持保存、放弃、取消；已有草稿时先完成或取消。剪贴板版本化携带对象、完整组、定义、实例与样式，允许没有普通草图几何；跨文档按身份及内容复用或重映射并确定性改名。
- DXF 复用原生 `BLOCK/INSERT/GROUP`；通用几何文字写入器须支持 modelspace 与块 layout。导出记录对象到全部 handle，导入记录 handle 到对象及结构化对象所需完整集合；只恢复完整唯一的组映射。尺寸匿名块和公差基准专用 INSERT 优先由原流程识别。外部原生内容优先于旧元数据，不支持块整体拒绝并列出原因，重复导入重映射且冲突名称确定性改名。图片延续未导出提示并报告组不完整，空组不输出，预览读取实际输出字节。
- 不以类型、命令注册或少量测试代替功能完成。每项只运行相关测试及直接受影响项，使用 `uv run --no-sync`；通过后记录命令和结果，不重复未受影响项。最终还需操作说明、支持矩阵、样图和 AutoCAD 2023/2025 人工验收清单；公差仍待人工验收。
