# U10 关联模型投影视图 Implementation Plan

**Goal:** 独立工程图关联零件后能够真实放置并更新模型投影视图，不修改源模型。

**Architecture:** 保持各文档独立内核与现有 `reference.attach` 命令，工程图工作台按文档种类和关联后的实际实体判断来源可用性；沿用已有投影工作进程、引用校验与命令总线。普通二维草图不因为含有上下文实体而自动获得工程图投影权限。

**Tech Stack:** PySide6、现有 CommandBus、隔离重放与 OpenCascade 投影适配。

**Spec:** `docs/design/2026-11-04-unified-ui-todo.md` U10、`docs/design/2026-11-04-unified-ui-design.md`。

## 约束

- 禁止直接修改来源文档和几何；工程图引用及视图写入沿现有命令总线。
- 没有关联或关联失效时明确提示；不根据文件名猜测来源。
- 静态参考和自动测试不代替 ST10 实机及用户验收。

## 实施

- [x] 以独立零件 + 独立工程图的真实会话，验证空图纸、关联模型、可生成投影与源文档不变；先运行观察失败。
- [x] 修正工作台的文档种类、来源状态和提示；保留旧零件文档内工程图的兼容行为。
- [x] 验证模型变更、引用更新、视图刷新、保存重开与来源丢失的状态；任何尚不支持之处明确记录。
- [x] 按改动范围运行类型、格式和相关 GUI/内核测试，记录结果及待验收项。
- [x] 在独立工程图空页面提供可见的来源选择按钮，复用文档菜单的真实选择与关联流程；以实际窗口和后续投影链验证可见性及绑定。

## 图纸切换守卫

- [x] 为跨图纸点击编写回归：未提交视图或文字、标注时保持活动图纸和草稿，提示用户完成或取消；同图纸内选择不误阻止。
- [x] 在 `DrawingWorkbench._select_tree_sheet` 统一判断目标图纸和活动操作，保留输入并恢复树选择；外部删除/撤销图纸仍走既有强制失效流程。
- [x] 验证取消后切换，以及普通图纸和视图设置仅修改目标；运行工程图视图、文字和标注 scoped 回归。

## 未确认视图操作的出图守卫

- [x] 对移动预览和待确认删除分别验证出图入口拒绝，Esc 后恢复出图；沿用现有错误提示，不修改持久模型。

## 视图预览生命周期

- [x] 移动或删除预览存在时，出图、保存和关闭单文档窗口要求先完成或取消。
- [x] 多文档会话把后台工程图的视图预览列入待处理项；退出对话框包含该文档，取消预览后恢复干净状态。
