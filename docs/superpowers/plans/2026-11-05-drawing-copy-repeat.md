# 二维 COPY 连续放置计划

目标：独立二维工作区的 COPY 以同一组选中源及基点连续生成多个副本，Enter、右键或 Esc 结束，已放置副本保留；每次放置可分别撤销。

1. 用真实窗口测试已保存与草稿混选、两次放置、基点和源身份稳定、结束、撤销/重做及保存重开；先确认当前单次结束导致失败。
2. 保留独立二维 COPY 的活动状态和原选择，单次放置使用已有草稿历史；零位移和取消保持源几何。
3. 覆盖命令栏坐标、空 Enter 结束、右键及 Esc；数值单次复制和零件草图现有行为保持原契约。
4. 更新受影响的单次复制测试和操作审计，运行二维草稿、命令栏、窗口生命周期及代码质量 scoped 检查。

追加增量：命令内 U 已接入，回退当前 COPY 已放置的最后一个副本，并恢复相对坐标基点；检查草稿历史边界，拒绝越过其他修改。

首点作为位移已接入：首次目标点提示时回车采用首点作为位移，零位移保留命令等待有效输入。依据 [AutoCAD 2025 COPY 文档](https://help.autodesk.com/cloudhelp/2025/ENU/AutoCAD-Core/files/GUID-1CF9287F-06E8-4D03-8377-2E130862FE02.htm)。COPYMODE 选项另行实现，自动测试不代替 AutoCAD 人工对照。

当前进展与测试范围见 [U09 证据](../../../.omo/evidence/ui-redesign/u09-progress.md)。
