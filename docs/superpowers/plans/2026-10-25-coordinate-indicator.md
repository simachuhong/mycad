# 坐标方向显示修复

用户指出坐标系看起来只有一根纵线，作为 P2 G 中途质量反馈继续处理。

## 诊断与选择

复现：空视口默认相机距离 10，旧 GLAxisItem 固定轴长 50，端点越界且无轴标签，细线在浅背景下不易辨认。原始截图 `/tmp/mycad-axes-before.png`。不能据此断言与用户当前窗口完全相同。

采用既有 Qt 绘图和当前 GL 相机矩阵，替换旧无标签世界轴；角落保持固定逻辑像素的 XYZ 指示器，颜色为红/绿/蓝，箭头与字母同时区分。正视某轴时用圆点（朝向观察者）/叉（背向）呈现，避免零长度线消失。现有坐标菜单控制真正世界原点的屏幕标记；角落方向标不冒充原点。叠加层鼠标穿透，不修改文档，不影响拾取/撤销。支持明暗主题和高 DPI。

备选：仅加粗旧世界轴仍会越界/遮挡；增加外部导航组件会引入不必要依赖。因此复用 Qt/pyqtgraph 的相机与绘制能力。

参考 Autodesk 官方 UCSICON：图标表达方向，原点不可见时可置于左下角。这里保留常驻角落方向标及独立可选原点标记，不宣称完整 UCS 编辑功能。
