# U09 OFFSETGAPTYPE 实施计划

依据 [Autodesk OFFSETGAPTYPE](https://help.autodesk.com/cloudhelp/2022/ENU/AutoCAD-LT/files/GUID-EB2A74E1-E6C8-4690-9658-7F731AB7FD84.htm)：0 延长、1 用偏移距离为半径圆角、2 到原顶点的垂距等于偏移距离的倒角。仅对产生间隙的外侧角应用，内侧角仍修剪交点。

1. 对开放、闭合、顺逆方向、内外侧、锐钝角和凹凸混合写几何验证；包含结果段方向、相切、半径、倒角垂距、相邻角的收缩与自交拒绝。保留模式 0 的既有结果。
2. 扩展核心偏移参数：以真实圆弧 bulge 表达圆角；倒角求与原顶点等距的切线与两条偏移线的交点。复用已有弧线精确相交检测，不能只检测弦；含圆弧来源不支持时必须明确拒绝，不能静默回退。
3. 将模式传给交互和数值入口、通过点判定和预览；支持系统变量输入、无效值与取消，按官方文档作为持久设置共享。验证混合草稿/已保存来源、撤销重做、存档重开和图层保护。
4. 分路径运行核心与窗口测试、类型/格式/lint；更新差异与人工验收记录。参考视频未展示此设置，真实软件与设备核对仍待执行。

## 后续：非平滑圆弧接头

- 对每条线段/圆弧先计算其有向偏移，按接头切向判断外侧间隙还是内侧相交；内侧交点须限制在可解释的有限分支并拒绝等距歧义。
- 圆角连接用原接点为圆心、偏移距离为半径，同时校验两端切线方向；倒角使用距原接点等距的切线与偏移支撑曲线求交，明确筛选有限段或可延长分支。
- 校验所有保留段不反转、弧扫角不改变方向且小于整圆；复用真实线/圆弧相交检测拒绝跨段自交，避免只按顶点或弦判断。
- 覆盖线弧、弧线、弧弧、正反法向、优弧、开放/闭合、连续偏移、通过点及失败回滚；在覆盖完成前对非平滑弧接头继续报明确错误。
