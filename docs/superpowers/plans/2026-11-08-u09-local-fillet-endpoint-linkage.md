# U09 同草图圆角端点联动

## 已确认的问题

同一草图的直线、圆与圆角弧带两条推断相切及直线端点重合时，将圆半径从 2 改为 2.5，PlaneGCS 固定圆角扫角，有限弧残差校验返回 2e-7 并拒绝。草图原样保留。跨草图已有显式端点连接和可变扫角实现，不应将旧的普通相切自动解释为端点连接。

## 实施步骤

1. 为本地相切增加明确、可序列化的端点语义，限制有效端点和引用类型，保持旧映射及旧版本命令 schema 不变；为创建草图、单草图修订、批量修订和约束添加/修改识别必要的新版本。建立映射、旧版拒绝与新版本接受测试。
2. 圆角自动推断只对新建圆角写入端点信息；当来源的实际端点与圆角端点重合时一并表达连接，普通用户相切及旧存档保持原语义。验证直线、多段线直线段、圆和圆弧，以及自动推断关闭时的行为。
3. 本地 `solve_sketch_constraint` 将明确的端点关系映射到已有端点求解绑定：按需放开圆弧扫角，加入稳定的方向与端点重合方程，同时校验有限曲线、相切分支、弧方向和已有局部约束。不将临时求解方程写入存档。
4. 先验证失败复现变为正确联动，随后覆盖固定约束冲突回滚、两种扫角方向、多段线弧、混合本地与跨草图关系，以及完成草图、修改尺寸、撤销重做和保存重开的真实窗口路径。


## 本轮实施

本地相切支持可选的显式端点字段，新增 sketch.create v13、sketch.revise v4、drawing.sketch.revise v8/v9、drawing.tangency.add v5、sketch.constraint.add v5 和 sketch.constraint.update v3；旧 schema 不接受新字段。圆角推断关系写入对应端点，普通相切保持原语义；尺寸求解和拖动复用跨草图端点约束及可变扫角绑定。重放带端点关系的约束编辑时重新验证有限几何与端点，篡改解被拒绝。已覆盖局部与跨草图混合、两种弧方向、直线/多段线段来源、冲突回滚、真实窗口预览及保存重开；更多复杂约束组合及参考软件人工对照仍待验收。
