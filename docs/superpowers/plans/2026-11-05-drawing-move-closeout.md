# 二维移动及编辑命令收口计划

**目标：** 跨草图与草稿混选移动保持原子性、可撤销和可重放；验证 MOVE 并更新其他编辑命令的对照。

**约束：** 保留现有工作区变更；文档修改只经命令总线；不丢失草稿、约束、图层及审计信息；不将模拟参考当成 AutoCAD 实机验收。

1. 用真实 GUI 测试复现跨已提交草图及与草稿混选时无法移动；覆盖一键撤销/重做及失败不变。
2. 实现跨草图和草稿的原子移动，设计可持久化的单次文档事务及草稿历史边界；覆盖保存重开、约束失败、锁层和坐标系。
3. 检查 MOVE 命令先行、预选、坐标、捕捉、确认及取消；补充端到端回归。
4. 基于当前代码及 Autodesk 参考更新其他编辑命令差异和缺项，明确部分实现与未实机核对。
5. 增量验证后按项目要求最终运行 ruff、format、basedpyright 和 pytest；记录实际结果及剩余差异。

- 后续分组中一组 184 项通过；一组 240 项通过、1 项 OpenGL 环境跳过、5 项失败，其中孔阵列异步预览测试已修复并复测通过；另一组 165 项通过、1 项 OpenGL 环境跳过、5 项失败，其中三项阵列历史预览等待已修复并复测通过。剩余六项旧零件草图完整流程测试需要迁移，未删除或跳过；不能宣称全量测试通过。

后续复核：上述六项旧零件草图流程已迁移到当前嵌入式工作台。支架圆角/倒角、法兰、轴、槽板以及提交失败后重试继续核对几何、撤销和存档；重复建模命令退出后再打开存档。原法兰测试使用的二维环形阵列不属于零件草图功能，已另以独立二维界面测试检查四实例、图元身份和撤销。两个流程文件加该二维测试在 Xvfb/xcb、软件 OpenGL 下共 10 项通过；三份测试文件的 Ruff、格式及 basedpyright 检查通过。投影性能目标及尚未完成的全量集成和人工验收不受此结果替代。

性能复核：独立运行 900 边投影测试为 5.339 秒，仍超过 3 秒门槛；无其他测试同时运行。另在当前进程对同一组输入做诊断测量，三个视图分别约 0.685、1.812、1.790 秒，总计 4.348 秒（不包括测试的跨进程传输，不能与正式测试数值等同）。Python 侧采样显示曲线长度计算调用较多，但尚未证明它是主要瓶颈；未修改实现或放宽阈值。

进一步的计时探针在另一运行中测得总计 8.153 秒，其中 OCCT 隐藏线 `Hide` 约 3.025 秒、`Update` 约 1.372 秒，曲线键计算累计约 1.607 秒；探针本身有开销，且运行间耗时明显波动。后续优化须保留可见性、精确曲线和来源关联，并以正式独立基准及投影语义测试共同验证。

后续代码优化：直线和圆弧长度筛选使用解析长度，接近阈值及其他曲线回退到原 OCCT 长度，单条边复用曲线适配器；投影、来源关联、验收和工作进程复用组合 23 项通过，改动文件 Ruff、格式和 basedpyright 通过。独立性能测试在实现的不同修订上分别为 3.606、4.272 和 5.386 秒，均高于 3 秒，且波动使收益无法可靠量化；最后一次 5.386 秒对应当前代码。性能门仍未通过，不改变阈值。
