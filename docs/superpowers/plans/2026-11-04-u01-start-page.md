# U01 启动首页与文档生命周期 Implementation Plan

> **For agentic workers:** 采用 superpowers:executing-plans；先逐项验证，保留当前工作区已有改动。

**Goal:** 冷启动显示四类入口，经真实会话创建或打开文档；返回首页和关闭文档保留现有守卫。

**Architecture:** `StartPage` 只呈现入口并发出文档种类与打开请求；`MainWindow` 负责会话守卫和切换，`DocumentSession` 继续拥有文档。启动入口不隐式创建文档；最近记录和模板取消须经独立测试确定。

**Tech Stack:** PySide6、现有 DocumentSession、QSettings、pytest-qt。

**Spec:** `docs/design/2026-11-04-unified-ui-design.md` §3；`docs/design/2026-11-04-unified-ui-todo.md` U01。

## Global Constraints

- U00 的 ST10 和 AutoCAD 参考核对未完成，继续记录缺口，不阻止不依赖参考的工程实现。
- 三个可用入口实际创建 `sketch`、`drawing`、`part`；装配不可创建。
- 不绕过活动命令、保存和文档身份守卫；模板取消不能创建文档。
- 零件、二维图、工程图和首页保持独立；不改 schema 或几何后端。
- 保留现有未提交工作，验证与提交仅限本包路径。

## Review Focus

- 用户取消模板或选择器：会话和脏状态不变。
- 当前零件草图有未提交图元：新建或切换不能丢草稿。
- 打开不存在/损坏文件：当前文档及首页状态不被覆盖。
- 最后一份文档关闭：守卫成功后回首页，取消则保留文档。
- 多个同名或过期最近记录：按路径和真实类型定位、移除或解释失败。
