# 二维 ROTATE 命令参考角增量计划

**目标：** 在已有预选/命令先行、旋转中心及相对角度流程中，增加 `R` / `REFERENCE` 的参考角与最终绝对角度输入，沿用现有候选与已保存对象修订路径。

**依据：** [二维命令差异审查](../../design/2026-11-04-autocad-2d-modify-audit.md)及 [AutoCAD 2025 参考旋转说明](https://help.autodesk.com/cloudhelp/2025/ENU/AutoCAD-DidYouKnow/files/GUID-D988658E-0A92-4353-B614-6C30CF6281A2.htm)。目标绝对角减去参考角作为实际旋转量；该增量先覆盖数值角度，不声称已支持任意两点参考线或 Copy 选项。

1. 写真实 Qt 命令栏测试：预选及命令先行，`RO`→中心→`R`→参考角→目标角，验证非零参考角、负角、超过 360°，最终坐标、源身份、预览前不写历史、撤销与取消；输入非法、非有限、空值及对象/文档失效时保留草稿并允许恢复。
2. 状态存于画布当前旋转操作，避免工具栏与命令栏拥有不同参考角。提供明确的参考角设置和目标绝对角应用接口，转换为既有相对角 `apply_rotation_angle`；鼠标目标复用同一参考方向。切换工具、取消、文档修订变动及结束时清空临时状态。
3. 测试已保存对象和草稿混选的候选提交、事务撤销/重做与保存重开；R 切换不能污染已有参考旋转复选框的行为。运行命令栏、旋转交互、已保存选择和相关路径 lint/格式/严格类型检查，更新 U09 对照差异。

## 2026-11-06 进度

已接入命令栏及画布的 R、数值参考角和目标绝对角；原有中心到单点参考方向也能配合数值目标。已验证重复 R、非法数值、下一次旋转的参考偏好恢复、草稿与已保存对象混选的撤销/重做和保存重开。任意两点参考线、Copy、所有输入选项与用户参考验收仍待完成。


## 2026-11-07 增量

命令 R 支持以任意两点定义参考线；两点重合时保留操作并允许更正，数值参考角和原单点后数值目标路径保留。C/COPY 可先于 R 选择，复制草稿或已保存对象后旋转新身份，不改来源。命令栏、画布键盘、重做、混选及保存重开已有定向测试；完整参考软件选项与人工验收未完成。
