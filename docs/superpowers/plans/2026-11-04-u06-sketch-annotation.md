# U06 零件草图尺寸与关系实施计划

**目标：** 在零件草图画布上显示、拾取和编辑实际尺寸及关系，复用现有求解与候选事务；驱动、参考和冲突状态可区分。

**依据：** 统一 UI todo U06、设计 §5.3、ST10-S08/S12/S13。草图和独立二维属于不同工作台；不能把独立二维完成情况计入零件草图。

**已知能力：** `SketchConstraint` 含稳定约束/图元引用、尺寸类型、单位、数值、驱动标志和可选放置位置；`SketchConstraintDialog` 可预览新增/修订，`PartSketchWorkbench.accept_constraint` 维护草稿与候选；视口现有草图尺寸标签主要来自已提交模型，活动草稿仅显示部分关系符号。编辑失败必须保留草稿及最后有效模型。

## 1. 草稿尺寸和关系可见

- [ ] 先编写草稿中驱动/参考尺寸可见、随求解预览更新和取消回滚的测试，覆盖长度、距离、角度、半径及直径；显示位置与稳定约束身份绑定，不以名称或行号猜测。
- [ ] 使用 UI 层的投影和已有草图图元/约束数据产生画布几何及文本；复用现有视口叠加层，缩放、旋转及草图结束时正确刷新和清理，不从 UI 导入 CAD 后端。
- [ ] 对不可解析/缺失引用明确反馈或不显示，不能用假数值冒充尺寸。尺寸位置优先使用已持久的 `text_position_mm`/`position_mm`。

## 2. 画布拾取、放置与修改

- [ ] 按稳定身份测试尺寸/关系的拾取、重叠候选与清晰的选中反馈；标注拾取不能替代几何选择或吞掉背景事件。
- [ ] 从选中图元创建尺寸，指定放置位置后使用既有求解候选；直接修改已选尺寸时预填并保留原约束身份，驱动与参考分明，参考尺寸只测量。
- [ ] 对关系提供可定位选择及删除，删除和尺寸修订纳入零件草图本地撤销/重做；关联提交只走原有 Bus 与候选链。

## 3. 冲突及完整验证

- [ ] 求解冲突显示受影响关系和图元并允许修正；失败保留最后有效草稿和下游模型。覆盖有序修改、下游预览、接受、撤销与存档重开。
- [ ] 运行 scoped UI、几何关联约束、分层及缩放测试；记录当前源码哈希和逐项证据。真实 ST10、物理 GPU 和用户验收未完成时保持待核对。
