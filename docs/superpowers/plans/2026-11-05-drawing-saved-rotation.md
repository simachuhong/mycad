# 已保存二维图元旋转实施计划

> 采用执行计划与测试驱动开发，复用当前工作区和隔离候选机制。

目标：支持对可见已保存图元和草稿混选旋转，并保持预览、原子提交、草稿与文档撤销、保存重开及工作平面坐标正确。

1. 在 `tests/ui/test_saved_drawing_selection.py` 先加入已保存图元画布旋转、数值旋转和混选旋转测试，确认现有限制导致测试失败。
2. 在 `sketch_editor.py` 的画布变换中支持已保存图元旋转预览，确认时发送选中 ID、工作平面中心和角度；继续拒绝锁定图层与失效约束。
3. 在 `main_window.py` 复用移动的隔离候选及混合草稿暂存时间线，以各草图自己的工作平面换算中心；保证批量旋转、撤销重做与过期保护。
4. 验证取消、相对参考角、不同原点、失败回滚、保存重开、约束和既有移动/复制；完成局部 lint、类型及分层检查。

镜像和 AutoCAD 全部命令选项另行实施，不以本项代替最终用户验收。

当前进展：旋转入口、混选暂存与原点换算已实现；自动回归及仍待验收事项见 [U09 证据](../../../.omo/evidence/ui-redesign/u09-progress.md)。
