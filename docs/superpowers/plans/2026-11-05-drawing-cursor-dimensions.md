# 二维光标旁尺寸提示实施计划

> **For agentic workers:** Use superpowers:executing-plans and verify the scoped tests after implementation.

目标：在独立二维的直线、矩形和圆绘制过程中，将现有动态尺寸状态同步显示在光标附近。提供只读提示，实际输入和锁定仍由现有尺寸控件完成；不声称已支持 AutoCAD 光标旁键入或全部动态输入语义。

- [x] 以真实鼠标测试验证：绘图起点之后出现提示并跟随鼠标；显示与锁定尺寸一致；禁用动态输入、取消或完成后隐藏；提示不拦截画布点击。
- [x] 以一个不接收鼠标事件的画布子控件展示现有尺寸字段的值与锁定状态；在画布边缘约束位置，且不能引入第二套几何解析或文档写入路径。
- [x] 回归尺寸输入、命令行、缩放及原有鼠标交互，运行所修改文件的 Ruff、格式、basedpyright 和相关 scoped pytest；将局限与视频参考区别记入 U09 证据。
