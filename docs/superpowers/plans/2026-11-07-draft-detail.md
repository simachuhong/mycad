# Draft 圆形局部详图开发计划

**参考：** ST10 Draft 01 号录像约 09:10–09:30 的局部圈选、详图和放置状态，见 `.omo/evidence/ui-redesign/st10-draft-video-reference/observations.md`。后续需要细化单击顺序、比例默认值及边界样式，不以单张截图推定细节。

**首期目标：** 选择已更新的模型投影视图，在父视图局部模型坐标中定义圆心和半径，放置独立比例的放大视图；来源或父视图变化后重新裁剪，未完成操作可取消。

**核心约束：** 圆区域、父视图身份、放置点、比例和标识作为可重放命令数据；只显示真实父视图几何在圆内的部分，保留原有可见/隐藏线类别。对直线、圆弧、椭圆及有理样条使用可验证的精确裁剪；不支持或存在歧义时报告诊断，不以丢曲线或折线近似冒充完成。裁剪产生的端点不能自动视为来源模型的端点；可关联几何需要保留明确的原始引用和裁剪参数。

**实施顺序：**

1. 建立与父视图和投影代次关联的圆形范围定义；校验半径、源类型及无循环依赖，保持旧命令读取。
2. 在几何适配层裁剪投影结果，保留精确曲线、可见性、源几何引用及可判断的裁剪信息；失败时保留旧结果并阻止出图。
3. 增加来源圈线、详图边界、标识和比例到共享纸面场景，保持画布、PDF、DXF 坐标一致。
4. 接入选父视图、圆心、半径与位置的草稿，保障取消、视图切换、来源变化、提交、撤销与重做。
5. 专项核对相切、边界重合、孔洞、多个曲线段、隐藏线、椭圆/样条、标注引用、保存重开和导出；保持用户实机验收独立。

**当前状态：** 已开始圆形范围数据、直线和圆弧解析裁剪及父投影裁剪的内部实现，并增加视图命令编码、带范围的后台投影缓存键、来源/详图圆和标识，以及圆心、半径和放置位置的交互草稿；默认比例相对父视图 2:1，可在放置前调整放大倍数。完整保留的曲线可沿用原始来源引用，截断曲线暂不建立关联。椭圆和非周期样条增加 OCCT 交点参数裁剪，对相切或重合的模糊情况拒绝；穿越边界的周期样条拒绝。详图场景在行为验证前被出图守卫拒绝；尚未做几何、交互、持久化或输出行为验证，功能标为开发中。
