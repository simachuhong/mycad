# Draft 等轴测视图实现计划

**目标：** 在工程图已有正投影之外，允许将来源实体的等轴测视图放到当前图纸。

**依据：** `01` 号 ST10 Draft 视频 06:30 的视图向导及 07:10 的三视图和立体视图，见 `.omo/evidence/ui-redesign/st10-draft-video-reference/observations.md`。

**设计：** 使用已有 `ViewBasis` 和 `drawing.view.create` 持久化独立视图，观察方向为全局 `(1, -1, 1)`、竖直向上为 `+Z`。等轴测视图单独放置，不从该斜向基准派生正投影视图；已有草图及六个正投影方向保持原行为。视图继续使用现有投影、撤销、更新、标注和输出路径。

**步骤：**

1. 在 `drawing_tools.py` 定义等轴测基和仅单视图放置选项。
2. 在 `drawing_workbench.py` 增加方向入口、画布放置提示和视图树名称，并避免不必要的派生投影。
3. 检查相关文件格式、静态类型和差异；行为验证、存档重放与 ST10 实机对照单独记录，未执行不得标为通过。

**边界：** 一次选择三视图加等轴测视图的布局向导、剖视、详图及人工验收均为后续工作。

**后续增量：** 正投影放置时可选“同时放置等轴测视图”；基准视图之后沿水平/垂直方向放正投影、沿对角方向放独立等轴测视图，所有视图作为一个命令组提交。各视图仍按既有源更新机制处理；预置布局向导尚未实现。
