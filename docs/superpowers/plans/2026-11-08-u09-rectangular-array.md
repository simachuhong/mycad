# U09 二维矩形阵列

参考 [AutoCAD ARRAYRECT](https://help.autodesk.com/cloudhelp/2024/ENU/AutoCAD-Core/files/GUID-BB3DA888-0C3A-4C68-A3ED-E0E528781205.htm)：行列数包含源对象，行列间距可为负；本阶段创建独立二维副本，不声称关联阵列、三维层、夹点编辑或完整命令选项。

1. 核心实现独立矩形阵列：源对象保持不变，逐行逐列生成独立 id，沿工作平面 U/V 使用行列间距；单行或单列允许，但两者不能同时为 1；仅需要对应方向的非零有限间距。总位置和生成图元数有明确上限，非有限输入及重复来源拒绝。
2. 二维数值面板增行数、列数、U/V 间距与独立矩形阵列入口，原线性/环形阵列保留；复用草稿及已保存混选、图层/修订保护和单步撤销，结果走现有可重放草图事务。
3. 覆盖草稿、已保存/混选、锁层、失败回滚、保存重开与撤销重做；补充界面布局和交互验证。剩余关联、路径阵列及参考设备验收明确留待后续。

## 命令入口增量

- ARRAYRECT 进入对象选择，Enter 固定选择，再依次输入行数、列数及需要的行/列间距；支持命令先行与预选，Esc 取消。单行/单列跳过不需要的间距输入。
- 固定来源身份、草稿历史和文档修订；来源变化、锁层及非法值拒绝，失败保持几何与可修正的输入阶段。完成仍通过现有草稿事务，支持撤销、重做及重放。
- 该入口当前创建独立副本；关联、三维层数、动态夹点及官方其余选项明确未覆盖。
