# U09 阵列额外输出位置覆盖实施计划

**目标：** 让多图元替换产生的额外输出可单独设置、清除位置偏移，保持其来源、共同锚点、身份及下游关联。

**方案：** 为额外输出新增独立于替换基点的偏移值，零值沿用旧序列化形式；使用新版本的关联阵列偏移命令和承载该记录的命令，旧版本明确拒绝新字段。候选先重算完整关联网络并核验约束和跨草图相切，再通过 CommandBus 原子提交。

**约束：** 旧历史不改变；UI 不依赖几何后端；锁定或隐藏图层、依赖环、约束与相切冲突不得部分写入；变更必须支持撤销、重做和保存重开。

1. [x] 在核心测试中构造带额外输出的阵列，验证单独偏移、清除、下游传播、初始替换基点非零、锁层及约束冲突；先运行并确认失败。
2. [x] 修改 `core/associative_array.py` 的额外输出数据、序列化、期望几何和偏移事务，保留旧记录结构；运行核心范围测试。
3. [x] 版本化 `drawing.array.offset` 及所有承载新字段的创建、修订、增加、调整和替换命令；测试旧版本拒绝、隔离候选、保存重开与撤销重做。（v2/v25/v24/v13/v14/v7。）
4. [x] 接入已有阵列成员位置编辑入口，覆盖只选额外输出、普通成员与额外输出混选、取消及错误回滚；补充窗口测试。
5. [x] 验证跨草图、非零锚点、下游来源、局部约束、跨草图相切和缩减/重置，运行受影响路径的 lint、格式、类型、分层和测试，记录结果。
