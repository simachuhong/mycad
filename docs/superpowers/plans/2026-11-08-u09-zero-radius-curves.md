# U09 零半径圆角的曲线组合

依据 Autodesk 的 FILLET 说明，半径为零时将所选对象修剪或延伸至交点，不创建圆角弧；圆保持完整。当前仅两直线可用。

1. 覆盖直线与圆/圆弧、圆弧与圆弧/圆的可行交点、修剪、延伸、拾取侧、无交点和歧义；沿用两直线既有行为。
2. 候选根据拾取位置选择，失败不改变源对象；草稿、已保存和混合来源均复用现有原子修订路径，不创建相切关系。
3. 验证修剪选项、Shift 临时零半径、撤销重做、保存重开和来源变化保护；参考录像未覆盖，需设备验收。

参考：[Autodesk 2D Fillets](https://help.autodesk.com/cloudhelp/2023/ENU/AutoCAD-Core/files/GUID-696681C1-4B8B-4995-8903-CCE6686179EA.htm)。

已实现直线、圆及圆弧组合的零半径求交和画布交互；圆保持原样，无交点和歧义拒绝。已保存直线来源的单次提交、撤销重做和保存重开，以及混合草稿的逐步撤销重做均有窗口专项；草稿已有用户约束时会拒绝更改并保留原几何。真实设备行为仍需核对。
