# U09 拆分圆弧相切重绑定计划

**目标：** 多段线零半径闭合拆分圆弧后，唯一结果段完整包含原有有向圆弧时保留跨草图相切。

**设计：** 比较圆心、半径、方向与有向角度区间，要求旧弧完整落入唯一结果弧。使用 `drawing.sketch.revise` v36，v35 及更旧版本维持原规则；最终关系仍由有限弧、分支与端点校验。对拆分点落在旧弧内部或身份不唯一的情况拒绝猜测。UI、暂存时间线、命令总线与重放使用同一证明。

1. 核心实现唯一圆弧包含证明，覆盖方向、截短、不同圆和重复候选，旧规则默认不变。
2. 注册 v36，重放和普通二维提交显式门控；验证旧版本及篡改拒绝、相切有效、保存重开和撤销。
3. 将证明接入已提交关系的混合暂存与待提交关系，逐步历史选择正确版本；验证草稿撤销、关系身份与后续编辑。
4. 路径级测试、分层和静态检查，记录兼容性及真实设备验收状态。

**进展：** v36 与统一证明已接入已提交、混合暂存和待提交关系。窗口验证关系身份、旧 v35 与篡改拒绝、保存及撤销重做；反向草稿目标和连续混合历史也有定向覆盖。旧程序可能无法重放 v36；旧弧跨越拆分点或无法唯一归属时仍保守拒绝。
