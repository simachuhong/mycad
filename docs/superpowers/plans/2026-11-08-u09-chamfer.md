# U09 二维倒角

目标：二维工作区提供符合常用 AutoCAD 操作习惯的倒角，命令栏和按钮同用事务路径，支持草稿、已保存及混选对象；错误回滚并保留撤销与重放。

参考：[Autodesk CHAMFER](https://help.autodesk.com/cloudhelp/2024/ENU/AutoCAD-Core/files/GUID-B1DCF991-90A7-4DB0-96FC-BDA3FB76337C.htm)：两距离或距离加角度、修剪/不修剪、多段线、连续操作、零距离交角与 Shift 临时交角。二维项目当前支持线、多段线，不支持射线和构造线类型。

1. [x] 实现和验证两条有限直线倒角：按拾取侧确定方向、允许延长、双距离、距离加角度、零距离、层与退化拒绝。
2. [x] 接入按钮和 CHAMFER/CHA 命令、距离/角度、修剪、连续、取消和撤销；草稿与已保存/混选复用既有受保护候选和 Bus。
3. [x] 接入多段线及矩形整体、相邻段、相隔一段及开放路径首尾倒角，以及不同对象之间的直线段连接；歧义路径和会丢失外侧路径的拾取受保护。
4. [ ] 完成最终定向回归，记录约束、锁层、保存重开、撤销重做及参考视频和实际设备验收边界。
