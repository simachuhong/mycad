# U09 关联阵列成员擦除实施计划

**目标：** 删除单个关联阵列副本后保留其格位和身份，重置时从当前源恢复，并支持保存重开、撤销和重做。

**结构：** 在成员记录保存擦除时的草图位置；擦除时从草图移除对应图元，空缺不参与几何显示和再生，但身份仍被保留。重置先恢复该图元，再统一清除位置与旋转覆盖。源或阵列变化后按当前参数重建；恢复使用记录位置插入，多个空缺按原位置顺序恢复。源属于其他阵列的成员或已绑定约束、跨草图相切的副本不可擦除，避免悬空。禁止其他图元复用保留身份。

**边界：** 现有命令版本保持原 schema 和重放语义；新增版本携带擦除字段，操作由 Command Bus 和独立候选事务执行。对失去图层、草图、源和身份冲突明确拒绝。多源阵列按当前逐图元成员模型处理，不声称完整多图元阵列项等价。视频未覆盖的交互不能据此宣称参考软件验收通过。

1. 已实现数据往返、擦除与源更新后重置、顺序、约束和下游依赖保护；保留身份禁止被其他草图复用。
2. 已更新创建、修订、添加和缩放 schema 版本，新增擦除命令与重置新版；覆盖旧版拒绝、保存重开及回滚。
3. 已接入画布删除键及既有重置入口，覆盖撤销、数量调整和共享源；混合普通对象或不同阵列的批量删除尚需后续开发，视频与设备未覆盖的行为仍需验收。
