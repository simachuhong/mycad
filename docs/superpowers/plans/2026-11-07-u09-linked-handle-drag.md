# U09 已保存草图控制点联动拖动

目标：对已保存草图中的线、圆和圆弧控制点拖动时，将局部约束与跨草图相切分量一起预览和原子提交，保持现有草稿控制点交互及命令历史语义。

1. 在应用组合根提供隔离的拖动候选：用原草图和选中的稳定点引用求解局部拖动；把所有发生变化的目标草图图元作为固定编辑目标，再求解相切连通分量。校验图层、分支、有限切点、原有约束和所有草图基准；只产生可重放修订，不改文档。
2. 画布对已保存图元提供控制点拾取；映射工作平面坐标，在拖动期间绘制关联草图预览。保留上一个有效位置，Esc、无解、过期来源和文档切换都不能写历史；草稿及混合草稿路径保持独立状态。
3. 松开时通过现有候选与 Bus 原子提交一次，校验被接受的预览和会话；撤销、重做、保存、重开及下游特征重建必须保持一致。隐藏或锁定图层不可更改。
4. 按顺序覆盖线端点、圆心、圆弧端点、不同工作平面、局部约束联动和多个相切关系；再覆盖冲突、锁定、过期、取消及参考尺寸刷新，并用真实 Xorg/xcb 窗口运行专项。

现有画布 `_control_point_at` 仅枚举草稿图元；已保存图元可选择和命令式移动，但尚无控制点拖动路径。必须先为已保存图元建立隔离预览，避免直接改写背景或丢失暂存草稿。

进展：已保存线端点、圆心和圆弧端点已接入画布拾取、异步关联预览和松开后的原子提交；拖动中取消、快速松开和来源过期均有窗口覆盖。混合草稿中的已保存和草稿控制点共用异步关联预览，松开后写入暂存历史；支持单个及多个暂存相切关系、连续拖动和分步历史。独立画布无法联动时保留原几何和关系。实际 Xorg/xcb 的大小窗口及相关曲线专项已有自动验证；更多工作平面、约束组合和人工验收仍待完成。

接下来：补齐混合预览期间取消及来源变化、不同平面、锁定关联标注、失败重试和多步组合的窗口对抗验证，并继续处理 U09 的完整命令选项与参考对照。

窗口红灯探针：建立相切线和圆后，在画布上从线起点 `(-10, 0)` 拖至 `(-10, 1)`；当前因已保存对象不参与控制点拾取而不改变草图（15 秒超时）。探针已从正式测试文件移除，接入窗口路径时应作为回归测试恢复。
