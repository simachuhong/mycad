# U08 零件草图工具分步计划

**目标：** 按点、样条、修剪、延伸、偏移、镜像依次接入零件草图；逐项具备真实几何、状态、撤销、重放和受限组合的明确反馈。

1. 点：建立有稳定 ID 的中立点实体与版本化持久化契约；作为定位几何而非闭合截面边界，支持捕捉、拾取、精确坐标、删除/撤销及保存重开。审查二维、DXF、求解、快照和 CAD 适配器所有实体分派，不能让既有 `else` 将点误判为矩形或圆弧。新命令版本必须保留旧档语义；引用点的具体约束类型需先与求解器能力对应，未支持的明确拒绝。
2. 样条：复用现有控制点三次样条 DTO 和精确 BREP；提供多次选点、预览、Enter 完成、Esc 取消与控制点拾取。至少四点，样条与直线闭合后通过特征回归验证；不声称支持现有内核不支持的修剪或偏移。
3. 修改工具依次复用中立编辑算法，针对每个工具定义目标与边界、临时预览和取消事务，支持的图元组合由已有算法决定；每项覆盖保存重放和模型消费。
4. 每一项做增量分层、UI、模型与跨环境回归，记录自动证据；不因可见入口而提前标记通过。
