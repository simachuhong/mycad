# U09 阵列成员替换计划

目标：以可编辑的来源图元替换选定成员，指定新来源的定位基点，保留目标身份并在来源修改、阵列编辑、重置、存档和撤销时一致重算。

设计：每个成员可引用独立替换来源并记录相对该来源基准点的定位偏移；替换基点对齐到原源在该格位的基准点，既有位置和旋转覆盖继续应用。原源与替换源均进入依赖图；拒绝缺失、已擦除、异平面、循环及不安全约束，源/目标及图层冲突整笔回滚。当前模型按逐图元成员替换；多图元对象组仍需后续扩展。重置清除替换，恢复原来源。新 schema 和命令版本不改变已有历史。

1. 已实现核心数据往返、定位、源与下游变化、循环和重置；替换来源不能是同一阵列的副本，仍需扩展。
2. 已增加版本化创建、修订、数量、替换和重置命令；覆盖旧版本拒绝、存档及相切事务保护。
3. 已提供窗口选择目标、来源和基点的入口，覆盖取消、无效坐标、数量调整、重置与撤销；多图元替换及视频未展示的交互仍需继续。
