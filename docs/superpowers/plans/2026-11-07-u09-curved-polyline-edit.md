# U09 圆弧多段线与二维编辑命令

目标：圆角后多段线保留精确 bulge，修剪、延伸、分割和偏移不能把圆弧当作弦线，也不能因图中存在无关圆弧多段线而阻断其他对象的编辑。

1. 先接入精确边界：把多段线分解为直线和有限圆弧，在线、圆和圆弧与边界求交时保持原图元身份并跳过构造边界；无关目标可继续编辑。目标命中必须使用真实有限曲线，无法处理时明确拒绝。
2. 对多段线目标实现精确分段、修剪与延伸：按路径参数确定保留区间，重建端点及 bulge，处理开放、闭合、同顶点去重、圆弧顺逆向及边界歧义；保留图层与构造属性。
3. 实现等距偏移的直线、圆弧连接、内外侧与退化处理；歧义、自交及不可表示情形保持原图并给出提示。
4. 覆盖草稿、已保存与混合来源，撤销重做、保存重开、DXF 及下游轮廓；验证旧直线行为和分层。参考录屏未覆盖的候选取舍单列待验。
