# U09 多草图 DXF 输出计划

> **For agentic workers:** Execute incrementally with regression evidence; preserve the existing one-sketch API and document compatibility.

**目标：** 支持独立二维文档中多个草图的 DXF 输出，并明确报告 DXF 无法保留的跨草图关系和阵列关系。

**设计：** DXF 预览继续使用与最终文件一致的字节和报告。先修复单草图关联阵列的静默丢失提示；再以同一参考平面输出共面的多个草图，保留每个草图的 XDATA、图元和尺寸，拒绝不安全的冲突或非共面输入，避免静默投影。现有单草图导出 API 和旧数据语义保持兼容；多草图导入边界须明确报告。

1. 通过真实 Bus 创建阵列，验证导出几何及报告包含关联语义丢失提示，撤销关系后提示消失。
2. 分析各草图坐标系、图层冲突、XDATA 和尺寸表示；新增多草图输出、相切关系遗漏提示及可靠回归。
3. 检查预览和最终文件一致性、失败时目标文件保护、非共面与身份冲突，并记录实测边界。

## 实施记录

- 已覆盖共面草图的旋转与反向法向、实体几何、图层冲突、身份歧义和标注单位换算；同一来源的重复图元身份不会使标注误绑定。
- 已验证预览字节与最终写出的文件相同，以及窗口确认、取消和过期保护。
- MyCAD 重导入仍合并草图分组；关联阵列、跨草图相切及不支持的标注语义通过报告提示。旋转或反向草图的投影尺寸、坐标标注及反向角度尺寸保留为原生 DXF 标注，但 MyCAD 暂不恢复其关联。非共面草图与图层定义冲突会被拒绝。
