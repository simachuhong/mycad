# U09 多图元阵列单元替换

关联阵列目前按每个源图元和单元位置各保存一个成员。核心命令已可在一次事务提交多个成员替换，但窗口仅接受一个副本。先支持在同一个单元选择多个副本，逐个选择等数量的替换来源，并以共同基点提交一条替换命令；原副本身份、下游依赖、重置与版本兼容由现有模型保留。不同数量的替换图元需要额外身份和恢复模型，作为后续范围，不能混称已覆盖。

1. [x] 检查同单元多源映射、共同基点、来源变化与重置的核心及应用行为，先构造窗口失败探针。
2. [x] 加入多选成员入口：要求来自同一阵列、同一单元、可见且身份唯一；逐项选择替换图元及共同基点，一次性写入 CommandBus。
3. [ ] 扩大锁层、重复或循环依赖、保存重开、撤销重做和重置的组合验证。

共同锚点续进已实现：将共同锚点来源记录进替换数据并作为依赖参与排序、重放、锁层和删除保护。移动主/次源、跨草图坐标、旧版本拒绝、创建、重放与草稿重绑定已有验证；仍需扩大复杂依赖和界面边界覆盖。

下一阶段：支持原单元与替换集合数量不同时，必须为额外图元建立稳定身份并保留被替换原图元的恢复位置，和依赖、约束、数量调整、重置及存档一起设计，不能通过合并不同图元类型或直接删除历史绕过。

先实现替换数量少于原单元图元数：在同一个新版本替换命令中，把多余的原副本按现有擦除模型记录邻接身份，将其余副本绑定共同锚点替换来源；隔离候选必须同时通过来源、约束、锁层、相切和依赖校验，重置恢复全部原身份。替换数量多于原单元仍需额外输出身份模型，另行实现。
