# U09 二维命令覆盖实施计划

**目标：** 为已有二维绘图、标注和修改功能补齐可交互命令入口，保留已约定后置的六个命令边界。

**架构：** 盘点功能区与 `Drawing2DCommandBar` 映射；命令行复用同一个画布及标注控制器，坐标和选项直接进入相同事务与状态，不能将按钮点击冒充完整命令。记录命令和尚未覆盖选项，以用户实际反馈及 Autodesk 文档校验。

**技术：** PySide6、现有二维命令状态机、pytest-qt。按用户规则只运行每个改动直接涉及的测试，不重复不受影响的验证。

- [ ] 审计二维绘图、标注、修改入口及其现有命令/选项，区分缺失和已有但受限的流程。初始审计及后续变化见 [命令覆盖表](../../design/2026-11-15-u09-cli-coverage.md)；尚未逐项证明全部选项一致。
- [ ] 增加已支持的尺寸标注命令，并覆盖鼠标、命令行步骤、取消、撤销和默认尺寸语义。常用尺寸命令已接入；部分操作和更多组合仍需设备核验。
- [ ] 根据审计补齐已有绘图和修改工具的缺失 CLI 入口与必要选项，每类单独验证。POINT、POLYGON、SPLIT 等已接入；SPLIT 与所列 POLYGON 场景已有用户通过反馈，POINT 独立设备结论及更多选项仍待核验。
- [ ] 核对常用别名、命令重复、焦点、动态输入、跨图纸状态和历史；对不支持选项给出明确提示。
- [ ] 更新命令覆盖清单和设备复验步骤，按用户反馈处理问题。覆盖表已同步到 2026-11-16；最新扩展的设备验收和最终差异确认仍待反馈。

范围边界：STRETCH、BREAK、JOIN、EXPLODE、LENGTHEN 和路径阵列继续遵循用户 2026-11-11 的后续开发约定。不要将接口名称存在等同于完整 AutoCAD 兼容。
