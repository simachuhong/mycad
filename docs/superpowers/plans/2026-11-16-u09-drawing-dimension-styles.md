# U09 图纸级标注样式实施计划

> 使用 `superpowers:executing-plans` 逐项实施；测试范围遵守项目 AGENTS.md，每项仅运行直接相关的定向验证。

**目标：** 在当前本机格式预设之外，提供随独立二维图纸保存的命名样式；新建尺寸可关联样式，编辑样式时已关联尺寸同步更新精度和比例，撤销、保存重开及旧图纸回放可靠。保留文字覆盖和驱动值，不对旧尺寸隐式建立关联。

**设计边界：** 样式仅包含 MyCAD 已有的精度和比例；文字覆盖仍属于单个尺寸。不能把本机 QSettings 预设当作图纸样式。删除正在使用或当前样式应拒绝并说明原因。单个尺寸手动修改精度或比例时解除该尺寸样式关联，避免隐藏覆盖规则。已保存尺寸与草稿尺寸的同步和撤销必须一致；发生无法原子提交的操作时拒绝，不直接改写文档模型。

## 文件和步骤

- [ ] **领域契约：** 新建 `core/dimension_styles.py`，验证样式名称、精度、比例、唯一性和当前样式；在 `SketchConstraint` 添加可选样式引用，旧记录默认无关联。新增核心定向测试，先覆盖序列化、非法样式和旧记录不变。
- [ ] **命令与回放：** 在 `builtin_commands/specs.py` 新增图纸样式设置命令及带关联字段的尺寸记录新版本；在 `geom/kernel.py` 按图层设置模式原子应用样式并更新使用该样式的尺寸，处理 reset、候选复制、下游重建和撤销重放；`core/document_kinds.py` 限定独立二维文档。测试新建、修改、占用删除拒绝、两文档隔离、撤销重做、存档重开和失败原子性。
- [ ] **版本路由：** 扩展 `app.py`、`ui/main_window.py`、`ui/part_sketch_workbench.py` 的新增和修订路由，所有携带关联尺寸的操作采用合适的后续命令版本，保留既有图片、跨草图、关联阵列和局部坐标语义。定向测试普通尺寸、已有图元修改、混合草稿、跨草图及图片的保存重放；旧版本严格不接受新字段。
- [ ] **界面及事务：** 在 `ui/dimension_presets.py` 或独立对话框提供图纸样式列表、创建、应用、修改及删除；`DIMSTYLE` 清楚区分本机预设和当前图纸样式。通过 MainWindow 的 Bus 和既有执行单元提交，处理未完成草稿、并发与撤销同步；样式更新失败时不能更改任何草稿或已保存尺寸。创建、取消、更新、删除占用、单图尺寸脱离、切换图纸及重开分别定向验证。
- [ ] **交换及收口：** 明确 DXF 输出当前样式值及样式关联的交换语义，无法保留时写交换报告；覆盖文字、旋转方向及驱动值不受样式更新影响。经代码复审后请求用户设备复验，并更新 U09 收口证据。
