# Draft 直线剖视开发计划

**目标：** 从现有模型投影视图指定直线剖切，放置可关联更新的剖视，并将剖切线、标识和剖面线一致地显示及输出。

**依据：** 01 号 ST10 Draft 录像 07:40–08:30；技术分层及外部项目参考见 `docs/design/2026-11-07-draftwright-reference.md`。

**首期范围：** 单一实体来源、单段直线剖切、两侧观察方向；闭合截面与孔洞必须正确，无法可靠计算时返回诊断并阻止出图。阶梯剖、局部剖、装配材料分别排期。首期不把普通投影视图误标为剖视。

**架构：** 命令历史存储剖切定义和父视图身份；纯 core 保存剖线与观察方向并计算模型平面，geom 层基于 BREP 生成真实截面和可见投影，返回可序列化投影与剖面线；UI 管理选父视图、两点、方向、预览、确认及取消；共享场景服务画布、PDF 和 DXF。来源和几何定义都进入投影代次/缓存键，结果过期不得覆盖新视图。

## 实施顺序

1. 定义父视图局部坐标中的剖切线、观察侧和对应世界空间切割平面与视图基；拒绝无效点、零长度及无效观察侧。
2. 扩展工程图视图命令映射和回放，保留旧文档兼容，校验父视图、来源、图纸和删除依赖。
3. 在 geom 生成保留侧实体投影和真实截面剖面线；处理孔洞、空截面和失败诊断；避免错误复用普通投影缓存。
4. 实现从选中干净父视图到剖切线、选择方向与放置剖视的画布草稿，确认时经 Bus 写入；取消、来源更改与页面切换保留既有守卫。
5. 增加共享纸面剖切线、箭头、视图标识和填充输出；保持 PDF/DXF 与画布一致。
6. 分别核对静态检查、回放、视图更新、错误恢复、输出和 ST10 人工对照；未验证的项目留待验证。

## 当前进度

已有剖切线/切割平面数据结构、单实体保留侧及截面提取、剖面线裁剪和剖切实体投影入口；已增加命令对象编码、后台投影代次与缓存键、场景剖切线/箭头/标识和剖面线数据通道，并接入选择父视图、两点、位置、提交与取消的 UI 草稿。投影引用只尝试通过 HLR 历史匹配原始实体面，新生成切面不猜测来源；关联稳定性尚未验证。剖视场景在行为验证完成前被出图守卫拒绝。此功能标为开发中，尚未做行为验证；几何结果对孔洞、多实体、相切边界、标识排布及失败处理均须验证，不能仅凭静态检查判定正确。

新增视图字段为可选字段，现有无剖视命令的文档继续使用原有编码；包含该字段的新文档是否能被旧版程序读取未作兼容承诺。剖视失败保留旧投影并提示原因；多实体、草图来源和从剖视继续派生视图当前拒绝。
