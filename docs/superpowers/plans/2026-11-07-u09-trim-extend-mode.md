# U09 TRIM / EXTEND 快速与标准模式

依据 [AutoCAD 2025 TRIM](https://help.autodesk.com/cloudhelp/2025/ENU/AutoCAD-Core/files/GUID-B1A185EF-07C6-4C53-A76F-05ADE11F5C32.htm)，标准模式先选择边界，空选择表示全部；快速模式直接操作并使用全部边界。TRIMEXTENDMODE 在两种命令间共享并记忆。

1. 增加模式状态和 QSettings 偏好，支持命令内 Mode → Quick/Standard 及 TRIMEXTENDMODE 0/1，活动围栏、候选和无效输入保护。
2. 标准模式启动直接进入现有边界选择；切换模式时明确处理边界及未完成操作，保证预览和提交一致。
3. 验证保存重开、鼠标及命令操作、边界空选与取消、草稿/已保存来源和回滚；快速模式无法修剪对象的删除语义单独实现并以撤销验证，不将模式切换误称完整等效。

快速修剪删除语义：仅对明确命中的可编辑目标且几何求交确定无可修剪区段时删除；将“无有效交点”与歧义、锁定、失效、约束错误、重叠分离。草稿、已保存、混合与围栏均走原有原子候选和撤销；标准模式及零件草图保持原有保守行为。验证删除预览、单次撤销、保存重开和失败保护。
