# U09 阵列额外输出旋转覆盖实施计划

**目标：** 支持对关联阵列额外输出指定旋转角和相对共同锚点的旋转中心，保留位置覆盖、替换基点和下游依赖。

**方案：** 给额外输出添加与普通阵列成员同语义的旋转角及中心偏移，默认零值不改变旧记录；将字段纳入预期几何和依赖传播。新增版本承载字段并在旧旋转命令中拒绝额外输出，窗口沿用成员旋转入口，重置仍按既有替换语义移除额外输出。

**约束：** 旧历史行为不变；所有修改经 CommandBus；锁定或隐藏图层、局部约束、跨草图相切、循环依赖和非法角度均原子拒绝；支持保存重开及撤销重做。

1. [x] 先写核心失败探针：额外输出绕指定锚点旋转，与原始替换基点、位置偏移和下游阵列组合；验证清零、非法值及固定约束拒绝。
2. [x] 修改额外输出数据和拓扑重算，旧零值序列化不变；旧版本覆盖验证只允许显式授权字段变化。
3. [x] 版本化旋转命令及承载新字段的创建、修订、增加、调整、替换命令；旧版本拒绝，覆盖保存重开、撤销重做和旧命令重放。
4. [x] 接入窗口成员旋转入口并覆盖额外输出、取消、非法输入、坐标转换及冲突回滚。
5. [x] 覆盖跨草图、下游依赖、位置覆盖、重置、锁层和相切约束；运行路径级 lint、格式、类型、分层和测试并记录结果。
