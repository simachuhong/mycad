# DXF 重复导入身份处理实施计划

**目标：** 在同一图纸重复导入带曲线身份和形位标注的 DXF，保留内部关联并可撤销重放。

**方案：** 预览前对点身份冲突的曲线分配新图元与确定性点身份，同步重映射草图约束及公差几何附着；基准名称冲突时分配唯一名称，按基准对象 ID 更新同批次公差引用，并在预览报告列明。其他未关联的同名文本不推断关联。仍通过既有单次候选事务保存，失败不修改文档。

**约束：** 保留未冲突的身份及旧版重放语义；只运行各子项和直接影响的增量测试；不宣称第三方 CAD 或 GB/ISO 规则已验收。
