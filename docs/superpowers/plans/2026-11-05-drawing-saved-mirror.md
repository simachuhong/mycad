# 已保存二维图元镜像实施计划

目标：为可见已保存图元及草稿混选提供镜像；保留源对象时生成新身份副本，删除源对象时经候选重放更新原图元，支持撤销和保存重开。

1. 先添加画布及数值入口、保留/删除源对象、混选与保存重开的真实窗口失败测试。
2. 在画布中生成正确预览；保留源对象时只把镜像副本加入草稿，删除源对象时发送镜像轴至文档工作区，约束及锁定图层仍受保护。
3. 为已保存对象复用候选修订，为草稿与已保存对象混选复用暂存时间线；将镜像轴从当前工作平面换算到各草图坐标系。
4. 验证取消、退化轴、约束、不同原点、撤销与保存重开，运行影响范围内的 UI、应用层、分层和代码质量检查。

连续操作和命令行逐提示选项仍属后续工作，不将本项视为最终人工验收。

当前进展：镜像入口、混选及工作平面换算已实现，专项证据和未完成项见 [U09 进度](../../../.omo/evidence/ui-redesign/u09-progress.md)。
