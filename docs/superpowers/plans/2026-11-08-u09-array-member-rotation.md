# U09 阵列成员旋转覆盖实施计划

**目标：** 按指定中心旋转关联阵列的成员，覆盖与阵列依赖、位置偏移、保存、撤销和重置协同。

**设计：** 成员记录旋转角及相对于源图元基准点的旋转中心偏移（阵列坐标系）；先将源绕基准点加偏移旋转，再按格位和成员偏移平移到目标。这样网格变更和上游编辑可重算；零旋转使用旧记录形式。跨草图使用现有共面同轴转换。约束图元的非平移变化先保守拒绝，可证明保持约束的平移仍允许；跨草图相切使用现有事务保护。矩形可能转换为多段线，身份保持，涉及引用拓扑的变化由现有保护拒绝。

**约束：** 不改变旧命令的 schema 和重放语义；新命令经 Command Bus、事务和版本化 schema；无后端依赖进入 core；输入无效或关联冲突不写历史。参考视频尚未展示此功能，交互选择行为不作参考软件等价断言。

1. 已实现成员覆盖的往返、非有限输入、旋转几何、源编辑和下游重算。
2. 已增加新版本 schema、旋转及重置命令和自动选版；覆盖旧版本拒绝、新版本保存重开、撤销重做及跨草图相切冲突。
3. 已接入窗口成员旋转及重置，覆盖输入、取消、数量调整和撤销；仍需扩大不同图元、真实设备和约束组合的验收。
