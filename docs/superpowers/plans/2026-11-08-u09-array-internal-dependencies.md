# U09 阵列内部成员依赖计划

目标：允许以同一阵列的其他成员作为替换来源，按成员依赖顺序重算，并继续拒绝真实循环、擦除来源和悬空关系。

实现：在现有成员图中保留所有源依赖，按稳定拓扑顺序遍历同一阵列成员；阵列级依赖忽略自身所属的成员边。间距及新增数量操作采用相同顺序，保留现有身份、锁层、约束、下游及回放保护。对旧版无法表示的内部依赖，采用版本化命令和带版本的创建、修订、添加、数量调整 schema。

验证：已覆盖倒序成员依赖、源修改、旋转、间距及数量调整、循环和删除依赖来源的拒绝；新旧版本、混合时间线、撤销重做、保存重开及窗口入口均已验证。跨阵列粒度循环但图元无环的案例另行处理，不将其视为已完成。
