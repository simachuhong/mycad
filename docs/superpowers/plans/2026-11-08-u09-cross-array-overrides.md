# U09 跨阵列批量成员覆盖

**目标：** 不同关联阵列的普通成员及额外输出可混选，统一设置位置偏移或绕共同画布中心旋转，单次操作是一条可重放历史。

**方案：** 新增版本化二维命令接收按阵列分组的覆盖，核心在隔离快照上一次构造完整阵列网络并统一传播，几何层校验局部约束及跨草图相切后原子提交。窗口按稳定身份分组、逐目标草图转换共同中心；同一阵列继续沿用既有命令。

**保护：** 成员及阵列身份重复或缺失、锁定/隐藏层、循环依赖、固定/尺寸冲突和跨草图相切冲突均拒绝全部更改；确认取消、非法数值、保存重开、撤销重做均覆盖。

1. [x] 核心先写跨阵列偏移和旋转的失败探针，覆盖共享尺寸、上下游依赖、约束和事务回滚。
2. [x] 核心提供批量覆盖函数，一次重算完整网络并同步可平移标注；保持既有单阵列函数和旧版本行为。
3. [x] 增加独立二维命令及几何适配，验证 schema、单条历史、保存重开、撤销重做与错误回滚。
4. [x] 窗口按阵列分组支持混选与共同中心，验证普通/额外输出、不同原点、取消、非法输入及选择变化。
5. [x] 运行受影响核心、应用、注册、分层、窗口、lint、格式及类型检查，记录视频和设备验收边界。
