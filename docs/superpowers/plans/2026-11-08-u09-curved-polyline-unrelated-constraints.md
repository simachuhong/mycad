# U09 曲线多段线与无关约束

圆角后的多段线具有 bulge；当前约束求解和拖动因草图中存在任何 bulge 就整体拒绝。对未被任何新旧约束或拖动引用的曲线多段线，将其保留为不可变的求解外图元，并计入未锁定顶点与弧段的独立自由度；其余图元正常求解。直接引用曲线多段线的约束和拖动继续明确拒绝，不能把弧当作弦线。

验证驱动/参考尺寸、拖动、锁层、自由度、既有约束拒绝、原图元逐值不变，以及通过 Bus 提交、撤销、重做、保存重开；若重放契约不能安全承载则先处理该契约。

跨草图相切组件只投影相切、驱动约束与锚点实际引用的图元，其他图元保持原样；对曲线多段线的直接约束仍拒绝。若冻结修订包含 bulge，使用新增 `drawing.tangency.add` v2 schema，原 v1 与无版本调用继续保留原有语义；验证版本选择、旧 schema 拒绝新字段与新旧档重放。
