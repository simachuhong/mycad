# U09 修剪圆弧后的相切迁移计划

**目标：** 零半径闭合修剪圆弧时，若原相切点仍属于唯一结果弧，保留跨草图相切。

**规则：** 原和新弧同圆、方向一致；相切的另一有限曲线和双方工作平面不变；原相切与候选相切均成立，且恰有一个候选。端点与分支由既有重放校验。相切点落在多个结果段、相切点被裁掉、另一曲线发生变化或几何不唯一时拒绝。新规则只在 `drawing.sketch.revise` v37 启用，保持 v36 及旧版本重放不变。

1. 在 core 提取带另一有限曲线的唯一候选证明，验证正反方向、相切点移除、拆分点歧义及不同圆拒绝。
2. 普通窗口与混合暂存按最小必要版本重绑定；几何重放对 v37 独立校验同一证明，保持命令总线事务。
3. 补充已提交、混合与待提交关系的窗口行为、篡改拒绝、保存重开及撤销重做；局部用户约束继续遵守原规则。
4. 执行改动路径的定向验证和静态检查，更新限制及旧版兼容说明。

**进展：** v37 已接入已提交、混合暂存及待提交关系；旧 v36 和篡改数据被拒绝。两种来源方向、保存重开与撤销重做通过。相切点位于多个候选弧、原相切点被移除或另一来源变化时不推断归属；真实设备和参考软件验收仍待完成。
