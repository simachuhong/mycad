# U09 倒角角度初始值

新建二维图纸的 CHAMFERD 初始值改为 0，符合 Autodesk 文档；现有 v3–v7 图纸继续按 45 重放。圆角及倒角参数仍由命令历史修改，撤销应恢复各图纸的初始值。

既有 v7 图纸已经仅保存圆角基线，不能把缺失角度解释为新值。采用新的存档版本保存两个明确的初始值；对旧版本默认角度为 45，升级后保留该值。另一种在旧存档中插入可撤销设置命令会改变历史与撤销语义，因此不采用。旧版程序可能无法读取新存档，须更新兼容说明。

执行顺序：

1. 先新增定向失败测试：新图、旧 v3–v7、首次设置及撤销重做、保存重开、复制、关联更新和候选事务。
2. 为新存档添加严格验证与只读基线，贯通文档构造、重放、临时内核和引用升级；保留旧版本语义及原子回滚。
3. 更新二维界面参数初始化和版本检查，验证角度 0 的查询、设置及命令交互。
4. 按路径执行测试、Ruff、格式与类型检查，更新验收证据和格式兼容说明；真实设备及最终集成另行验收。

参考：[Autodesk CHAMFERD](https://help.autodesk.com/cloudhelp/2021/ENU/AutoCAD-Core/files/GUID-19EB0506-005C-491A-B2E6-AF12890A3786.htm)。

进展：v8 已接入文档、重放、候选、复制、引用及二维窗口；旧 v3–v7 初始角度保持 45，新图纸为 0。关联和旧格式、参数持久化及窗口入口已有定向验证；进一步的复杂约束组合、最终集成和真实设备验收仍待完成。
