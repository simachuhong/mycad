# U09 修剪/延伸命令内撤销

1. 仅登记当前 TRIM/EXTEND 会话实际成功的草稿或混合操作，并核对历史位置，U/Undo 不得回退命令开始前的编辑或越过外部历史变更。
2. 已保存图元的直接修订记录文档命令身份，命令内撤销须验证来源会话、最新命令身份及异步状态；失败时保持对象并提示。
3. 覆盖单击、围栏、连续操作、混合历史、外部修订、取消及旧快捷键；确保命令仍可继续操作，未执行的动作不能撤销。

2026-11-07 核对 [AutoCAD 2025 TRIM 官方说明](https://help.autodesk.com/cloudhelp/2025/ENU/AutoCAD-Core/files/GUID-B1A185EF-07C6-4C53-A76F-05ADE11F5C32.htm)：标准模式的 Undo 回退该命令最近一次修改；快速模式、Crossing、Project、Edge、Erase 等仍需独立实现或核对，快速模式的不可修剪对象删除行为尚未实现。所下载参考视频未覆盖这些选项。
