# U07 草图区域与特征衔接实施计划

**目标：** 使用同一套精确轮廓候选驱动画布填充、拾取及拉伸/旋转；保持现有草图引用和旧文件行为。

**现状与约束：** `make_sketch_faces` 已依据精确 BREP 检查闭环、自交、内孔和嵌套区域；旧的草图截面仅含 `sketch_id`，拉伸消费全部区域、旋转要求单一区域。当前没有可持久化的区域引用，不能用画面排序或面索引猜测身份。草稿无效时需保留原模型；UI 不得导入几何后端。

1. 先为后端轮廓分析建立中立区域结果：每个区域使用外边界的稳定图元身份，包含内孔、绘制网格和精确拾取所需信息；复用现有校验和构造线排除。用带孔、多个区域、嵌套、开口和自交测试证明候选与实际特征面一致；失效或身份歧义应显式拒绝。
2. 扩展草图截面契约，允许可选稳定区域引用；未带引用的旧命令保持原行为。按身份精确选面，覆盖重放、草图修改、候选失败、保存重开及撤销；避免顺序索引与隐式替代。
3. 将中立候选用于视口的填充、悬停和选择，同一候选驱动命中与显示；验证孔内不可选、重叠遮挡、旋转缩放及资源清理。
4. 接入零件草图结束后的区域到拉伸、旋转工作流；在未确认草稿和来源改变时按现有候选/Bus 守卫处理，验证取消、回编辑和下游更新。
5. 执行 scoped 几何、拾取、交互、分层和高 DPI 测试，记录限制；物理 GPU、ST10 和用户验收单独待核对。
