# 二维 COPY 阵列选项增量计划

**目标：** 在现有 COPY 基点后的 `A` / `Array` 中输入总数量，并用目标点指定步距或使用 Fit 指定总位移；支持草稿、已保存和混选，复用现有线性阵列算法。

**依据：** [AutoCAD 2025 COPY](https://help.autodesk.com/cloudhelp/2025/ENU/AutoCAD-Core/files/GUID-1CF9287F-06E8-4D03-8377-2E130862FE02.htm)：数量包括原始选择；普通方式目标点指定单步位移，Fit 方式目标点指定最后副本位移。

1. 使用真实命令栏测试 `CO`→选择→基点→`A`→数量→目标点及 `F` Fit；验证数量包含源、普通与 Fit 坐标、源身份、单步撤销、取消、无效数量/距离与连续复制模式。新选项未完成时不能改变草稿或历史。
2. 画布维护当前 COPY 的阵列阶段、数量、Fit 和当前选择，预览及确认共用 `linear_array_entities` 的结果；仅从可见未锁定的草稿和已保存来源生成副本。新选项结束时恢复原 COPY 偏好，任何修订/选择/草稿变化失效。

**进展（2026-11-06）：** 已实现步距和 Fit、混选、预览、整组撤销与来源失效保护；COPY Array 专项 7 项、二维编辑组合 212 项和已保存图元相关组合 14 项通过，修改路径 Ruff、格式与 basedpyright 通过。人工参考对照仍待进行。
3. 已保存与草稿混选验证数量、坐标、身份、失败回滚、保存重开及撤销/重做；运行 scoped 二维命令、草图和分层检查。确认与 AutoCAD 的重复、Undo 等未核对差异，不将部分选项冒称完整。
