# U09 标注选择、删除与右键

目标：点击普通或驱动尺寸可选中，Delete 删除并支持撤销；已保存尺寸经可重放事务处理。标注完成后右键与 Enter 一致，输入驱动值时确认而不丢弃。

1. [x] 定向验证 Enter 与右键结束标注和确认驱动值，保留 Esc 取消。
2. [x] 点选尺寸及 Ctrl/Shift 加减选，保留拖动和双击编辑；验证草稿删除、锁层和撤销重做。
3. [x] 已保存尺寸和普通图元可通过 Command Bus 原子删除；覆盖多个已保存草图、锁层拒绝及单步撤销。
4. [ ] 草稿/已保存混选、依赖标注的锁定与隐藏保护及 ERASE 已覆盖；跨草图相切图元与标注混删已支持，关联阵列普通成员、额外输出及成员本身标注的混删已接入。下游阵列来源、非标注约束和复杂依赖组合继续受保护，更多组合及设备验收仍需检查。
