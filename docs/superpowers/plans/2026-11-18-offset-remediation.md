# OFFSET 整改实施计划

**目标：** 基于现有 OFFSET，对齐 AutoCAD 常用交互并逐步支持复杂轮廓和样条偏置。
**约束：** core/UI 不引 CAD 后端；文档写入走 Bus；保存重放、撤销和图层约束保持一致；逐项增量验证。

1. [x] 统一绘图工具栏 OFFSET 入口，保留数值偏移能力与现有命令状态机；Qt 交互测试覆盖无预选和已有选择。
2. [x] 建立复杂偏移几何试验：用锁定 OCCT 验证凹多段线收缩、分裂及开口/闭合与连接模式；定义多输出、失败原子性、方向及误差契约，再接入 geom 接口及 UI 预览/提交。
3. [x] 明确样条偏移数据表示、曲线误差和持久化/DXF 往返，按需版本化数据契约；接入拾取、通过点、预览与原子保存。
4. [x] 对各子任务只跑对应单项和直接关联项；记录未解决的外部 AutoCAD 实机比对和 OpenGL 环境限制。

验收依据：工具栏未选和预选场景见 `tests/ui/test_drawing2d_command_bar.py`；复杂路径和几何方向见 `tests/geom/test_drawing_offset_backend.py`，预览、分裂、撤销和往返见 `tests/ui/test_offset_multiloop.py`；样条误差和分支见 `tests/geom/test_offset_spline.py`，交互、预览、撤销及往返见 `tests/ui/test_offset_spline.py`。各次增量验证和失败处置见 `.omo/start-work/ledger.jsonl` 中 `offset-remediation` 记录。AutoCAD 实机对照未执行；在无有效 OpenGL 上下文的环境中，涉及三维视口的设备测试不能视作通过，偏置草图的离屏测试不能代替该验证。

进度：多段线分裂结果已接入二维工具栏距离、通过点、预览、整体撤销、存档和 DXF；开放和闭合的直线及圆弧轮廓已覆盖常见三种转角。已验证删除已保存源对象后多结果的保存、重开与单次撤销/重做。开放样条偏置采用有界误差拟合，输出多个独立片段；可确定方向的开放和闭合分支分开保留。连续偏置将相连样条片段构成完整路径后再计算，分支分别处理，已验证通过点、删除已保存源对象及分步撤销；退化或方向无法判断的情况仍会拒绝。已修复后端回退的身份校验以及圆角和倒角连接的通过点。椭圆弧创建入口已接入；尚需真实 AutoCAD 对照。

椭圆实施顺序：先定义完整椭圆和椭圆弧的中立参数、旋向、退化检查及版本化映射，保证旧命令 schema 不变；再接通草图命令版本、渲染拾取、DXF ELLIPSE 导入导出与保存重放；最后在 geom 层使用精确椭圆构造 OCCT 偏置，并以可验证误差的可持久化曲线结果承载，覆盖闭合/开放、两侧、通过点、失效和撤销。投影视图已有的 `EllipseCurve` 不能直接作为草图实体，现有草图消费者存在按矩形或圆弧兜底的分支，新增类型前必须逐一处理，避免静默误绘或丢数据。

椭圆进度：中立参数 DTO 和 OCCT 偏置转换已验证正反方向、顺逆椭圆弧、闭合轮廓和 0.001 mm 采样距离；向内达到所选椭圆弧最小曲率半径时会拒绝退化结果。椭圆已加入版本化草图图元，支持画布显示拾取、命令或鼠标创建完整椭圆、原生 DXF 交换、保存重放、距离/通过点/连续 OFFSET 和撤销。椭圆弧可通过工具栏或 ELLIPSE 的 A 选项绘制，支持顺逆方向、鼠标及数值角度输入，也可通过 DXF 导入；椭圆约束及控制点编辑暂不支持。

椭圆支持精确平移、旋转、镜像、缩放和复制；原生 DXF 交换通过 MyCAD XDATA 保留顺逆方向和完整椭圆的参数接缝，非 XY 平面和不支持的法向会拒绝。需继续验证其他草图命令与椭圆共存，以及真实 AutoCAD 对照。
