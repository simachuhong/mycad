# 拉伸方向手柄实施计划

> 按用户本轮直接实施要求，在当前工作区顺序执行；沿用已确认的 Solid Edge 操作基线。采用 writing-plans 技能记录执行步骤。

**目标：** 拉伸选面后显示沿精确外法向的手柄，支持鼠标推拉和动态距离输入，预览期间保持选面与导航。

**架构：** geom 通过 app 返回中性面坐标；独立 UI 操纵器管理投影、手柄绘制、距离输入和局部手势；视口路由鼠标，主窗继续通过草稿、隔离预览与 Bus 提交。参数条与动态框共用同一距离。

**技术：** PySide6/QPainter、现有 pyqtgraph 投影和 build123d 面查询。不增加依赖。

**规格：** docs/design/solid-edge-interaction-acceptance.md 与本轮用户要求。

## 交互决定

- 单击箭头开始随动，再单击定距；按住箭头拖动、松开也可定距。
- 普通左键保持面拾取。中键旋转、Shift+中键平移、滚轮缩放不改距离；结束导航后重新计算推拉基点。
- 单个紧凑尺寸框输入有符号 mm；直接数字/D 进入编辑；Enter 接受尺寸并返回视口，不写模型；Esc 先取消当前输入/推拉，再次 Esc 取消命令。
- 短右键在推拉时只定距；定距后短右键提交最新有效预览。提交时锁住手柄和输入。
- 手柄投影过短（正视法向）时禁用鼠标推拉，提示旋转或输入距离，不能暗自改用全局轴或屏幕垂直轴。
- 输入框优先避开模型投影包围矩形；无空间则调用已有顶部距离字段，避免扩大弹窗。
- 鼠标距离即时反馈，几何预览按节流采样且队列只保留最新需求；过期预览不可确认，切面/退出后不能恢复旧手柄。

## 步骤

- [x] geom/app：提供选中平面的精确中心与单位外法向；保持命令与存档格式不变。
- [x] ui/extrude_manipulator.py：实现沿轴投影距离、屏幕手柄、紧凑输入与手势状态。
- [x] viewport：路由手柄事件、保留点击位置，导航后重置移动基点；退出/提交清理状态。
- [x] main_window/modeling_toolbar：同步距离和输入有效性，节流最新预览，支持面来源及显式 XY 截面来源。
- [x] 静态 lint/类型检查、检查差异，更新人工验收说明与日志，运行程序交用户人工测试。本轮不新增或运行自动测试。

## 重点人工场景

顶面/底面/侧面/斜面；正负距离跨零；俯视导致轴投影退化；推拉途中中键旋转和缩放；快速变值与慢几何；预览换面；输入 '-' 等中间文本；Enter/右键两阶段确认；Esc 还原；取消/切换来源/提交后清理；窄视口和无空白区的尺寸框位置。
