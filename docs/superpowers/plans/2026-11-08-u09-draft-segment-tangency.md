# U09 草稿多段线段跨草图相切

草稿与已保存来源的待提交相切端点支持图元或具体段；旧 ID 对和历史保持兼容。段引用进入草稿撤销历史和混合编辑事务，冻结求解结果经 Bus 原子提交。新增版本保存段引用，旧 schema 不变；来源变更、锁层、取消或不满足有限相切时不能部分写入。

1. 扩展中立端点类型、确定性关系 ID 和草图创建/混合修订版本，验证新旧 schema、两种草稿方向、保存重开和撤销重做。
2. 接入草稿历史、待提交关系裁剪、混合拖动和来源变换，保持既有 ID 对、同草图约束与跨草图相切。
3. 扩展相切对话框，允许选择当前草稿及已保存对象；先隔离预览、确认后纳入草稿历史，不提前写文档，覆盖取消、失效与多步撤销。
4. 增量运行求解、命令版本、UI 和分层检查并记录视频与设备验收范围。
