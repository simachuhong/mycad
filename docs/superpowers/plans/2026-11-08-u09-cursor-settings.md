# U09 二维光标与系统设置

目标：独立二维画布默认短十字，系统设置可切换为贯穿画布的十字线；选择持久化并应用于当前及后续二维画布。

方案：二维画布隐藏原生指针，在原始鼠标屏幕位置绘制十字；鼠标离开清除，保持捕捉、命令、动态输入与其他工作区语义。系统设置对话框含中文选项与确定/取消，使用现有 QSettings，错误配置回退短十字。

1. [x] 定向测试十字位置、两种长度、离开画布、二维范围及操作指针同步。
2. [x] 绘制可切换的二维光标，不改变几何坐标或鼠标事件。
3. [x] 增加设置对话框、持久化及当前编辑器更新，测试确认、取消和重建。
4. [x] 定向运行 UI 测试、Ruff、格式和类型检查；记录设备与人工验收边界。
