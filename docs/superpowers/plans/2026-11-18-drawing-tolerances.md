# 二维尺寸和形位公差实施计划

**目标：** 在独立二维图纸中提供结构化尺寸公差、公差框和基准标识，支持交互、历史和 DXF 交换。

**依据：** `docs/design/2026-11-18-drawing-tolerances-technical-route.md`；GB/ISO 优先，不实现几何合格判定。

**约束：** 沿用现有未提交的文字字体工作区；全部模型写入经 Bus；仅运行受改动影响的定向测试；不改变旧命令版本的含义；缺乏外部 CAD 样本时不声称互操作验收通过。

### 外部基准名称修改的安全恢复

对 MyCAD 导出并保留完整元数据的共享布局基准，仅当图形块唯一文字从单个大写字母改成另一个大写字母、其余签名全部不变、原名称与元数据一致且文字可放入原框时，恢复修改后的可编辑基准，保留原框尺寸并明确提示文字重新排版。公差框原有引用标签不被猜测性改写；名称不匹配时解除关联并提示。多文字、几何变化、样式变化、框太小或元数据冲突继续降级为普通图元。定向覆盖第三方修改、引用降级、保存重开、冲突与正常自往返；不据此声称任意第三方块编辑均可恢复。

外部基准名称修改增量：对保留 MyCAD 元数据的共享布局基准，只有单文字大写字母改名、其余图形及外观未变、原名称与元数据一致且新名称适合原框时恢复可编辑基准；保留框尺寸并提示重新排版，原公差框的旧标签解除关联并提示。几何、文字数目、颜色、隐藏状态、元数据冲突、过宽文字及不支持的名称继续降级；英寸换算、界面导入、撤销重做和保存重开已按子项自检。外部 CAD 实际操作和其他块编辑仍需验收。

外部基准改名扩展：在相同图形、外观、元数据及原框校验前提下，支持普通多字符和 Unicode 名称；原本为保留 `%`、`^` 等字面字符而分段的文字可以保留未修改片段并修改其他普通片段。每段必须落在原框内且不与下一段重叠；新增或修改的 DXF 控制码仍不能猜测，异常时降级。旧引用不按名称自动改写。上述单字母限制是前一增量的历史记录，不是当前范围。

DXF 默认颜色修正：MyCAD 默认图层色此前同时导出 ACI 7 与深灰真彩色，外部 CAD 优先使用真彩色，在深色背景下基准和公差框几乎不可见。默认色现在导出为无真彩色的 ACI 7，外部未指定真彩色的 ACI 7 导入为 MyCAD 自适应默认色；其他自定义真彩色原样保留，显式真白也不被转换。默认及自定义图层、隐藏锁定冻结、CADCraft 另存的公差与基准关联有定向测试；CADCraft 0.20.1 隔离 GUI 修复前后截图已核对，真实桌面及 AutoCAD 仍待验收。
