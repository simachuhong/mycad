# U09 矩形阵列数量夹点

参考 [Autodesk 矩形阵列操作说明](https://help.autodesk.com/cloudhelp/2022/ENU/AutoCAD-Core/files/GUID-181BF535-D6F4-4B90-B04D-EB99C5488DAB.htm)，数量夹点沿行列轴改变格位数。先实现二维投影及项目容量校验，再接入可区分的画布命中、稳定副本身份、预览及 `drawing.array.resize` 事务；覆盖约束、锁层、下游关系、撤销重做和重开。

单行或单列首次启用另一轴时，如旧记录未设置该轴间距，暂以已启用轴间距的绝对值作为新轴步距；参考软件的单轴夹点细节需实机核对。超过项目容量时拒绝、清除无效预览并保留原图元。
