# U09 OFFSET 选项

依据 Autodesk OFFSET 命令说明：距离或通过点、Erase、Layer 以及对象选取后的 Multiple、Undo。先补齐 Layer 的来源/当前层选择，保持同一文档的交互设置；预览与提交使用同一目标层，锁定或隐藏的实际目标层不得写入。随后处理命令内连续偏移和撤销，确保与已有草稿、已保存来源及混合事务的历史一致。

1. 用真实命令栏和窗口测试 L → Current/Source、默认值、无效输入、当前层变化、锁层、草稿与已保存来源、预览/提交及撤销重做。
2. 命令状态显式维护 Layer 选项并在编辑器延续；修改偏移候选和目标层检查，保留 Bus 与来源约束保护。
3. 对照文档实现 Multiple 与 Undo 状态，验证重复对象、通过点、删除源、取消、历史边界及跨版本隔离。
4. 运行针对性静态、几何和 Qt 回归；记录视频未覆盖及设备验收。

## 补充：距离默认值

- 参照 Autodesk OFFSETDIST 的初始通过点语义，OFFSET 初始提示 Enter 使用通过点；输入距离或 T 后，同文档后续命令的 Enter 沿用上次距离或通过点。
- 保留两点量距过程与取消保护；编辑器重建继承当前会话选择。系统变量命令及跨文档行为单独核实，不写入文档存档。
- 先覆盖默认值、距离、通过点及编辑器重建，再实现并跑针对性验证。

## 补充：OFFSETDIST 会话变量

- 独立命令读取和设置有限实数：负值代表通过点，非负值为默认距离；0 可存储，但实际偏移仍拒绝零距离并提示重新输入。
- 主窗口运行期共享默认值，切换文档及同文档编辑器重建时同步；不写入图纸或持久设置，重启窗口恢复初始 -1。
- 空输入保持现值、无效值重试、Esc 取消；活动手势中不改变设置。先验证单窗口命令、跨文档同步及重启默认值。
