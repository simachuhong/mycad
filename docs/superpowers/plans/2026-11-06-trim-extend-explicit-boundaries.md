# 二维修剪/延伸显式边界实施计划

**目标：** 在已有自动边界的修剪/延伸之外，提供选择一组边界后再操作目标的标准流程；同一组边界用于预览、单击与拖动，支持草稿和已保存图元。

**依据：** [统一 UI TODO](../../design/2026-11-04-unified-ui-todo.md)、[AutoCAD 二维审查](../../design/2026-11-04-autocad-2d-modify-audit.md)，以及 Autodesk [AutoCAD 2025 TRIM 命令说明](https://help.autodesk.com/cloudhelp/2025/ENU/AutoCAD-Core/files/GUID-B1A185EF-07C6-4C53-A76F-05ADE11F5C32.htm)：标准模式先选择边界并按 Enter，再选择目标；开始时直接 Enter 使用全部边界。用户已允许 AutoCAD 2023/2025 作为对照。

**约束：** 保留当前自动边界和 Shift 临时延伸；不得因增加选择状态破坏草稿/已保存混合拖动的原子候选。未选中作边界的图元仍留在文档和草稿中，不能成为隐式切割边界或被结果过滤删除。隐藏对象不参与，锁定对象可作为边界但不可作为修改目标；身份冲突、来源或边界变化时拒绝旧预览和提交。无效目标不能静默删除：AutoCAD Quick 的删除行为与当前安全语义存在差异，需记录，不能冒称等价。

1. **边界过滤与测试。** 构造一条目标被两个草稿及已保存边界相交：明确仅选其一时，预览和提交均按选中边界计算，其他图元保持原身份、位置、属性；空边界选择按全部可见边界计算。分别验证修剪、延伸及边界重叠/身份冲突。几何操作仍复用现有 core 算法。
2. **界面状态。** 在二维命令栏提供进入边界选择、点选/框选、Enter/右键完成、Esc 取消；选中边界状态与目标状态明确可见。Shift 临时切换、目标连续操作及现有自动模式不变。标准模式进入与退出时清理旧选区和预览，不污染其他文档或三维草图。
3. **原子拖动与失效。** 对已保存目标与草稿混合拖动验证整个操作一次撤销、预览与提交一致；不可操作目标、锁定、来源修订和边界变化时完整回滚。保存/关闭/切换文档遵循活动操作守卫。
4. **验证和证据。** 针对新增真实窗口路径、既有修剪/延伸、选择和保存重开运行 scoped 测试，并验证相关 Ruff、格式、严格类型与分层规则。记录仍不支持的 Fence、Crossing、Project、Edge、Undo 及 Quick 删除等选项，用户参考操作另验。

## 2026-11-06 进度

当前 `TRIM`/`EXTEND` 命令中 `C` 开始边界点选或框选，Enter/右键确认，空选使用全部可见边界；草稿和已保存目标、锁定图层作边界、源修订/草稿边界变化、已保存目标与草稿边界混合拖动及撤销已有定向回归。开始新工具清除指定边界；选边期间变更来源时必须重新选边，不静默回退全部边界。完整 AutoCAD 模式、Fence、投影/Edge 等选项及参考软件操作验收仍待实施或核对。

同一编辑器成功提交自身的已保存目标修剪/延伸后，仅当修订恰好增加一次且所选边界仍完全一致时，保留边界供继续操作；其他修订变化继续拒绝。连续两次真实保存目标修剪与外部修订过期分别有回归。工程 scoped 测试结果详见 U09 证据；这不代表参考操作或整包验收通过。
