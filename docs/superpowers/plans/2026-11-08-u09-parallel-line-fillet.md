# U09 平行直线圆角

依据 Autodesk 的 Fillet Parallel Lines 说明，两条不同的平行直线使用线间距的一半作为半径，第一条线的选取侧确定半圆所在端。保留第一条线的长度，第二条线按拾取侧修剪或延长；不修剪时保留两条原线。重合、退化和拾取侧无法确定的情况应拒绝，不修改草稿或文档。

1. 用精确几何测试覆盖正反方向、选取顺序、平移/旋转、不同长度及半径被忽略，验证半圆切点与保留端。
2. 复用既有圆角事务及自动关系，覆盖修剪、不修剪、零半径、草稿/已保存来源和撤销；显式拒绝重合与过期来源。
3. 运行路径级检查和相关核心、窗口回归。参考录像未覆盖该行为，保留真实设备验收记录。
