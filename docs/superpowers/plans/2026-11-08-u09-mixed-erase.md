# U09 混合删除事务计划

目标：一次删除不同关联阵列的副本与普通已保存图元，保留阵列成员可恢复身份，并作为单条可撤销命令保存重放。

设计：新增 `drawing.array.erase` v3，提交完整稳定图元引用。内核先在隔离草图上删除普通图元及其可删除约束，再逐阵列擦除成员并校验所有依赖；若删除普通图元使跨草图相切失效，同时移除该关系。任何锁层、引用、图层或相切冲突拒绝整笔事务。普通源图元仍被阵列使用时拒绝；成员局部约束按现有规则保护。旧版命令保持原有语义。

1. 核心测试多阵列与普通对象、顺序、约束、锁层、依赖冲突和原子回滚。
2. 增加 v3 版本化命令和跨草图关系事务；覆盖存档、撤销重做、旧版本及冲突。
3. 接入窗口的已保存对象混选删除，覆盖失败回滚和重置；草稿与已保存图元混合时间线需独立处理，不误称覆盖。
