# U11 Bound Hole Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 在零件工作台提供明确升级确认、可追溯面选择、局部位置、预览及提交的绑定孔交互。

**Architecture:** 在已有隔离重放候选上先创建不改变源文档的身份升级预览，使用候选自身的视口拓扑身份生成 `BoundFaceRef`；在同一候选中追加 `feature.hole@3` 并预览，最终一次确认才提交升级及孔。基于现有命令条、候选视口和面局部帧，保持旧孔入口兼容；失效/歧义不猜测其他面。

**Tech Stack:** Python、PySide6、Command Bus、OCCT 适配层、pytest-qt。

**Spec:** `docs/design/2026-11-04-unified-ui-todo.md` U11；`src/mycad/core/bound_refs.py` 支持范围。

## Global Constraints

- 任何历史身份升级必须由最终确认显式授权，取消与预览不改变源文档或 redo。
- 绑定面仅允许已有 box 六个平面及 cylinder 顶/底面，未知或歧义拒绝，不猜测。
- 局部坐标使用设计面固有的帧，而非鼠标当前相机坐标或临时选面中心。
- 会话、源文档修订、候选代次和参数变化均失效旧选择及预览。
- Qt 只在 UI 层；几何后端只在 geom；所有模型更改经 Bus。

## Review Focus

- 旧文档预览并取消：格式、命令身份和 redo 不变；明确说明确认后的升级。
- 点击不支持、过期、其他场景或多个来源的面：不产生持久引用并提示原因。
- 面局部坐标超出面或孔失败：保留源模型与输入，不可确认。
- 预览后来源文档或参数变化：旧选择/结果不可确认；切换会话清理资源。
- 成功后改动源特征、保存重开及撤销重做：身份和位置按受支持的重放关系保持。
