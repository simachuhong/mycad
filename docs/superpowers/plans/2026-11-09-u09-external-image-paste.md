# U09 外部图片粘贴实施计划

## 目标和设计

用户实际从外部软件复制的是图片。二维画布应能通过 Ctrl+V、编辑菜单和画布右键接收剪贴板图片，在鼠标或坐标指定的位置放置，并随图纸保存、重开和撤销重做。首次放置默认按照图片纵横比确定大小，使用图纸坐标；大小需要可调整，不能把像素默认为真实物理尺寸。保留图片像素和透明度，不能静默将位图转为矢量。

图像作为独立的二维参考对象，命令参数包含经过验证的 PNG 数据及位置、尺寸，走 Command Bus 和既有历史重放，不写入草图轮廓或约束求解器。数据内嵌，避免临时剪贴板文件失效。新命令由版本化注册表控制，旧程序无法识别新命令时应明确失败；不改变旧文档或旧命令语义。二维几何剪贴板行为继续保持。DXF 若不能可靠携带图片，导出前必须明确报告语义损失，不能假装图片已导出。

## 分步

1. 建立不依赖 Qt/CAD 后端的图片数据 DTO、尺寸及资源上限校验，覆盖非有限坐标、畸形/过大数据及序列化。
2. 注册版本化图片添加、修改和删除命令；在内核重建、候选、提交和重放中维护图片对象，覆盖旧档、事务、撤销重做及保存重开。
3. 读取 Qt 剪贴板图像并转换为受限 PNG，接入菜单、快捷键及右键，画布可预览、定位并保持纵横比；粘贴失败和取消不修改文档。
4. 支持图像选择、删除和位置/尺寸编辑，并遵守图层可见、锁定、冻结及混选保护；跨二维图纸的图像复制粘贴保持嵌入数据。
5. 接入 DXF 输出预览和损失提示；验证同图与跨图、透明度、撤销重做、重开、资源上限、既有图元复制粘贴以及工作区隔离。按路径增量验证，最后再做集成和用户设备复验。

## 开发边界

先实现可靠的 PNG 剪贴板数据、图纸内置及放置；文件 URI、复杂剪裁、图像跟踪和三维对象扩展分别识别，不能以临时显示冒充已保存。实际可输出格式和选取行为以运行结果为准，不将尚未实现的 DXF 图片嵌入视为完成。
