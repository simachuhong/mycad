# U09 TRIM / EXTEND 边界延长选项

依据 [AutoCAD 2025 TRIM 官方说明](https://help.autodesk.com/cloudhelp/2025/ENU/AutoCAD-Core/files/GUID-B1A185EF-07C6-4C53-A76F-05ADE11F5C32.htm)，Edge 选择有限边界或沿自然曲线延长的虚拟边界。

1. 在几何求交中引入明确的延长边界选项：有限目标保持有限，边界直线延长为支撑线，边界圆弧延长为支撑圆；构造对象、隐藏对象、身份排除和明确边界过滤规则不变。覆盖直线、圆弧、圆、开放及闭合路径，交点与近重合情形失败保护。
2. 在 TRIM / EXTEND 命令栏实现 Edge 与 Extend / No Extend 状态和提示，设置仅影响后续候选；预览、单击、围栏及已保存目标使用一致的几何选项。
3. 验证草稿和已保存混合目标、撤销、Esc、边界选择、来源变化、分层和旧有限边界回归；记录二维投影与参考软件的差异。
