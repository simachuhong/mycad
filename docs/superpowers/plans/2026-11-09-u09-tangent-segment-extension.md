# U09 相切来源线段延长后的重绑定计划

**目标：** 两段多段线零半径闭合延长相切来源时，在能证明旧线段完整保留且关系仍相切的情况下保持跨草图关系。

**设计：** 通过有向共线、旧段完全被包含、结果匹配唯一证明线段身份；拒绝截短、反向、偏移、重复或有歧义的候选。新增 `drawing.sketch.revise` v35 使用该证明；旧版本继续严格要求线段完全不变。关系分支、端点语义和最终有限曲线相切仍经既有校验；不改变本地尺寸或其他约束的重绑定规则。所有更改经命令总线，撤销由历史重放完成。

1. 在 core 增加旧段完整包含证明及可选重绑定，覆盖延长、反向、截短、重合歧义和旧默认拒绝。
2. 注册 v35，在几何重放端仅对 v35 使用相同证明，保留 v34 行为；核验非法映射和相切失效均原子拒绝。
3. 二维修订优先使用原规则，必要时使用扩展证明并提交 v35；测试真实窗口的闭合、关系身份、索引、撤销重做和保存重开。
4. 按变更路径执行定向测试、ruff、格式和类型检查，更新进度与验收记录。草稿混合操作和圆弧段拆分关联不在本次自动推断范围内，仍需后续处理。

**进展：** v35 已接入二维已保存图元修订和重放；窗口覆盖来源线段索引改变与不变、旧 v34 拒绝、篡改截短拒绝、保存重开及撤销重做。相切、多段线、规格、CLI 与分层定向回归及相关静态检查通过。旧程序若不支持 v35 命令则无法重放新历史；草稿混合路径和圆弧段拆分关联仍未覆盖。

**混合暂存续进：** 已提交相切关系的线段延长证明贯通草稿混合预览、逐步历史和 v35 提交；索引改变或不变、草稿撤销重做、保存重开、旧版本及篡改拒绝已覆盖。带未提交相切关系的混合编辑和圆弧拆分关系仍需另行核验。

**待提交相切续进：** 已保存多段线为来源、草稿圆为目标时，线段延长后的待提交相切按同样证明迁移；同时保持关系身份并以 v35 重放，索引改变和不变均已验证。反向来源/目标组合及拆分圆弧关系还需继续核验。

**反向组合补验：** 已保存圆为来源、草稿多段线为目标的直线段延长，两种索引情况及保存撤销均通过；圆弧拆分关系仍待处理。
