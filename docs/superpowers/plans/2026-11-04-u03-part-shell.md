# U03 三维功能区与导航 Implementation Plan

> **For agentic workers:** 使用 superpowers:executing-plans 按任务执行，测试先行，保留现有会话和 U02 设置。

**Goal:** 为零件工作台提供紧凑 QAT、分组功能区、独立文档标签、左侧模型导航和可操作的状态反馈。

**Architecture:** `ribbon.py` 构造复用 `ActionCatalog` 中 QAction 的分组，不持有业务状态；主窗口保留原草图活动面板和文档会话。结构树及其信号属于原 `RightPanel`，只迁移同一 QWidget 到左侧，不复制模型；独立二维保持自己的工具栏与工作台。

**Tech Stack:** PySide6、现有 MainWindow/RightPanel/CommandPalette、pytest-qt。

**Spec:** `docs/design/2026-11-04-unified-ui-design.md` §§4–5、8–9；`docs/design/2026-11-04-unified-ui-todo.md` U03；ST10 有序视觉参考 `.omo/evidence/ui-redesign/reference-solidedge-st10-ordered-user.png`。

## Global Constraints

- 尚未取得 ST10 有序/同步完整行为证据；本包只记录可核对的视觉与操作，不标记参考或用户验收通过。
- 所有功能入口复用既有 QAction、命令注册表和 Bus；不添加没有处理逻辑的曲面、PMI、仿真或装配页。
- 草图页常驻；活动草图命令条与已实现的两种选面流程维持可达。
- 模型树和画布选择继续共享真实身份；二维和工程图不出现三维树及三维草图组。
- 保留旧布局备份、按 U02 环境隔离设置；仅当菜单、搜索、快捷键覆盖后隐藏重复建模栏。

## Review Focus

- 1024×768 下选面、绘图、完成和取消始终可达；不得裁切重要控件。
- 非零件环境不展示三维功能区或模型树，往返不丢草稿与视角。
- 无文档、执行中、选面变化：相同动作所有入口状态一致。
- 多个同类型文档及脏状态：文档标签按 document_id 区分，切换尊重命令/保存守卫。
- 原有选择、高亮、可见性和历史编辑信号在迁移树后仍双向工作。

## Task 1 — 分组功能区组件

**Files:** 新增 `src/mycad/ui/ribbon.py`、`tests/ui/test_ribbon.py`；调整 `src/mycad/ui/main_window.py`。

**Interfaces:** `RibbonGroup(title: str, primary: Sequence[QAction], secondary: Sequence[QAction], parent: QWidget | None = None)`；大按钮使用图标上文字下，小按钮两行，所有按钮 `setDefaultAction`；标题在底部。主页使用选择、草图/平面、基础体、特征、修改/阵列的真实动作；草图保持已有活动面板栈。检查页链接现有测量面板；工具页链接选项、单位；视图页链接适应窗口、方向、显示样式等真实 QAction。

- [ ] 先测试组内按钮复用动作、状态一致、组名位置和 1024 宽度可访问，运行确认缺失组件失败。
- [ ] 实现组件并按主页/草图/检查/工具/视图连接真实动作；不要创建未实现的功能页。
- [ ] 更新既有两页数目断言为五页行为断言，复验草图活动页、两种入口和 1024 布局。

## Task 2 — 独立文档标签

**Files:** `src/mycad/ui/main_window.py`、`tests/ui/test_workspace_tabs.py` 或新测试。

- [ ] 先测试两个同类型文档以 document_id 区分、切换激活正确会话；切换中有草稿或活动命令时保持当前文档与标签。
- [ ] 在中央工作区上方添加 QTabBar，项目文档身份作 tabData；在会话刷新中阻塞信号更新标题、脏标记及活动标签，保留原 workspace 容器以承载各工作台。
- [ ] 标签选择调用现有会话切换守卫；关闭和返回首页由 U01 现有路径处理，测试最后文档关闭及首页不丢文档。
