# U09 对象捕捉追踪增量

依据 Autodesk 2025 Object Snap Tracking 与 2024 状态栏文档，F11 控制基于对象捕捉点的追踪；默认沿水平、竖直路径，可结合两个已获取点求交。视频未覆盖此功能，文档参考不能替代人工验收。

1. 在既有对象捕捉候选上获取最多两个可见点，不将对象追踪当成持久约束；F3/F11 关闭、工具切换或来源失效时清理。
2. 在真实指针移动和落点中复用对象捕捉优先、正交追踪与两个追踪点交会；明确坐标和 Shift 临时关闭优先。跟踪提示和路径须可见，移动/复制与绘制共用结果。
3. 定向覆盖 F11/F3、获取和交会、单轴、撤销、编辑器隔离、预览与提交、来源失效、显式坐标及 Shift；窗口验证和真实设备验收分别记账。
4. 追踪方向可选正交或极轴角度，后者使用增量、附加角及相对基准；支持双射线交会和沿单条追踪方向输入距离。F9 的极轴距离捕捉适用于两种追踪方向，显式输入的距离不被取整。
5. 获取方式可选自动获取或按 Shift 获取；再次移入已获取点可移除该点。按住 Shift 仍临时关闭捕捉，释放后可使用获取的追踪点。全部 AutoCAD 设置尚未完成；视频未覆盖 F11，仍需人工设备验收。
