# U09 草稿与已保存阵列成员混合删除

目标：草稿与已保存关联阵列成员混选删除时，预览、提交、逐步撤销和重放保留成员恢复信息，且每次用户操作是一个历史步骤。

1. [x] 构造真实文档和草稿时间线的失败探针，覆盖一个已保存成员与草稿对象同时删除、撤销重做及保存重开。
2. [x] 为草图事务引入版本化成员擦除参数；同一隔离候选中校验来源、锁层、约束和相切关系，避免历史步骤拆成两条。
3. [x] 时间线根据相邻草图快照识别成员删除，携带稳定引用并校验计算出的几何与请求修订一致；旧版本语义不变。
4. [x] 接入画布预览，覆盖普通删除、多阵列和相切约束，运行相关增量检查并记录支持范围。
5. [ ] 继续扩大复杂连续编辑、取消及失败回滚的组合覆盖。
