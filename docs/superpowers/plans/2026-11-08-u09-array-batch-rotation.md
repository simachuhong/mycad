# U09 阵列成员批量旋转

**目标：** 同一关联阵列中可混选普通成员和额外输出，输入共同旋转角和编辑平面中心，以单条命令原子应用。

**约束与方案：** 复用 `drawing.array.rotate` 的成员列表，包含额外输出时使用 v2；逐个将共同中心转换到目标草图，并按各自锚点保存中心偏移。跨阵列、身份不唯一、锁层、约束或相切冲突拒绝；取消和无效输入不写历史。

1. [x] 写窗口失败探针：普通成员与额外输出共同绕同一中心旋转，验证单条历史、保存重开、撤销重做；取消、无效输入与跨阵列选择保持原状。
2. [x] 扩展窗口选择、共同角度和中心输入，逐成员计算目标草图中心偏移；保持单选、无变化提示和版本选择。
3. [x] 覆盖不同平移坐标系、局部约束和跨草图相切冲突；运行受影响 UI、应用、核心、分层及静态检查，记录边界。
