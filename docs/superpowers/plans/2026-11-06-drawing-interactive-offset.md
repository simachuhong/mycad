# 独立二维交互式偏移实施计划

**目标：** 在现有数值偏移之外提供 `OFFSET`/`O` 命令与画布交互：距离、对象、侧向、连续选择，保持草稿和已保存对象的来源及撤销安全。

**依据：** [中期余项](../../design/2026-11-06-unified-ui-midterm-remaining.md)、[二维修改审查](../../design/2026-11-04-autocad-2d-modify-audit.md)、[已有数值偏移计划](2026-11-06-drawing-saved-offset.md)。

**设计选择：** 保留现有参数面板的数值偏移；新增画布内独立状态机，命令栏和画布共享同一状态与提示，生成图元仍交给 `offset_entities` 和现有草稿历史。直接复用 MOVE 状态机不能表达每次重选对象及侧向；仅添加 OFFSET 命令别名无法提供此交互。

**边界：** 初期覆盖直线、圆、圆弧及无歧义的多段线/矩形侧向；对点、样条、退化、侧向歧义及偏移自交按实际算法拒绝并保持草稿。只选择可见、未锁定的当前工作平面图元；来源文档修订变化立即失效，不能对旧对象生成副本。每次成功产生独立草稿撤销步骤，退出命令保留已完成副本；新对象身份唯一、图层和构造属性遵守原算法。命令进入/退出和后台忙碌与现有草稿、文档切换、保存守卫一致。

1. **几何侧向与预览契约。** 为线段与曲线确定方向的局部计算写参数化测试：两侧、反向线、顺/逆圆弧、圆内外、多段线路径方向、拐角等距和侧点落在对象上。侧向不能唯一确定时拒绝；预览和确认共用相同候选，缩放不影响几何方向。验证源对象及元数据不变。
2. **画布状态。** 先编写交互测试覆盖输入正的有限距离、选择草稿或已保存对象、两侧预览和确认、连续选择、右键/Enter 结束和 Esc；随后实现状态和提示。无效距离、无效对象、缩小至零半径、锁定/隐藏、身份冲突、文档修订或切换均保持现有几何及历史。对模糊选择要求重新选取，禁止任意猜测。
3. **命令入口。** 为 `O`/`OFFSET`、命令先行、输入无效距离后更正、重复命令、显式坐标侧点、输入法预编辑与 Esc 补命令栏真实 Qt 测试；连接现有画布状态，不复制第二套状态机。原面板数值偏移继续工作。
4. **事务与集成。** 用实际文档验证草稿和已保存源、多个连续副本、每步撤销/重做、取消、保存重开、平面/图层/身份及过期来源；再运行二维命令栏、画布修改和已保存选择相关 scoped 测试以及涉及文件的 Ruff、格式、严格类型与分层检查。结果更新 U09 证据和差异审查，不将 AutoCAD 实机对照标为通过。

## 2026-11-06 进度

- 距离、侧向及现有偏移函数的衔接已覆盖直线、圆、顺/逆圆弧和多段线/矩形；发现并修复了既有圆弧负距离符号丢失。路径顶点附近的等距情况拒绝猜测。
- 画布、`O`/`OFFSET` 和“侧向偏移”按钮已接入，原数值偏移保留；已验证单对象连续生成、预览与确认使用同一候选、已保存源、保存重开、来源修订、草稿目标变化、锁定/隐藏及取消。逐次草稿撤销在结束命令后验证。
- 仍需更多复杂图元/约束组合和实际 AutoCAD 参考对照。当前只接受键入正数距离，尚不支持以两点量距、通过点、图层或删除源等 AutoCAD OFFSET 选项；真实中文输入法和物理 GPU 仍待核对，未将整项标为完整。
