# 独立二维圆与圆的非修剪圆角

目标：针对用户提供的 AutoCAD 2023 录像中 `FILLET`、半径与 `NOTRIM` 场景，先实现可准确说明边界的两圆外切圆角；保留原圆，不宣称支持全部 AutoCAD 圆角组合。

1. [x] 以独立几何测试确定圆弧与两圆的外切关系、根据两处拾取点选择圆弧、无解和退化情况；保持输入圆不变且非有限半径被拒绝。
2. [x] 复用二维画布图元拾取、图层及草稿提交路径，提供 `FILLET`/`F`、`R` 半径和依次选择两圆；无解、图层锁定和取消不得修改草稿或已保存文档。先限制为 `NOTRIM`，不静默处理其他图元及修剪选项；结果为独立圆弧，不自动建立关联约束。
3. [x] 通过真实 Qt 鼠标和命令栏测试圆角创建、方向选择、错误恢复、取消、草稿及文档级撤销/重做和保存重开；运行分层及变更路径检查。人工对照和用户验收单独记账。
