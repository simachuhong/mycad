# 非遮挡建模命令交互规范

日期：2026-10-25。状态：按用户要求将已确认的圆角交互扩展到全部内置建模命令。

修订：操作语义与交付判定以 [Solid Edge 操作验收基线](../../design/solid-edge-interaction-acceptance.md) 为准。此文早先仅统一参数条的范围不足以代表专业 CAD 操作验收通过。

## 行为基线

- 所有内置建模命令共用视口外的一行命令栏；参数输入、选择状态、预览状态、确认和取消均在该命令栏或状态栏反馈，不再把参数窗体叠在模型上。
- 命令按其几何前置条件启用拾取：拉伸默认选模型平面，只有显式切换来源后才在 XY 放置参数截面；长方体、圆柱体、旋转和差集当前仍在 XY 放置；孔、孔阵列选择一个平面；圆角选择一条或多条边。
- 完整参数及必需拾取齐备后，参数编辑自动防抖触发隔离预览。预览不写 Document/CommandBus，保留相机；有效且最新的预览才允许通过命令栏按钮、视口 Enter 或短右键“应用并执行”。
- 预览期间仍可在原始已提交模型上继续进行该命令需要的几何拾取，参数更新立即使旧预览失效。建模命令中中键拖动旋转、Shift+中键拖动平移；提交中锁定拾取但保留导航。取消丢弃当前草稿；确认仍经既有 Plan/CommandBus 路径。
- 长方体、圆柱体、拉伸、旋转、孔、孔阵列、差集均为单次提交；圆角沿用当前连续分组行为，每组独立提交。

## 命令拾取与输入

| 命令 | 视口拾取 | 命令栏参数 |
|---|---|---|
| 长方体 | XY 放置中心 | X/Y/Z 尺寸、建模方式 |
| 圆柱体 | XY 放置中心 | 半径、高度、建模方式 |
| 拉伸 | 默认选择模型平面；显式切换才放置 XY 截面 | 平面模式仅显示距离（正向添加、负向切除）；XY 模式显示截面尺寸和建模方式 |
| 旋转 | XY 截面中心 | 圆/矩形、对应尺寸、X/Y 轴、角度、建模方式 |
| 孔 | 单个平面 | 孔径、盲孔/贯穿与深度 |
| 孔阵列 | 单个平面 | 基础孔参数、阵列半径、数量、起始角 |
| 差集 | XY 刀具体中心 | 长方体/圆柱体刀具及其尺寸 |
| 圆角 | 一条或多条边 | 沿用已确认的连续圆角命令栏和半径输入 |

孔的位置继续使用当前命令 schema 支持的面心定位。任意面内点选、草图编辑、线性阵列、QuickPick、径向菜单与同步建模不属于此次 UI 扩展，也不应在界面中伪装成已支持能力。

## 失败与保护

- 无效/不完整参数、缺少拾取或几何预览失败时禁用确认，显示可恢复的状态提示并保留用户选择和参数。
- 新输入开始时旧预览立即失效；过期的异步结果不可覆盖当前状态。
- 切换命令或退出时停止防抖计时、丢弃临时预览并恢复进入命令前的选择过滤器。
- 任何已确认几何写入只能经现有 Plan 执行与 CommandBus；隔离预览只在 scratch document/kernel 上运行。

## 人工验收重点

逐个启动各建模命令；确认只有顶栏命令条变化、视口主体不被浮窗盖住。对点放置命令重定位后应见到模型预览；孔/孔阵列改选平面后保持可继续拾取；参数连续改动只呈现最新预览；预览失败后可修改参数恢复；确认只提交一次，取消不增加命令；圆角仍可连续完成多组。
