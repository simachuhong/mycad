# 工程图标注入口与文本

用户反馈工程图没有可发现的尺寸/文本入口。现状：尺寸仅第二行裸文本按钮，右侧标注页只编辑格式；没有自由文本模型或操作。

顶部主工具条提供“尺寸标注”菜单（水平、垂直、对齐、半径、直径、角度、中心标记），另有“文本标注”按钮；第二行尺寸工具有完整名称和现有图标。右侧标注Tab增加同一组创建工具，避免工具条被隐藏后无入口。触发工具时显示右侧标注页及图中提示，尺寸维持关联参考尺寸。

新增纸张所属 DrawingNote(note_id, sheet_id, text, position_mm, height_mm=3.5, layer='TEXT')；drawing.note.create/update/delete v1命令，档案v3，Bus唯一写入。文本以局部纸面毫米定位，与视图比例无关；删除纸张级联，删除视图不删纸张文本。旧命令不变，工程图源指纹排除note布局操作。

文字采用画布内编辑器：启动工具→纸上单击→直接输入（支持中文、多行）→Ctrl+Enter或完成按钮提交，Esc取消；双击重开，拖动移动，Delete删除，撤销恢复。不能与视图/尺寸预览冲突，切文件/切纸取消临时文字，未提交文字受已有保存保护。右栏调整纸面字高。文字可独立出图；空白纸张仍禁止出图。DXF/PDF与画布共享PaperText，不解释HTML或DXF格式。

取舍：采用独立纸张文字对象，避免伪造几何引用；首版不含引线、富文本、旋转和自动排版。沿用现有Python/Qt/命令及输出路径。直接执行本次明确整改请求，不增加审批停顿；复用当前功能分支，保留用户Logo素材和运行中的GUI。
