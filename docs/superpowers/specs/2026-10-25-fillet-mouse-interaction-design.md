# 圆角鼠标交互设计草案

日期：2026-10-25。状态：已确认；核心交互已实现，待人工验收。

## 目标与范围

围绕同一零件完成选边、输入统一半径、动态预览、确认一组圆角，允许连续操作。用户始终能看到目标几何，不必移动窗口、反复点预览或重新选择已选边。

参考依据：[Solid Edge 鼠标操作研究](../../design/solid-edge-mouse-interaction-study.md)。下面的按键优先级、尺寸和时序是 MyCAD 的设计提案，不宣称逐项复刻 Solid Edge。范围限于固定半径圆角；本轮不引入可变半径、整套径向菜单或同步建模求解器。

## 布局选择

| 方案 | 优点 | 代价与结论 |
|---|---|---|
| 视口外单行命令条，加临时就地输入 | 几何可见，常用输入接近操作位置，保留明确完成和取消入口 | 需要避让与焦点规则；本草案推荐 |
| 固定侧栏编辑半径 | 不覆盖模型，实现规则较简单 | 指针频繁往返；不作为主要输入方式 |

不再沿用旧的视口内大参数窗体。即使窗体可拖动或半透明，也不能作为遮挡问题的解决办法。

### 命令条

在视口上方预留独立的 36–44 个逻辑像素高区域，不叠在渲染画面上。内容保持一行：

`圆角    R 1 mm    已选 2 条边    ✓ 完成此组    × 退出`

- 无选择时显示“选择边”，完成按钮不可用。
- 指针停留在按钮上再解释快捷键，不常驻长段操作说明。
- 进度和错误使用窗口现有状态栏；详细诊断通过“详情”展开到日志区。
- 窄窗口中缩短文字为图标和边数，保留可访问名称与提示；不得横向溢出或覆盖几何。
- 仅显式适应窗口动作可以重新取景；进入命令也不自动缩放模型。

### 半径输入

只有一个活动输入框，内容为 `R [1.00] mm`，目标尺寸约 120–160 × 28–36 个逻辑像素。尺寸以系统字体和缩放设置为准，不裁切文字。

- 输入框出现于模型投影轮廓外的空白区域，并尽量靠近最近选中的边；与模型保留至少 12 个逻辑像素间隔。
- 避让整个模型投影、选中边、已有控件和视口边界。仅限制在窗口内不算完成避让。
- 无足够空白区域时，将同一个输入框放入命令条的半径位置。不能要求用户先搬动面板。
- 输入框进入编辑后位置稳定，不追随每次鼠标移动。若导航后产生遮挡，则移入命令条并保持文本、光标和焦点。
- 不常驻背景卡片、说明段落、预览按钮或错误堆栈。

## 正常操作流程

### 1 开始

允许两条入口：先选择当前模型的边再调用圆角，或先调用圆角再选边。只接收当前有效的边；预选的是面或实体时，进入选边状态并提示，不猜测用户想圆哪些边。

进入命令自动启用边选择。初始半径使用本次文档会话中最近一次成功提交的圆角半径；没有记录时为 1 mm。初值只是起点，不代表该边一定可以生成圆角，不根据板厚猜测最大可用半径。

### 2 选择边

- 无按钮悬停时，只对将要选中的边预高亮，不改变选择集。
- 左键单击添加一条边；再次单击同一条已选边将其移除。圆角命令内采用累加选择，不要求每次按 Ctrl。Ctrl 加单击保持同样的切换行为。
- 点击空白不清空选择，也不完成命令；清空可通过命令条边数菜单中的“清空选择”执行。
- 超过点击容差的左键拖动不旋转视图，也不触发单击选边；相机操作使用中键。容差内的手部抖动仍按单击处理。
- 选中边用持续的颜色和线宽标识，候选悬停与正式选中可区分。
- 对当前内核或定位器不支持的边，给出“不支持此类边”的就地提示，不先收进选择集再抛内部异常。

密集区域存在多个候选时，悬停后显示 QuickPick 提示。提示激活后的短右键打开紧凑候选列表；指向某项时只临时高亮对应边，左键选取后回到圆角。浏览列表不改变已有选择；确认候选时按上述添加或移除规则处理，不提交圆角。指针离开候选区域即撤销提示激活状态。等待时长初拟 500 ms，属于后续体验调节项。

### 3 输入半径

第一条边选中后即用当前半径请求预览；保持视口可继续接收选边操作。

从视口直接键入数字或小数点，或者按 R，即可进入半径输入；不需要先用鼠标点中数值框。数字输入替换旧数值，R 键进入时选中当前数值。点击命令条半径同样可以编辑。

半径为大于零的有限数值，当前单位明确显示为 mm。第一版不承诺表达式或其他单位解析。

- 合法数值变化后自动更新预览。
- 输入中间状态如空串、单独的小数点不提交，也不弹出错误窗；显示“请输入大于 0 的半径”。
- 输入框中的 Enter 接受本次数值编辑并把焦点交回视口，**不会同时提交圆角**。
- 输入框中的 Esc 放弃这次数值编辑，恢复进入编辑前的半径，保留已选边。
- 编辑期间单击视口：文本合法时接受数值并继续执行该次选边；不合法时不改选择，保留输入并提示修正。中键导航仍然可用。

### 4 动态预览

选择集或合法半径改变后自动计算，不提供必须另点的“预览”按钮。输入停止约 200 ms 后发起计算；这是初拟防抖间隔，不是几何计算耗时保证。

- 保持用户相机位置、缩放和旋转中心，不自动适应窗口。
- 保留选择集；预览存在时仍能添加或移除原模型上的边。
- 预览几何与选边使用不同数据：选边依附进入该组操作时的已提交模型；预览生成的新边不能冒充原始选边对象。
- 选中原边可用细线显示在圆角结果上，表示输入依据；预览新增边不作为可选候选。
- 点击目标与原始可选边必须对应。预览表面产生遮挡或候选难以辨认时，悬停显示原边候选，并可用 QuickPick 选择；不能出现无提示的不可见热点。
- 输入改变立即将旧结果标记为过期，并禁止确认。等待期间旧结果可淡化保留，状态栏显示“正在更新，尚未确认”；只有对应当前输入的成功结果才恢复正常显示。
- 不排队积累过期预览；结果返回时核对文档、模型版本、选择和半径。过期结果不得覆盖新结果。

### 5 确认与连续操作

视口获得焦点且最新预览有效时，短右键、Enter 或命令条 ✓ 都表示“完成此组”。三个入口执行完全相同的动作。

- 正在输入半径、QuickPick 列表已打开或其提示已激活时，先由对应交互处理，不能顺带提交。
- 短右键必须在松开时识别，且无修饰键、未发生拖动。初拟移动容差 5 个逻辑像素、短按上限 350 ms；后续结合系统设置与体验校准。
- 右键长按或拖动不确认。完整径向菜单不在本轮范围内，不能因暂未实现长按菜单而将长按退化为确认。
- 无选择、无效输入、计算中、失败或预览过期时不可提交。计算中按确认不预约自动提交，提示“预览更新中，完成后再确认”。
- 提交期间锁住重复确认和模型写入，仍允许视图导航；仅在提交成功后清空本组边，保持半径，继续等待下一组选边。
- 成功提交后显式提示“已完成本组圆角，可继续选边；Esc 退出”。重建下一组的原模型选取依据。
- 每组只形成一条可撤销命令。提交失败保留本组输入与选择，不进入下一组。

## 导航与取消

| 动作 | 圆角命令中的行为 |
|---|---|
| 中键拖动 | 旋转视图，保持当前选择和参数 |
| Shift 加中键拖动 | 平移视图 |
| 滚轮 | 指针在视口中时缩放；位于半径输入框上时不意外改数值 |
| 双击中键 | 用户主动要求适应窗口 |
| QuickPick 打开时 Esc | 只关闭候选列表 |
| 输入框中 Esc | 只取消当前数值编辑 |
| 视口中 Esc 或命令条 × | 退出圆角，丢弃未提交的这一组；已完成的组保留 |

导航结束不会产生额外选边、确认或取消。退出圆角恢复原选择过滤器和当前已提交模型显示，不恢复进入命令时的旧相机位置。

## 失败反馈

例如截图中的 R10 不能生成圆角时：

1. 清除不适用于当前输入的候选结果，显示已提交模型和原选中边。
2. 保留 R10 的输入，选中边不丢失，不移动相机。
3. 状态栏显示“当前半径无法生成圆角，请减小半径或调整选边”，提供“详情”入口。
4. 用户直接改为另一个半径，自动重试预览；可继续增删边。

不能仅凭一次内核失败断言半径过大或报告未经求解的最大半径。多边失败时也不能悄悄只应用其中成功的边；只有得到可靠定位结果时才标出具体冲突边。

## 状态与架构约束

主流程为：等待选边 → 编辑或计算 → 有效预览 → 提交 → 等待下一组。失败返回可继续编辑状态；任一尚未提交状态都可退出。

- UI 维护本组原模型身份、边集合、半径编辑状态和预览代次；命令执行仍通过既有 CommandBus 确认与写入路径。
- 鼠标或键盘的“完成此组”是明确提交动作，不能用悬停、输入数值或预览完成替代用户确认。
- 预览在隔离几何环境中计算，不写活动文档、历史或存档。
- 操作中若文档切换或基础模型版本发生变化，废弃候选结果，不将旧拓扑套到新模型。若由当前命令外的操作触发，结束本组并说明原因。
- 不取消当前的分层、可重放参数和存档兼容约束。

## 人工验收脚本

使用与反馈截图相同的法兰，同时记录鼠标、焦点、选择、相机和历史变化。以下是待实施后的验收要求，不代表已经通过。

1. 调用圆角，单击外缘：边高亮并自动预览，模型不被窗体遮挡。
2. 不点击输入框，直接键入 1.5：只出现单行半径编辑，模型自动更新。
3. 输入框内 Enter：只结束数值编辑，历史不增加。再从视口 Enter 或短右键：恰好提交一组。
4. 预览存在时选第二条边，再取消第一条边：选择连续可见，最新预览只对应第二条边。
5. 修改半径期间旋转、平移、缩放：参数不丢、选边不丢、导航结束不误提交。
6. 使用不能生成圆角的半径，再改回有效值：原边仍选中，不必重新启动命令；错误不遮挡模型。
7. 密集边处打开 QuickPick：高亮与候选一一对应；右键没有同时完成圆角。
8. 快速修改半径、切换选择：旧结果不回跳；计算中确认不会导致稍后自动提交。
9. 短右键、长右键、右键拖动分别操作：只有符合提交条件的短右键完成此组。
10. 输入框、QuickPick、视口分别按 Esc：取消层级符合上表；已提交组可由正常撤销恢复。
11. 约 480 像素宽的视口、模型占满画面、放大字体：输入框退回独立命令条，目标几何仍可见。
12. 成功完成一组后继续选边：使用更新后的模型；每次提交一条历史，最后 Esc 退出。
