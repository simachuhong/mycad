## 目标与范围

测试用户目前集中在 Windows，因此首个桌面发行物优先 Windows x64。
用户通过中文安装向导安装并启动，无需预装 Python、uv 或开发工具。
包含现有 GUI、几何内核及 x64 草图求解依赖，不新增建模功能。
首轮以 Windows 10/11 x64 为目标；实际支持声明以打包后验证结果为准。

用户补充要求更正式的安装包，以便在 Windows 主机测试全流程。
首轮主交付改为 Setup.exe，覆盖安装、启动、覆盖升级和卸载；不增加自动更新。
不自动创建 Gitee Release，不以自动检查替代用户操作验收。

## 方案比较与选择

用户已选择优先 Windows 桌面包，并要求正式安装体验；便携 ZIP 不再作为主交付。
具体工具采用代理建议的 PyInstaller + Inno Setup；用户已确认准备本机构建流程。

1. **PyInstaller 目录产物 + Inno Setup（推荐）**：先收集原生依赖，再生成中文安装器，
   适合本轮个人测试主机的安装、升级和卸载验证。
2. **WiX/MSI**：适合明确要求原生 Windows Installer、企业部署及修复能力的场景；
   本轮尚无此要求，暂不引入其组件和升级规则维护成本。
3. **Nuitka + Inno Setup**：可选编译路线；首轮不同时引入编译优化和安装器两类变更。

Setup.exe 并非 MSI；若明确要求原生 Windows Installer 格式，应选择方案 2。

## 安装器行为（已纳入本轮配置，实机待验）

- 默认当前用户安装到 LocalAppData/Programs/MyCAD，无需管理员权限。
- 中文向导包含许可、目标目录、快捷方式和完成后启动选项。
- 开始菜单及 Windows 已安装应用显示名称、版本、发布者和卸载入口。
- 固定 AppId，升级沿用安装目录；使用两个递增测试版本验证覆盖升级。
- 安装和升级前检查运行中的 MyCAD，提示正常关闭，不静默强杀。
- 升级替换受管程序文件，保留文档、用户字体、块库及设置。
- 卸载移除程序文件、自有快捷方式和注册项，保留用户文档和数据。
- 文件关联可作为可选任务，注册和卸载限定为 MyCAD 自有项。
- 提供安装日志、运行日志和 SHA256；预留签名配置，证书是否可用待确认。
- 本轮提供 Windows 本机构建脚本；Windows CI 留待后续接入。

## 构建与启动

- 固定 Python 3.12 x64，使用仓库 uv.lock，安装 desktop 和 sketch-constraints extras。
- 添加独立桌面启动入口，默认打开 GUI，允许传入一个文档路径。
- GUI 启动故障写入用户目录日志，并提供可见错误提示，避免双击后静默退出。
- 主入口在加载 GUI 前处理 multiprocessing.freeze_support()，支持工程图 spawn 工作进程。
- 为旧版 DXF 字体布局进程提供冻结程序可识别的内部入口；保留源码运行路径。
- 收集 OCP/OCCT、PlaneGCS、Qt 平台与图像插件、必要资源及分发元数据。
- 从实际发行目录收集第三方许可证，保留 LICENSE 和 NOTICE；授权待核实项不得宣称已解决。
- 打包工具及其版本固定；排除开发工具，避免无差别收集无用的 Qt 模块。
