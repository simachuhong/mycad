## 对标定位

M2-B 采用历史驱动的零件草图：编辑草图后重建消费者，保留草图身份与依赖。Solid Edge 的顺序草图与此更接近；其同步特征可脱离原草图并迁移尺寸，不能直接套入 MyCAD。[Siemens 对两种模式的说明](https://blogs.sw.siemens.com/solidedge/fallouts-of-sketch-based-features/)

平面锁定、原位绘制和正视操作借鉴 Solid Edge；命令生命周期、确认和原子性遵守 MyCAD 契约。本次依据官方教材与教程进行文档对标，未验证 Solid Edge 最新版界面或实机行为。

## 目标与边界

在原零件三维视口中，选择并锁定平面，完成独立草图绘制、驱动尺寸、确认和后续拉伸；已有草图可编辑并在确认前完整预演下游。草稿归零件文档，不创建或切换 `.my2d`，不实例化 `SketchEditorDialog` 或依赖其画布、私有状态及可变会话。二维工作台行为保持原样。每个基准、草图和拉伸分别确认。

首个闭环包括线段/连续线、矩形、圆、圆弧；选择、端点拖动、删除及草稿内 undo/redo；普通/构造几何切换；长度、距离、角度、半径、直径驱动尺寸及已有求解端口支持的适用几何约束。以上是目标能力，完整约束提交和已有草图任意几何修订仍受下文 B1/B2 阻断。非共面空间草图、角度/三点基准、关联投影、新模型面持久绑定和完整坐标系管理仍分别属于 M5、M3、M6、M4/E3-B、M3。不得将草图显示、纯标注或不完整求解器结果冒充可编辑和驱动能力。

## 方案与现状

- **推荐：独立三维工作台 + 中立共享底层。** `PartSketchWorkbench` 拥有工具栏、事件路由、草稿和生命周期；零件视口绘制、命中和捕捉均基于同一场景令牌。复用 `core.sketch`、`core.sketch_edit`、约束求解端口和 `spatial_positioning`；需单独实现三维交互和草稿控制，改动较大，但符合已确认的工作台分离要求。
- 重用二维 `SketchEditorDialog` 并嵌入或覆盖视口：短期实现较快，但状态和事件仍属于二维编辑器，不符合原位编辑及工作台独立要求，故不选。
- 修改核心为新的通用草图系统：会扩大持久化、已有二维行为和求解器迁移风险，故不选全面重写。既有 DTO、Bus 和求解端口可复用，但初版“既有命令足以完成全部闭环”的判断撤回：需补足下文 B1/B2 提交契约。

当前 `MainWindow._on_sketch_start` 对 part 仍创建二维 `SketchEditorDialog`；现有草图 overlay 仅负责显示。`GLViewport.capture_view()/restore_view()` 已保存距离、中心、欧拉角或四元数、投影和选择/显隐；不能仅使用只含距离/中心的 `camera_state()`。`sketch.create@4` 的关联支撑只接受已确认 datum plane 引用及 UV 偏置、旋转和翻法向；它与旧 `support_face` 查询语义不同。`ReplayAppend` 不保证跨 stage 的新命令身份稳定，因此不把未确认的平面作为后续草图父对象。

## 支撑、坐标和视图

入口区分独立二维文档与 part：二维入口保持原有编辑器；part 进入零件草图工作台。新建时选择世界 XY/XZ/YZ 或本零件已确认、可见且有效的 datum plane；明确显示来源、U/V/N 和锁定状态。世界主平面使用已有固定 `WorkPlaneFrame` 与兼容的 `sketch.create@3` 参数，不悄悄创建 datum；datum 使用已有 `sketch.create@4` 的 `support` 引用及局部放置，首次需要 v6 在候选中准备并在确认摘要提示。禁止引用未确认候选或隐藏、过期、错误类型的基准。选择旧模型平面时仅保留现有 `support_face` 查询兼容并明示其非持久绑定；本包不把它升级或描述为新的绑定面能力。平面可无限绘制，datum 矩形只限制显示和点击范围。

锁定工作平面后，绘图以其 UV mm 为唯一编辑坐标，世界点由帧转换；相机旋转不会更改帧。进入前捕获完整 `ViewportViewState`，提供正视，允许旋转/平移/缩放；确认、取消和退出按当前文档会话恢复原视图，切换文档不能把旧相机或选择写回新文档。视线近平行时禁止鼠标落点并提示正视，数值输入仍可用。

平面悬停、选定和锁定是不同状态：悬停反馈平面及 U/V 方向，显式锁定后进入编辑；视口及草图树项显示活动状态。新建锁面后默认正视，之后切绘图工具不更换支撑、不重置相机。锁面和正视分别提供操作；可采用 F3 锁面与 Ctrl+H 正视，但必须先检查项目快捷键冲突，且不抢输入框焦点。这些键位来自 [Siemens 官方教程](https://media.plm.automation.siemens.com/solidedge/tutorials/robot-claw/text/Solid-Edge-Robot-Claw-1-Linkage.pdf)，不是强制兼容保证。空草稿可重新选面；非空草稿与已有草图不支持直接解锁后迁移，提示先完成或取消当前草图，不偷偷重解释 UV。

首包不具备 Solid Edge 完整的模型面支撑体验，此差距必须保留在验收记录中。已有隐藏草图可从树进入编辑，临时显示该草图；隐藏支撑不作为新建时的拾取候选，已有支撑的有效性应按身份/引用检查，不能把隐藏本身误判为引用失效。

## 编辑、约束和捕捉

草稿使用独立的 `PartSketchEditSession`，保存所属文档/session、源 revision、锁定支撑和帧、稳定 sketch/entity IDs、几何、约束、选中对象和本地 undo/redo。新建与编辑复用 `Sketch` 的中立数据及纯算法；不得共享二维工作台的对象、undo 栈或活动选择。工具的鼠标、键盘、字段值、拖动、删除和取消有明确状态；错误输入或无解保留可修正草稿，不偷偷替换成旧结果。

Esc 先取消未完成图元或还原本次拖动，再退出当前绘图工具；处于选择状态时清选择，不能丢弃整个草稿。右键结束连续绘制后返回选择，不提交模型。Enter 接受当前字段或工具步骤；“完成草图”和“取消草图”是独立明确操作。局部 undo/redo 按一次已接受的草稿编辑恢复几何、关系和尺寸；删除实体前列明受影响关系，作为同一草稿操作处理，持久化采用下文正式修订契约。

以锁定帧投影到屏幕进行实体/端点/尺寸命中；命中容差使用逻辑像素并随视图更新，不能用屏幕重叠冒充几何重合。候选重叠提供可见切换与高亮；隐藏对象不参与。支持对象捕捉、栅格显示、栅格吸附三个独立开关；世界/用户坐标系原点及可见端点、中点、圆心使用现有精确锚点。离面锚点默认拒绝，只有显式选择一次正交投影才投影并标示；数值输入不再次吸附，Shift 临时绕过。绘制中草稿锚点属于本草稿 generation，不能从上次预演借用旧对象身份。

另设独立的“自动几何关系”开关；首包推断草稿内水平、垂直和端点重合，关系符号先预示，再经验证随图元一起接受，允许撤销。对象捕捉本身只取一次坐标；外部模型、世界/用户原点和显式离面投影不自动生成关联约束。编辑时的下游实体预演是只读上下文，不能作为当前草图的持久上游支撑或关系，避免自依赖。相切、平行等关系显式调用已支持的求解能力，不承诺全部自动推断。Shift 临时绕过捕捉和推断，不放松已有约束。

驱动尺寸和几何关系通过现有 `preview_sketch_constraint` / `preview_sketch_constraint_update` / 拖动求解端口获取结果。输入区区分本次坐标/几何取值、持久驱动尺寸与参考测量；驱动标记和参考标记使用文字/图标，参考值只读且随几何刷新。长度、角度、半径等工具字段若仅决定初始几何，不标称持久尺寸；需通过显式驱动选项和成功求解生成尺寸记录。

显示未求解、欠约束、DOF=0、冗余、冲突、无解或求解器不可用。未知 DOF 不显示伪造计数；成功的欠约束草图可以完成；DOF=0 不代表唯一解。继承 ADR-010 的分支变化提示和确认，不能在尺寸变化时静默翻转几何。求解失败阻止接受该操作；下游失败阻止模型提交，保留输入和原模型。求解器缺失时普通无约束草图仍可绘制和提交；禁用需要新求解的操作，已存冻结结果仍可重放。

构造几何可选择、捕捉并参与适用约束，使用不同线型，不参与拉伸截面。合法开放草图可以完成保存；“草图可保存”和“截面可拉伸”分别判断。拉伸沿用现有封闭轮廓能力，定位开口、自交、分叉及相触等失败对象，不静默补线、不借模型边自动闭合。多轮廓/孔洞按现有内核语义解释，不在本包引入同步区域推拉。

## 预演、提交和生命周期

提交必须按编辑类型选择契约，不能统一替换创建命令：

1. 初始无约束草图及当前创建 handler 支持的初始关系/尺寸，可通过 `ReplayAppend(sketch.create)` 预演。
2. 已有数值尺寸修改从当前接受状态求解，通过隔离候选追加 `sketch.constraint.update@1` 并完整重建消费者；保留原历史及约束顺序，使用现有历史 undo/redo。增加显式关系走现有 `sketch.constraint.add` 版本契约。
3. `ReplayEdit(sketch.create)` 只用于可证明没有后续草图状态摘要/冻结解依赖的受支持修订，并预演全部消费者。不能通过绕过摘要检查、仅重写摘要或重复应用旧解来处理已有约束链。
4. **B1 待落定：** 任意已约束草图的加删实体、拖动或删关系，需要正式的冻结草图修订契约。推荐追加修订而非重写全部旧约束，须设计存活身份、被删引用、求解来源、冻结状态、消费者重建、审计和 undo/redo。未完成这项时不能宣称已有草图完整可编辑。
5. **B2 待落定：** 创建 handler 当前不能接受任意 user 几何关系；“全草稿一次完成”需要原子提交包或新版本命令设计。ADR-010 当前要求显式约束逐条确认；本设计不默默取消该规则，也不能在草稿尚未确认时提前落盘。必须在实施计划前解决确认与撤销粒度，或明确收窄交付范围并获用户同意。

确认前显示当前候选与影响；不能绕过后续拉伸或其他消费者。参数变化立即废弃旧成功预览、选择、捕捉和授权；回调及确认检查文档 ID、会话、revision、candidate ID/generation、草稿 generation 和完整参数。成功后一次性授权并经现有 Bus 原子提交，失败、取消、过期或重复确认不更改源模型、历史、审计、redo、版本及 dirty。保留原审计时间；草稿撤销、追加命令历史撤销和创建命令修订的撤销能力分别说明，不声称已有通用修订级 undo。

会话独立管理切文档、保存、关闭和退出：未提交草稿不能被静默丢弃或写入档案；沿用项目现有未保存草稿处置交互，在用户明确选择前不完成有损切换。关闭、取消、过期、源文档变化后断开事件和计时器，晚到结果不得更新新会话。已有草图查找和编辑必须定位所属创建命令，并保留与同一草图关联的约束及后续消费者；无法无歧义重放时明确拒绝，不按名称或序号猜测。

草图树提供定位、编辑和显隐，标明活动草图和消费者。完成后恢复模型视图并选中新草图，提供独立的拉伸入口；拉伸仍独立预演和确认。拉伸成功后保留草图身份和重新编辑入口，不自动删除、迁移尺寸或合并同平面的独立草图。

## 验收

**版本和收口门槛：** 以 [Solid Edge ST10 操作验收基线](../../design/solid-edge-interaction-acceptance.md) 的“ST10 验收规则”、M2-B 必验清单 ST10-S01–S15 和综合样例为准。下列工程用例继续保留，不能替代 ST10 操作对照和用户人工验收；未核对、未实现或未执行的子项不得标通过。图标采用 MyCAD 自有设计，其例外不免除命令可发现性和状态可辨认性的验收。

1. 空零件创建并确认偏置 datum → 选择并锁定它 → 在原三维视口捕捉原点画闭合轮廓 → 施加驱动尺寸 → 旋转检查、正视 → 确认草图 → 独立拉伸 → 保存重开 → 编辑尺寸并重建下游；检查精确帧、体积、关联、历史及审计。
2. 世界 XY/XZ/YZ 与旋转/偏置 datum 的 UV、正负法向、边界外绘制、相机姿态与正交/透视恢复正确；锁面后旋转不改草图。旧模型面查询与 datum 关联分别验证，不以旧查询声称持久绑定。
3. 对每个绘图工具、选中/拖端点/删除、草稿 undo/redo、驱动尺寸和适用约束，验证实际几何变化、数值输入及错误恢复；验证欠约束、冲突、无解、求解器缺失和下游失败。
4. 验证三个捕捉/栅格开关、精确锚点、离面拒绝/显式投影、重叠切换、Shift、隐藏对象、近平行视线、不同视角与 HiDPI；捕捉和显示使用同一来源与 generation。
5. 验证取消、失败、重入、重复确认、过期回调、切文档、关闭/保存和 v4→v6 迁移的原子性；比较源命令、审计、redo、revision、dirty、版本、几何及相机；确认和拉伸分别执行一次。
6. 使用真实内核、候选重放、档案与 Qt 交互执行路径级 lint、格式、严格类型和测试；最终集成才执行全量四门。另记录真实桌面人工操作；自动测试、截图和已有 M2-A 验收不能替代人工验收。
7. 开放且欠约束的合法草图能保存；不能拉伸时定位问题。构造线不改变截面或体积；未知 DOF、冗余、冲突、分支变化和求解器缺失分别验证。
8. 推断与捕捉分别启停；关系持久性经后续拖动验证；外部捕捉不引入自依赖。锁面后切工具不换面；Esc/Enter/右键和输入框焦点行为不导致误提交或丢稿。
9. 创建→约束→拉伸→后加关系→改尺寸，验证完整下游、参考值刷新、原历史不改及无求解器重开。另以替换原创建状态导致摘要失效为负例；B1/B2 设计落定后补任意几何修订与完整草稿提交的成功用例，不能仅靠拒绝操作通过验收。

## 2026-11-04 原位草图交互调整

根据桌面验收反馈，零件草图工具改为主窗口内嵌的上下文命令栏，按平面与绘图、约束与完成操作分组，捕捉及数值输入收起在选项中。启动草图时结束其他建模命令，草图进行中阻止启动冲突命令；工作区切换时隐藏命令栏并保留草稿。已确认的可见基准平面可在视口中选中后锁定。活动草图在实体前绘制，以便平面位于实体内时仍可见；绘制和拖动提供临时几何预览，未确认之前不修改文档。

以上参考 [Siemens Solid Edge 的平面锁定、动态绘图和关系提示教程](https://blogs.sw.siemens.com/solidedge/custom-shape-springs-in-solid-edge-part-2/)。这里实现的是零件中的平面草图，不声称实现 Solid Edge 的空间 3D 草图或全部同步建模能力。

## 2026-11-04 ST10 对标基准

用户否定了仅将对话框嵌入工具栏的处理方式，确认应重新组织三维零件环境的草图入口、绘图工具和画布交互，随后明确指定对标 **Solid Edge ST10**，图标不得复制。此要求优先于本文早期交互方案；它是后续整改基准，不是当前实现完成声明。

ST10 同时是设计与验收版本，正式验收要求统一维护在 [操作验收基线](../../design/solid-edge-interaction-acceptance.md)，不得仅在本设计文档声明版本而沿用旧版本的通过结论。

### 已确认的产品要求

- 三维零件环境提供明确的“创建草图”入口和常驻可发现的“草图”工具页；不得用“二维绘图”视图名称代替创建零件草图的入口。
- 图元工具覆盖点、直线、连续线、矩形、圆、圆弧和样条曲线。编辑、关系、尺寸、构造几何、平面和视图操作按职责分组；尚未实现的能力必须在进度记录中说明，不以空按钮冒充可用功能。
- 支持先选择模型平面再启动草图，以及先选择绘图工具再在画布中确定平面的入口。绘图工具可被发现、可启动，缺少平面时由当前命令引导用户选择。
- 绘制期间由画布提供候选平面、捕捉、临时轮廓、关系和尺寸反馈；命令参数按图元展示长度/角度、宽/高、半径/直径，输入值与临时预览一致。
- 区分基准面/实体平面、闭合草图区域和曲面建模，不将它们混成一个“面”工具。区域识别、填充、拾取及特征输入需要完整实现，不能用着色效果替代几何语义。
- 草图渲染应区分普通轮廓、构造几何、参考几何、选中对象和动态预览，并明确遮挡规则。先前统一穿透实体显示仅解决可见性，不代表完成对标。
- 以“新建零件 → 发现矩形工具 → 选面绘制 → 输入宽高/标注尺寸 → 选择轮廓生成特征 → 返回编辑并更新”为主要人工验收路径；测试通过不替代操作验收。

### 模式与架构

用户本次指定了 ST10，但未指定仅对标同步或仅对标有序模式；不得记录为用户已选择其中之一。资料和行为对照表应逐项标注所属模式。

MyCAD 当前保留草图驱动特征、Command Bus 唯一写入和历史重放。可以借鉴直接启动绘图工具的交互，但不能由此声称具备同步建模内核，也不能默默改成草图消费后不再驱动特征的语义。非共面的空间 3D 草图与零件中的平面草图分别核对。
