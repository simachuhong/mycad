# 工程图标准模板库与 DXF 导入

用户已批准：内置 GB、ISO 机械工程图模板，支持导入其他标准/企业 DXF 模板，保存到模板库并用于出图。本文件落实已批准的方案。

## 范围与方案

采用内置模板库 + DXF 导入。另一方案是同时建设可视化模板编辑器，成本更高，用户选择先实现模板库与导入。首期不含 DWG/DWT 解码或任意格式模板编辑器。

- GB、ISO 模板覆盖 A0–A4；按幅面和方向生成图框、标题栏、投影符号。标题栏提供图号、名称、材料、单位、版本、设计/审核、日期、比例和页码等字段。
- GB 图框依据 GB/T 14689-2008，标题栏参考 GB/T 10609.1-2008；ISO 图框依据 ISO 5457:1999（含 2010 修订），标题栏字段参考 ISO 7200:2004。模板标识标准版本；ISO 标题栏排布为 MyCAD 布局，不把字段标准说成唯一固定版式。发行前标准全文逐项合规审查与功能验收分开记录。
- 默认 GB 模板。保留“原有简单图框”选项，旧档案缺少模板字段时仍按原样重放。
- 首期 DXF 支持纸空间/模型空间选择、毫米/英寸等单位换算、显式幅面、原点偏移、图块展开、直线/多段线/圆弧/圆和 TEXT/MTEXT/ATTRIB；不支持的元素必须报告并阻止不完整导入。标题栏属性 tag 或手动指定的文字字段可映射为可填写字段。导入预览后保存到模板库。
- 用户库保存独立 JSON 模板，使用稳定 UUID 文件名和原子写入。库中损坏文件显示诊断，不阻止内置模板使用。模板内容完整嵌入 drawing.sheet.create/update 命令，不在重放时访问外部路径。
- 应用模板只更改图纸设置，不挪动/缩放已有视图。应用前预览，已有视图/文字越界时提示；保留标题字段值。绘图对象变更均通过现有 Bus。
- 画布、PDF、DXF 使用同一纸面图元，文字支持定位、旋转和宽度约束。模板与视图使用不同坐标尺度。

## 实现约束

core 仅 stdlib；DXF 解析在 formats；Qt 界面在 ui；保持零类型抑制。新增 sheet 命令 v2 接受嵌入模板，v1 不改变语义。无依赖升级，沿用现有 ezdxf/PySide6。复用当前 codex 分支工作区，保留用户未跟踪资源。

## 验收

内置幅面/边距/字段/投影符号；导入单位与图块变换、文本映射、未知实体拒绝；存档移除源文件后重开/撤销/重做；UI 导入预览取消不写文档、模板切换保留字段；画布/PDF/DXF 内容和物理尺寸一致；旧档案兼容、分层检查和严格类型检查。
