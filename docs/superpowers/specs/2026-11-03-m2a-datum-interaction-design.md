# M2-A：三维基准交互与共享定位设计（设计复核待实施）

日期：2026-11-03。状态：**Solid Edge 对标复核已补充，M2-A 设计复核待实施**。本文不是 GUI 已交付或测试通过的声明。

依据：[三维建模基础框架](2026-11-02-3d-modeling-foundation-design.md)、[ADR-016](../../adr/ADR-016-spatial-datum-archive.md)。M0/M1 已有开发 API、v6 引用和候选提交能力，不代表已有本文交互。本文细化 M2-A，不改变 ADR-016 的档案、主平面方向或唯一 Bus 写入契约。

## 1. 目标与边界

在零件三维视口中创建、预览、确认、取消、显示和选择相对坐标系、主基准面及偏置基准面；空白零件也可使用。提供后续草图和绑定孔共用的场景上下文、射线平面定位、UV 转换、精确捕捉及独立栅格控制。

M2-A 仅提供基准的基础树节点、选择和单对象显隐，不提前交付 M3 完整管理。M2-B 负责独立三维零件场景草图工作台，M3 负责角度/三点平面及坐标系完整管理，M4 负责跨消费者关联编辑和修复闭环，M5 负责真正非共面空间草图，M6 负责高级构造及关联投影。三维零件草图必须独立于二维绘图工作台；本包不得借用二维窗口冒充原位绘图。

偏置父对象只支持 ADR-016 已实现的 datum 平面；主平面只支持世界/已确认坐标系。受支持模型绑定面仍须另行扩展适配和验收，不能把所有 BREP 平面都列为可用父对象。每次基准创建独立确认；新建草图只能引用确认后的基准，不把两个操作合并确认，不依赖候选追加命令跨 stage 的临时身份稳定性。

## 3. 统一场景与引用契约

采用**统一场景交互快照**：几何端口提供网格、草图、基准和精确捕捉数据，app 层绑定来源，视口只消费相同上下文。拒绝“基准单独渲染、拾取仍用旧模型”的局部补丁。

- 上下文包含文档会话、源修订、来源类型（已提交/候选/只读历史）、候选 session/generation、对应快照与几何端口、允许对象类别及输入框架。无候选时相关字段为空，而不是沿用上一个候选。
- 坐标系/平面显示记录为后端中立的不可变 DTO，包含创建命令 instance_id、输出 role、名称、求值框架和来源状态。世界坐标使用 world 引用。对象名称不作外键；同名对象显示类型和身份短码，不能误选。
- 有限平面矩形只决定可见和命中区域，数学工作平面无限。显示正轴箭头、轴字母、平面名称、原点及 N 方向；不能只依靠颜色表达状态。空场景具备合理的初始视距和适合视图的基准尺寸，不能以 `viewport=None` 或空 mesh 表示没有内容。
- 坐标系、坐标轴、datum 面、BREP 面/边/点、草图实体具有不同类别；坐标轴选择必须可回溯其所属坐标系，不能伪装 BREP FaceId。模型持久引用与当前 revision 的临时拓扑 ID 分离。
- 渲染、hover、点击、重叠列表、对象捕捉、状态坐标和确认使用同一上下文。相机变化使屏幕命中缓存重算，但不改变模型 generation、工作平面或模型定义。
- 参数变化 stage、源修订变化、切文档、取消、关闭任务、重新打开/reset 或预演失败均废弃旧选择/捕捉/授权。结果回调到达时再次校验来源；晚到的旧结果不能覆盖新预览。
- 候选失败前缀只用于诊断，不可作为成功场景生成持久引用或确认。历史预览只读；进入创建前显式回到当前已提交状态，不能借历史对象跨状态引用。
- 目前 `viewport_protocol.py` 的网格/草图记录及 `viewport.py` 的候选显示不是本契约的完成证明；精确 BREP 顶点已有基础，但边折线和非可选草图 overlay 不等于 datum/曲线捕捉端口。

## 4. GUI、选择与方向

### 4.1 创建输入

从零件命令入口分别启动相对坐标系、主平面或偏置平面任务。无实体时入口也可用；父对象选取支持树、视口及任务内清单，使用相同的类型/来源校验。

- **相对坐标系**：名称、父坐标系（默认 world）、父系 X/Y/Z 平移 mm、旋转角度。为消除含糊，首版角度约定为父固定轴旋转，列向量 `R = Rz(rz) × Ry(ry) × Rx(rx)`，UI 标示“依次绕父 X、Y、Z”；角度单位度。转换成三个正交右手轴后提交，档案不另存欧拉角。预览显示父/子框架和变换后的原点；轴向量可只读核对。后续编辑不能依赖欧拉角唯一反解。
- **主平面**：名称、已确认坐标系、XY/XZ/YZ。轴映射以该坐标系的轴表示：XY 为 `(U=X,V=Y,N=Z)`；XZ 为 `(U=X,V=-Z,N=Y)`；YZ 为 `(U=Y,V=Z,N=X)`。这由 ADR-016 固定，与 Solid Edge 的 Front 名称或旧说明文字无关。
- **偏置平面**：名称、已确认 datum 父平面、有符号距离 mm。`O_child = O_parent + d × N_parent`，U/V/N 不变。输入正、负、零距离都能预览；“反向”操作等同 `d → -d`，不是翻法向。单独翻面和面内转向不作为本包新命令字段。
- 解析非有限数、缺字段、错误父类型、非刚体轴系均给出字段级错误，禁用确认；绝不悄悄修成世界坐标。UI 显示输入所属框架，不能让激活另一坐标系重新解释已输入参数。名称校验沿用已有命令规则，不为同名对象另造身份。

这里的位姿输入约定是 MyCAD GUI 设计决定，未宣称 Siemens 使用相同控件或欧拉角约定。

**共享定位的首个实际消费者是相对坐标系原点。** 创建任务的原点 XYZ 字段旁提供“在平面上定位原点”入口；这不是独立建模命令，也不等待 M2-B 或 E3-B：

1. 先确定父坐标系。进入定位步骤后，从世界 XY/XZ/YZ 或当前文档已确认的 datum 面中明确选择工作平面，并点击“锁定”。世界主面是运行期数学框架选项，不隐式追加 datum 命令；已有 datum 的选择可用树、视口或清单。选择平面期间只选支撑，锁定后才接受落点；支持显式返回重新选面。
2. 锁定后显示平面来源、UV 数值、世界 XYZ、对象捕捉/网格显示/网格吸附开关及“正视工作平面”。鼠标移动给出定位预览，点击锁定一个点；也可直接输入 U/V。数值输入取得当前落点的优先权，之后移动鼠标不能覆盖它，需显式“重新拾点”才恢复鼠标模式。Shift 仅在未按中键的鼠标定位中临时绕过吸附；Shift+中键仍是平移，不接受落点。
3. 工作面框架将 UV 转为世界点 `P_world`，父坐标系刚体逆变换再得到命令字段 `origin_mm = R_parentᵀ × (P_world − O_parent)`。该值是父系局部坐标；即使工作面与父坐标系不同，也不把工作面 UV 当作父系 XY。父引用、旋转轴参数保持不变。定位来源是一次取点，不给坐标系命令增加 datum/顶点关联字段。
4. 点击“采用位置”只更新创建草稿中的 XYZ 和候选预览，仍需外层任务的“确认”才由 Bus 写入。定位步骤的“取消”恢复进入该步骤前的原点草稿；外层取消丢弃全部候选。直接编辑 XYZ 时退出鼠标取点模式，采用数值，不再次吸附。切换父坐标系会废弃未采用的定位结果并要求重新定位，不能用旧父框架解读旧结果。
5. 源修订、候选 generation 或文档会话变化时，未采用落点和旧回调立即失效；必须在新的有效上下文中重新定位。采用位置后重新 stage 得到新 generation，旧落点的来源令牌不再用于后续操作。即使没有任何实体，也可通过世界平面和 UV 数值完成此流程。

主平面创建继续只选择父坐标系及平面枚举，偏置创建继续输入有符号距离；本包不增加“过鼠标点偏置”等其他构造语义。上述定位入口为 MyCAD 为满足本包可操作验收作出的设计选择。

### 4.2 双向选择、预高亮和重叠

基准树按坐标系/平面组织最小节点，底层执行顺序仍来自历史。树中选中对象在视口显示选中态；视口点选同步到对应树节点并滚动定位。hover 仅显示预高亮和名称/类型/来源提示，不改变正式选择，不提交命令。树选择基准不能触发历史回退预览。

重叠或共面的对象必须可逐一选择：提供候选列表或明确的循环入口，显示名称、类型与必要身份短码，切换项时对应预高亮。顺序按有效可选类别、屏幕命中距离、深度及稳定身份消歧；相同场景/视角结果稳定。当前父选择步骤不允许的类别不进入列表。显式重叠选择可以选被其他对象遮挡的**可见对象**，不可绕过“隐藏”状态选择幽灵对象。清空、取消和移出视口均清除预高亮；不能把离开的候选遗留为鼠标下一次点击结果。

### 4.3 显隐、过滤、锁定、相机

基础显隐是每文档 UI 状态，不写建模历史、不使档案 dirty、不改变父引用有效性；重开可恢复默认显示，本包不承诺保存视图配置。隐藏 datum 后视口不命中、不捕捉它；树节点仍存在并标明隐藏，可从树选择、检查或显式用作合法父对象。隐藏对象的树选择只显示“已隐藏”状态，不自动解除隐藏。隐藏父平面不能让子平面、草图或实体消失/失效；子对象有自己的显隐状态。

选择过滤按任务收敛：相对坐标系父步骤只收 world/坐标系；主平面同上；偏置只收 datum 平面。普通选择可区分坐标系/基准/模型对象。调整过滤后清除不再合格的临时命中，并提示重新选择；视图选中不等于激活输入坐标系，不等于锁定工作平面。

共享定位使用一个明确锁定的工作平面并显示名称、来源与锁定状态。悬停另一平面不能自动改锁；用户显式重新选择后才更新。**锁定平面不锁相机**：中键或其他视图操作可任意旋转、平移、缩放；相机不受世界 Z 约束也不能改写工作平面 O/U/V/N 或已有 UV。提供“正视工作平面”，只改相机，不另建基准。近平行视线禁用鼠标落点并提示正视，数值输入仍可用。M2-B 再接入完整草图开始/退出及相机恢复生命周期。

## 5. 共享定位、捕捉与栅格

射线与工作平面求交拒绝非有限数据、零方向、近乎平行及交点位于射线后方；不能回退到世界 XY 或上一次有效落点。平行判定使用归一化方向的角度容差，不用随视距变化的世界长度。UI 显示当前世界 XYZ 与工作平面 UV；前后转换遵守同一右手框架。平面共面容差使用项目几何容差并明确 mm，屏幕捕捉阈值不能充当几何共面容差。

| 捕捉/定位类别 | M2-A 契约 | 后续或排除 |
| --- | --- | --- |
| 端点/顶点 | 精确 BREP 顶点或解析草图端点；标出类型和对象 | 不用网格三角顶点替代 |
| 边中点 | 开放边按有效裁剪范围弧长的一半求值；圆弧按弧长中点；直线即端点均值 | 任意曲线在端口不能可靠计算时禁用并说明，不取采样折线中点；完整闭合圆无唯一中点 |
| 圆/圆弧中心 | 几何端口给出解析中心；中心可在可见曲线范围外 | 椭圆/样条中心等不自动冒充圆心 |
| 框架原点 | 世界、可见坐标系和 datum 平面精确原点 | 坐标轴箭头端点/有限面角点不是建模锚点 |
| 交点、延伸交点 | 本包不承诺；明确列为 M2-B 后续定位扩展，先定义共面、参数范围及去重 | 屏幕交叉不等于三维几何交点 |
| 垂足、切点、象限、最近点、推断对齐 | 本包不承诺；M2-B/后续草图定位按各自定义单独设计验收 | 不把 IntelliSketch 的推断或持久关系当作已有对象点捕捉 |
| 离面锚点 | 默认拒绝；显式开启“一次投影到工作平面”时，沿 N 正交投影，并标出原点、投影点和投影状态 | 不静默丢弃 Z，不创建持久关系；曲线投影/复制及关联归 M6 |

捕捉锚点带对象归属、种类、精确世界坐标及上下文令牌，由相同几何端口计算。UI 只负责屏幕距离、允许类别和可见性筛选。首版采用 12 个逻辑像素阈值（须覆盖 HiDPI）、对象捕捉默认开、栅格吸附默认关；这些是 MyCAD 决策。多个合法锚点先取屏幕距离，完全并列依次原点/端点、中心、中点，再按稳定身份；重叠列表允许显式改选。对象命中优先于栅格；无命中才使用栅格，二者都无则用射线交点。Shift 临时绕过对象与栅格吸附，松开恢复开关原值。

对象捕捉只产点值，状态标示“一次定位”，不建立永久顶点/边关联。父 datum 的持久引用另走命令参数，不可混用。数值框输入的 mm 值直接预览与提交，不在鼠标移动、失焦或确认时二次吸附；非法数值保留错误提示，不用上次捕捉值替换。

**对象捕捉、栅格显示、栅格吸附三个状态独立**。允许隐藏栅格但保持吸附，状态栏必须清楚显示吸附仍开。栅格属于锁定平面的 UV，原点与轴默认等于该框架；主网格可随缩放按 1/2/5 序列改变绘制密度，吸附间距使用明确显示的 mm 值，不因相机缩放偷偷改变。高级重定位栅格原点、旋转栅格、点/线多模式列 M2-B 后续定位扩展，不阻塞本包。E3-B 复用这些服务时，孔 UV 仍属于 ADR-015 来源框架，不能被用户坐标系替换。

## 6. 预演、引用失效与事务闭环

任务生命周期为：输入/选父 → stage → 预演中（禁确认）→ 当前成功预览（可确认）或失败（禁确认）→ 明确确认/取消。参数变化立即使上次成功预览和授权失效；确认前校验文档会话、来源修订、候选 generation 和变更摘要，取得一次性授权，交由原 Bus 提交。重复点击、旧回调、切文档后的旧确认不能重复提交或污染另一文档。

首次需要 v6 时在候选中准备迁移，并在预览摘要显示档案版本变化及将创建的对象/父对象；v4 的身份提案包含活动和 redo 命令，v5 的已有身份不得重分配。确认仅通过源 Bus 的既有原子采用路径生效，禁止直接改 Document。取消、任务关闭、源文档切换或预演/提交失败丢弃候选，恢复源场景；若源修订已经改变，恢复当前源状态而非覆盖回旧快照。

父对象只能引用同文档之前已确认的正确输出。缺失、前向、循环、错误 role/类型、旧 generation 或失效绑定来源均拒绝，并显示失败命令、参数路径、父来源身份和原因；不靠同名、最近面、数组索引自动修复。候选失败前缀可供定位错误，但不准确认部分成功。由其他入口发生的父改参、undo/redo、重新加载和 reset 必须同步更新基准求值和交互上下文。M2-A 验证已有重放链的这种行为，不新增任意中间节点删除/抑制或级联删除；改绑 GUI 和跨消费者影响列表分别归 M3/M4。

失败与取消需比较档案版本、序列化历史和审计、instance_id、redo、revision、dirty、几何及基准求值表。成功必须只采用一次变更；undo/redo 沿既有命令规则，不把原子多改动提交误称新增“整次历史修订一步撤销”。保存、另存、重开及重放必须保留父身份、轴方向和几何结果；选择、相机、hover、栅格开关不进入模型档案。
