# 外部二维块库：技术评估与设计草案

日期：2026-11-26。状态：方案评审稿，尚未实施、未宣称验收通过。

用户已确认：必须实现外部块库，用于本地块库与共享目录之间跨图纸复用。本文把旧计划中“外部块库后续实现”提升为新的开发工作包。以下标记为“建议”的产品选择尚待本方案评审；不扩大到嵌套、属性或动态块。

## 1. 结论与方案选择

推荐：**版本化单块文件＋目录库＋插入时复制到目标图纸**。

| 方案 | 适用性与代价 | 结论 |
| --- | --- | --- |
| 整张 `.my2d` 作为库 | 可携带多个定义，但读取要重放历史，混入无关图元，修改和共享粒度过大 | 保留打开旧图纸后另存块的路径，不作为库的存储单位 |
| 每块独立文件、目录管理 | 易复制、备份、分类；支持无实例定义；无需服务端；需增加资源格式、索引和导入规则 | 推荐；用户已确认本地库＋共享目录方向 |
| 数据库/服务端资产系统 | 可做权限、审批、协作和版本发布；引入服务、账户及并发治理 | 当前跨图纸复用不需要，另立后续项目 |

本期建议共享目录只读：支持添加本机已挂载的共享路径，浏览、搜索、预览和插入。发布者在应用外分发块文件；应用内多人共同修改、网络认证和共享目录写锁不纳入本期。若需要应用内共享库写入，必须先补并发发布方案。

图纸内的块与库文件互相独立。库文件变化、删除或离线不改变已插入图纸；BEDIT 修改当前文档定义，也不回写库。新库版本再次插入时作为新定义处理，不自动更新既有实例。

## 3. 用户操作与首期交付

### 3.1 保存到库

1. 创建块成功后，或在“块管理 → 当前图纸”选择定义，点击“保存到块库…”。无需先插入实例；纯文字块也适用。
2. 选择本地库分类，填写名称、说明、标签，查看以局部原点为插入基点的预览。
3. 导出定义本体，不把选中实例的世界位置、旋转或比例烘焙进去；预览明确“块定义，基点 (0,0)，比例 1”。实例烘焙另存不纳入本期。
4. 成功后显示实际保存位置，并立即在库中可见；失败保留输入，清楚说明原因，不能仅在命令栏打印异常。

可从未完成草稿的合并视图保存已创建的定义。这里是立即写入外部资源：窗口明确提示“已保存到块库；取消当前草稿不会删除库文件”，不隐式完成草稿，不改变文档命令历史。

本地修改采用“另存新条目”默认路径。同名允许跨分类/目录存在，界面显示来源；同目录同名默认确定性增加后缀。更新现有条目是显式操作，校验打开时的文件摘要并保留可恢复旧版本；本期不自动覆盖来源文件。

### 3.2 从库使用

- “块与组”工具栏增加“块库”；`INSERT` 窗口提供“当前图纸 / 外部块库”入口。现有块管理继续管理当前图纸定义，增加“保存到块库”。
- 库窗口建议为可调整大小的普通窗口：目录/分类、名称搜索与列表、所选块预览与详情；名称、说明、对象数量、单位和来源路径可读，内部 ID 只在诊断详情。
- 支持“仅导入定义”和“插入图纸”。插入进入原有画布定位流程，输入位置、角度、正等比比例；基点随鼠标预览，Enter/右键确认，Esc 取消。
- 每次确认放置形成一个暂存/持久动作。首次放置包含资源＋定义＋实例，再次放置只增加实例。取消尚未确认的放置不遗留定义、样式或图层。
- 完成后反馈“已插入块 X；当前草稿尚未提交”或“已导入定义 X，可用插入块放置”，避免把暂存误报为存盘。
- 建议 UI 命令别名 `BLOCKLIB` 打开库，`WBLOCK` 将当前选择的块定义另存库文件；两者为 UI 工作流，不把文件系统副作用注册为文档重放命令。无明确块定义时进入选择窗口。

## 4. 文件、资源与存储

### 4.1 原生文件

建议扩展名 `.myblock`，UTF-8 JSON，`format="mycad.block"`、`version=1`。独立于 `.my2d` 存档版本，不包含命令历史或可执行内容。

字段：`format/version/asset_id/name/description/tags/units/definition/text_styles/layers/content_sha256`。

- `asset_id` 是新分配的 hex UUID；创建一个新库条目时生成，更新该条目时保持。
- `units` 首期只接受 `mm`；局部原点就是插入基点，不重复存储一个可能与坐标不一致的 base point。
- `definition` 复用现有几何、文字序列化，名称必须与顶层名称一致。只允许一个定义，无嵌套和实例。
- 仅保存实际使用的文字样式、非 0 图层及必需的默认表项；不携带源文档当前图层/样式选择、尺寸、约束、组、图像、阵列、外部引用。
- 样式必须完整描述有效字高、宽度因子、字体族/样式、字体文件名；剥离源电脑绝对路径，只保留文件名。文件名不等于内嵌字体，缺字/替代需要提示，不能承诺跨机排版完全一致。
- 本期不嵌入字体二进制；用户可通过既有字体管理补齐资源。标签和说明作为纯文本显示。
- `content_sha256` 对规范 JSON 的 definition/text_styles/layers/units 计算：排序键、固定分隔、UTF-8、禁止 NaN/Infinity。校验前使用现有类型解码及重新编码，统一数值表达；元数据说明和标签不影响内容版本，名称属于 definition 因而影响版本。载入重算并比较，不信任外部摘要。
- 建议上限：单文件 16 MiB、几何＋文字 50,000 项、所有多段线/样条合计 500,000 个点、文字内容合计 4 MiB UTF-8、JSON 嵌套深度 32；标签最多 32 个、每个 64 字符、说明最多 4,096 字符。遇到未知版本、重复键/身份、非有限坐标、缺少样式/图层时整条拒绝，给出字段位置。深度限制需在完整对象构造前检查；文本中的括号/转义不能计为 JSON 结构。

### 4.2 目录与可靠性

默认本地库使用 `QStandardPaths.AppDataLocation / block-library`；缩略图和可重建索引使用 `CacheLocation / block-library`。QStandardPaths 调用只在 UI 层，向存储层传入 Path。Qt 将持久应用数据与可清除缓存分开，符合此用途：[Qt 文档](https://doc.qt.io/qt-6/qstandardpaths.html)。

- 支持添加/移除库根目录、分类子目录、手动刷新；移除目录配置不删除文件。
- 本地可写库支持改名、更新、移入本库 `.trash` 和恢复。文件名用资产 UUID，显示名写在内容中，避免中文名称和路径字符混用。旧版本保存在排除扫描的 `.history` 中。
- 单个目标文件用同目录临时文件、完整校验、flush/fsync、原子替换；原文件在失败时保留，临时文件清理。更新/改名/回收采用应用进程间锁和 expected digest；检测冲突后停止并要求刷新。恢复旧版本同样核对当前文件摘要：V1→V2 的回执不能在文件已变成 V3 后覆盖 V3；回收恢复要求原路径空闲，冲突时保留回收文件。所有恢复操作也遵守根目录只读设置。共享根只读，不宣称此本地锁对任意网络文件系统提供多写者保证。
- 文件扫描在后台分批进行，不阻塞绘图；符号链接循环、断开的目录、权限错误和坏文件逐项报告，其他正常条目仍可用。共享库离线时明确显示不可用，不把旧缓存冒充可插入数据。
- 索引和预览可删除后重建；缓存键含文件内容摘要、预览版本和字体解析结果。预览取已校验内容；插入前再次读取校验，文件变化时更新预览并重新确认。
- 候选准备后冻结实际资源字节/摘要，进入放置后的资源变化不悄悄替换本次内容；提示本次使用已预览版本。下一次选择再刷新。

## 5. 导入、重名和重复使用

### 5.1 事务边界

导入先解析为不可变值，再完成依赖协调、目标身份规划及隔离候选验证。资源、定义和首个实例通过现有 `drawing.objects.batch@1` 一次提交，最低文档版本沿用 v8；旧文档走现有显式升级候选。

仅导入定义使用相同流水线，不制造临时实例。预览与提交使用同一组固定 ID；历史记录内保存实际资源和定义数据，重放不读取块库路径。正常重放、优化重建和重开撤销都必须通过。

草稿存在时写入 `DrawingCollectionSession` 同一时间线；读取 `_collection_view`，校验 document revision 与 session checkpoint，过期不得自动套到新图纸。取消草稿撤回导入的全部图纸状态，不删除外部库。

### 5.2 身份和同名

不能只按名称复用，也不能让每次插入都产生“副本”。采用可重放的来源记录，不使用连续候选编号搜索：

1. 新增不可变 `BlockLibraryOrigin(definition_id, asset_id, content_sha256)`，在 DrawingCollectionState 和 Snapshot 中保存只读 tuple。一个定义最多绑定一个库来源；记录只作来源证据，不指向外部路径，不提供内容可信保证。
2. 新增内部 `drawing.block_library.bind@1`，最低存档 v8，参数为这三个字段。只允许独立二维文档、已有定义，重复完全相同绑定为无变化，其他重绑拒绝。加入 batch 白名单；首次导入按资源→定义→绑定→可选实例组成一条 batch。新定义及所有成员分配新 ID，并在预览前冻结。
3. 再次导入先枚举当前全部相同 asset_id/content_sha256 的来源记录，对比候选定义的实际内容与依赖。比较忽略定义/成员/曲线点的对象 ID 和定义显示名，按有序成员位置规范化身份；几何类型与坐标、拓扑点序、构造标记、文字字段、解析后的样式内容以及非 0 成员图层属性必须一致；0 层比较继承标记，不把某次实例所选图层纳入定义等价判断。来源或摘要相同本身不能替代内容核对。
4. 多个等价候选时按定义 ID 的 hex 字典序稳定选择；没有等价候选才分配新身份创建。BEDIT 修改后的来源记录保留，但内容不符便不复用；删除定义同时删除其来源记录。这样删除先前导入版本不会遮蔽其余可复用定义。
5. 新定义同名冲突用既有“名称 副本”“名称 副本 2”规则，确认前显示。定义已由用户改名但实际内容未变时可以复用，并显示当前文档名称。同内容但不同 asset_id 不自动合并；同 asset_id 不同内容版本不覆盖旧实例。
6. 来源记录跟随 reset、候选复制/安装/失败回滚、普通重放、优化重建、草稿快照、撤销/重做恢复。绑定命令进入普通六字段审计历史，**不新增 `.my2d` 顶层字段，也不改变旧块命令 v1 参数**。不支持新命令的旧程序明确报告不支持。
7. 同文档复制实例仍共享定义及其来源；本期跨文档旧剪贴板/DXF 不携带库来源，沿用普通块身份规则。通过这些途径进入图纸的定义不冒充库导入记录；再次从库插入时可能创建另一个定义，界面报告重名，不按外观相同猜测来源。

此路线比仅派生 ID 多了一个持久状态维度，但消除了删除/重开后漏认定义的问题。必须先通过“导入→BEDIT→再导入→删除最早定义→保存重开→再插入”的定向用例，再接 UI。

### 5.3 资源协调

- 文字样式复用 `reconcile_text_style_ids`，按实际内容复用，冲突分配新 ID/名字，不修改目标已有样式；目标当前样式不切换。
- 0 层成员始终保留 0 的继承语义，不把源文档 0 层属性覆盖到目标 0 层；实例落在用户选择的目标可编辑图层。
- 非 0 层同名同属性可复用，同名异属性另建带后缀层并报告；重复导入需找到此前同源名称后缀且属性一致的层，避免每次多一层。
- 隐藏、冻结、锁定成员/目标层维持既有校验，整次拒绝并指出具体层；不通过自动解锁或自动克隆可编辑层绕开限制。
- 依赖协调只生成变更方案，取消和候选失败不能提前向主文档添加资源。

## 6. DXF 与外部兼容

原生 `.myblock` 是可靠主存储；DXF R2010 是交换入口，DWG 不在现有提供方能力内，不伪装支持。

- “导入 DXF 到库”：复用实际文件读取结果，列出普通命名块，支持无实例定义；允许选择若干条，逐条完整预检并给出接受/拒绝原因。
- “将模型空间保存为一个块”另有显式选项：用户指定名字和基点；只允许支持的几何与文字，任何不支持对象都要求用户处理，不静默忽略。尺寸匿名块、公差基准专用 INSERT 不列作用户块。
- 同一文件内多个普通块独立入库；不支持嵌套、属性、动态块、外部依赖、非平面内容。DXF 中 BLOCK 与 INSERT 并非同义，不能仅按当前 INSERT 统计定义：[ezdxf 说明](https://ezdxf.readthedocs.io/en/stable/blkrefs.html)。
- 单位沿用已有 DXF 单位解析，未声明时显式确认，统一换算 mm；已有基点归一逻辑只执行一次。
- “导出所选库块为 DXF”：一个原生 BLOCK 加一个原点、角度 0、比例 1 的展示 INSERT，带所用图层和文字样式。展示实例只是交换预览，不写回库。
- 预览来自实际输出字节读回；报告名称转换、字体替代和不支持外观。不能把有损结果标为原生无损保存。
- 直接把 `.my2d` 当库扫描会涉及后台重放及进程级内核隔离，本期用“打开原图 → 块管理 → 保存到库”覆盖，不增加扫描重放路径。

## 8. 风险与必须证明的结果

1. **重复使用**：A 图导出、B 图连续插入两次、保存重开再插入，只含一个未修改的对应定义，三实例共享它；样式/图层冲突也成立。
2. **图纸独立**：删除/断开库后 B 可打开、编辑、分解、撤销重做；库更新不改变旧实例。
3. **草稿**：未保存草稿经圆角/修剪及确认约束后创建“保留源对象”块，可直接入库；取消源草稿不删除库；目标草稿插入/取消不留资源。
4. **跨对象事务**：库导入首个实例的定义、图层、文字样式一起回滚；保存重开一次撤销仍成立，后续普通草图修改不丢库导入状态。
5. **UI 反馈**：没有块、只含文字、无实例定义、坏文件、缺字体、同名冲突、目录离线都有可读提示；窗口不能无响应或确认后悄悄失败。
6. **共享只读**：两个进程浏览同一目录互不影响；文件换版后刷新预览；读取中被替换不能得到半个资产；本地库并发写检测冲突。
