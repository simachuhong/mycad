# 二维工作区空间整合

用户最新要求取代上一版左侧导航方案：图形信息并入右侧功能 Tab，减少画布底部占用，二维同样提供 CLI 与 AI 对话窗口。

- 单个右侧可浮动/关闭功能坞，页签为绘图、UCS、修改、图形。保留选择联动与图中尺寸编辑。
- 坐标输入、结束/闭合连线、多段线完成移入绘图页；撤销/重做移入修改页。完成草图/取消放入上方操作行，隐藏侧栏仍能操作。
- 主窗口底部共享可收起 Tab：信息、CLI、AI 对话、计划。二维首次进入默认只显示标签条；点击展开，再点当前标签或收起按钮折叠。沿用原生停靠、浮动和关闭。
- 信息页记录完整提示；状态栏保留一行最新提示。鼠标坐标高频变化不写日志。切换二维/三维不重建 CLI、对话草稿或计划。
- CLI 复用原串行执行与文档绑定；保留模型 Bus 与确认规则。
- AI 后端当前不存在，已向用户询问本轮范围；未指定连接参数前，提供明确未连接的窗口与禁用发送，不编造回复或默默发送数据。
- 不重启现有 MyCAD，不改动已有未提交建模工作，不提交混合工作树。
