# 球体基本元素补齐设计

日期：2026-11-03。状态：用户已批准实施；完整验收以实际验证结果为准。

## 目标与范围

按照 `.omo/evidence/next-package-analysis-2026-11-03.md` 的次序，先独立交付球体命令及桌面交互闭环，再另行设计 M2-B 零件草图。球体提供 `feature.sphere@1`，参数为正有限半径 `radius`、三个有限数的世界球心 `center`（默认 `[0,0,0]`）和 `mode`（默认 `new`，另有 `add`、`cut`）。单位为 mm。拒绝布尔值、未知参数和非有限数。

## 方案与取舍

- 推荐：球体作为现有基本体命令接入同一 Bus、几何布尔、隔离预演、来源和 GUI 工作流；复用共享定位服务。这样延续现有事务与重放契约，但必须同时处理球面来源和精确捕捉。
- 仅增加内核/CLI：改动较小，但不能满足分析要求的桌面预览、定位和确认闭环。
- 与 M2-B 合包：能并行推进草图，但把两个独立交互的验收与回归范围混在一起。

## 行为与边界

`new` 替换当前实体，`add` 合并，`cut` 切除；空模型 `cut` 拒绝，其他布尔结果遵守既有单实体和失败规则。界面明确说明 `new` 的替换语义。支持世界 XYZ 数值、世界原点和可见精确对象锚点的一次定位；数值不得重新吸附，不得静默投影离面点，Shift 绕过捕捉。复用现有定位服务及其上下文和显隐规则，不引入第三套坐标语义。

球体无平面来源角色，不能将球面误作为可绑定平面。完整球体的球心由几何端口提供，绑定可见实体与当前场景；不从缝线或实体质心猜测。裁切后球面中心不在本包承诺范围。布尔对原有平面绑定的影响沿用保守拓扑演化：正确保留或明确失效。内联布尔工具球体、半球和角度截断不属于本包。

预览采用现有候选 session/generation 和 Bus 确认机制；参数变化、取消、切文档及失败使旧预览失效。确认前不更改源历史、redo、dirty 或档案；保存继续遵循既有版本策略，不因新增命令无条件升级。支持撤销/重做、历史改参、保存重开及 STEP/STL 导出。保持 core/geom/ui 分层与零类型抑制。

## 验收

1. R=10、球心原点的球体体积为 `4πR³/3`，包围盒尺寸为 20 mm；任意 XYZ 球心及完整球体中心锚点准确。
2. 验证参数、未知命令、三种布尔模式、相离/切空、失败回滚、来源平面和隔离重放；不得凭球面制造平面角色。
3. 验证 GUI 预览、数值和捕捉、Shift、隐藏对象、不同视角、连续修改与旧候选拒绝、确认和取消；失败及取消保持历史、redo、dirty 和模型。
4. 验证撤销/重做、历史改参、保存重开和 STEP/STL 导出；针对改动路径执行 lint、格式、严格类型和测试，最终集成再运行全量四门。桌面人工操作单独记录，不以自动测试或截图冒充。

M2-B、E3-B 保持后续工作；本设计不宣称已交付或通过验收。
