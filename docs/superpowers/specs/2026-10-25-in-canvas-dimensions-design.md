# 图内尺寸标注重做

用户于 2026-10-25 确认整体重做。批准范围：图内拾取、捕捉、动态预览、点击放置、连续操作、Esc 取消；拖动尺寸线及文字、双击就地编辑；参考/驱动尺寸明确区分；智能、水平、垂直、对齐、角度、半径、直径、连续、基线、坐标和弧长工具；草稿和已提交图形操作一致；位置保存、撤销及重放。

## 方案

采用现有 PySide6 画布上的命令控制器及内嵌命令条。保留现有中性约束 DTO、求解器和 Bus，把放置点、文字位置、投影方向作为尺寸的可选属性。普通标注默认参考尺寸；显式启用驱动后通过原有求解预览及确认写入。已提交几何仍通过 Bus；草稿通过本地事务，完成草图时提交。

将模态对话框仅改为非模态无法提供图内引用和放置；在侧栏复制原表单同样不能满足鼠标工作流，因此均不采用。原几何关系约束窗口不属于本次尺寸入口，保留。

## 验收

每种按钮须有实际鼠标路径、独立图标、提示和选中状态。尺寸预览必须包含线、箭头、文字并随鼠标变化，平移缩放可用。捕捉须对应稳定的端点、圆心、顶点或线段引用；拒绝跨草图引用和无效几何。连续沿上个终点、基线沿第一个起点，坐标沿用户选取的基准点。双击编辑使用画布内数值框；文字与线位置分别可拖动。失败或取消不得写历史；草稿、已提交尺寸均可撤销且旧档案仍可读取。
