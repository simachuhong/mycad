## 下一轮开发任务细化

### 复核结论

下一轮以 **P2-12 与 P2-19 联合收口** 为主线。108 条全链执行是已完成的成果，但“当前几何正确”和“上次选中的设计对象仍正确”需要不同断言。之前将 RC-02 整体描述为实现完成偏宽，本节收窄其结论，不撤销已有 184 项定向通过记录。

本次判断来自当前工作树的源码与测试阅读；没有重跑已确认的测试，也没有据此宣称新增功能通过。

| 复核发现 | 代码证据 | 开发含义 |
| --- | --- | --- |
| 扰动只检查存在可选面，没有保留并解析原引用 | `tests/scenarios/test_parameter_perturbations.py::_assert_expected_geometry` | 不能证明孔、面或边没有静默换对象；补指定对象的引用断言 |
| 自动生命周期测量的是整体体积 | 同文件 `test_supported_part_lifecycle_roundtrip` | 加孔径、孔位、壁厚等局部断言，特别是位置改变但体积不变的横向孔 |
| STEP 回读只返回实体数和体积 | `tests/helpers/step_roundtrip.py::read_step` | 增加 BREP 有效性、包围盒和关键孔洞/局部尺寸，防止等体积错误模型通过 |
| semantic 引用主要是运行时 generation + 谓词重新查找 | `core/semantic_refs.py`、`geom/selectors.py::resolve_semantic_face` | 明确“查询选择器”和“绑定设计对象”两种契约；不能给旧 rank 查询偷偷附加身份含义 |
| 面/边绑定到最新运行时特征，重放使旧 generation 失效 | `geom/kernel.py::bind_semantic_face`、`core/identity.py` | 缺少跨重放的来源特征与语义角色定位；单加 split/merge 错误码不够 |
| 实体来源已有，但不是面/边演化关系 | `geom/body_provenance.py::operation_origins` | 不直接把 BodyOrigin 用作面分裂/合并证据；演化信息必须在操作执行时捕获 |
| 目录仍有历史范围描述 | `examples/representative_parts.json` 与 `tests/ui/test_p2_g_part_workflows.py::_slot_plate` | “无专用槽命令”不等于无法用草图构造槽板；逐条复核 6 个拒绝和 6 个候选，不能硬保留旧分类比例 |

### 技术路线取舍

1. **继续增强位置、半径、面积谓词**：改动较小，可用于候选筛选和后置检查，但无法单独证明分裂/合并来源，也无法区分几何相同的不同设计对象。不足以关闭 P2-12。
2. **来源特征与语义角色 + 有限操作演化 + 几何后置检查**：推荐。先用真实基础零件证明一条垂直链，再扩展到已承诺的操作。无法确定唯一继承时停止并提供修复，禁止按距离或 rank 猜测。
3. **一次建立通用拓扑命名系统**：涉及任意曲面、所有布尔与复杂重构，范围和验证成本超出当前 Phase 2 收口。作为后续演进，不作为本轮实现目标。

推荐方案仍需先验证锁定后端能否提供足够的操作历史：即使一次布尔能得到演化关系，重放重建了源形状后，还需要来源特征/角色重新建立绑定。清理、合并同域面和结果归一化也可能改变映射，必须把这些步骤纳入原型。

N1/N2 已在本轮落实为**有限引用契约和操作局部演化原型**，不是持久拓扑命名系统：rank/最大面是每次按谓词重查的查询；绑定引用附带 owner feature 与 topology generation，owner 更换或 generation 失效时必须报错，不把 rank 当身份。单次 cut/fuse 的 OCCT history 可以给出来源与结果索引关系；这些索引只在该次操作有效。切削工具面贡献到零件上的结果记为 `generated`；既有参数面改形记为 `modified`；原生历史缺失仍记 `unknown`，不得推断为删除或合并。后端无关 DTO 位于 `mycad.core.topology_evolution`，OCCT 适配只留在 `mycad.geom.topology_evolution`。

本轮对 N1 的验收矩阵覆盖查询随尺寸变化、绑定 generation 漂移、重复最大面歧义、owner 替换失效，以及拓扑保留/修改/生成/分裂/合并/删除关系；对应测试为 `tests/geom/test_semantic_selectors.py` 与 `tests/geom/test_topology_evolution.py`。目前 operation-local mapping 已接入 `feature.hole`（包括草图孔）和 `modify.boolean_cut`，并用切孔、槽切、双盒融合及完全切除验证。它不会更新/持久化 `SemanticFaceRef`，也不覆盖圆角、倒角、相交、阵列等操作的跨特征 lineage；这些属于 N3～N5，不能从原型测试推定已完成。逐项预期和边界见 [N1/N2/N6 实施记录](../.omo/evidence/task-N1-N2-N6-topology-2026-10-29.md)。

N6 已加强 108 条扰动记录的圆柱局部直径预期；18 个受支持样本的 STEP 回读另检查实体有效性、包围盒尺寸/中心及预期圆柱直径。生命周期回归在 undo 后先与“已修订命令链去掉最后一条命令”的独立重放前缀比较，再 redo 核对扰动结果。该局部尺寸集目前覆盖存在的圆柱面直径，不声称验证所有孔位、孔数或拒绝样本导出策略。详细证据见 [N1/N2/N6 实施记录](../.omo/evidence/task-N1-N2-N6-topology-2026-10-29.md)。
