# ADR-015 — 首条可重放绑定面孔

状态：2026-11-02 用户授权 E2-B 开发后实施。范围及验证见 [E2-B 验收](../../.omo/evidence/e2b-bound-face-hole/acceptance.md)。

## 决策

注册 `feature.hole@3`，完整保留 @2 的查询孔和草图孔分支，增加显式绑定分支。注册表仍默认选最高版本；@1/@2 schema 不变。只有绑定分支要求文档已通过 ADR-014 的 Bus 提案显式升级到 v5，以及支持绑定能力的内核。普通查询/草图孔不触发格式升级。存档加载在 reset 前检查绑定所需格式及 canonical UUID；无效引用返回命令、历史序号、参数路径和原因。

绑定数据为 `{kind: "bound_face", source_instance_id: "<32 位小写 hex UUID>", role: "box.+Z"}`，作用域是当前文档。支持 box 六个轴向平面角色及 cylinder.top/bottom。不得保存运行时 TopologyId、结果面下标、rank 或最大面作为绑定身份；没有对应面时拒绝，不退回查询。

绑定孔可使用既有 `center`（当前有限面面积中心）、`point`（全局三维点），或新位置 `{kind: "local", uv_mm: [u,v]}`。局部原点为来源 primitive 原始面的中心，法向为其外法向。Z 面 u 为全局 +X，X/Y 面 u 为全局 +Z，v = normal × u。上游尺寸/位置变化重新构建来源框架；后续裁切不移动框架。点必须位于当前有限面区域，不能落在已切掉的区域或孔内；不自动投影或吸附。孔径、盲孔深度和贯穿切削复用现有几何实现。

## 演化与拾取

几何层从具有命令实例上下文的原始 box/cylinder 精确输入播种角色，用原生 Boolean history 跟随 primitive add/cut、孔和 inline boolean_cut。primitive add 的工具来源也通过原生 fuse 映射，允许分离的同尺寸实体；非身份路径保留原有运算。候选替换和草图再生必须一起采用精确候选 Part 与其原生面映射，不能单独 deepcopy 映射。工程图来源在隔离环境重放；来源角色不会泄漏到宿主绑定表。

只接受唯一 preserved/modified 后继，并复核平面法向及位置。分裂、合并、删除、缺失 history、未知来源、漂移及不支持的特征均给出失效原因；不猜测后继。新切削生成面、圆柱侧壁以及非 primitive 角色暂不可绑定。原生索引仅在单次输入/输出演化内有效，重放时重新生成。

`interactive_face_binding(TopologyId)` 从当前精确拾取面取得绑定描述，不经过查询/rank 转换。过期、其他内核或无法唯一归属的面不能产生引用。查询选择器 API 保持原义。绑定失败沿用 Bus 事务回滚，既有历史、审计、redo 和几何不被半成品替换。

## 边界

这是一条通过开发 API 启用的真实 Bus 消费链，不是通用拓扑命名。默认桌面文档仍为 v4；普通建模选面仍走既有查询/交互选择器。通用参数表单可表示新 schema，但没有自动把普通拾取转换成绑定，也没有升级确认、失效定位及用户修复工作流；这些属于 E3。不扩展边绑定、跨零件绑定、任意草图生成面的角色、任意 fillet/chamfer 后继或 Solid Edge 全部引用语义。P2-12/P2-19 仍为 partial。
