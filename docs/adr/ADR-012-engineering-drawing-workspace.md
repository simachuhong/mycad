# ADR-012：工程图领域、投影隔离与输出

Status: Accepted 2026-10-27
- 关联：ADR-001、ADR-007、ADR-008、ADR-011

## Context

用户批准将草图、工程图、3D 工作区分开，并在图中生成关联三视图与标注。T0 实测决定采用进程隔离，保持既有分层和历史重放不变量。

## Decision

工程图是三维零件档案中的独立图纸/视图/标注对象，通过 `drawing.sheet.*`、`drawing.view.*`、`drawing.annotation.*` 命令与 Bus 写入、撤销和重放，保存为 v3。它不改写平面草图，也不增加实体几何修订。组放置用一个含 `views` 数组的命令实现一次撤销；现有批事务失败回滚语义不变。

中央保留平面草图、工程图、3D 三页，按显式工作区身份路由命令，不销毁隐藏页。工程图布局/标注预览在画布进行，只有确认动作写入 Bus。

实测 QThread 内的 HLR 可阻塞 GUI 心跳超过 250 ms，故采用预热的单工作进程。由串行执行单元取得不可变 BREP 快照，进程返回无 Qt/CAD 对象的中性曲线 DTO；接收时核对文档会话、模型指纹、视图和请求代次。旧结果不能覆盖新状态。取消可停止发布与排队，不能强行中断正在 OCCT 内运行的任务；崩溃后显式重试重建工作进程。

几何来源使用 HLR 的 NewSOldS 历史与 IsSame 校验构造证据；核心层执行保守的唯一匹配。圆柱轴加材料侧区分外圆与内孔，半径不参与身份谓词。多个候选拒绝猜测。该策略支持有限的尺寸修改，不承诺任意拓扑编辑的持久命名；相同几何替换的语义身份仍是限制。

画布、标注、DXF/PDF 消费同一不可变 DrawingScene。DXF 保留精确曲线及纸空间比例；画布/PDF 使用误差有界的矢量三次曲线。QPdfWriter 实测存在整数纸张边界与文本 Unicode 映射问题，以锁定的桌面依赖 pypdf 归一化精确 MediaBox 与每个标签 ActualText，保留 Qt 字体和矢量绘制。输出校验完整、最新、无失关联场景后原子替换文件。

## Consequences

单独进程增加首次启动时间与内存，缓存有界且随窗口关闭清理。新增 pypdf 仅属于 desktop extra，并更新 NOTICE。工程图存档升级要求新版读取器；v1/v2 读取保持兼容。相同几何来源不能保证跨语义替换的身份区分，歧义时要求人工重新关联。
