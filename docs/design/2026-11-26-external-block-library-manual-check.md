# 外部二维块库操作与人工验收

当前记录为待人工验收。离屏 GUI 与定向自动测试不能替代真实桌面操作；AutoCAD 2023/2025 的交换结果也尚未填写。公差人工验收独立记录。

## 操作入口

1. 在独立二维图纸中完成块创建；块允许由几何和文字组成。已有图纸内定义不必先插入实例。
2. 点“块管理”，选中定义后点“保存到块库”，填写名称、说明、标签和分类并保存。`WBLOCK` 也可进入保存工作流。保存会立即写入本地库：即使之后取消当前草稿，库文件仍在。
3. 在另一二维图纸中，点“块与组”工具栏的“块库”，或输入 `BLOCKLIB`。也可从“插入块”进入块库；图纸没有块定义时，`INSERT` 直接打开块库。
4. 在块库中选来源、搜索并选块。选“仅导入定义”，之后可使用“插入块”；或选“插入图纸”，填写角度、正比例与图层，在画布指定插入点。按 Enter、右键或左键确认，Esc 取消。名称或图层冲突会先显示处理方案，可取消导入。
5. 共享源在块库窗口用“添加共享目录”配置；选择该来源即可浏览。首期共享源只读，移除目录配置不会删除目录及文件。本地库支持重命名、移入回收站和恢复。库文件所在位置会在保存成功消息中显示。
6. “导入 DXF”选择支持的块；“DXF 模型空间入库”需指定名称和基点；“导出 DXF”显示实际输出预览后保存。未知单位须明确选择。损失或不支持对象会提示。

图纸内定义是导入时的副本。库之后发生更新、离线或删除，不会自动修改已保存图纸；库操作不会进入图纸撤销历史。字体文件不随库打包，缺少字体时检查替代提示及最终显示。

## 支持范围

| 对象或能力 | 首期行为 |
| --- | --- |
| 几何、文字及所需图层和文字样式 | 保存并跨图纸导入 |
| 本地库、只读共享目录 | 浏览、预览、搜索及导入；本地可管理文件 |
| 旋转、正等比缩放 | 插入时指定 |
| 块内关键点 | 可捕捉；不建立块外持久关联 |
| 尺寸、公差、图片、约束、阵列入块 | 不支持；保留源对象时复制当前几何，不复制约束 |
| 嵌套、属性、动态块、镜像、非等比缩放 | 不支持 |
| DXF | 支持范围内原生几何与文字块；不支持的块整体拒绝并报告；DWG 不支持 |

## 可重建样例

在项目目录下执行，将参数替换成**不存在的全新目录**：

```bash
uv run --no-sync python docs/examples/block-library/generate.py /tmp/mycad-library-examples
```

脚本生成几何与中文文字、非 0 图层、纯文字、同名不同内容、损坏文件和嵌套 DXF。添加该目录为共享源：正常 `.myblock` 应显示，损坏文件应报告；导入嵌套 DXF 时应报告父块不支持，受支持子块可独立选择。所有示例均为无实例的库定义，可直接导入。
