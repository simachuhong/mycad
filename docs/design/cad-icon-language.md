# CAD 图标规范

本轮修正来自用户对主工具栏图标语义和一致性的反馈。

## 绘制与状态

- 自有 SVG，24 × 24 网格，主体 1.5 单位线宽，圆端点和圆连接；不借用系统图标来代表建模命令。
- 深灰轮廓表示实体，蓝色表示操作、方向或作用区域；不同命令必须有不同轮廓，不能只依靠颜色区分。
- 明亮/暗色主题有显式配色，禁用状态使用低饱和灰色。图标引擎按 Qt 请求的尺寸渲染矢量内容。
- 主工具栏使用 24 px 图标并保留中文文字，按文件、历史、视图、计划、建模分组。
- 菜单和工具栏复用 QAction，图标、启用状态和快捷键保持一致。

## 语义映射

| 操作 | 图形 |
|---|---|
| 新建 | 带加号的折角文档 |
| 打开 | 打开的文件夹 |
| 保存 | 磁盘及保存槽 |
| 撤销 / 重做 | 方向相反的回转箭头 |
| 适应窗口 | 四角边界与向外展开箭头 |
| 返回当前模型 | 实体与返回箭头 |
| 着色边线 | 着色实体及清晰轮廓边线 |
| 待确认计划 | 清单与待处理时钟 |
| 拉伸 | 截面成体、原轮廓虚线及法向箭头 |
| 旋转 | 旋转轴、截面与绕轴箭头 |
| 孔 | 实体上的孔口及孔轴 |
| 圆角 | 实体的圆滑过渡边和作用区域 |

源文件在 `src/mycad/ui/icons/`；集中加载、主题和禁用状态在 `cad_icons.py`。这些是本项目绘制的通用 CAD 图形，不是 Solid Edge 品牌资源。

本轮完成图标预览板视觉检查，以及改动路径的 lint、格式、严格类型检查；未增加或运行自动测试。

## 全界面覆盖（后续统一）

- 命令库、特征菜单、主工具栏和结构树历史节点共用 `COMMAND_ICONS`。八个内置命令分别映射到明确的建模图形；未知插件使用独立的扩展图形，不按名称后缀猜测。
- 命令库分类与结构树分组分别使用特征、修改、文档、基准、草图、实体等语义图形。命名组使用分组图标；“（空）”占位不画实体，避免造成存在几何对象的错觉。
- 树图标为 20 px；原有命令 ID、历史序号与点击行为保留。图标名存放在独立数据槽，主题切换只更新现有节点的图标，不重建树。
- 文件、编辑、视图、工具、计划、帮助菜单的动作及子菜单均有明确图标；顶层菜单栏继续使用文字。菜单中的勾选、禁用与快捷键仍由 QAction 管理。
- 特征菜单列出八个现有建模操作；主工具栏中的四个快捷入口直接复用同一 QAction，不各自维护启用状态。
- 确认、取消、关闭、保存参数按钮使用同一 SVG 图标入口，替换字体中的对勾/叉号及应用自建对话框的系统按钮图标。纯文字按钮可以继续使用文字，不为装饰强加图标。
- 内核、命令参数、历史存档与模型结果不受图标主题影响。

新增语义包括选择实体/面/边/顶点、着色/边线/线框/诊断网格、标准方向、投影方式、轴/网格、面板位置、配置、测量及帮助。资源总计 68 个，集中列举并校验名称，避免缺失时悄悄显示错误图形。

检查记录：实际 Qt 窗口遍历 64 个可见菜单动作、8 个命令库叶节点及当前法兰存档的 3 个历史节点，无图标遗漏/命令映射不一致；深浅主题切换后树节点身份、展开/选择状态和文档命令数保持不变。补充检查了未过滤命令库的深浅主题小尺寸截图。8 个源码路径的 lint、格式、严格类型检查通过。
