## 结论

三维建模已有可复用的几何、命令历史、候选预演、空间基准和部分草图关联编辑基础；**M2-B 的三维草图交互仍未完成，未达到本次 ST10 验收门槛**。最优先的工作是草稿状态正确性、工具入口与选面流程、动态输入、画布尺寸及区域到特征的衔接。绑定孔产品流程和通用失效修复仍有明显缺口；空间草图、完整同步建模和高级曲面属于后续独立工作包。

## 2. 本次审查发现（按影响排序）

### R1 — 未完成图元未阻止完成草图（P1，已复现）

已有矩形后启动直线，只放第一点并显示临时线段，再执行预览与完成：确认仍启用，工作台关闭，仅保存矩形。未完成图元没有明确的完成/放弃步骤。`preview()` 只检查已接受实体，`confirm()` 不检查待输入状态，见 `part_sketch_workbench.py:996`、`:1100`。这不满足 S11 的命令状态要求；处理时应让用户明确结束或取消当前图元，不把它静默遗漏。

### R2 — 预览轮廓与自动约束落点不一致（P1，已复现）

直线从 (0,0) 画到 (10,0.05)：动态预览终点是 (10,0.05,0)，接受后水平关系把终点改为 (10,0,0)。`_preview_drawing()` 使用原点位，`place_uv()` 另外执行水平/垂直推断，见 `part_sketch_workbench.py:497`、`:688`。应共享同一份“解析后的几何＋推断关系”结果，供显示和接受使用；不能仅增加关系图标。

### R3 — 绘制中撤销后残留临时轮廓（P2，已复现）

完成一条线，再开始矩形并移动鼠标，执行撤销：已接受实体和待输入点均归零，临时矩形仍有 5 个点，视口仍登记 1 条曲线。`undo()/redo()` 清 `_points` 却未清 `_rubber_band_curve`，见 `part_sketch_workbench.py:905`、`:911`。需连同切工具、Esc、拖动和预览失效统一清理临时状态。

以上三个结果由[可重运行探针](../../.omo/evidence/st10-3d-review-2026-11-04/probe.py)和[JSON 结果](../../.omo/evidence/st10-3d-review-2026-11-04/probe-results.json)确认；使用临时内存文档与 offscreen Qt，检查真实命令/草稿/显示数据。没有渲染帧缓冲，且包含对内部方法的诊断调用，因此不是用户桌面录屏或 ST10 行为证明。本轮仅报告，未修复。

### R4 — 草图入口与工具组织仍不通过（P1，源码确认且用户已退回）

`main_window.py:796` 把草图放在特征菜单，`:856` 的“二维绘图”仍触发 `_on_sketch_start`；`part_sketch_toolbar` 默认隐藏，锁面前绘图按钮禁用。没有常驻草图工具页及先选绘图工具后选面的完整入口。倒角等已实现命令的主入口也不统一。对应 S01–S04。

### R5 — 动态输入、画布尺寸与区域交互存在实质缺口（P1，源码确认）

- 只有折叠选项中的 U/V 坐标输入，没有按线/矩形/圆变化的长度角度/宽高/直径参数锁定，见 `part_sketch_workbench.py:157`。
- 尺寸和关系通过 `SketchConstraintDialog`；活动草图显示方法主要绘制曲线与 H/V/重合符号，没有画布尺寸拾取编辑闭环。已有已提交草图尺寸文字显示不能代替活动草图标注工具，见 `:609`、`:917` 及 `viewport.py:3035`。
- 未接入闭合区域填充、区域拾取与稳定区域输入；拉伸入口当前以已提交草图 ID 为输入，见 `main_window.py:2602`。后端轮廓/孔洞分析可复用，但不能把屏幕填充多边形当成建模轮廓。

### R6 — 图元和编辑能力不能从二维工作台直接认定完成（P2，源码确认）

三维零件工作台工具集只有选择、直线、连续线、矩形、圆、圆弧。能显示已有 `SplineEntity` 不代表能新建样条；`core.sketch` 也没有独立点图元。`core.sketch_edit` 已有部分变换、偏移、延伸、分割和修剪算法，但三维工作台尚无相应完整入口与选择流程。点需要中立模型/保存/拾取/消费者排除契约，不能用零长线伪装。

### R7 — 草图透显只是临时策略（P2，源码确认）

`viewport.py:478` 的活动草图线关闭深度测试，统一覆盖实体。普通线、构造线和选中颜色已有区分，但前后遮挡、参考几何、临时预览和重叠选择尚无完整验收规则。应与区域绘制及拾取一并处理，不能先改变着色再让拾取沿用另一套几何。

### R8 — 通用历史编辑预览与失效修复尚未闭环（P1，源码确认）

`right_panel.py:123` 的“预览影响”只校验参数并展示差异和下游数量，没有进行完整候选几何重放；这与 M2-B 独立工作台已具备的候选预演不同。E3-A 后端无需重写，需接入历史编辑、绑定孔与有限修复 GUI。通用候选失败虽有结构化信息，当前草图只显示命令序号/原因文字；还缺受影响对象定位、替代引用选择及全部下游成功后的整体确认。

依赖：T1/T2。退出条件：鼠标和数值均能准确绘出 40×30 mm 矩形；锁值后移动鼠标不改变已锁尺寸；开放合法草图仍可保存。

### T4 — 画布尺寸与关系编辑

- [ ] 从画布选几何放置尺寸，选已有尺寸改值；区分驱动/参考，显示尺寸线、文字和必要关系标记。
- [ ] 复用已有求解端口和版本化约束命令，增加画布命中与操作状态；关系冲突、分支改变、DOF 未知或求解器缺失有准确提示。
- [ ] 选取、尺寸更新、拖动预览、撤销/重做及下游预演始终对应当前 generation。

依赖：T2/T3；不重做已实现的约束提交与冻结解。退出条件：直接在画布把矩形宽度从 40 改为 50，参考值同步，错误/取消恢复原状态。

### T5 — 真实区域识别、绘制、拾取与特征输入

- [ ] 先确定中立区域结果与引用语义：所属草图/版本、组成边界、孔洞、有效性；持久输入须可重放，不能存屏幕多边形下标。
- [ ] 从精确草图几何生成可选区域，复用后端闭合/自交/包含判断；构造线排除、开放草图不误填；显示网格只服务渲染。
- [ ] 同一数据源驱动填充、悬停、选中和拉伸/旋转输入；处理前后遮挡、临时/参考几何样式及重叠选择。
- [ ] 打通区域→特征→返回草图修改，保留草图/消费者身份。

依赖：T2；与 T3/T4 的完成结果集成。退出条件：矩形、带孔截面、多区域样本都能明确选择并产生正确实体；开口/自交不得生成误导性区域。先完成契约再做着色，避免后续推翻拾取和特征参数。

### T6 — 补齐图元及编辑工具广度

- [ ] 点：中立图元、档案版本/兼容检查、显示/拾取/捕捉、适用约束及不参与拉伸边界的规则。
- [ ] 样条：复用已有准确三次 B 样条；接入三维创建、控制点编辑、预览/取消和重放，明确支持的是控制点式还是其他方式。
- [ ] 修剪、延伸、偏移、镜像及适用变换：复用现有纯算法，新增零件画布选择/预览/接受与关联引用处理；保留算法的真实支持边界。
- [ ] 补齐工具分组和自有图标，查漏已有倒角等命令入口；逐个工具跑正确与失败用例。

依赖：T1/T2；尺寸关联依赖 T4，影响区域的编辑需接 T5。可先做独立点/样条契约，但不抢在矩形主路径之前扩大交互实现面。退出条件：S01/S02/S05 所列工具均可实际操作，未支持子场景明确记录，不用二维测试代替三维验收。

### T7 — M2-B 主闭环集成与用户复验

- [ ] 执行 S01–S15 的当前范围项，以及 40×30×10→50×30×10 的完整样例（体积 12000→15000 mm³）。
- [ ] 覆盖偏置/旋转 datum、模型面查询支撑、带孔截面、构造线、多实体、保存重开、历史撤销/重做、失败取消和切文档。
- [ ] 明确一次完成草图可能生成多条审计命令时的撤销粒度；不把原子提交宣传为一步撤销整个操作。
- [ ] 改动路径检查完成后做最终全量集成；真实桌面/缩放/图标与用户复验独立留证。完整引用修复相关子项若仍缺，维持未完成，不据“主路径通过”关闭整个三维版块。

依赖：T1–T6。交付：可以综合测试的零件草图工作流；这是第一阶段产品里程碑，不等于全量 ST10 或完整同步建模。

### T8 — 通用历史预演与绑定孔 GUI（E3-B）

- [ ] 通用历史编辑接已有 E3-A 候选重放，显示真实结果/失败前缀及影响，不再仅展示参数差异。
- [ ] 绑定孔显式入口、候选面拾取、固定来源框架 U/V、对象捕捉和栅格；首次档案迁移在候选中预演并随孔原子确认。
- [ ] 复用 T2/T3 的选择和输入规则，保留普通查询孔与绑定孔的语义区别；源版本/候选 generation 过期立即失效。

依赖：已有 E2-B/E3-A、稳定共享定位和 T7 主流程。退出条件：建立绑定孔→改上游→孔位正确保持或准确报告失效→保存重开；失败取消不改源文档。

### T9 — 基准管理扩展与有限失效修复（M3/M4、E3-C/D）

- [ ] M3：角度/三点平面、多坐标系编辑/树管理、显隐、影响预演；一次定位与真正关联来源明确。
- [ ] M4：结构化失败定位到对象和参数；候选前缀中重选仍可持久表达的有效角色，预演全部下游后整体提交。
- [ ] 模型面草图持久支撑单独定义；split/merged 子面表达先于任意子面重选，禁止最近面/rank/临时 ID 兜底。
- [ ] 做 E3-D 实机闭环，补齐 S13 对应范围项，记录仍不支持的拓扑变化。

依赖：T8 及现有身份/引用基础。M3 扩展与“现有角色范围内”的修复可分别交付：**无需等角度/三点平面全部做完才实现已有基准的有限诊断修复**；需要新平面或新子面类型的修复才等待其契约。

### T10 — 后续能力按各自依赖推进

- [ ] M5 空间草图：独立 XYZ 点/线/折线、坐标系定位、真实长度、保存重放；再扩空间曲线/约束。依赖稳定的三维交互和空间框架，不能用倾斜平面草图冒充。
- [ ] M6 构形引用：关联投影、边提取/求交、曲线法向等高级基准，依赖相应持久引用与失效处理。
- [ ] 曲面/扫掠/放样：先定义结果类型与多输入依赖，再做具体消费者；合法开放曲面不能靠删除现有实体有效性检查来接入。后续修剪/缝合/加厚、抽壳/拔模和高级连续性分别验收。
- [ ] STEP 导入和长计算：可重放导入、单位/来源/自包含数据与后续直接编辑一起规划；逻辑取消与硬中断能力分别说明。
- [ ] 同步建模：按既有 S0 技术探针→S1 受限直接编辑→S2 三维关系传播→S3 混合建模路线单独立项。S0 在 M2-B 和有限 M4 稳定后即可开展，**不必机械等待所有 M5/M6/曲面工具完成**；不占用当前 M2-B 的验收结论。

后续能力排序依据是依赖和可验收样例，不按工具按钮数量或底层 API 数量估算工期。原高级特征方案和[同步建模评估](../../.omo/evidence/synchronous-modeling-feasibility-2026-11-03.md)保留作专项输入，不将其中“建议”当作已开发。
