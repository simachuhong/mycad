# 二维修改命令对照检查

初查日期：2026-11-04；代码复核：2026-11-05。范围：独立二维文档中的常用几何修改；参考 AutoCAD 官方文档和本项目代码。此检查不是 AutoCAD 实机或用户验收；“部分”也不表示全部对象类型、选项或输入方式已验证。版本基线现为 AutoCAD 2023 或 2025 完整版，见 [专项验收基线](autocad-2d-interaction-acceptance.md)。

用户确认先以官方文档和现有录像记录差异；录像中无法确认的操作标为待核对，不推断为实机验收通过。

## 交互和已知差异

| 命令 | 当前情况 | 对照与差距 |
| --- | --- | --- |
| MOVE 移动 | 草稿支持预选/命令先行、基点和目标点、预览、Esc、撤销；已提交对象支持跨草图及与草稿混选移动，命令栏支持 MOVE 和坐标；画布空格可结束对象选择或确认首点位移 | [MOVE 2025](https://help.autodesk.com/cloudhelp/2025/ENU/AutoCAD-Core/files/GUID-47CE7325-84C0-4414-80A3-29DC98392709.htm)：支持基点、第二点、首点作为位移及坐标输入。捕捉、各种确认方式与动态输入仍须逐项对照。 |
| COPY 复制 | 二维工作区支持连续复制、命令内 U 回退、首点位移、COPYMODE 偏好及命令内 Mode/Multiple；Enter、右键或 Esc 结束，数值位移入口为单次 | 命令内 Array 等选项尚未实现；[AutoCAD 2025 COPY 文档](https://help.autodesk.com/cloudhelp/2025/ENU/AutoCAD-Core/files/GUID-1CF9287F-06E8-4D03-8377-2E130862FE02.htm)描述首点位移与多次复制，具体交互仍待实机核对。 |
| ROTATE 旋转 | 草稿及可见已提交图元支持中心、方向、键入角度、可选参考旋转和预览；混选经候选暂存并可撤销 | 参考旋转以勾选框启用，并非逐提示命令选项；参考角的数值输入、复制选项与精确命令行行为待核实。 |
| MIRROR 镜像 | 草稿、可见已提交图元及混选支持两点镜像轴与预设保留/删除源；已保存对象的删除源变换经候选重放 | [MIRROR 文档](https://help.autodesk.com/cloudhelp/2026/ENU/AutoCAD-Core/files/GUID-595277C8-9B87-4CFB-A3AF-769537A22F3D.htm)在轴指定后询问是否删除源对象；本项目提前用复选框设置。该参考为 2026 文档，2025 实机待核实。 |
| OFFSET 偏移 | 草稿以数值面板和符号距离执行；样条不支持 | 缺少指定距离后点选对象及侧向、连续偏移等交互；已提交对象不可修改。 |
| ARRAY 矩形/环形阵列 | 草稿以数值面板生成线性或环形副本 | 当前线阵是单方向步距，未确认二维行列、路径阵列、关联阵列及交互式夹点编辑；已提交对象不可参与。 |
| TRIM 修剪 | 草稿支持点选、拖动路径及 Shift 临时延伸；仅部分几何类型 | [TRIM 2025](https://help.autodesk.com/cloudhelp/2025/ENU/AutoCAD-Core/files/GUID-B1A185EF-07C6-4C53-A76F-05ADE11F5C32.htm)有快速/标准模式、边界选择、围栏和交叉等；本项目无完整模式及选项，且目标和边界来自草稿，样条不支持。 |
| EXTEND 延伸 | 草稿支持部分直线、多段线、圆弧端点延伸 | 缺标准模式中显式选择边界及完整选项；已提交图元不能作为当前实现的目标/边界，需按对象类型核对。 |
| 分割 | 基于交点拆分部分草稿直线、矩形边和多段线 | 不等同 AutoCAD BREAK 任意两点打断或 BREAKATPOINT，无法视为二者完整实现。 |
| ERASE 删除 | Delete 支持删除草稿或纯已提交选择，已提交对象经候选重放及撤销；依赖约束随对象删除，锁定或隐藏的依赖约束阻止操作 | 已提交对象与草稿混选仍明确拒绝；命令式 ERASE、更多依赖和完整选择选项未完成。 |
| FILLET 二维圆角 | 已支持两圆间不修剪圆角，包括已提交圆；可设置半径 | 目前不是完整 FILLET：两直线、线与圆弧、修剪选项等仍需对照和开发。 |

MOVE 的指针正交锁定已补充：鼠标位移沿较近轴，明确输入坐标和对象捕捉优先于正交，与 [AutoCAD 2025 正交模式文档](https://help.autodesk.com/cloudhelp/2025/ENG/AutoCAD-Core/files/GUID-C3B5D7B3-8057-4D8B-A3A2-0F5F0778BF37.htm)对照；其他捕捉和键盘组合仍需逐项核对。

移动已提交图元使用可重放修订历史，提交时会把低于 v6 的文档升级至 v6；旧版程序需支持 v6 才能读取升级后的存档。草稿与已提交图元混选的历史边界见[专项设计](2026-11-05-mixed-drawing-move-history.md)。

## 常用命令缺口

以下是常用二维几何修改范围，不是 AutoCAD 所有命令的穷举。依据 Autodesk 的[对象修改命令清单](https://help.autodesk.com/cloudhelp/2027/ENU/AutoCAD-OnBoarding/files/ACD_FOUNDATIONS_MAIN7.html)与二维编辑器可见命令和实现对照；清单为 2027 文档，具体 2025 差异待核对。

当前未发现完整独立二维等效命令：**SCALE 缩放、STRETCH 拉伸、CHAMFER 二维倒角、BREAK 两点打断、BREAKATPOINT 单点打断、JOIN 合并、EXPLODE 分解、LENGTHEN 调整长度、路径阵列**。FILLET 已有两圆不修剪的部分实现；项目里的三维圆角或同名分割不代表这些二维命令已经完整实现。

## 优先修复与验收

1. 统一草稿与已提交图元的选择、预览、事务和撤销；支持多草图及混选，失败时全部回滚，覆盖约束、锁定图层、保存重开与重放。
2. 对 MOVE 逐项复核数值、坐标、空格确认和命令行，测试对象捕捉、零位移、Esc、无效约束；记录存档版本升级。
3. 修复 COPY/ROTATE/MIRROR/OFFSET 等对已提交对象的限制，逐条覆盖命令先行、预选、预览、确认、取消和撤销。
4. 补常用命令和 TRIM/EXTEND 模式；按具体对象与选项逐条测试，不能仅按按钮名称验收。
5. 按官方文档和现有录像保留差异记录；材料未覆盖的交互标为待核对，不视作实机验收通过。
