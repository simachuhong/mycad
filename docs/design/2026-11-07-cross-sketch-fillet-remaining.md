# 跨草图圆角关系余项

## 当前边界

二维独立文档把每次提交的草稿保存为独立 `Sketch`。草图内约束仍只引用本草图；新增的文档级相切记录分别保存草图及图元身份和几何分支。隔离连通分量求解、原子修订和重放已支持；修剪和不修剪圆角均可为已保存来源与新草稿圆弧建立关系。已保存图元与混合草稿的移动、旋转和镜像路径可固定选中目标并求解关联草图；已保存草图的驱动尺寸支持连通分量预览和原子提交，参考尺寸跟随几何刷新。线、圆及圆弧的已保存控制点拖动已接入关联预览和提交，混合草稿中已保存或待保存控制点也支持异步关联预览及暂存。不支持的约束、不可编辑图层或无解情形会拒绝提交。更多工作平面、图元及约束组合和混合拖动失败保护仍待验证。

## 后续实现

1. 定义可版本化的文档级关系记录：稳定关系身份、双方草图和图元身份、关系类型、工作平面及约束分支；新增可重放命令，不能修改旧命令语义或直接改文档状态。
2. 定义约束组件：查找受影响草图，在共面条件下转换到同一二维工作平面，建立一次临时求解；将解转换回各自局部平面，校验相切、端点、约束冲突和几何分支，再通过单个候选事务确认所有草图修订与关系命令。
3. 把相关草图后续拖动、尺寸修改、删除、修订和历史重放接入组件，检测失效引用和环；失败时整体回滚，禁止只更新其中一个草图。处理加载旧档、保存/重开、撤销/重做、跨文档切换及依赖特征重建。
4. 继续补齐自动关系开关、锁定图层、方向相反的共面工作平面、不同草图与多次圆角、约束过度和求解失败的窗口测试；验证版本升级与旧档不变。修剪和不修剪圆角的混合暂存已接入自动跨草图关系，部分混合变换已接入联动求解，其余混合编辑仍待实现。

## 其他命令余项

- `FILLET` 的 `P` 多段线选项支持不修剪和修剪模式：前者保留原对象并生成独立圆弧，后者保留原对象身份并以 bulge 保存精确圆弧段。相邻直线间的相切圆角可重设半径或以零半径移除；不适合处理的角点和其他圆弧保留。冲突角点按顶点顺序处理，尚需与参考软件核对其具体取舍。
- [Autodesk 关于整体多段线圆角的说明](https://help.autodesk.com/view/ACD/2027/ENU/?caas=caas%2Fdocumentation%2FACD%2F2014%2FENU%2Ffiles%2FGUID-357499AE-7EF5-4228-8DE9-7FA6A8F11C27-htm.html)也提到长度不足的部位以及已有圆弧。不修剪模式保留原有圆弧并只生成新增圆角；线—弧、弧—弧相邻角点已接入有限曲线圆角，复杂组合、候选分支以及更多编辑操作仍需覆盖和核对。
- 圆角修剪模式支持圆弧延长至切点；等长的两个延长方向被视为歧义并拒绝。完整多对象组合和参考软件的延长方向选择仍待核对。
- Shift 第二次拾取临时零半径已有草稿窗口测试；仍需核对连续模式的退出/重复语义、完整候选分支及真实 AutoCAD 对照，避免将已支持的半径、修剪开关、连续和命令内撤销选项称作全部选项。
