# Phase 2 工作台设计稿 v0.1 — 检查记录

日期：2026-10-22。对象为设计原型，不是 MyCAD 应用版本的功能验收。

## 文件与使用

- workbench.html：可编辑的设计片段，供聊天内预览使用。
- preview.html：独立离线评审文件，直接在浏览器打开即可。
- 01～09 PNG：三种工作区、AI 设置三页、计划确认及两种错误状态。
- LUCIDE-LICENSE.txt：预览内嵌 Lucide 1.8.0 的许可证；来自本机已安装依赖，未修改应用依赖。
- qa-results.json：尺寸检查、主色对比、交互结果和原型内容摘要。

离线文件内嵌图标，无字体或图标 CDN 请求。图片中的模型 ID 和连接状态均为示例。
不接触用户 API Key；云端密钥输入框只读。

## 检查环境

Ubuntu / Google Chrome 154.0.8037.57，Playwright 驱动的独立 headless 浏览器，
deviceScaleFactor=1。同时验证了聊天预览包装页和独立离线文件。
浏览器未捕获 JavaScript 运行错误或图标警告；离线预览没有 HTTP(S) 请求。

## 画面与适配

九张截图已生成并目视检查。发现并修正：

- 参数面板过长时，应用/取消被挤出可见区：改为固定底部动作区。
- 草图命令列表挤压网格行：明确可收缩布局与面板滚动区域。
- 截图残留前一场景临时提示：清除非当前状态提示后重新截图。
- 原警告文字及草图状态颜色对比偏低：调整候选色。
- 错误草图尺寸被隐式夹到最小值：改为保留上次有效形状并标出冲突输入。

| 离线文件窗口 | 普通三维稿高度 | AI 展开稿高度 | 主要应用动作在窗口内 |
| --- | --- | --- | --- |
| 1920 × 1080 | 1043 px | 1043.80 px | 是 |
| 1440 × 900 | 893 px | 893.80 px | 是 |
| 1366 × 768 | 743 px | 763.80 px | 是 |
| 1024 × 900 | 743 px | 763.80 px | 是 |

另检查 1920 / 1366 / 1024 / 736 / 375 / 320 px 宽度下四种主场景，
未发现页面级水平溢出。模型表格在必要时局部滚动。
窄屏右栏下移属于设计稿的评审适配，不是移动端产品承诺。
