# My3D 零件建模对标 Solid Edge 的开发评估

分析日期：2026-10-28；落盘及进展校准：2026-10-29。

My3D 已具备基础机械零件建模框架。对标 Solid Edge 的下一步重点，是建立可编辑、可验证的“曲线—曲面—实体”流程。放样、扫掠、曲面修剪和加厚需要与曲面体管理、几何引用、依赖编辑和质量检查一起交付。

范围为 `.my3d` 零件及零件内多实体，不包含 assembly。钣金、完整同步编辑、细分造型及网格混合建模单列后续范围，不自动纳入本轮。本文是能力评估与任务分解建议，不改变 Phase 2 已批准范围，也不代表高级功能已获实施批准。

2026-10-28 的源码和探针基线为 `ef21b2e` 及当时工作区；2026-10-29 当前提交为 `ba2f53920e78a1f349196e23d3c09e2978389d32`。新增 ADR-013 已交付多文档与 v4 存档，文档归属按新决策解释。Solid Edge 对照采用 Siemens 官方公开的成熟功能资料，部分细节来自 ST 系列；不能解释为指定最新版的实机等价认证。

关联资料：[Phase 2 进度与下一步任务](../phase2-progress-and-next-tasks-2026-10-29.md)、[原始探针证据](../../.omo/evidence/my3d-part-assessment-2026-10-28.json)。

## 必须先补齐的基础能力

### 曲面体与结果类型

当前建模状态主要围绕实体组织，`validate_result()` 对有几何而无 solid 的结果返回 `no-solid-result`。曲面接入需要实体、曲面体/壳体和参考曲线的类型、来源、树节点、显隐、选择及生命周期，并为不同结果类型提供独立后置条件。

实体继续检查实体结构、体积与 BREP；曲面应检查面积、边界、方向、连通性及需要时的流形性。开放曲面可以是合法中间结果，封闭壳体只有通过方向、封闭性等验证后才能实体化。不能全局删除原实体检查来接纳曲面。[现有校验](../../src/mycad/geom/query.py)

2026-10-28 两圆截面探针：半径 10 mm、Z=0 与半径 5 mm、Z=20。

| 结果 | 内核有效性 | MyCAD 校验 |
| --- | --- | --- |
| Solid.make_loft | 有效，1 实体、3 面 | 通过 |
| Shell.make_loft | 有效，0 实体、1 面 | 拒绝，no-solid-result |

### 自由曲面与曲线引用

现有选择器面类型主要为 `plane/cylinder`，边类型为 `line/circle`；渲染或临时拾取成功，不代表可持久引用自由曲面。高级命令需要曲面类型、样条边、参数范围及生成角色，并能解释分裂、合并、删除和歧义。[选择器](../../src/mycad/core/selectors.py)

引用应组合来源特征、语义角色、适用算法提供的 Modified/Generated/IsDeleted 信息和几何验证；无法唯一解析时明确拒绝并提供重新关联。运行时 UUID、实体输入关系和 v4 文件身份解决不同问题，均不能替代逐面持久命名。不承诺一次实现通用拓扑命名系统。

### 构形曲线与关联基准

现有 SplineEntity 是二维开放夹持均匀三次 B 样条，控制点数据是权威定义。应逐步补充以下能力，而非直接把草图采样折线作为建模输入：[样条定义](../../src/mycad/core/sketch.py)。

- 关联偏置面、角度面、三点面、曲线法向面，以及基准轴/点。
- 边提取、投影曲线、曲面交线、组合曲线和穿透点关系。
- 先支持引用已有空间边和生成空间曲线，再扩展完整 3D 草图。
- 拟合点、端部切向、周期闭合、分段/连接、重参数化与曲率梳。
- 在受控编辑状态内修改已提交截面，预览下游重建，经 Bus 确认，不改变直接画布编辑范围的既有用户决定。

Solid Edge BlueSurf 可使用草图、空间曲线和模型边，穿透点反馈帮助组织截面与导线。[Siemens BlueSurf 输入](https://blogs.sw.siemens.com/solidedge/special-traits-of-the-bluesurf/)

### 多输入依赖与重建

放样可能依赖多张草图、多条导线和邻接面。需要记录消费者、输入角色、编辑影响、失效输入和失败特征。先保留全量重放正确性，建立可解释的依赖描述；增量重建和 BREP 检查点由长链性能证据决定，不另建模型真相源。

v4 的独立文档与来源快照已实现，不应重复立项。高级特征接入须适配来源采用版本、解除关联、重开与文档隔离，并保留旧 v1/v2/v3 文件和命令版本语义。

## 放样的三级交付

| 层级 | 功能 | 难点 | 验收样本 |
| --- | --- | --- | --- |
| 基础 | 多截面、排序、方向、闭合起点、平滑/直纹、实体/曲面输出 | 对应关系、扭转、封口、结果验证 | 圆到圆、圆到矩形、偏置多截面 |
| 工程 | 引导曲线、连接点映射、端部方向、邻面相切、放样切除 | 交点、支撑面关系、局部形状 | 弯曲变截面风道 |
| 高级 | 曲线网格、曲率连续、局部补面、插入截面、闭合及退化端部 | 多边界约束、曲率质量、鲁棒性 | 手柄和外观罩壳 |

每一级都要具备创建、预览、修改、失败恢复、撤销重做、存档重开及交换验证。高级参数应随能力逐步开放。

放样任务必须明确以下规则：

1. 显示截面序号、方向箭头、起点及连接线，允许用户调整并持久化决定。圆、矩形、多段样条的边数不同不能依靠隐式默认对应。
2. 明确导线与截面交点规则；缺交、多交、相切、导线交叉和方向冲突应定位具体输入。
3. 自由、指定方向、截面法向、邻面 G1/G2 分别定义。邻面条件必须取得支撑面信息。
4. 新曲面体、新实体、合并、切除分别选择。首版可明确拒绝带孔或多轮廓截面，不能忽略内环。
5. 控制点、截面顺序、导线及终止条件修改后，保持可追踪的下游关系；失败保留输入。
6. 单独检查扭转、自交、局部收缩、尖点及极短边；返回 shape 不等于设计意图满足。

Solid Edge BlueSurf 的邻面边界与切向权重控制构成更高一级能力，普通 loft 调用不能替代。[Siemens BlueSurf 边界控制](https://blogs.sw.siemens.com/solidedge/bluesurf-and-the-nurbs-mesh/)

## 底层算法与技术风险

本地 build123d 0.11.1、cadquery-ocp-novtk 7.9.3.1.1 已确认存在 Solid/Shell.make_loft、sweep、Face.make_gordon_surface 和 Face.make_surface_patch。普通放样可复用底层算法；约束补面和曲线网格仍须独立验证。

Gordon 本地接口要求每条 profile 与每条 guide 相交，各方向曲线端点位于另一方向的曲线上，点输入只能位于首尾等。产品必须将这些约束转为输入检查和用户反馈。

对规则网格 x,y∈{0,10,20}、z=kxy 的对照结果：

| 表达 | 最大曲线对最短距离 | 结果 |
| --- | --- | --- |
| k=0，直线 | 0 mm | 成功，面积 400 mm² |
| k=0.02，直线 | 约 1.8×10⁻¹⁵ mm | 可重复的 IntersectionError |
| k=0.02，三点插值样条 | 约 1.8×10⁻¹⁵ mm | 成功，面积约 420.599576 mm² |

失败到达 ocp_gordon 的交点矩阵构建。已确认表达敏感性，尚未确定具体数值根因；成功对照不是通用修复。后续需固定线/样条/圆弧表达、方向、端点相交和尺度的回归样本，不能靠放宽容差掩盖问题。

OCCT ThruSections 的 SetContinuity 控制近似过程连续性，不直接证明与外部支撑面 G2。MakeFilling 提供边界、支撑面及连续性约束，可用于补面原型；算法可用性仍需结合锁定版本验证。[ThruSections](https://dev.opencascade.org/doc/refman/html/class_b_rep_offset_a_p_i___thru_sections.html)、[MakeFilling](https://dev.opencascade.org/doc/refman/html/class_b_rep_offset_a_p_i___make_filling.html)

## 曲面到实体的完整流程

| 工作包 | 功能 | 用途 |
| --- | --- | --- |
| 基础造面 | 平面、拉伸面、旋转面、直纹面、放样面、扫掠面、复制/提取面 | 构形素材 |
| 编辑边界 | 投影、求交、修剪、分割、延伸；取消修剪后续扩展 | 大面裁切和局部形状 |
| 连接补洞 | 缝合、自由边、间隙检查、边界补面 | 构成可管理壳体 |
| 转换 | 封闭壳体实体化、曲面加厚、曲面切实体 | 形成工程零件 |
| 混合编辑 | 偏置、替换面、删除面并修补、局部过渡 | 修形和导入修复 |
| 检查 | 曲率梳、斑马纹、法线、连续性偏差、厚度和拔模 | 设计质量 |

Siemens 官方案例包括延伸曲面后选择封闭区域生成实体，表明造面以外的编辑及转换同样重要。[曲面构造实体案例](https://blogs.sw.siemens.com/solidedge/an-example-of-literal-reverse-engineering-using-solid-edge/)

曲面加厚、实体抽壳、曲面偏置应分别建任务：三者的输入和输出不同。局部曲率半径、凹角、自交和薄区碰撞都可能使操作失败；共享内核不等于共享验收结论。

G0 为位置接合，G1 为切平面连续，G2 在相切基础上检查相关曲率。不得与依赖参数化的 C0/C1/C2 无条件混用。验收需明确距离、法向夹角、曲率偏差、单位、容差、采样与奇异点策略。斑马纹辅助观察，不能由显示网格平滑代替几何检查。[Siemens 曲面质量观察](https://blogs.sw.siemens.com/solidedge/the-secret-language-of-surface-design/)

## 扫掠与机械特征补充

扫掠首轮可覆盖单截面、单路径、开放/闭合截面、跟随路径或固定方向、添加/切除及自交检查。随后扩展变截面、缩放/扭转规律、辅助导线、螺旋和闭合路径。路径经过直段、拐点及空间曲率变化时必须检查姿态翻转，不能把全部行为交给一个默认参数。

| 优先级 | 机械设计工作 | 场景 |
| --- | --- | --- |
| 高 | 抽壳、加厚、拔模 | 塑料件、铸件、罩壳 |
| 高 | 关联基准、全局参数及表达式 | 多截面布局与系统改参 |
| 高 | 可重放 STEP 导入、来源/单位和几何检查 | 外部零件协作 |
| 中高 | 筋、薄壁拉伸/旋转、标准孔和螺纹表达 | 常规工程零件 |
| 中高 | 分割体、曲面切体、替换面 | 多实体与复杂局部形状 |
| 中 | 特征级阵列/镜像、抑制、重排与修复 | 修改与复用 |
| 中 | 变半径和面间圆角、复杂角部 | 零件细节 |
| 中 | 材料、质量属性、截面、最小距离与壁厚 | 设计检查 |
| 专项 | 完整同步编辑、细分造型、网格混合建模、钣金 | 独立范围和预算 |

Solid Edge 的同步、细分和网格混合能力是进一步的对标方向，不是本轮放样的隐含承诺。[Siemens 进阶设计能力](https://solidedge.siemens.com/en/solutions/products/3d-design/next-generation-design/)

首个完整目标选择变截面风道或罩壳：基准→截面→放样/扫掠→修剪→缝合/加厚→加工特征→STEP。高风险顺序为曲线网格/G2、复杂偏置/抽壳、跨拓扑修改引用，其次是修剪缝合和扫掠姿态。先完成风险探针再定工期，不按 API 数量估算整个产品投入。

当前串行 Qt worker 不会中断运行中的 OCCT 操作；高级曲面应验证耗时上界、预览合并、逻辑取消和迟到结果。硬超时或崩溃恢复若成为需求，再评估独立进程隔离。[现有执行单元](../../src/mycad/ui/execution.py)

## 验收零件与共同门槛

| 零件 | 覆盖 | 反例或修改 |
| --- | --- | --- |
| 圆口到矩形口过渡件 | 映射、封口、放样 | 反向、角点改变、截面重排 |
| 变截面风道 | 导线、放样、加厚 | 弯曲半径改变、缺交/多交 |
| 空间弯管/槽 | 扫掠姿态、切除 | 直段至空间弯段、翻转、自交 |
| 手柄外壳 | 曲线网格、邻面连续 | 修改截面、镜像接缝质量 |
| 开口罩壳 | 抽壳、拔模、圆角 | 厚度过大、偏置自交 |
| 缺口曲面壳 | 补面、缝合、实体化 | 超差间隙、非流形连接 |

每个样本覆盖参数扰动、失败不写历史、保存重开、撤销重做、STEP 往返和真实鼠标操作。对比几何和公差，不要求不同内核生成相同拓扑编号或文件字节。人工复验、自动 GUI 和内核测试分别记账。

所有实现继续遵守 core/geom/ui 分层、Bus 唯一写入、版本化命令及审计、不放宽类型/分层守卫、不擅自升级几何依赖。新增命令 ID 须按项目的命名空间流程释放。
