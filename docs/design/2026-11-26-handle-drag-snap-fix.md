# 对象端点拖动捕捉补正

## 问题和根因

用户反馈在选择对象后用鼠标拖动端点，无法捕捉其他图元端点。按矩形、右侧半圆弧和内部直线的场景复现：草稿控制点通过 `_drag_target` 捕捉；已提交对象及混合关联控制点走 `_saved_handle_drag`，鼠标移动和释放两处均直接使用原始坐标，同时未更新捕捉标记。

新增界面测试修复前确认已提交对象不显示“端点”，而草稿路径可捕捉。测试固定画布尺寸，避免异步状态栏换行引起画布尺寸变化，混淆释放坐标与捕捉行为。

## 修改

`_drag_target` 接受当前拖动原点；已提交对象的移动预览与释放使用该共同捕捉逻辑，并同步游标位置、捕捉类型与画布提示。仍排除原拖动点，仍尊重几何捕捉开关。约束求解、历史事务及数值坐标编辑继续走原路径；本次不新增几何重合约束。

## 增量自检

- `tests/ui/test_handle_drag_snapping.py`：4 项通过，包含草稿／已提交对象与捕捉开／关组合，检查预览提示、精确落点、其他对象不变，以及撤销重做。已提交对象的预览和提交均通过真实鼠标事件及应用工作线程执行。
- 直接关联回归：约束草稿端点拖动 2 项、已提交对象数值坐标编辑及历史重放 1 项通过。
- 修改的源码及测试文件 Ruff、格式和 basedpyright 通过；未执行全量测试。
- 隔离画布证据：[脚本及截图](../../.omo/evidence/endpoint-grip-snap-2026-11-26/README.md)。使用临时设置和独立 Xvfb，不改动用户窗口或设置。

## 人工验收

1. 开启几何捕捉，在图纸画矩形、圆弧和一条端点未重合的直线。
2. 选择直线后按住端点拖到矩形顶点或圆弧端点附近；预览应吸附并显示端点捕捉提示，松开后精确重合。
3. 保存后重新打开，再执行同一操作；检查撤销与重做。
4. 关闭几何捕捉，拖到端点附近应保持自由坐标；拖动中按 Esc 应取消。

自动化及隔离截图不替代用户桌面验收。
