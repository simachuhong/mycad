# 公差工作包人工验收交接单

**状态：待人工测试和项目专业人员复核。** 本单用于启动验收并记录结果，不表示整改包已通过。详细操作及全部边界见[人工测试清单](2026-11-18-tolerance-remediation-manual-check.md)，已有自动与第三方证据见[自检记录](2026-11-18-tolerances-self-check.md)。

## 测试前

1. 记录系统、屏幕缩放、MyCAD 构建或工作区标识；工作区有未提交改动时保留补丁或构建包，不能只记录提交号。
2. 从项目根目录启动 `uv run --no-sync mycad gui`。如需依赖准备，按项目 README 操作。
3. 打开[专业复核样图](../../.omo/evidence/tolerance-expert-review-2026-11-18/review-sample.my2d)，另存测试副本；对应 [DXF 样图](../../.omo/evidence/tolerance-expert-review-2026-11-18/review-sample.dxf)已按当前默认颜色规则重新导出，供交换检查。样图不是标准合规示范。
4. 固定用于对标的 AutoCAD/Mechanical 版本、字体和项目采用的 GB/ISO 标准版本；专业复核由项目专业人员执行。

## 首轮检查

以下为验收入口，不替代详细清单中涉及的操作、异常与交换场景。

| 项目 | 操作及预期 | 结果 / 问题编号 |
| --- | --- | --- |
| 工具栏和公差编辑器 | 检查形位公差与基准图标、名称和分组；放置公差框，在分格编辑器选择符号、填写公差与基准，对照指定 CAD 的视觉和操作。 | 待测试 |
| 基准创建和样式 | 用工具栏、`AMDATUMID` 和 `DATUMLABEL` 分别创建基准，检查均先指定目标和框位置，再输入名称；核对引线、三角形、字框、默认名称、预览及 Esc 取消，对照指定 CAD。 | 待测试 |
| 基准框与自动引线 | 新建附着直线或圆的自动基准，移动或旋转目标、移动基准框并复制；检查可见引线不穿越框和箭头，正交模式下框边到法向首段之间保持水平或竖直。修改基准名称及共享文字样式后检查框与预览、保存重开及 DXF 显示一致；无法安全避让时应提示且不改变图纸。 | 待测试 |
| 公差框引线箭头 | 新建带引线公差框，对照基准三角形及指定 CAD，检查箭头比例、点选框选及保存重开；导出后在目标 CAD 对照。旧对象应保留原画布外观，导出时提示可能变化。可参考[新版引线样图](../../.omo/evidence/tolerance-frame-arrow-28/sample.dxf)。 | 待测试 |
| 旧图引线导出 | 打开含未保存框侧锚点的旧公差框，分别导出原生和图形兼容 DXF；核对引线位置、字体依赖提示及原图历史不变。对框侧或目标侧顶点隐藏的法向及自动引线，原生 DXF 导回后旋转附着线，核对法向和自动路径；图形兼容模式应提示不能恢复相应约束。字体被替代时预览应提示；图形兼容模式缺字或无法取得轮廓时应拒绝并保留目标文件。取消后目标文件保持原样。 | 待测试 |
| 图形兼容字形 | 使用多行、旋转、宽字、带内孔数字及材料条件的公差框，导出图形兼容 DXF；在指定 CAD 中核对文字填充、内孔、格线、引线连接及圆圈位置。查看字体替代提示，确认文字与公差框已转为不可结构化编辑的图形。 | 待测试 |
| 图形兼容基准 | 使用共享和旧式基准、宽字及带内孔名称导出图形兼容 DXF；在指定 CAD 中核对文字填充、内孔、基准框和引线。确认导出报告说明结构化基准不可恢复，关联表面延伸失去归属时有提示。 | 待测试 |
| 旧式基准原生导出 | 用旧式基准及非默认字体样式分别验证无引线、多段引线，导出原生 DXF 并检查框、引线、箭头及文字位置；导回检查基准身份与关联，确认字体替代提示及原图历史不变。 | 待测试 |
| 单独基准文字样式交换 | 创建不与公差框共用样式的基准，设置非默认字体、字高和宽度，原生 DXF 导出后导回，核对样式名称、身份和排版；在目标 CAD 另存或修改字体后重新导入，核对实际字体及导入报告，记录软件是否保留快照。 | 待测试 |
| 旧式基准 CLI 导出 | 分别使用桌面命令栏和独立命令行导出相同旧式基准，核对框尺寸、引线和字体提示；有导入字体时检查已加载字体，无桌面组件时确认估算提示。 | 待测试 |
| 适应窗口 | 使用只含公差框、基准和引线的图纸，将视图缩放或平移远离标注后执行适应窗口，核对框、引线及表面指示均进入画布；隐藏标注不应影响结果，锁定但可见的标注仍应显示。 | 待测试 |
| 选择及编辑 | 在选择元素工具中分别点击基准框、引线和三角形，并从两方向框选；删除及撤销。对公差框重复选择、编辑、移动、复制和撤销。 | 待测试 |
| 基准整体移动 | 分别直接拖动未选中基准框、选中后拖动，以及使用工具栏“移动”（先选基准再启动、先启动再选基准两种顺序），检查整体移动及撤销重做；无附着时框与指向点一起移动，附着其他对象时指向点和关联保持。另按实际图纸复测 MOVE、夹点及图层状态并记录提示。 | 待测试 |
| 基准与基线尺寸箭头 | 选中基准，分别从“基准操作 → 基准主引线箭头样式”和 `DATUMARROW` 选择实心、空心和无箭头；检查选择、撤销重做、保存重开及原生和图形兼容 DXF。表面指示次级箭头不随此设置改变。对于基线尺寸，在“标注样式”分别修改第一、第二箭头并保存，检查两端可独立更改、已使用该样式的尺寸及 DXF。 | 待测试 |
| 基准复制 | 使用工具栏“复制”分别先选基准再启动、先启动再选基准；另通过 COPY、复制粘贴及菜单入口复制。检查名称对话框预填未使用字母、可修改且不允许重名，完成放置后检查引线、附着、撤销重做。多选基准粘贴时检查建议名称互不重复。 | 待测试 |
| 关联与失关联 | 将基准及公差框附着几何，移动或修改目标、删除目标、解除及重新关联；检查提示、位置及撤销恢复。 | 待测试 |
| 暂存相切混合删除 | 在草稿中创建与已提交几何的暂存相切，再同时选择草稿图元、公差框及可选文字和图片删除；检查受影响关系被移除、无关相切保留，一次撤销与重做恢复对应对象和关系；锁定文字图层时检查整次操作被拒绝。 | 待测试 |
| 暂存阵列混合删除 | 创建暂存矩形阵列，同时选中一个阵列成员、文字和公差框删除；检查成员变为阵列删除状态，撤销重做后完成草图并保存重开。选择仍被阵列引用的源对象时应整体拒绝。 | 待测试 |
| 双阵列与尺寸混合删除 | 同时选择暂存和已提交阵列成员、所选尺寸、文字和公差框；检查一次删除、撤销重做和保存重开。另检查附着于所删目标但未选中的基准提示失关联，未选中的关联尺寸阻止删除。 | 待测试 |
| 尺寸公差 | 设置对称、上下偏差和极限尺寸，核对数值、精度及位置；修改单尺寸覆盖并检查撤销。 | 待测试 |
| 旋转坐标参考尺寸 | 从包含非零原点和旋转坐标轴的 DXF 导入 X/Y 坐标及偏差，核对数值、文字方向和引线；放大后分别点击箭头内部、引线和文字并框选，检查撤销重做和保存重开；再导出到指定 CAD 另存并导回，核对方向及名义值。若外部软件删除或修改方向字段，应检查导入警告；同时记录是否保留 MyCAD 方向快照。 | 待测试 |
| 保存和交换 | 保存重开；导出原生及图形兼容 DXF，检查导入报告，在指定 CAD 中检查可见性、位置、数值及可编辑性。 | 待测试 |
| 外部基准名称修改 | 在能保留 MyCAD 扩展数据的 CAD 中，将共享布局基准块中的普通名称修改后导回，并检查多片段名称的部分文字修改；若其他图形未变且名称放得下，应恢复可编辑基准并提示排版及旧引用需检查。修改几何、颜色或隐藏状态时应降级并报告；记录外部软件是否保留元数据。 | 待测试 |
| 曲线身份交换 | 多段线或样条上放置关联基准和公差框，导出后导入新文档并检查关联；第三方修改曲线后再导入，检查警告和失关联。重复导入同一文档时检查预览中的身份与基准改名提示、两份标注各自的关联及一次撤销重做。 | 待测试 |
| 旧曲线点身份升级 | 使用[旧曲线样图及步骤](../../.omo/evidence/tolerance-legacy-curve-upgrade/README.md)，选择已提交的多段线或样条，通过基准操作菜单或 `CURVEIDUPGRADE` 升级；核对几何与既有附着不变、一次撤销重做和保存重开。如实际操作能够产生具备可信映射的多段线精确反序，检查基准仍指向原顶点、撤销重做和重开；等待每次历史操作结束再进行下一次。分别混选其他几何、标注、约束、图片及文字，或选择锁定图层的曲线时应整体拒绝；复杂变形后仍须检查附着。 | 待测试 |
| 专业复核 | 项目专业人员核对样图中的符号、材料条件、基准及组合，并记录标准版本和逐项结论。 | 待复核 |

重点限制：基准在第三方 CAD 中是图形块；LibreCAD 2.2 的已验证打印路径不显示原生公差框；CADCraft 的部分编辑路径会生成不显示公差的图形。复杂几何重排、阵列和第三方修改的支持边界以[支持矩阵](2026-11-18-geometric-tolerance-support-matrix.md)为准。
