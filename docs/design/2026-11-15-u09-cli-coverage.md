# U09 二维命令覆盖与缺口

本表记录 2026-11-15 用户要求补齐绘图、标注和修改命令后的工作范围，按截至 2026-11-16 的工作区与验收记录更新；“可启动”不代表完整 AutoCAD 选项已实现。设备反馈只覆盖用户实际确认的操作，详细证据和更新顺序见 [U09 进度](../../.omo/evidence/ui-redesign/u09-progress.md)。

| 入口 | 当前状态 | 待处理或边界 |
| --- | --- | --- |
| LINE、PLINE、RECTANGLE、CIRCLE、ARC、SPLINE | 已有命令入口及部分坐标/选项；直线可捕捉已有圆和有效圆弧段的切点；圆以及三点和圆心圆弧可在相应选点阶段捕捉已有直线、圆和有效圆弧段的切点。状态栏“两对象相切”支持依次点选两个对象创建直线、圆或圆弧，后两者需输入半径；原 LINE 的 TAN 选项保留。 | 圆和圆弧与直线的指定场景及两对象相切入口的指定流程已获用户设备通过。普通切点捕捉确定创建时的几何位置；两对象入口在启用自动推断时会建立或暂存相切关系，提交结果以实际状态为准。其余选项和按钮与命令状态组合仍有边界。 |
| POLYGON、POL | 支持边数、中心、内接/外切、半径或端点，以及边（Edge）方式；支持画布输入、重复及撤销 | 边数限 3–128。 |
| POINT、PO 独立点绘制 | 已接入命令和画布入口，坐标、鼠标、图层锁定、撤销重做、保存重开有定向验证 | 点外观变量 PDMODE/PDSIZE 尚未实现；其他未支持的绘图类型单列，不以命令别名冒充实现。 |
| DIM、DIMLINEAR、DIMALIGNED、DIMANGULAR、DIMRADIUS、DIMDIAMETER、DIMARC、DIMCONTINUE、DIMBASELINE、DIMORDINATE | 已接入现有标注控制器；支持拾取及坐标输入，DIMLINEAR 支持 H/V 和 R 旋转方向 | 已验证智能圆直径、指定线性、对齐、角度、半径、直径、弧长、连续、基线和坐标流程；旋转参考尺寸有定向验证。尺寸文字在标注选项设置，`<>` 表示测量值；按用户要求不提供 CLI 的 T 文字选项。可拾取的引用、参数化尺寸及输出语义沿用现有实现，不声称完整 AutoCAD 兼容。 |
| DLI、DAL、DAN、DRA、DDI、DAR、DCO、DBA、DOR | 对应现有标注命令，支持重复 | 缩写对照 [Autodesk 命令速查表](https://www.autodesk.com/akn-aknsite-article-attachments/085f47ca-feb6-40e8-bf88-8128d443a05a.pdf)。 |
| DIMSTYLE、D（空闲时） | 独立二维图纸打开随图纸保存的命名标注样式管理；可应用精度和比例、更新已关联尺寸并撤销重做。仍可从管理器打开本机命名格式预设 | 图纸级样式及关联路径有定向验证，设备复验待进行；此前设备反馈通过的是旧版本本机预设场景。活动倒角等命令内 D 保持其对应选项。 |
| DIST、DI | 两点距离、平面坐标差和方向角；支持鼠标捕捉、坐标、相对坐标、取消和重复 | 只读查询，不新增尺寸或几何；结果按当前二维坐标显示。 |
| AREA | 点或坐标定义简单闭合多边形，或用 O 选择圆、矩形、闭合多段线（含弧段）；支持累计增加/扣减面积和周长、U 撤销点以及画布边界预览 | 只读；自交和退化边界拒绝。逐点圆弧边界及其他官方对象类型未支持；用户已确认基础矩形测量及圆和矩形对象累计增加、扣减与轮廓预览的指定复验。 |
| MEASUREGEOM、MEA | Q 支持有限直线与圆、圆弧之间的动态距离，附近圆弧半径，相交直线直角提示，以及由直线、圆、圆弧、多段线或样条围合的区域点选、面积、周长和 Shift 增减；D、AR、R、A 分别提供距离、面积、半径和角度查询 | 样条对象间动态距离、体积及部分复杂边界组合未覆盖；含样条区域每次点选后台重新计算，采样仅用于高亮。用户设备反馈覆盖直线分割圆、闭合圆弧多段线、样条与直线围合区域的指定操作，以及线弧距离和直角提示。圆上两半径按 0°–180° 显示，与参考文档的锐角表述有差异。 |
| QSELECT | 可按类型、图层筛选可见且可选择的二维图元、尺寸和图片；支持直线长度、圆/弧半径、尺寸原始测量值（毫米或角度）、当前选集/整图、包含/排除及追加 | 无独立约束类型筛选，数值条件尚未覆盖图片及其他图元属性，阈值范围为 ±10⁹、六位小数；用户确认基础筛选、多边形、尺寸/图片与尺寸数值筛选，以及多选删除和混合移层的指定流程。 |
| MOVE、COPY、ROTATE、SCALE、MIRROR、OFFSET、ERASE、TRIM、EXTEND、FILLET、CHAMFER、BREAKATPOINT | 已有命令入口及部分选项 | 对照现有修改工具继续审计命令先选/后选、选项和真实执行；受约束及关联限制见既有修改审计。 |
| ARRAYRECT | 已有交互命令和专项记录；预览、关联、基点与间距选项支持 Tab 补全 | 关联选项和图纸状态以现有能力为界。 |
| ARRAY、AR、ARRAYPOLAR | 可选择矩形或环形阵列；环形支持中心、数量、角度、预览编辑和确认，支持撤销及保存重开；类型选择和环形预览选项支持 Tab 补全 | 环形生成独立副本，尚无关联阵列；单次最多生成 10000 个图元。路径阵列明确后置。 |
| 线性阵列 | 已有二维界面入口；ARRAYRECT 可设置单行或单列生成线性排列 | 暂未提供独立线性阵列命令。 |
| 分割（附近交点） | `SPLIT` 启动现有分割工具，支持鼠标或坐标、撤销、取消及重复 | 与 BREAKATPOINT 的指定点打断不同；用户对交叉线附近分割、撤销及重复反馈通过。 |
| BREAKATPOINT（单点打断） | 已有独立按钮及命令入口，在指定点打断支持的对象 | 不等同于“分割（附近交点）”，也不等同于此前约定后置的 BREAK 全部功能。 |
| LAYER、LA；PROPERTIES、MO；OPTIONS、OP | 打开图层、特性和系统设置入口 | 复用现有界面；并非 AutoCAD 的 -LAYER 命令行选项。用户已对上述入口反馈通过。 |
| PAN、P；ZOOM、Z | PAN 支持两点平移；ZOOM 支持相对比例、E/A 适应、窗口两角和 P 上一视图（最多 10 条），窗口支持画布预览 | E/A 当前都按已有图形适应，不能视为完整 AutoCAD ALL 语义；用户对窗口两角、预览、放大及上一视图的复验请求反馈通过。 |

用户 2026-11-11 已将 STRETCH、BREAK、JOIN、EXPLODE、LENGTHEN 和路径阵列明确后置；本表不更改这一范围。参考：[Autodesk DIMLINEAR](https://help.autodesk.com/cloudhelp/2025/ENU/AutoCAD-Core/files/GUID-E908848F-4621-43D2-B377-FD3FBC2B8848.htm)、[DIMRADIUS](https://help.autodesk.com/cloudhelp/2023/ENU/AutoCAD-Core/files/GUID-99EED401-D7DF-4CF3-95ED-BBD107A13855.htm)、[ARRAYPOLAR](https://help.autodesk.com/cloudhelp/2021/ENU/AutoCAD-MAC-Core/files/GUID-E30C89BB-47F0-467B-B706-05FE15A414F0.htm)。
