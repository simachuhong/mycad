# 形位公差首批表达范围与验证状态

本表是功能和验证范围记录，不是 GB/ISO 合规声明。用户选择 GB/ISO 优先；[GB/T 1182-2018 官方目录](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=C87A687A21B36E2F2D3A09BDF03DCA01) 和 [ISO 1101:2017 官方目录](https://www.iso.org/standard/66777.html) 显示二者为现行版本。用户已指定由项目专业人员复核标准正文及相关基准、材料条件规则；复核尚未完成。

增量说明：椭圆曲线的基准及公差框附着支持参数位置，命令版本 13 包含该数据；椭圆本身仍在独立开发，第三方 CAD 和实际桌面交互未验收。

被外部修改而不能恢复结构的基准块，导入时会尝试保留支持的线条和文字；实心图形降级为轮廓，无法处理的内容及语义损失均报告，复杂块不保证完整保留。

关联尺寸及独立参考尺寸的 DXF 原生文字超过 255 UTF-8 字节时会报告保守兼容风险；具体目标 CAD 的长度限制和行为仍需实测。

| 表达要素 | 当前实现 | 限制和待验证项 |
| --- | --- | --- |
| 形状、方向、位置、跳动 | 14 种枚举及无字体依赖矢量符号 | 与标准逐符号和实际 CAD 样例的外观对照待专业复核；同轴/同心、对称等概念的适用版本需审查 |
| 公差值 | 非负有限数字、0–8 位显示精度 | 常规控件范围为 0–10⁹、最多 8 位小数；“精确输入”支持科学计数法及非负有限浮点数，超出控件显示能力时保留并提示。外部单位换算为毫米时按比例增加必要小数位，最多八位。非零值按所选精度将显示为零时，画布和编辑器提示精度不足，DXF 导出中止；旧 DXF 的一致元数据保留原值并报告。非零值小于八位精度时需核对输入，不能通过增加小数位解决。不校验实际工件，也不按被测要素判断数值合理性 |
| 单行、多行 | 独立行，各行包含特征、一个值、最多三个有序基准 | 不承诺全部复合公差框语义；CADCraft 的多行创建、移动和 AutoLISP 数值编辑已验证；数值编辑样例丢失 MyCAD 扩展数据，导入后基准引用未关联并提示；其他 CAD 及 GUI 编辑仍待验证；原生内容编码超过 255 UTF-8 字节时须拆分或采用图形兼容模式 |
| 本机公差模板 | 公差框编辑器可将当前公差行保存为命名模板，之后应用或删除；保留数值、精度、符号和基准标签 | 模板存放于本机设置，不随图纸或 DXF 传递；应用时基准身份不随模板复制，须在当前图纸显式关联。应用前确认替换当前编辑内容；不内置标准组合，不提供组合合法性校验；真实桌面待验收。 |
| 尺寸偏差输入 | 编辑器支持有符号偏差及字号比例 | 偏差常规控件范围为 ±10⁹、最多 8 位小数；比例常规控件为 0.001–100、最多 3 位小数。“精确输入”支持科学计数法；偏差须为有限浮点数，比例须大于 0 且不超过 100。超出常规显示能力时保留并提示；非零偏差按所设精度会显示为零，或不同的上下偏差、极限值会显示相同时，画布显示“公差精度不足”，导入会报告，DXF 不输出受影响标注。极限值相加溢出时画布提示、DXF 不输出该无效标注，需修正数据。 |
| 基准主引线箭头 | 选中基准后使用“基准操作 → 基准主引线箭头样式”或 `DATUMARROW`，可选实心、空心或无箭头；独立对象保存样式，原生及图形兼容 DXF 保留图形 | 该设置针对基准主引线，表面指示的次级箭头不随之改变；旧对象默认实心，非默认样式需要形位公差命令版本 29，旧版 MyCAD 可能无法恢复该基准结构。标准适用性和第三方 CAD 显示仍须人工复核。 |
| 文字样式 | 尺寸样式、公差框和基准标识可引用图纸文字样式，公差框和基准随样式字高与宽度排版，支持复制及 DXF 交换 | 基准标识以图形块交换，外部字体表与文字图元尺寸不一致时拒绝恢复并报告；新导出包含可核对的公差框文字样式快照，原生字体与字高未变时可保留样式身份；普通文字共用相同样式时复用导入后的文字样式，旧文件或冲突仍可能重新分配；超长 DXF 样式名会缩短并提示，字体文件或字体族超过 255 UTF-8 字节时中止导出；原生公差框在其他 CAD 的实际字体及排版仍需验证；尺寸文字宽度因子在画布上限于 0.01–40，超界按最近边界绘制 |
| 直径、M/L | 结构化字段与矢量绘制 | 当前只校验字段类型，尚未按特征和被测要素约束组合合法性；不应视为标准校验通过 |
| 基准引用 | 最多三个有序标签，支持引用本图基准对象、重命名同步和删除保护 | 未解析标签可保留并在画布及编辑窗口提示，可在编辑窗口显式关联同名基准；DXF 引用的身份缺失、重复或标签冲突时解除关联并报告；支持稳定点、直线、矩形边、圆、圆弧、多段线和样条位置附着及失关联提示；单独选中基准后可用 `DETACHDATUM` 或工具栏解除附着、用 `REATTACH` 或工具栏重关联。相关点原坐标换索引、整体平移并置换点序、部分平移重排，以及至少两个点坐标变化时的两点平移互换等情况会拒绝新修订；某些对称变形也可能被拦截。只改变一个索引点的常规编辑允许通过，但无法排除坐标完全相同的交换歧义；其他复杂重排仍可能静默错位，应解除附着后修订并重关联检查 |
| 独立基准标识 | 框、标签和引线点；通过单一事务维护 | 支持独立坐标或唯一已有几何点、直线、矩形边、圆、圆弧、多段线和样条位置附着；样条曲线位置在控制点数量改变后失关联，数量恢复不会自动重连；控制点或曲线端点附着时数量变化须先解除附着；样条自交处不自动猜测，复杂重排仍有风险；可识别的直线、圆弧、矩形边方向反转及曲线端点重排会拒绝修订，直线绕中点旋转 180° 等坐标相同的变换也可能被拦截；圆弧中心引用不受方向反转影响；大型 DXF 元数据压缩时旧版 MyCAD 可能无法恢复身份与关联，导出报告会提示；基准符号形式与标准细节待复核 |
| 混合移动和复制 | 可同时处理所选几何、基准、公差框、独立参考尺寸、文字及图片；同次复制重映射内部引用，保留完整选中约束及命名样式；跨图文字样式冲突会分配新身份 | 跨选区约束、对象相切和关联阵列会明确拒绝；跨图纸同名图层使用目标属性并提示；目标图纸在粘贴放置前变化时取消本次粘贴。混合剪贴板总上限 32 MB、最多 1000 张图片，单张 PNG 限 12 MB；真实桌面和跨软件复制待验收 |
| 多选删除 | 可在一次事务中删除公差框、基准、独立参考尺寸、文字、图片与普通草稿或已提交几何及其尺寸；暂存与已提交阵列成员可与所选尺寸、文字及公差标注一同删除并撤销，选中标注附着于待删尺寸或成员的情况已验证。受删图元影响的暂存相切关系一并删除，其余有效关系保留；未选择基准的目标被删除后，基准保留为失关联状态 | 仍有未选中公差框引用基准、对象或关联约束所在图层锁定时整个事务拒绝；阵列使用的来源、被未选尺寸或受保护相切关系引用的成员不可删除，暂存混合变换及部分复杂草稿约束组合仍需分别处理 |
| 标注身份 | 新版命令阻止公差框、基准、独立参考尺寸之间新增相同身份；导入时重分配并保留有效基准引用 | 旧命令历史仍按原样重放；旧档跨类型身份冲突时可用 `REPAIRANNOTATIONIDS` 或工具栏修复，保留基准及关联，修复作为一次操作可撤销。涉及锁定图层时先解锁，否则整批不提交。 |
| DXF 公差框 | 原生 TOLERANCE，支持限定内容格式，字形字符按大小写区分，无法解析时报告；元数据损坏或与其原生内容不一致时采用原生内容并报告 | 基准引用标签支持 Unicode 字母、数字、下划线和连字符，空格及可能与控制码冲突的字符仍拒绝；中文仅完成本软件写入和读取验证，其他 CAD 的显示和编辑未验证；与非全局 XY 基准草图混合输出时拒绝导出，避免错误投影；LibreCAD 2.2 的打印路径实测未显示公差框，导出报告会提示；[Autodesk FCF 内容示例](https://help.autodesk.com/cloudhelp/2018/ENU/OARXMAC-RefGuide/files/OREFMAC-AcDbFcf__setText_ACHAR__.html) 是编码参考，已用 LibreDWG 提供的外部样本验证单行解码；原生内容以 255 UTF-8 字节作为保守上限，超限中止导出；可读取的超长外部内容保留并提示风险；CADCraft 的多行创建、移动和 AutoLISP 数值编辑已验证；数值编辑样例丢失 MyCAD 扩展数据，导入后基准引用未关联并提示；其他 CAD 及 GUI 编辑仍待验证；公差框元数据超过保守预算时压缩，旧版 MyCAD 可能无法恢复身份和关联 |
| DXF 图形兼容模式 | 导出时可选将形位公差框转换为近似线条与文字，并在报告中注明不可作为结构化公差编辑或无损恢复 | LibreCAD 2.2 打印路径的 14 种符号及独立双行/M/L 样例可见；字符排版与画布不同，不代表其他 CAD 或全部情形已验证；默认宽度下单格文字超过 255 UTF-8 字节会中止，需缩短文字。 |
| DXF 基准标识 | 图形块与 MyCAD 元数据；外部平移可还原，元数据与文字/指向不符、修改块或不支持的变换时报告 | 其他 CAD 中为图形块，不宣称是可结构化编辑的原生基准；同身份基准重新分配身份并解除歧义引用，重复名称保留首个、跳过后续对象并报告；为避免 DXF 将特殊字符解释成控制码，含 `%` 或 `^` 的标签会拆分成多个文字图元；长 Unicode 标签按 255 UTF-8 字节上限拆分文字图元，本软件往返保留标签，其他 CAD 的字体和排版尚未验证；对保留元数据且其他块图形和外观未变的共享布局基准，可恢复不含 DXF 控制码的普通文字改名；既有的分段转义文字可保留，文字片段必须不重叠且放入原框。旧基准引用解除关联并提示；其他块内容编辑不恢复结构 |
| DXF 曲线点身份 | 多段线和样条将点身份及完整有序几何快照写入 MyCAD 扩展数据；本软件读回时校验快照、身份所属图元及重复身份，保留有效的基准及公差框几何附着 | 源曲线坐标、顺序、闭合或曲率变化，以及可检测的元数据损坏、丢失和重复时，保留几何但解除相关附着并报告；重复坐标无法安全核对，亦解除。几何快照是保守一致性检查，不能证明第三方操作的历史或防止有意篡改。若第三方同时删除身份标记和全部身份元数据，无法识别其原本具有点身份，按旧 DXF 路径处理；第三方交换尚待实测。导入当前文档时，冲突曲线取得新身份并重映射内部尺寸与几何附着；基准名称冲突会自动改名、更新已关联引用，并在导入预览中提示。未关联的同名基准标签保持未关联，不推断目标。 |
| DXF 预览 | 读取实际输出文件的内容，以共享矢量符号和临时图元绘制 | 临时图元不写入导出文件；文字宽度估算会产生排版差异，界面提示；实际外部 CAD 排版待对照 |
| 外部尺寸公差 | MyCAD 元数据尺寸可按原生字段读取外部修改 | 没有 MyCAD 引用的外部线性、对齐、半径、直径、轴对齐 X/Y 坐标及三点及两线角度尺寸可作为独立参考尺寸导入；长度单位换算会在八位上限内增加名义值和公差的显示精度。原命名样式因单位变化或样式扩展数据被移除无法安全恢复时，非空原生公差作为单尺寸覆盖恢复并报告，样式继承关系不保留；公差快照缺失或无法核对时优先采用可读原生公差及精度并报告。外部公差形成不支持的组合时保留几何，不恢复该尺寸并报告。两线角度按交点与方向重建，原始线端不保留并报告。部分关联草图坐标轴变换及特殊文字位置仍报告不支持；负坐标极限值的导出图形块已修正，其他 CAD 重新生成该图形后的表现尚未验证 |

外部独立坐标参考尺寸支持旋转坐标轴，按 DXF 方向及原点投影名义值；±360°、720° 与 0° 等价。新导出的尺寸另存方向及 X/Y 类型快照，第三方改动或删除方向组码、改变测量轴时按原生字段导入并警告；旧文件缺少相应快照时无法检测变化。CADCraft 0.20.1 另存一个 90° 样本时删除该方向，导致名义值改变，不能将此路径视为无损交换；见[验证记录](../../.omo/evidence/tolerance-rotated-ordinate/README.md)。此支持不扩展到其他不支持的关联草图坐标尺寸。DXF 方向角定义见 [Autodesk 尺寸通用组码](https://help.autodesk.com/cloudhelp/2023/ENU/AutoCAD-DXF/files/GUID-EDD54EAC-A339-4EBA-AEA6-EC8066505E2B.htm)。

此表列出的功能状态不是整包验收结果。复杂拓扑关联、外部尺寸模型、标准组合规则和第三方 CAD 测试仍有缺口；不得用自往返测试代替第三方互操作证明。

补充：通用草图修订提交路径可对坐标唯一、线段连接及 bulge 不变的精确多段线重排生成版本化映射，保留基准和公差框附着；已有界面管线及历史测试，尚未以实际鼠标工具触发重排验收。该多段线被局部约束或跨草图相切引用时，仅允许经过原有规则证明仍指向原有向几何的重绑定；支持证明几何身份不变的部分平移、旋转、动态基点、替换及额外输出阵列，详见下方版本 58–62 补充。链式阵列和发生变化的成员相切仍受限制，无关阵列和相切不会因此拦截。其他复杂重排与变形仍应先解除附着再检查和重关联，不能由这一增量推断为全部安全。

版本 58 补充支持受限阵列中可证明指向同一物理顶点的动态基点索引重绑定；版本 57 保留原有拒绝行为。版本 59–62 的替换及额外输出增量见下方记录；链式关系和变化成员的相切仍不支持。

## 外部样本证据

- CADCraft AutoLISP 数值编辑：外部将 MyCAD 双行公差首行从 0.12 改为 0.25 后保存；MyCAD 正确读回数值和基准标签。该操作未保留公差框的 MyCAD 扩展数据，原 ID 和基准关联无法恢复；导入报告提示未关联，必须显式检查。样本、散列及范围见[验证记录](../../.omo/evidence/tolerance-cadcraft-2026-11-18/README.md)。

- CADCraft 角度公差：其对 MyCAD 的角度尺寸设置弧度显示单位和原生偏差后，MyCAD 按字段换算为度并保留两条几何引用；角度显示单位不保留并报告；三点角度的组 16 缺省与零点按等价比较。CADCraft 的 SVG 输出发生明显裁切，不能证明外观正确；命令和样本见[验证记录](../../.omo/evidence/tolerance-cadcraft-2026-11-18/README.md)。

- CADCraft 尺寸公差：外部创建的线性尺寸以独立参考尺寸导入；对 MyCAD 关联尺寸执行 `dimoverride` 改为上偏差 +0.04、下偏差 +0.01 后，MyCAD 恢复数值及几何引用，检测到默认文字位置重算后维持自动定位；缺省与空字符串的 DIMPOST 均表示无前后缀，不再误报差异。CADCraft SVG 显示偏差排成一行且文字偏离尺寸线，外观未保持；详细样本与散列见[独立软件验证记录](../../.omo/evidence/tolerance-cadcraft-2026-11-18/README.md)。

- CADCraft 0.20.1 命令行创建的原生双行 DXF 已由 MyCAD 正确读取；其 SVG 输出可见 MyCAD 的双行样例，直接 PNG 输出在本环境对比度极低；CADCraft 对 MyCAD 样本执行移动并保存后，MyCAD 读回新位置、两行及基准关联。通用属性接口修改文本的尝试未实际生效；后续 AutoLISP 编辑能够修改数值，但不保留该公差框的扩展数据。版本、命令和样本散列见[独立软件验证记录](../../.omo/evidence/tolerance-cadcraft-2026-11-18/README.md)。该证据仅覆盖 CADCraft，无 GUI 或 AutoCAD 交互验证。

外部原生公差框引线：对于不含 MyCAD 扩展数据的二维直线 LEADER，若其原生关联句柄唯一指向可导入的 TOLERANCE，可按实际顶点恢复可编辑引线；不猜测几何附着，独立图层及外观覆盖会提示。多个引线指向同一框、曲线引线、无箭头或非 XY 平面时不按结构恢复，尽可能保留支持的普通图元并报告。此路径的样例来自移除本软件扩展数据的测试文件，尚非其他 CAD 独立创建的公差框引线实证。

原生 LEADER 的箭头样式按 `DIMLDRBLK` 检查：非默认自定义样式不能结构化保留，会提示使用本软件默认实心箭头；没有公差框关联时保留可读引线线段并报告不支持自定义箭头。尺寸箭头 `DIMBLK` 不作为引线箭头样式。

公差框原生 DXF 导出时，法向控制顶点与框连接点重合的有效表示会压缩为一段并保留元数据；其他相邻顶点重合时中止并提示修正，不覆盖已有目标文件。正常短引线仍可导出，箭头大小受首段长度限制。

历史公差框若有引线但未保存框侧锚点，桌面导出使用当前画布文字样式和字体度量一次性计算连接点；仅导出文件保存锚点，不改原图或命令历史，并在报告提示字体依赖。预览会列出画布检测到的具体字体替代及缺字。命令行安装桌面组件时使用隔离离屏进程及同一套布局计算；桌面内命令行使用画布字体资源目录，独立命令行使用当前启动程序的 Qt 字体资源目录。缺少桌面组件、字体布局进程失败或超时会拒绝导出；不同启动程序或机器可能使用不同字体目录或替代字体，导出提示应予核对。普通对象的无头导出不依赖桌面组件。

旧引线框内开头的不可见顶点不写入 DXF 可见路径，并在报告中提示；若靠近目标的法向控制顶点仍可见，可保留几何附着及法向约束。自动布线或法向控制点也被遮住时，画布或离屏字体进程提供完整框尺寸快照，导出与导入按该快照重新核对裁切路径、锚点和顶点数量，并将原始拓扑与约束保存在 MyCAD 扩展数据中；无尺寸快照的旧自动布线交换文件仍仅接受可证明位于符号格的隐藏顶点，目标侧法向被遮住时则必须有完整快照。原生公差框、引线、样式或唯一身份变化时，保留可见引线并解除无法核验的约束。缺少扩展数据时无法知道曾有隐藏顶点；图形兼容导出不保留法向或自动布线约束。快照不一致等情况拒绝导出。原始图纸和历史均不修改；其他机器替换字体时仍需人工核对显示。
