# 圆圈基准短线方向与新建默认样式整改

依据用户三项要求：短线跟随基准线方向；菜单能设置矩形／圆圈默认值；圆圈默认值在选择基准线和放置预览时生效。

实施：复用现有附着法向解析，将其切线方向用于圆圈基准短线。增加可保存的短线方向及命令版本保护；有附着时随几何更新，无附着或失关联时保留已有方向。旧附着圆圈在重放和显示时解析目标方向。画布、拾取、预览与 DXF 共用纯几何函数。默认样式保存为本机偏好，在工具菜单和标注工具栏的基准操作菜单提供两个可切换默认项；只影响后续创建，创建开始时固定本次样式。

验证：定向覆盖斜引线接水平／竖直／倾斜基准，默认切换和重开，新建预览／提交，附着几何变化、撤销和保存重开，原生及图形兼容 DXF。仅执行对应增量检查，不执行全量测试。

## 人工复测未通过后的补充整改

用户重启后仍出现短线随斜引线倾斜。复现发现：此前测试和截图均先用 `commit_new_sketch` 提交几何，未覆盖“新建图纸 → 画矩形 → 立即放置圆圈基准”的草稿路径。拾取仅查询已提交草图，草稿边线未提供方向，绘制回退到垂直于连接线。

圆圈创建的目标拾取现在同时读取当前草稿，按唯一命中的边线投影指向点；预览和确认时解析该边的切线并保存方向。未提交草图尚无可重放引用，因此仅记录方向，不伪造已提交草图附着。已有合法附着继续按原路径解析。自由放置且没有可唯一识别边线时保留原有行为。

新增界面回归先观察到失败，再验证直接绘制矩形后的悬停、斜引线预览、确认、通过保存菜单保存及重新打开；新证据脚本也使用画布绘制及基准菜单入口，不再预先提交几何。
