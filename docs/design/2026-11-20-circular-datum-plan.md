# 圆圈基准标识实施计划

目标：按用户附图提供“短粗线、连接线、圆圈及字母”的可编辑基准标识，保留原矩形样式和旧图历史。图示是外观与交互目标，具体 GB 版本及组合适用性仍由项目专业人员复核。

实现采用现有结构化 `DatumIdentifier`，增加版本化样式字段，不能把圆圈与线段当成无关联的临时图形。圆圈字母保持水平；短线指示被指定位置，必要时支持附着公差框或几何对象。画布、拾取和 DXF 复用同一几何定义；无法忠实恢复结构的交换必须报告，不静默替换。基准样式改变应支持撤销重做及保存重开，旧版本历史和已有图纸外观保持不变。

1. 建立纯几何表示和定向测试，覆盖不同指向、退化及有限值输入。
2. 为对象、命令历史和交互入口增加明确样式及版本保护，覆盖编辑、引用及历史重放。
3. 实现画布绘制、点选框选、夹点和适应窗口，支持公差框及几何目标，并检查锁层和撤销。
4. 实现原生和图形兼容 DXF 的图形、元数据、导入及不支持情况的报告，验证保存重开和交换。
5. 更新手工验收及支持边界；专业人员复核标准样式与适用性，目标 CAD 和真实桌面需人工测试。

每一步仅运行对应定向测试及直接相关项；未完成全部步骤前不得将该样式标为可交付或标准合规。

2026-11-20：第 1 步的圆、径向连接线及垂直短线几何已实现；定向测试 7 项、修改文件 Ruff、格式及 basedpyright 通过。尚未接入模型、界面或 DXF，不能在产品中使用。字母保持水平由后续画布与导出步骤验证；第 2–5 步未完成。

2026-11-23 增量：基准对象新增版本 30 的圆圈样式，选中普通引线基准后可从“工具 → 基准标识样式”或标注工具栏“基准操作”切换；命令栏可使用 `DATUMSYMBOL`。画布绘制圆圈、径向连接线及短线，支持短线点选、移动、复制和撤销；原生 DXF 用图形块及元数据表达，图形兼容输出转为图形并失去结构，外部图形修改及旧版兼容有保护或提示。限制：当前不支持无引线或带表面指示的基准切换圆圈样式；尚未验证所有夹点、框选、附着变化、复杂字体及第三方 CAD，真实桌面与项目专业人员标准复核仍待完成。
