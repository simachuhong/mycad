## 3. 启动首页与文档入口

### 3.1 默认打开流程

无文件参数启动且没有待恢复会话时，显示首页，不先创建空零件或空二维图。首页使用简洁应用壳，显示产品名、文件操作和以下四张同级入口卡片；不显示尚无上下文的绘制工具、模型树或参数面板。

| 入口名称 | 解释文字 | 动作与状态 |
| --- | --- | --- |
| 二维图 | 独立平面绘图、图层与标注 | 创建独立二维文档，进入 AutoCAD 参考工作台 |
| 工程图 | 从模型建立投影视图、尺寸与图纸 | 新建工程图并选模板/图纸；模型来源可在插入视图时选择，不私自创建零件 |
| 三维零件 | 草图、特征与实体建模 | 新建零件并进入 ST10 参考工作台 |
| 三维装配 | 组织零部件与装配关系 | 当前卡片可见，明确“规划中，暂不可创建”；后续具备真实装配能力后启用 |

首页同时提供“打开文件”、最近文档列表（名称、类型、路径、最近打开时间）及清除最近记录入口。失效路径可定位或移除记录，不删除原文件。模板选取提供默认项，取消不产生脏文档。

从文件关联/命令行打开合法文件，直接进入对应环境；打开失败保留现有会话并显示可恢复错误。恢复上次会话若已支持，应尊重用户设置且显示恢复结果；本包不附带承诺自动恢复未保存草稿的新能力。

任意环境可回到“首页”，已有文档及未提交状态保留；首页不是关闭文档。创建第二份文档、切换到其他文档时，活动命令必须按当前会话守卫显式结束/取消，不能静默丢失。关闭最后一份文档回首页；应用退出仍执行现有未保存检查。

## 4. 公共框架：共享能力，分环境呈现

顶部按应用按钮、紧凑快速访问、文档标题、功能区组织；文档标签与功能区标签明确分层。新建/打开/保存/另存/导入导出放入文件入口；QAT 默认保存、撤销、重做，支持按环境配置。传统菜单作为兼容与完整功能入口可保留，但不再另铺一排重复的大按钮。

一个动作有稳定身份及统一启用/禁用/选中状态，Ribbon、QAT、菜单、搜索、快捷键复用它。参数编辑状态由活动命令持有，不由每个按钮另存副本。暂不具备前提的动作禁用并解释原因；尚无实现的功能不铺满灰色页签。首页装配卡是明确的文档类型预告例外。

布局按 `home / drawing2d / part / part-sketch / drawing / assembly` 概念环境分别管理；具体持久化键在实施包确定。共享动作不意味着共享可变编辑会话。二维别名和三维键位分别作用于所属环境，输入框内不抢走文字、数字、空格或 Enter。

文件/工作台切换只改变活动上下文，不把二维文档转成零件草图。现有“用作草图”等显式跨文档操作继续遵循引用与保存规则。

## 5. ST10 路线：零件与零件内草图

### 5.1 布局

```text
┌ 文件  QAT                  文档标题                         ┐
│ 主页 | 草图 | 检查 | 工具 | 视图                            │
│ 分组 Ribbon：大主按钮 + 多行小工具 + 组名                    │
├ 文档标签───────────────────────────────────────────────────┤
│ 当前命令条：步骤 / 选取对象 / 参数 / 预览 / 接受 / 取消       │
├ 导航选项卡 ──┬ 三维画布 ──────────────────┬ 按需属性面板 ──┤
│ 模型树       │ 模型、草图、动态输入、尺寸  │ 对象属性       │
│ 基准/草图    │                            │ 不重复命令表单 │
│ 特征/实体    │                            │ 可收起         │
├──────────────┴────────────────────────────┴────────────────┤
│ 提示：下一步动作       消息：对象/数量     视图与状态控制     │
│ 信息 / CLI / AI / 计划（默认收起，按需展开）                 │
└───────────────────────────────────────────────────────────┘
```

这是 MyCAD 默认位置提案。ST10 命令条的浮动/停靠细节需单独核对；本项目优先提供视口外可达位置，避免遮挡绘图对象。公共框架不能强制独立二维沿用此模型树或命令条。

### 5.2 功能区信息架构

| 页面 | 建议分组 | 要求 |
| --- | --- | --- |
| 主页 | 选择、草图/平面、实体特征、修改、阵列 | 拉伸/旋转/孔等居主层；长方体/圆柱/球集中“基础体”，不继续常驻独立左竖栏 |
| 草图（常驻入口） | 选择、绘制、编辑、尺寸、关系、构造、平面/视图、结束 | 未进草图也能找到绘制工具；点击进入选平面流程。未实现工具在 TODO 中跟踪，不能用空按钮通过验收 |
| 检查 | 测量、几何/引用诊断 | 保留真实可用测量功能，缺失诊断逐项实现 |
| 工具 | 变量/参数、文档选项、插件及应用设置 | 参数与显示配置分开，不承诺未实现变量表 |
| 视图 | 标准视图、显示样式、基准显隐、窗口布局 | 纯视图动作不改变模型历史 |
| 后续上下文/扩展 | 曲面、PMI、仿真、装配等 | 随真实能力独立交付；不能仅创建同名空页宣称对标完成 |

高频主要动作采用图标上、文字下的大按钮；同类次级动作采用两至三行小按钮；相近变体用下拉。组名统一在底部，用细分隔线控制层次。工具描述、命令参数、错误长文不塞进组标题。

### 5.3 命令条与草图生命周期

功能区负责“做什么”，命令条负责“做到哪一步及需要哪些参数”。基本步骤为选对象/支撑 → 定义参数或几何 → 查看候选 → 接受/取消；具体命令可省略无必要的步骤。接受操作满足既有确认红线并只提交一次，不在按钮之外再增加无意义的重复确认。

零件草图必须同时支持先选面再创建、先选绘图工具再选面。平面候选、锁定、正视分开显示；旋转相机和换工具不更换支撑。未锁平面时保留选中的绘图工具，拒绝非平面支撑并说明原因。

动态图元提供线长/角度、矩形宽高、圆半径/直径；锁定值不得被自动关系或捕捉覆盖。预览和最终落点共用几何解析结果。画布尺寸与关系反馈须真实可编辑且区分驱动/参考，不能用弹窗字段替代整个操作闭环。

未完成图元、已完成图元、整张草图三层状态明确区分：不能静默遗漏临时图元后完成草图；取消本图元、取消整张草图、撤销/重做都清除所属临时显示。无效输入保留可修正状态；模型写入仍经过 Bus。

封闭区域需填充、悬停和选择反馈；开放/自交轮廓定位错误；构造线不参与截面。区域身份与拉伸/旋转输入一致。全部操作继续以 [ST10-S01–S15](solid-edge-interaction-acceptance.md) 验收。

### 5.4 导航、视图与消息

左侧路径查找器展示文档、基准、草图、特征、实体及依赖/失效状态；显隐和抑制/删除必须区分。画布选择与树双向定位，身份使用稳定模型标识而非行号/名称猜测。右侧属性按需显示，当前命令参数不再分散在“选项”页和多个浮窗。

命令查找器提供紧凑搜索入口，结果包含名称、所在页/组、可执行状态；开发命令 ID 只在详情显示。提示条只展示当前步骤及可操作提示，消息区展示对象名称/数量/失败摘要，历史进入信息页。视图控制集中且可键盘访问。

## 6. AutoCAD 路线：独立二维工作台

独立二维不是“不整改”，而是**按 AutoCAD 独立整改**。保留已有可用几何、图层、尺寸和修改能力，再统一其入口、命令步骤和反馈。不能为三维整改搬走二维面板或改变二维快捷键。

```text
┌ 文件 / QAT / 图纸标题                                      ┐
│ 主页 | 注释 | 参数化 | 视图 | 管理 | 输出                    │
│ 绘图 / 修改 / 图层 / 特性（按页面呈现）                      │
├ 文档标签───────────────────────────────────────────────────┤
│            二维画布：十字光标、UCS、捕捉、夹点              │
│            光标附近动态坐标 / 长度 / 角度       [特性/图层] │
├ 二维命令行：当前命令、步骤、选项、输入；可展开历史 ──────────┤
│ 坐标 | 栅格 | 捕捉 | 正交 | 极轴 | 对象捕捉 | 动态输入 | 比例 │
└───────────────────────────────────────────────────────────┘
```

页面与状态开关为目标设计，尚无能力不启用假开关。现有明亮主题可继续使用，AutoCAD 参考不强制黑色背景；背景提供环境偏好。

| 方面 | 设计要求 |
| --- | --- |
| 绘图/修改 | 高频绘图和移动/复制/旋转/镜像/修剪/延伸/偏移集中；统一对象选择、基点、参数和结束步骤 |
| 命令输入 | 二维交互命令行与按钮驱动同一活动命令；支持逐步提示和选项，后续支持别名/历史。现有面向 Bus 的 CLI 不能直接冒充交互制图命令行 |
| 动态输入 | 光标附近显示坐标/长度/角度，键盘可切换和锁定；与命令行共享状态。规定绝对/相对/极坐标语法及单位，失败保留输入 |
| 状态栏 | 栅格显示、栅格捕捉、正交、对象捕捉、极轴追踪、动态输入分开；未实现极轴等明确作为缺口，不以正交代替 |
| 图层/特性 | 当前层、颜色/线型/线宽、显示/冻结/锁定集中；按需打开图层管理和选中对象特性，不使用零件特征树 |
| 选择/编辑 | 保留窗口/交叉框选及加减选；补齐与命令前选/后选、夹点、取消和焦点一致性。具体鼠标和键位在 AutoCAD 基线中核对 |
| 标注/约束 | 常规制图标注与参数化驱动关系明确区分；当前默认驱动尺寸与 AutoCAD 普通标注语义的差异必须专项评审，不在 UI 迁移时悄悄改旧档语义 |
| 保存/交换 | 保留文档归属、DXF 子集报告和现有审计；AutoCAD 风格不代表新增 DWG 或完整 DXF 支持 |

二维命令行默认保留紧凑可输入区域；三维 CLI 默认收起。AI/计划面板不替代二维命令行。二维的 Esc、Enter、空格、右键行为按命令阶段定义，与零件草图分别测试。

## 7. 工程图与未来装配

工程图使用 ST10 Draft 参考：功能区按图纸/模板、模型视图、尺寸、注释、检查、输出组织；导航显示图纸、视图及模型来源，参数只作用当前工程图。投影、剖视、比例、来源更新、引用断开和保存依赖分别给出状态。不把自由二维绘图、工程图尺寸和零件 PMI 混为一个标注系统。

装配本轮只设计入口和未来工作台边界：组件树、放置/配合、关系状态、爆炸/检查、来源引用需要独立领域与验收包。首页入口可见不等于装配文档已经支持；禁用状态不能悄悄落到零件文档。未来实现后沿用文档类型路由，无需再次改造首页四类结构。

## 8. 视觉、适配与设置迁移

- 复用明亮主题和 MyCAD 自有矢量图标；统一字号、间距、按钮状态和工具提示。默认 16/20 逻辑像素小图标、32 逻辑像素主图标作为原型起点，不冒充 ST10 精确规格。
- Ribbon 使用稳定高度与分组对齐，不与通用工具栏挤在同一行。窗口变窄时依序压缩次级文字、折叠组到可访问弹层、收起非必要侧栏；接受/取消和当前输入始终可达。
- 以 1024×768、1366×768、1920×1080 窗口及 100%/125%/150%/200% 系统缩放做布局检查，按实际可用逻辑尺寸调整。超出可用区域允许面板滚动，禁止按钮相互覆盖或落在屏幕外。
- 参数与错误同时有文字/图形提示，不只用颜色；支持 Tab 焦点、可访问名称及输入法。缩放与长中文标签不能破坏组布局。
- QSettings 增加布局版本并按环境保存；旧布局先备份并迁移，只重置受影响键。三维布局迁移不能清空二维工具栏、图层面板和快捷键偏好；提供“重置当前环境布局”。
- 按功能入口逐步迁移，确认功能和快捷键覆盖后才移除旧默认工具栏；不能旧壳与新壳长期同时铺满窗口。

## 9. 实现边界与验收

沿用 PySide6、当前 pyqtgraph GL、Command Bus、隔离候选及历史存档。UI 结构调整不需要改几何内核或历史 schema；确有新几何语义时独立评审。`ui` 不导入 `geom`/OCP，`core` 不引 Qt；动作描述与命令表单可拆出 UI 模块，避免继续堆进 `MainWindow`。

活动命令归属文档及来源修订；失效候选、切文档后旧回调、撤销后的旧预览不能提交。插件通过统一动作和环境分组贡献入口，卸载后保留可解释状态。AI 与企业功能按 Phase 3 实施，不因功能区设计提前引入网络依赖。
