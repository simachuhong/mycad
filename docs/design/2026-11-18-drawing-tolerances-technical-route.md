# 二维尺寸公差与形位公差技术路线评估

日期：2026-11-18。状态：技术路线建议，尚未进入实现。

下一工作包同时包含尺寸公差、形位公差框和独立基准标识。用户已确认 **GB/ISO 优先**；首批提供结构化标注表达，不进行实际几何的公差合格判定。建议沿用现有尺寸关联模型，新增独立形位标注对象，共用字体解析、排版度量和命令事务。主要成本在组合排版、关联生命周期和 DXF 交换，暂不需要新增几何内核或约束求解器。

本评估基于当前工作区，包含上一工作包尚未提交的文字字体实现。用户已反馈文字字体人工测试通过；此前自动验收证据的记录边界继续以原自检报告为准。

## 一 已确认范围与建议边界

| 项目 | 本工作包范围 |
| --- | --- |
| 尺寸公差 | 对称公差、上下偏差、极限尺寸；公差精度、字高比例、对齐；图纸样式及单尺寸覆盖 |
| 形位公差 | 形状、方向、位置、跳动符号；单行与多行公差框；直径前缀、材料条件修饰符、基准引用 |
| 基准标识 | 独立、可编辑对象；字母标识、放置位置和引线/指向位置 |
| 通用操作 | CLI、菜单/工具栏、画布放置、特性编辑、移动复制、删除、撤销重做、保存重开、DXF 导入导出 |
| 标准方向 | GB/ISO 优先，明确采用的版本和首批支持子集；不混入 ASME 专属规则 |

建议首批限定独立二维文档，零件草图和工程图纸面标注另行接入。多行先支持若干独立公差行堆叠，不将其自动解释为具有特殊共享格或复合语义的公差框。公差带实体生成、检测算法、公差链、配合代号自动查表、完整三维 PMI 不纳入首批。

GB/T 1182-2018 与 ISO 1101:2017 可作为几何公差标注规则的起点；基准、材料要求等规则还需核对各自适用标准。这里确认的是标准方向，不声明已逐条审查标准全文或实现完整标准符合性。[GB/T 1182 官方条目](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=C87A687A21B36E2F2D3A09BDF03DCA01)、[ISO 1101 官方条目](https://www.iso.org/standard/66777.html)

当前外部 `DIMENSION` 无 MyCAD 引用元数据时会报告未导入语义，不能把现有自导出往返当作通用外部尺寸导入。锁文件和本地安装版本为 ezdxf 1.4.4；其 `entities/tolerance.py` 能读写 `TOLERANCE`，但 `addons/drawing/frontend.py` 没有该实体的绘制分派，实体自身也未提供虚拟几何。这是原生形位公差导出预览的明确缺口。

## 三 方案比较

| 路线 | 收益 | 代价与判断 |
| --- | --- | --- |
| 扩展尺寸模型，新增独立形位对象 | 复用尺寸引用与历史，保留公差结构；影响范围可控 | 要增加组合排版和形位 DXF 编解码；**推荐** |
| 先统一所有二维、零件、工程图标注模型 | 长期可共用更多逻辑 | 涉及旧模型、坐标与持久化迁移，显著扩大本包回归范围；后续单列 |
| 使用外部完整标注/交换引擎 | 可能减少部分复杂兼容开发 | 当前没有确认可用的替代组件，需评估依赖、授权与集成；不作为本包前置 |

普通 TEXT/MTEXT 拼接可作为预览片段或有提示的图形降级输出，但无法承担公差真相源、基准关系和可编辑往返，不构成满足已确认范围的独立方案。

## 四 推荐数据与计算路径

### 尺寸公差

建议新增纯领域值对象 `DimensionTolerance`，由样式提供默认值、尺寸提供可选覆盖。名称为建议接口，最终以详细设计为准。

- `mode`：`none / symmetric / deviation / limits`。
- 数值：统一保存有符号的 `upper_deviation`、`lower_deviation`，单位继承尺寸的 mm 或度。要求有限数值且上偏差不小于下偏差；不能把“下偏差必须为负”当作规则。
- 排版：独立精度、文字比例、上下/居中对齐。显示精度不改写保存的偏差值；显示时消除负零。
- 继承：尺寸覆盖为 `None` 表示继承；显式 `mode=none` 表示关闭公差。首批建议完整对象覆盖，避免逐字段覆盖组合过多。
- 样式若提供数值默认，应区分长度与角度两组，避免将 0.1 mm 原样用于角度。无公差旧尺寸读入默认保持原外观。

例如名义尺寸 20、上偏差 +0.02、下偏差 -0.01，极限显示为 20.02 / 19.99。上偏差 +0.03、下偏差 +0.01 也必须可表达。公差模式转换保留同一组偏差数据，极限值由当前有效尺寸值计算，不保存两个可能过期的显示字符串。

驱动尺寸的名义值仍由原约束系统管理。修改公差只改变技术要求和标注，不驱动几何、不改求解器数值容差、不触发合格判定。角度必须使用画布当前扇区对应的显示值，避免沿用另一扇区的值计算极限。

`text_override` 需要明确优先关系：含一个 `<>` 时保留前后缀并由该位置插入结构化尺寸内容；纯字面覆盖或多个占位符与公差叠加时，建议要求用户先恢复单一数值占位符，防止伪造主值或重复公差。旧档读取保留原文本并提示冲突，不能静默丢弃数据。

### 形位公差与基准

建议新增 `core/geometric_tolerance.py`，与普通文字并列，不塞入 `SketchConstraint` 的求解关系。

| 对象 | 建议字段 |
| --- | --- |
| `FeatureControlFrame` | 稳定 ID、行列表、位置、旋转、图层、字体/尺寸样式引用、可选引线与附着引用 |
| `ToleranceRow` | 几何特征枚举、数值、显示精度、直径前缀、材料修饰符、有序基准引用 |
| `DatumReference` | 基准标签、可选本图标识 ID、修饰符；顺序明确，不用无序集合 |
| `DatumIdentifier` | 稳定 ID、标签、位置、指向点或稳定几何引用、图层和外观 |

建议首批符号清单覆盖直线度、平面度、圆度、圆柱度、线/面轮廓度、平行度、垂直度、倾斜度、位置度、同心/同轴度、对称度、圆跳动、全跳动；按 GB/ISO 表逐项确定显示名和允许组合。清单是开发建议，不代表这些符号在所有上下文下均可任意组合。

材料要求使用语义枚举，默认“未显式标注”，首批提供圈 M、圈 L 的适用表达；不从 AutoCAD 的选项集合直接推导 GB/ISO 合法性，也不默认添加圈 S。数值允许零的场景需按规则表判断，不能一律限制为大于零。建议增加理论正确尺寸的方框显示作为配套子项，单列验收；它与数值尺寸公差互斥，最终是否纳入首批需在详细设计中明确。

结构校验检查有限数值、必填格、枚举、ID 和引用完整性；标准规则校验采用显式矩阵，每条规则对应标准依据和测试案例。首批不把有限规则校验描述成完整的设计合规判断。

基准标签与基准对象 ID 分离：外部图纸可以先含 A/B/C 引用而没有本图基准对象，读入后标为未解析，保留顺序和文字；本地已解析引用支持显式关联。重命名应同步已关联引用。删除被引用基准时应拒绝或通过明确的解除关联操作完成，不能静默改为无基准公差。

引线附着复用稳定几何引用，首批限定已有可唯一解析的点、线和曲线位置。删除或重建目标导致失关联时保留标注与最后位置，并提示重关联；不使用最近几何自动猜测。复制同时选中的几何、基准和公差框时重映射内部 ID；单独复制框保留对同图基准的引用。跨图纸冲突必须显式重映射或报告。

## 五 绘制与交互

建立“语义解析 → 文字/符号片段 → 度量与格布局 → 绘制和命中”的共享流程。普通文字内容和字体解析复用上一包；公差堆叠、格线、引线和符号属于新的组合布局能力，不能仅调用现有单段 `layout_text` 后宣称已支持。

GB/ISO 几何符号、圈 M/L、直径符号和框线建议用自绘矢量图元，避免依赖用户字体是否含工程符号。数字、基准字母和说明使用字体服务。界面 Qt 适配留在 `ui`；供 DXF 预览/导出共享的符号轮廓和布局数据保持无 Qt、无几何后端依赖，字体度量通过接口传入。

同一布局结果提供字框、格框、选择边界和引线锚点，覆盖缩放、旋转、高 DPI、字体替代及样式更新后的缓存失效。标注尺寸采用物理单位，继承当前图层可见、冻结、锁定规则。

交互建议：DIMSTYLE 增公差页和文字样式引用；尺寸特性提供继承/覆盖/关闭。`TOLERANCE` 创建公差框，基准标识提供独立入口；菜单和工具栏均接相同应用操作。编辑窗口支持逐格输入与预览，画布点击提交，Esc 取消；未提交内容阻止误切文档，提交一次形成一次撤销操作。

## 六 命令 存档与兼容

尺寸公差扩展现有尺寸新增/修订命令与样式命令的版本。形位框建议 `drawing.tolerance.add/update/remove/batch`，基准建议 `drawing.datum_label.*`，避开项目保留的顶层 `datum.*` 建模命名空间。这里不提前注册命令 ID。

对象创建、修改、批量变换、样式依赖合并都经 Command Bus。公差框与基准状态纳入 reset、候选复制、批事务回滚、普通重放及优化重放；既有文字状态的处理路径可作参照，但不能省略任何生命周期分支。

继续采用 JSON 命令历史与既有审计字段。旧档缺少新字段使用兼容默认值；新字段通过有版本的命令参数保存，不因添加标注就改顶层存档格式。新版本读旧档必须覆盖；旧程序不能识别新命令时应明确报告版本不支持，不承诺新档可被旧版无损编辑。

不必为本包重写整个标注体系。将新增领域模型、布局、格式编解码放到独立模块，主窗口、画布及 DXF provider 负责接入，控制已经较大文件的新增职责。

## 七 DXF 路径与前置风险

### 尺寸公差

继续原生 `DIMENSION`/`DIMSTYLE`，加入 `dimtol`、`dimlim`、`dimtp`、`dimtm`、`dimtfac`、`dimtdec`、`dimtolj` 等已支持字段。内部下偏差为有符号数，DXF 下限按减去 `dimtm` 表达，转换必须显式处理：`dimtp = upper_deviation`，`dimtm = -lower_deviation`。公差和极限模式互斥。[ezdxf 公差接口与字段说明](https://ezdxf.readthedocs.io/en/stable/tutorials/linear_dimension.html)

每个已支持尺寸类型分别验证，不能用线性尺寸成功推定角度、径向、弧长、坐标尺寸全部成功。更新属性后同步生成匿名尺寸图形块，否则外部软件可能显示旧外观；原生属性、实体覆盖和样式继承的解析顺序保持一致。[ezdxf 尺寸图形说明](https://ezdxf.readthedocs.io/en/stable/howto/content.html)

原生公差字段加入当前快照/变更检测机制，并升级元数据版本。外部改过偏差后重导入必须采用外部值；不允许旧 MyCAD XDATA 把外部修改覆盖回去。

### 形位公差和基准标识

优先用原生 `TOLERANCE` 交换公差框。其 DXF 字段主要是内容字符串、DIMSTYLE 名、位置和方向，不能直接代替内部逐行逐格结构。[Autodesk TOLERANCE 定义](https://help.autodesk.com/cloudhelp/2024/ENU/AutoCAD-DXF/files/GUID-ADFCED35-B312-4996-B4C1-61C53757B3FD.htm)

需要独立内容编解码器，并用目标 CAD 产生的单行、多行、直径、M/L、基准组合样本验证。补充发现 Autodesk 的 [AcDbFcf::setText](https://help.autodesk.com/cloudhelp/2018/ENU/OARXMAC-RefGuide/files/OREFMAC-AcDbFcf__setText_ACHAR__.html) 提供了字符编码、字段分隔及示例，可作为编码依据；仍需用实际 CAD 文件验证细节，不能仅凭能写出实体就承诺互操作。复杂或未知格式应保留原始数据并报告未解析状态；输出降级必须说明语义损失。

基准标识和引线须单独评估原生表达。必要时可用内部生成的图形块承载外观和补充元数据，不等待下一工作包的用户级 BLOCK/INSERT 编辑功能。采用这种方式时，必须明确外部软件中它是图形块，不能声称外部也能作为结构化基准编辑。

导出预览建议扩展渲染适配，从**实际导出字节重新读取**原生公差框，再通过同一编解码器与矢量符号库绘制。不能以导出前 UI 截图冒充输出预览，也不能在文件里无条件叠加原生公差框与重复可见线条。若提供纯图形兼容导出，应作为单独模式并报告不可编辑的语义降级。

### 外部导入分级

1. MyCAD 原生往返：结构、样式、位置、关联可恢复，并尊重外部修改。
2. 支持子集的外部 `TOLERANCE`：无需 MyCAD XDATA，恢复可编辑的结构；基准引用允许未解析状态。
3. 支持子集的外部 `DIMENSION`：解析原生公差。若无法重建几何关联，建议作为独立参考尺寸保留名义值、偏差和定义点，并明确不随几何自动更新；不得冒称驱动尺寸。该独立参考尺寸模型是额外工作量，详细设计须单列。
4. 未支持格式：保留原始实体或明确报告无法保留的部分，禁止静默跳过。预览可见与语义可编辑分别记账。

其中第 3 项超出当前尺寸导入模型。若首批仅做自往返，必须明示这一缩减并重新确认，不能默认把已确认的 DXF 导入导出解释成只支持自有文件。

## 八 建议开发顺序与退出条件

| 顺序 | 子包 | 退出条件 | 相对工作量 |
| --- | --- | --- | --- |
| P0 | GB/ISO 支持矩阵与 DXF 风险验证 | 明确标准版本、符号/修饰组合、多行边界；获取并核对外部 CAD 样本及预览方案 | 中 |
| P1 | 尺寸公差领域、继承与事务 | 有符号偏差、旧档、单尺寸覆盖、撤销重放成立；公差不改几何 | 中 |
| P2 | 字体接入、组合布局和尺寸 UI | 三种模式可放置编辑；命中与绘制一致；旧尺寸外观兼容 | 中 |
| P3 | 公差框、基准、符号与关联 | 单/多行、M/L、基准、移动复制和失关联处理形成闭环 | 大 |

## 九 单元品控重点

| 子项 | 关键验收样例 | 最小验证范围 |
| --- | --- | --- |
| 数值与模式 | ±0.02、+0.02/-0.01、双正/双负偏差、0、负零、精度、极限尺寸、非法数值 | 新领域值对象及格式化测试 |
