## ST10 验收规则（2026-11-04 修订，优先适用）

1. **对照对象固定。** 同步操作可采用上述 ST9 视频，记录文件名、时间码和模式；其余每项记录 ST10 的具体版本/维护包（未知则标待核对）、同步或有序环境、界面语言、显示缩放、鼠标与快捷键设置，以及 MyCAD 的源码版本/工作区变更标识和运行环境。不得混用两种环境的操作结果，也不得把后续版本的界面当成 ST10。
2. **操作与结果共同通过。** 检查入口可发现性、工具分组、命令顺序、画布反馈、输入方式、取消/完成行为和最终几何。仅后端支持、按钮可点击、对话框嵌入工具栏或生成相似实体，不构成通过。
3. **图标例外明确。** 对标命令用途、分组和操作习惯；不要求像素级图标相同，不复制 ST10 图标。MyCAD 自有图标仍须能辨认、含文字或工具提示，并明确显示启用、禁用和活动状态。
4. **资料、工程验证、人工验收分开。** 结果分为“待核对 ST10 / 待实现 / 待复验 / 不通过 / 通过”；未执行不能填通过。每项通过须有 ST10 行为依据（同步操作可用已认可的 ST9 视频行为依据）和 MyCAD 实际操作证据，最终综合验收由用户确认。自动测试和代理截图单独记录，不自动转换为用户验收通过。
5. **差异不得自行豁免。** 已核对的适用参考行为（ST10 或已认可的 ST9 同步视频）与 MyCAD 不同，须记录具体差异、原因、影响及用户是否接受；未获用户接受的范围内差异仍阻断该项验收。不能以“当前尚不支持”把必验项改成不适用。
6. **范围与模式透明。** 用户指定 ST10，尚未限定只对标同步或只对标有序。各项先核对对应模式；MyCAD 当前草图驱动特征的历史语义按有序模型验证，直接选工具的入口可参考同步交互并明确记录。完整同步建模内核、非共面空间草图等原后续阶段功能单列，不据此扩大或缩减已确认的 M2-B 交付范围。

### 综合验收样例与证据

主路径：空零件 → 从常驻工具页启动矩形 → 选择 XY 平面 → 绘制 40×30 mm 矩形并建立宽高驱动尺寸 → 完成草图 → 选择轮廓沿法向拉伸 10 mm → 返回草图把宽度改为 50 mm → 保存重开 → 撤销/重做并核对历史。在没有其他几何、圆角或布尔操作时，初始体积应为 12000 mm³，改宽后为 15000 mm³；数值回归采用相对误差不超过 1e-6 的项目验收容差（不是声称 ST10 的内部公差）。

第二条路径从已有实体平面预选开始；另测偏置/旋转基准、带孔轮廓、构造线、开放草图和失败恢复。主路径通过不能代替 S01–S15 的其他子项。

## 所有建模命令的共同门槛

2026-10-25 草图分支反馈补充：约束求解成功后仍比较原几何与候选几何；检测到方向、跨侧、圆弧或内外关系变化时，预览以橙色标记相关图元，并在对话框列出变化，需核对勾选后确认。修改输入立即清除旧勾选。草稿控制点拖动中的分支警告保持到松开后，不能被坐标状态覆盖；Esc/撤销可恢复。该检测是保守几何检查，不证明解唯一。自动证据见 `task-P2-33-branch-feedback.md`，实机视觉与人工验收仍待完成。

1. 鼠标指向时能辨认候选对象，选择后明确显示面、边、区域或实体。支持纠正选择，禁止静默替换为默认对象。
2. 参数条位于模型之外；模型、选择和预览保持可见。命令过程中仍能旋转、平移、缩放及继续选择。
3. 当前步骤只显示当前所需参数，方向和尺寸直接关联所选对象。改值自动更新预览，相机不跳变。
4. 缺少目标或选择不适用时，明确说明需要什么，禁用确认，不生成看似成功的无关几何。
5. 最新有效预览才允许确认。确认只写入一次；取消还原原模型；失败保留可修正的输入。撤销、重做、存档重放得到同一结果。
6. 右键接受步骤与结束命令必须有明确状态区分；不能同时触发旋转、提交或弹窗。文字输入框的 Enter 与图形区的 Enter 分别验收。

## 二维绘图与草图（P2-32 开发自检；人工验收待完成）

当前绘图窗口保持临时草稿；只在“完成草图”时确认一次并通过 Bus 保存。文件菜单可新建独立二维图；它以 v3 `document_type: drawing2d` 存档，旧 v1/v2 文件继续按零件读取。二维图只接受已释放的草图命令，命令库会过滤三维特征，DXF 是其交换出口。当前实现支持 XY/XZ/YZ 基准面、原点偏置、局部 U/V 坐标输入、直线/折线/圆/圆弧/矩形、构造几何、线段端点/中点/圆心，以及有限直线段与有效圆/圆弧之间的交点捕捉；从线/折线下一点锚点还支持线段垂足和有效圆/圆弧切点。候选距离相同时，优先级为端点、交点、垂足、切点、圆心、中点、中心；绘图时按住 Shift 可临时关闭对象捕捉，状态栏显示该模式，正交模式保持独立。圆-圆、圆-弧、弧-弧交点只在各弧的有效扫掠范围内出现。顺/逆时针圆弧和完整草稿撤销/重做已实现。工作平面在第一条几何开始后锁定，未完成图元不能切工具或提交；Esc 先清除未完成图元，再次 Esc 取消整个草稿。完成后是一条可撤销、重做和重放的 `sketch.create` 命令。

Solid Edge Fundamentals 的二维绘图教学覆盖线、弧、圆、矩形、多边形、精确输入、网格/关系提示、移动/复制/旋转/镜像/缩放/拉伸、修剪和延伸；其草图教程也支持拖过多个元素修剪，并由尺寸驱动几何。MyCAD 已提供独立二维文档与上述基础图元。草稿画布另支持单击预选、多选、移动、复制、旋转、水平/竖直镜像、线性/环形阵列和带符号曲线偏移；阵列数量包含原始元素，完整 360° 环阵不重复首末位置。偏移适用直线、圆、圆弧、开/闭折线和矩形，以斜接连接折线转角，并对过尖转角、过大偏移、短边和自交结果拒绝操作。变换前后身份明确，复制/阵列/偏移元素分配新身份，旋转矩形在非正交角度下转为闭合多段线；草稿操作可逐步撤销/重做，完成按钮才经 Bus 提交。该范围仍不具备完整 IntelliSketch/自动关系提示、完整尺寸驱动拖柄、旋转/阵列方向操纵手柄；当前线性/环形阵列使用明确数值参数。

以下行为仍不得标为通过：完整圆延伸、多段线内部段延伸、完整闭合多段线拖动修剪/分割、圆角/倒角连接样式、偏移链的复杂拓扑修复、对已提交草图的就地完整编辑、尺寸驱动拖柄、完整 IntelliSketch 关系提示，以及 Solid Edge 实机操作对照。绘图草稿支持单击修剪和按住左键连续拖过多个可修剪区段；拖动过程直接显示草稿几何预览，松开后作为一次草稿撤销操作，Esc 还原原几何。修剪边界仍由当前草图自动推断。草稿还支持独立直线/圆弧端点及开放多段线首尾端点延伸、独立直线和开放多段线段交点分割、受限偏移及参数化变换。它们都不替代 Solid Edge 的完整选择/动态手柄流程，具体边界见 P2-34 自检。构造几何会保留并显示，草图拉伸会忽略构造元素。

自动化证据见 `.omo/evidence/task-P2-35-dxf-sketch-exchange.md`；目标 CAD 桌面与显示质量待用户验收。

Solid Edge Fundamentals 将移动、复制、旋转、镜像、缩放和拉伸列为 2D 操作；其 [CircularPatterns2d API](https://support.industrysoftware.automation.siemens.com/trainings/se/107/api/SolidEdgeFrameworkSupport~CircularPatterns2d_members.html) 说明二维环形阵列可由圆或弧定义。MyCAD 本轮对照并实现其中的移动、复制、旋转、镜像和基本线性/环形阵列；缩放、拉伸、阵列方向手柄与实时预览仍不支持。

人工验收步骤：

1. 使用“文件 → 新建二维图”，绘制并保存单独的 2D 图；核对存档为 v3 且标记 `drawing2d`，重开后检查元素、平面、单位和身份，确认没有意外生成 3D 实体，且尝试三维命令会被拒绝。
2. 分别在 XY、XZ、YZ 中输入相同局部坐标，检查世界坐标方向和法向；更改原点后检查所有几何整体移动。
3. 用鼠标和数值输入绘制同一条线、矩形、圆与弧；输入零长度、零半径、相同弧起终点和自交闭合多段线，检查定位提示且不能确认。分别用圆-弧、弧-弧相交样本验证有效扫掠区内会捕捉为交点，另用同一底层圆的扫掠范围外交点确认不会错误吸附。以已有线段作垂足目标、已有圆/圆弧作切点目标；距离近似时分别验证捕捉优先级。绘制过程中按住 Shift 确认捕捉暂时关闭且状态可见，松开后恢复；单独打开正交模式确认 Shift 不解除正交锁定。
4. 先完成一条元素，再开始下一条并撤销；对未完成元素按 Esc，确认只清除该元素；再次 Esc 取消草稿且文档历史不变。
5. 尝试在有几何后改工作平面或切换工具，确认选项恢复原值且元素不移动/消失；完成草图后撤销、重做、保存重开并核对 `sketch_id` / `entity_id`。
6. 选顺时针与逆时针圆弧，核对曲线实际经过方向而非只检查端点相同。
7. 选择并移动/复制线、圆、圆弧和矩形；确认源身份保留、副本身份唯一。分别以 90° 和非 90° 旋转矩形，检查轴对齐矩形类型与任意角闭合轮廓；镜像圆弧后核对方向反转。
8. 对两条已选择的几何做线性阵列，核对数量包含原件且步距按 U/V 生效；分别做 360° 和 180° 环阵，检查没有重复终点、部分角阵首末都在输入角度。连续撤销阵列、复制和移动，逐项确认几何与选择恢复。
9. 取消含有变换的草稿，确认文档历史不变；重新绘制、变换、完成草图，再撤销/重做并保存重开，核对草图元素数量、几何位置和稳定身份。
10. 对直线、圆弧和矩形分别做正负偏移，核对 U/V 左侧与曲线内外侧定义及新实体身份；对零偏移、过大的闭合轮廓内偏移、极尖拐角及交叉轮廓检查错误可读且原图保留。与 Solid Edge 偏移命令对照连接样式和预览差异。

## 参数化草图约束（P2-33 开发自检；人工验收待完成）

已有尺寸现在可在“操作”下拉框选择，保留目标图元、引用和尺寸身份，修改数值、驱动/参考语义及显示格式；确认按钮显示“确认修改”。预览在工作线程中同时求解草图并重建下游实体，曲线/标注和实体同步临时显示；改输入或取消会清除预览。只有完整预览成功才可确认，通过 `sketch.constraint.update@1` 追加修改历史。原命令与时间戳保留，后加的约束参与求解，参考标注按新几何刷新。自动回归覆盖已有半径修改后的实体重建、附加固定关系、参考直径、撤销/重做/无求解器重开、二维驱动/参考切换和非法轮廓回滚；分支变化提示、橙色定位和额外确认已补齐，见 `task-P2-33-branch-feedback.md`。

约束从“特征 → 草图约束”进入，按已保存草图与稳定图元身份选择引用。关系与尺寸先运行一次可取消预览；自由度、求解失败、冲突约束 ID、冗余约束 ID 及失败几何提示显示在对话框内。只有预览成功后“确认添加”可用，确认经 Bus 增加一条 `sketch.constraint.add` 命令；取消不写历史。保存命令包含求解后的完整几何、稳定约束引用、求解器版本与基础状态哈希，撤销/重做/重开从命令记录还原坐标，不重新调用求解器。驱动长度、距离、角度、半径和直径会改变草图；参考尺寸只测量当前几何并保存实际值，不移动图元。

当前可用子集包括重合、水平/竖直、平行/垂直、相切、同心、相等、固定点，以及长度/点间距离/角度/半径/直径；引用类型不匹配、零尺寸、无效弧段和不支持组合拒绝预览。PlaneGCS 0.9.6 仅作为 x86-64 可选依赖；未安装时保留普通绘图并明确禁用求解，T2/aarch64 未验证编译。MyCAD 对尺寸残差额外检查：线性容差为 `max(1e-12 mm, 草图范围 × 1e-9)`，角度容差为 `1e-7°`。自动样本覆盖 0.01～100000 mm；1000000 mm 样本由求解器显式失败，不返回部分几何。自由度为零不代表解唯一；欠约束解仍需人工检查位置与设计意图。

绘制直线时，接近水平/竖直的方向会提供可关闭的自动关系吸附；捕捉到唯一既有端点、顶点或圆心时，源码也会记录稳定重合关系。草图草稿画布用 H/V 与重合符号标出基础自动关系，手动约束对话框显示求解自由度、冲突/冗余引用和尺寸值。关系随草图保存和重放；后续草稿编辑若使自动关系失效，会移除并提示。新绘图草稿中的几何控制点拖动可调用 PlaneGCS，预览同时返回几何与约束，失败时保留上一个有效草稿状态，松开可作为一个撤销操作；约束拖动、完整草稿历史和冲突恢复已完成定向自动验证。自动推断仍只有水平/竖直与唯一重合子集，没有完整 IntelliSketch 关系提示或专用约束符号拖柄。按当前范围不提供已提交草图的画布几何编辑；尺寸改动后的重建已有定向自动证据；更复杂模型关联、aarch64 求解器构建和实机分支体验仍待验证。当前通过选择框、可读图元/引用与冲突红色高亮定位对象，实机直接选择/纠正体验仍待验收。

人工验收步骤：

1. 先绘制带两条相交线的草图，从“草图约束”依次添加重合、水平、垂直和平行关系；每次先预览，确认变化只在用户接受后写入历史。
2. 同一条非零线段先加水平关系，再加竖直关系；检查失败提示指出相关约束，不能写入退化零长线段，随后可取消并继续编辑。
3. 在圆、顺/逆时针圆弧、矩形边和多段线段上分别试半径、直径、弧长、等长、相切与同心；不匹配组合必须明确拒绝。
4. 给线段加驱动长度，改变数值后查看预览和自由度；撤销/重做、保存重开后核对同一 ID、数值和位置。再添加参考长度，确认测量值只读且原图元坐标不变。
5. 用 0.01 mm、典型零件尺寸和 100000 mm 尺寸样本查看误差；把工作几何扩大到求解器失败范围，确认没有部分结果被确认。
6. 在没有 Planegcs 的平台启动普通绘图，检查草图仍可保存；添加约束时要显示求解后端不可用，而不是伪造成功。
7. 在未提交草稿内绘制近水平/垂直线，并让端点/顶点/圆心捕捉到唯一既有几何；检查 H/V 与重合符号出现、位置跟随几何，撤销/取消后不留残影。再以冲突/无效约束做拖动预览，确认上次有效几何和符号一并保留。

上述手工步骤、视觉定位和误操作恢复仍待用户验收；自动测试不等于 Solid Edge 实机对标通过。

自动化证据只证明桌面控件与几何值符合断言；上述手工步骤、性能和显示质量由用户验收。

## 二维曲线修剪、直线/圆弧延伸与线段分割（P2-34 开发自检；人工验收待完成）

绘图草稿新增“修剪”工具。悬停在唯一候选直线、圆、圆弧、矩形边或开/闭合多段线段上会用青色加粗预选；单击要删除的交点间区段，修剪后继续留在工具中。线段切割器是有限直线段（含普通折线段和矩形边），曲线切割器为圆或圆弧；构造几何不参与相交。完整圆修剪后变为保留段对应的圆弧；圆弧按原方向分段，原 `entity_id` 保留给沿原方向的第一个剩余曲线段，其他片段取得新身份。开放多段线允许修剪某一段上相邻交点/路径顶点之间的一个区间：点击端头侧会将路径端点移到该交点；点击内部段时若产生两个有效路径，前段保留原 ID、后段分配新 ID，未修改顶点和构造状态保留。闭合多段线/矩形仅在至少有两个唯一交点时可按相邻交点限定的环区间修剪；修剪后剩余部分转为按原方向排列的单条开放多段线，保留原 ID、图层和构造状态。相邻边界、点击交点、重合或相切导致的交点不明确以及退化结果拒绝。对于引用用户约束的图元，移动/变换/修剪/延伸/分割在会改动该图元时明确拒绝，保留几何与关系；其他图元的约束保持。自动推断关系只在几何仍满足、且顶点引用拓扑未改变时保留。动作发生在尚未提交的绘图草稿中，完成草图时仍一次性经 Bus 写入 `sketch.create`，取消整个草稿不会写入历史。

鼠标必须命中唯一目标曲线，并点击交点之间的可移除区；点击交点、圆弧端点、重叠候选、相切点或没有足够交点会给出提示并保持草稿不变。直线交点切割只使用非构造有限线段；圆/圆弧之间按各自有效曲线范围求交。延伸目标为独立直线、圆弧或开放多段线首尾端点：直线和多段线路径端部沿各自已有方向延至最近的非构造有限直线段、圆或有效圆弧交点；圆弧端点沿现有顺/逆扫掠方向延伸到最近的范围外交点，切割对象可为直线段、圆或有限圆弧，构造几何不参与。延伸多段线只替换开放路径第一个或最后一个顶点，保留顶点顺序、中间顶点、构造属性和原 `entity_id`；不延伸内部段或闭合路径。圆弧扫掠达到整圆、交点不明确、点在曲线内部或端点方向无交点时拒绝且不修改草稿；成功操作保留原 `entity_id`。完整圆没有可延伸端点。

“分割”可选独立直线、矩形边及开/闭合多段线段；直线/开放多段线按最近交点分为两段，保留原 ID 的片段顺序确定；闭合路径/矩形至少需要两个唯一交点，点击两相邻交点之间时从该环区间的两个交点处切开，生成两条开放路径，所点区间对应的第一条保留原 ID，另一条分配新 ID。两条路径均保留构造/图层属性，边界、交点不明确、相切/重叠及退化时拒绝且草稿不变。三个操作都只在草稿内立即改几何，不单独写入命令；完成/取消仍沿用草图整体提交边界。

Solid Edge 的官方 `Line2d.SplitAtPoint` API 明确提供在指定点分割二维线的方法；其成员列表也列出该方法，并注明闭合 BSplineCurve2d 需要 `SplitAtPoints`。这支持“草图元素分割”这一功能方向，但不能证明多段线单段点击、片段身份/构造属性保留或当前 UI 步骤与 Solid Edge 等同；这些仍需桌面实机对照。参见 [SplitAtPoint API](https://support.industrysoftware.automation.siemens.com/trainings/se/106/api/SolidEdgeFrameworkSupport~Line2d~SplitAtPoint.html) 和 [Line2d 成员](https://support.industrysoftware.automation.siemens.com/trainings/se/106/api/SolidEdgeFrameworkSupport~Line2d_members.html)。

开放多段线跨多个段的连续区间修剪、开放多段线内部段/闭合路径延伸、闭合路径拖动跨段分割、已提交草图编辑、约束引用迁移仍未实现。闭合多段线目前仅支持单击删除两个唯一交点间的环区间，或以同样的交点区间将其分成两条开放路径；拖动跨段、以路径顶点作为边界及约束引用迁移仍未实现。这些是明确的支持边界；原 P2-34 条款及当前证据映射见 `task-P2-G-final-traceability.md`。

Siemens 的 [Solid Edge Fundamentals ST5 草图教程](https://support.industrysoftware.automation.siemens.com/training/se/en/ST5/pdf/mt01413-s-1050_en.pdf)展示了 Trim 拖过一个或多个元素的流程，也描述将开放线延伸到下一条几何；官方 [Line2d Trim API](https://support.industrysoftware.automation.siemens.com/trainings/se/106/api/SolidEdgeFrameworkSupport~Line2d~Trim.html)与 [Circle2d Trim API](https://support.industrysoftware.automation.siemens.com/trainings/se/106/api/SolidEdgeFrameworkSupport~Circle2d~Trim.html)说明按交点修剪对象，[Line2d Extend API](https://support.industrysoftware.automation.siemens.com/trainings/se/106/api/SolidEdgeFrameworkSupport~Line2d~Extend.html)说明可把开放图元延至指定位置，[Arc2d 成员](https://support.industrysoftware.automation.siemens.com/trainings/se/107/api/SolidEdgeFrameworkSupport~Arc2d_members.html)列出 Trim/Extend，[Line2d.SplitAtPoint API](https://support.industrysoftware.automation.siemens.com/trainings/se/106/api/SolidEdgeFrameworkSupport~Line2d~SplitAtPoint.html)说明可按给定点分割二维线。这些资料确认功能方向，不证明 MyCAD 的拓扑、身份和交互等同。MyCAD 修剪支持单击和连续拖过多个可操作区段，并从当前草图自动推断切割对象；拖动会产生一个草稿 undo 单元。Shift 按住时可临时切换到延伸预览，单击执行；悬停修剪/延伸目标会淡化原几何并高亮有效结果，预览不修改草稿。仍没有 AutoCAD Quick Trim 的 Fence 选择或 Ctrl 多段线子段选择；连续拖动延伸也未实现。预览、曲线边界和草稿撤销/重做已有定向回归。开放多段线仍只允许修剪单个段上由交点/路径顶点界定的区间；闭合多段线仅可单击删除由两个唯一交点限定的环区间，修剪后转成开放路径。圆弧延伸只接受端点并限制到不形成整圆。Solid Edge 的具体选择步骤、视觉反馈及约束迁移仍待桌面实机对照。

AutoCAD 的官方 [Streamlined Trim and Extend](https://help.autodesk.com/cloudhelp/2021/ENU/AutoCAD-LT-MAC-WhatsNew/files/GUID-61BE2250-3BFB-40D6-84EB-1429B1586818.htm)说明 Quick 模式默认把图中对象作为候选边界，并支持单选、拖选和两点 Fence；其 [命令预览说明](https://help.autodesk.com/cloudhelp/2024/ENU/AutoCAD-DidYouKnow/files/GUID-2EBF913D-2FDC-4D66-A397-068899D492DC.htm)展示悬停时预览修剪/延伸结果，[TRIM/EXTEND 模式切换说明](https://help.autodesk.com/cloudhelp/2020/ENU/AutoCAD-Product-Insights/files/GUID-E0C31199-27BA-48AA-8649-73FA3262E035.htm)说明按住 Shift 可在两种操作间切换；[PEDIT 多段线选择](https://help.autodesk.com/view/ACD/2026/ENU/?caas=caas%2Fdocumentation%2FCIV3D%2F2014%2FENU%2FfilesACD%2FGUID-648BDC21-E835-478F-A318-9D201479998D-htm.html)还支持 Ctrl 单击选择多段线子段。Solid Edge 的 [Extend to Next 教程](https://support.industrysoftware.automation.siemens.com/training/se/en/ST4/pdf/mt01413-s-1040_en.pdf)则采用先选择待延伸元素、再点近端头的流程，并可用 Ctrl 指定目标元素。MyCAD 目前自动取最近有效交点，已有目标悬停高亮，但没有结果预览、Shift 切换、Fence/拖选或多段线子段 Ctrl 选择；这些是与成熟工作流的明确差距，列入明日人工对照，不宣称功能等价。后续设计优先复用这些可验证的交互惯例；若因草稿边界或拓扑安全暂不采用，应记录具体差异与理由。

人工验收步骤：

1. 绘制一条水平线和一条穿过其中部的竖线；切换“修剪”，悬停目标线确认唯一线段青色高亮，再点击交点一侧，检查保留侧恰好终止于交点，工具仍可继续使用。
2. 让两条竖线穿过同一水平线，点击两交点之间；确认中段删除、两端保留，并检查首段保留旧 ID、另一段使用不同 ID。
3. 点击交点、线端、没有交点的直线，以及重叠的目标直线；每种失败都应说明原因，几何不变且仍可纠正后继续。
4. 选择直线两端分别延伸到不同的近邻线段交点，检查端点方向、最近交点和原身份；再分别从顺时针、逆时针圆弧的起点/终点延伸到直线、圆或圆弧交点，检查方向不翻转、最近交点和原身份。扫掠即将闭合成整圆时必须拒绝，点击曲线内部或无交点方向时几何不变。
5. 在一条被两根线穿过的直线和开放多段线段上分别靠近左/右交点使用“分割”，检查选择最近交点、两段共享交点、前段保留原身份、后段使用新身份且构造状态保留；等距点击应拒绝，不得任意挑选。再让两根非构造切割曲线穿过闭合多段线/矩形，在两个交点之间使用“分割”，确认生成两条开放路径且所点区间对应片段保留原身份、另一条获得新身份；交点不足、点在交点上或构造线作为唯一切割对象时草稿不变。
6. 用两条切割线穿过完整圆，分别删除小弧和大弧；再用一条切割线裁切顺/逆时针圆弧，确认圆转为剩余圆弧且源 ID 保留、圆弧断开时新片段 ID 唯一。以两个圆相交作切割器，检查交点角度和所点区段；圆弧有效范围之外的虚交点不能参与修剪。
7. 将构造线作为唯一交叉线，确认它不会意外修剪、延伸或分割工作几何；修剪/延伸时用圆和有效范围内的圆弧作切割对象；在修剪目标存在时把圆弧悬停在“分割”上，应没有错误预选；在开放多段线段上悬停应预选唯一目标。
8. 完成编辑草稿后确认只写入一条草图命令，取消草稿则历史不变；保存重开后核对最终坐标与实体身份，再检查整张草图命令的撤销/重做。
9. 对穿过两条切割线的开放多段线单段，在两交点之间使用“修剪”，检查路径分成前/后两条、前段保留原 ID、后段获得新 ID，其他顶点与构造状态保持；点击交点或无交点段应明确拒绝。
10. 分别从开放多段线首端和末端使用“延伸”，确认悬停高亮、沿终端段方向取最近交点、路径其余顶点/顺序/构造状态/原 ID 保持；尝试点内部顶点、闭合路径顶点或只有构造切割线时应提示且草稿不变。撤销成功延伸应还原整条原路径。
11. 让开放多段线的首段/末段各只有一个内部交点，分别点在交点与端点之间并在交点另一侧；检查删除区间、剩余路径连通性和原 ID。再让内部段只有一个交点并点选区间，检查断开的有效两段按原顺序排列；单侧无有效边段时只保留另一段，撤销恢复完整路径。
12. 沿包含多个可修剪间隔的直线、圆弧及同一开放多段线拖动；检查每段预览随鼠标更新、松开后一次撤销可还原整次拖动、Esc 可取消；再在“修剪”工具下用 Shift+单击唯一开放端点，确认临时执行一次延伸，普通单击仍保持修剪。
13. 绘制闭合多段线并让至少两条非构造切割曲线穿过闭环；单击两个唯一交点之间的环区间，确认剩余曲线依原方向变为一条开放多段线，源身份/图层/构造状态保留；点击交点、切线/重叠切割或交点不足时草稿不变。
14. 让两条非构造曲线穿过矩形边，单击其中一个唯一矩形边区间；确认矩形转为具有原身份、图层、构造状态的开放多段线，并且没有剪切器时矩形保持原样。
15. 悬停可修剪区段，核对淡化原目标与高亮结果预览；将鼠标移到无效/歧义区间，确认预览消失且原几何不变。在“修剪”工具内按住 Shift 悬停开放端点，检查切换到延伸结果预览，松开恢复修剪；再单击执行并验证撤销。
16. 用直线/开放多段线首末端分别延伸到有限直线段、圆和有效圆弧；核对沿端段方向取最近交点。让线与圆弧相交但交点位于圆弧扫掠范围外，确认不显示预览且点击不能改变几何。

已有自动回归覆盖修剪/延伸/分割的有限线段交点、删除点击所在区间、中段删除后的分裂身份、圆/圆弧曲线切割、顺逆向弧修剪与端点延伸、开放多段线单/双交点修剪与撤销、开放线/多段线段分割、首尾端点延伸与撤销、最近交点、整圆延伸拒绝、构造线过滤，以及真实 Qt 画布悬停预选和鼠标点击。闭合路径/矩形修剪与分割、Shift 临时捕捉关闭、约束标记和引用保护已有回归；最终审查另修复了跨起点顶点次序，并用成功路径、长度和身份断言覆盖。分割工具的悬停会预选直线、矩形边与多段线段。实机视觉与 Solid Edge 实际命令步骤仍待用户验收。

## 草图驱动实体（P2-36 开发自检；人工验收待完成）

`feature.extrude@2` 允许拉伸命令引用历史中先前提交的草图。建模命令栏提供“草图”来源，选择已有草图、距离和新建/添加/切除方式后，先在隔离模型上预览，再显式确认并经 Bus 提交。命令保存稳定 `sketch_id` 引用；历史重放按引用草图当时的状态重新生成几何。版本 1 参数及旧历史语义保持不变。

目前轮廓组装支持互不相交的多个闭合区域、偶数层级实体岛及其直接孔环；构造几何被忽略。`feature.extrude@2` 可用任意右手工作平面和正负距离，`@3` 支持居中对称总深度，`@4` 的草图分支支持选取有限平面面作为到面终止对象。到面终止复用 build123d `Until.NEXT`，目标面需覆盖截面到达终止位置的区域；曲面面和无法与扫掠截面相交的选择会失败。`feature.revolve@2` 可从草图生成回转体，支持 X/Y/Z 全局轴及受限的角度范围，`@3` 可引用同草图构造线作为偏置轴。多区域实体数、接触/重叠区域及复合曲线已有定向验证；已有草图数值尺寸可预览并重建下游，直接画布自由几何编辑和完整通用关联重建不支持，也不应把当前范围表述为完整特征树或 Solid Edge 等价能力。

人工验收步骤：

1. 在 XY 草图中绘制圆形外环和中心孔，再选择“特征 → 拉伸 → 草图”；确认预览保留孔洞，正负距离分别沿法向两侧生成。
2. 选择矩形加封闭折线内环、以及由顺/逆圆弧组成的闭环；确认体积与轮廓一致。构造线不得被当作实体轮廓。
3. 在 XZ/YZ 草图中执行正负拉伸，检查与局部法向的关系；依次试新建、添加、切除和非法相交轮廓。
4. 在确认前取消，文档命令数与模型不变；确认后撤销/重做、保存重开并核对体积与稳定草图引用。
5. 在无效输入、空草图、开口轮廓、自交轮廓和相交外环时，确认按钮禁用或出现定位错误，不能残留半个实体。
6. 在 XZ 平面绘制远离 Z 轴的矩形截面，选草图来源与 Z 轴回转，验证 360° 回转体及小于 360° 的开放角度预览；确认回转轴原点约束显示清楚。
7. 在一张草图中绘制两个分离的外环、其中一个外环的孔和孔内实体岛；确认拉伸输出的区域/实体数量、孔洞与岛的材料关系正确，保存重开及 undo/redo 保持一致。再使两个外环相交或相切，确认操作拒绝并明确提示。

本次自动回归覆盖草图引用、内外环、构造元素过滤、圆弧闭环、非 XY 与正负方向、异步预览确认、undo/redo 和存档重放；手工步骤、视觉显示与 Solid Edge 实机比较仍待用户验收。
