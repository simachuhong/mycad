## 1. 设计目标与参考

### 1.1 目标

- **中间**：Solid Edge 式干净大视口，作为建模主舞台。
- **左右架**：借鉴 Node-RED 的左侧可折叠分类 + 检索菜单，以及右侧可伸缩、可扩展 Tab 工作区（**不**使用 Node-RED 流程画布）。
- **底栏**：Chat + CLI；改模型默认 **先列出命令再确认**。
- **顶层**：常驻菜单 + 可消隐、可换边 Toolbar（命令分层对齐 Solid Edge，而非整条 Ribbon 照搬）。

### 1.2 非目标

- 像素级复刻 Solid Edge 或任何商业 CAD。
- 一屏同时堆满 Ribbon、双树、流程图与大聊天区。

## 2. 主布局

```text
┌ 菜单栏 MenuBar（常驻）──────────────────────────────────────────┐
│ Toolbar（可消隐；可停上/下/左/右；可锁）                          │
├─────────┬──────────────────────────────┬────────────────────────┤
│ 左栏     │         3D 视口              │ 右栏 Tabs               │
│ 🔍 搜索  │     （主舞台）                │ 结构|属性|选项|显示|测量 │
│ 分类折叠 │                              │ （可拖宽 / 收起）        │
│ 命令库   │                              │                        │
├─────────┴──────────────────────────────┴────────────────────────┤
│ 底栏 Tabs： Chat | CLI          （可拖高 / 收起，宜留一行入口）   │
├─────────────────────────────────────────────────────────────────┤
│ 状态栏（一行常驻：提示 / 单位 / 重建状态）                         │
└─────────────────────────────────────────────────────────────────┘
```

### 2.1 区域职责

| 区域 | 职责 |
|------|------|
| 菜单 | 完整功能入口与设置；不消隐 |
| Toolbar | 高频动作；可消隐、换边、锁定 |
| 左栏 | 完整命令库：分类 + 搜索（Node-RED 调色板式架子） |
| 视口 | 几何结果与点选 |
| 右栏 | 结构（PathFinder 语义）、属性、命令/计划参数、显示、测量 |
| 底栏 | 对话计划确认 + CLI |
| 状态栏 | 常驻一行提示，不与底栏合并 |

### 2.2 刻意换位说明

Solid Edge 的 PathFinder 多在左侧。本产品左侧固定为命令库，故 **结构树放在右栏「结构」Tab**，避免左栏同时承担树与命令。

## 4. Toolbar

### 4.1 行为

- **消隐**：视图菜单或快捷键切换可见性。
- **换边**：可停靠上 / 下 / 左 / 右；拖到边缘吸附。
- **锁定**：锁定后不可拖换边。
- **布局记忆**：边与显隐写入 `QSettings`，下次启动恢复。
- **与底栏关系**：停在底部时，位于底栏 Chat/CLI **上方**，不得遮挡输入框。
- **与左栏关系**：停在左侧时，优先贴窗口最外侧，命令库在其内侧。
- **自动滑出**：可作为二期；首期手动显隐 + 换边即可。

### 4.2 最小图标集（约 12–17 个）

**文件与历史**

1. 新建  
2. 打开  
3. 保存  
4. 撤销  
5. 重做  

**选择与视图**

6. 选择  
7. 适应窗口  
8. 旋转观察  
9. 平移  
10. 窗口缩放  
11. 显示样式（着色 / 线框）  

**建模高频**

12. 拉伸  
13. 旋转  
14. 孔  
15. 圆角  

**智能体**

16. 待执行计划（有草稿计划时高亮）  
17. 确认执行 / 取消计划  

更多命令只进入左栏，避免 Toolbar 膨胀。

## 6. 右栏：Tabs（对齐 SE）

### 6.1 默认 Tabs

| 顺序 | Tab | 对标 SE | 内容 |
|------|-----|---------|------|
| 1 | **结构** | PathFinder | 特征树；基准/草图/特征/实体分组；点击与视口联动 |
| 2 | **属性** | 选中属性 | 名称、可见性、特征摘要；无选中时文档属性 |
| 3 | **选项** | 命令参数面板 | 当前命令或待确认计划中选中步骤的参数表单 |
| 4 | **显示** | 显示配置 | 着色模式、基准/草图显隐等 |
| 5 | **测量** | Measure | P2-14 已启用：当前实体体积、圆柱面直径、两圆边中心距、平行平面间距；精确 BREP 查询，其他面积/长度测量后续扩展 |

默认常驻展示：**结构**、**属性**；**选项**在有命令或计划时自动展开；显示/测量可按需打开。

**不在右栏放置完整 Chat**（聊天在底栏）。

### 6.2 结构树分组

```text
文档名
├── 坐标系 / 基准
├── 草图
├── 特征
└── 实体 / 设计体
```

### 6.3 自动跳转

| 用户动作 | 右栏行为 |
|----------|----------|
| 选中视口或树节点 | 聚焦 **属性**（或结构内滚动到对应项） |
| 启动特征命令 | 切换 **选项** |
| Chat 生成待确认计划 | 切换 **选项**；点步骤可编辑参数 |
| 启动测量 | 切换 **测量** |

### 6.4 扩展约定

```text
register_right_tab(id, title, widget_factory)
```

## 7. 底栏：Chat 与 CLI

### 7.1 Tabs

| Tab | 作用 |
|-----|------|
| **Chat** | 多轮对话；展示计划卡片；执行 / 编辑 / 取消 |
| **CLI** | 精确命令与历史；与计划命令文案等价 |

可选后期：**Log**（重建错误、工具调用轨迹）。

### 7.2 计划确认交互（默认）

```text
用户：做一个法兰，外径 80，内孔 20，厚 8，4 个均布 M6，孔距 50

Agent 计划卡片：
  1. cylinder d=80 h=8
  2. bore / cut d=20
  3. hole_pattern d=6 count=4 pcd=50
  [执行] [编辑] [取消]
```

- 编辑：可改数字；与右栏「选项」同步后再次展示计划。
- 执行：整批提交 Command Bus；失败则事务回滚。
- 输入区：可统一输入框，以 `/` 或模式切换分流到 CLI（实现可选）。

### 7.3 伸缩

- 高度可拖；折叠后宜保留一行入口或芯片。
- 默认高度约主区分屏的 20%–25%。
- 建议快捷键切换底栏（实现时在帮助中列出）。

### 7.4 扩展约定

```text
register_bottom_tab(id, title, widget_factory)
```

## 9. 视觉方向（初稿级）

- **气质**：工业灰蓝，接近专业 CAD，而非消费级紫色炫光风。
- **层次**：左右栏略深，视口区域更亮、更干净。
- **字体**：选用清晰的 UI 无衬线字体（实现时在 QSS 中固定，避免系统默认杂乱）。
- **手段**：PySide6 + QSS；图标首期可用开源图标集，风格统一即可。
- 本文件不规定像素稿；后续可另附视觉规范。

## 实现注记（阶段 1 落地差异）

- **Chat 页**：当前为「计划卡片流」——命令库双击起草 → 卡片编辑/取消/整批执行（§7.2 的卡片三键与选项同步已实现）；多轮自然语言对话输入属阶段 2，输入区分流暂不实现。
- **Toolbar**：消隐/停靠换边与 QSettings 位置记忆已实现（§5）；高频动作按钮已落地为 13 个文字按钮（文件/历史 5 + 视图 3 + 建模 4 + 智能体 1），与菜单共用同一批 QAction 对象（勾选/启用不分叉），建模快捷键走左栏命令库同一条起草路径（草稿 → 确认 → 执行）；首期无图标资源故为纯文字按钮，§4.2 的选择/旋转观察/平移/窗口缩放由 GL 视口鼠标手势承担，确认执行/取消计划在 Chat 计划卡片内完成。
- **命令速查**：帮助 → 「命令速查…」打开可搜索对照表——每行给出 CLI 动词（`cylinder`）、命令 ID（`feature.cylinder`）、中文名与必填参数（`radius*` 标必填，括号内为嵌套子键），用于消除「动词 vs 命令 ID」混用（§6.2 的命令清单在 GUI 内只读呈现，执行仍须走命令库起草 → Chat 确认）。
- **CLI Tab**：与 headless REPL 同源——复用 `cli/session.execute_line`，文案与退出码逐字一致；`quit`/`exit` 在 GUI 内不关窗，仅回显提示。
- **视口拾取**：采用数学射线×三角形求交（确定性、离屏可测、CI 稳定），未走 glReadPixels 编码色读回；默认只测试当前模型快照，命中选择当前模型整体，不推断命令来源。点击结构树中的特征行会进入历史预览并以该命令执行后的完整状态替换视口场景；“视图 → 返回当前模型”退出预览。预览期间视口不做当前模型拾取，状态栏显示预览 ordinal。


## 2026-10-25 图内尺寸标注重做

尺寸工具采用画布命令，不再打开尺寸表单窗口。工具栏提供智能、水平、垂直、对齐、角度、半径、直径、弧长、连续、基线、坐标，分别具有图标、提示及活动状态。对象或捕捉点选择后显示尺寸线、箭头与实测值，随鼠标移动并点击放置；滚轮/中键仍可导航，Esc/右键取消当前命令。连续沿上个终点、基线沿本组首点，坐标由用户拾取基准点。

默认驱动尺寸，可切换参考尺寸；命令条切换驱动、固定方式、显示精度和比例。双击标注，在文字旁显示内嵌数值框；驱动值先求解预览再确认，分支变化再次明确确认。拖动文字与尺寸线分别保存文字点及放置点，普通单击或双击后取消不得增加历史。草稿保持本地撤销事务，已提交标注通过同一画布操作和后台 CommandBus 更新，并重建下游实体。位置按草图局部 mm 持久化；同平面不同原点的显示和预览使用相同坐标变换。

设计与验收范围见 [图内标注设计](superpowers/specs/2026-10-25-in-canvas-dimensions-design.md)。本节描述当前实现，不表示 AutoCAD/Solid Edge 实机等价验收已通过。


## 2026-10-25 DIM 默认层与整张图纸图层控制

新尺寸默认进入 DIM 层，尺寸线、箭头、文字共用独立层的颜色、线型、线宽；工具栏可选择其他标注层，或“使用当前图层”。旧尺寸省略独立层时仍继承几何图层，可在管理器批量移入 DIM。隐藏几何层不影响独立 DIM 标注，隐藏 DIM 不改变几何。

图层属性管理器采用非模态表格，统一控制草稿和已提交对象。显示/隐藏、冻结/解冻、锁定/解锁分别保存；解冻不自动打开已关闭图层。冻结图层不参与显示再生、适配范围、选择或捕捉，关闭图层仍计入范围；当前绘图层不能冻结。锁定标注层不能新建或修改该层尺寸。隐藏和冻结保持几何及驱动约束有效。

图层属性、默认标注层与已提交旧标注迁移通过 drawing.layers.set 命令记录，可撤销、重做、存盘重开。局部草稿历史与全局图层命令按历史位置交错撤销，草稿撤销不会恢复过时的图纸层属性。DXF 原生图层写入独立的 off/frozen/locked 状态，DIMENSION 实体使用其标注层；不包含布局视口专属冻结。


## 2026-10-26 图内驱动尺寸与固定方式

新尺寸默认驱动，用户可明确选择参考尺寸；编辑已有参考尺寸不会改变新建命令的默认方式。首次放置驱动尺寸后，值框位于尺寸文字旁；Enter 确认、Esc 取消。确认后收起该输入框并把焦点交回画布，连续标注命令仍可继续。

水平、垂直投影保持原测量方向；坐标尺寸保留有向正负值。线性尺寸的命令条可选自动、固定起点、固定终点、中心对称。自动遵守连通约束分量内已有定位关系，否则固定首个测量点；径向尺寸保持圆心，角度保持第一条边。显式固定方式和既有约束冲突时拒绝本次操作，不删除关系、不应用部分结果。

固定方式保存在尺寸 anchor_mode 中，缺省 auto 兼容旧档案；它只在当前编辑求解时临时定位，不生成永久固定关系，界面自由度按原有持久约束计算。预览尺寸线及关联参考数值随候选几何更新，取消恢复原图。冲突图形和尺寸在画布中标红，并显示自由度、冲突及冗余摘要。DIM 归属、尺寸位置、稳定身份和审计历史保持，草稿本地撤销、已提交尺寸走 CommandBus，重开重放使用冻结解。
