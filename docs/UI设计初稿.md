## 1. 设计目标与参考

### 1.1 目标

- **中间**：Solid Edge 式干净大视口，作为建模主舞台。
- **左右架**：借鉴 Node-RED 的左侧可折叠分类 + 检索菜单，以及右侧可伸缩、可扩展 Tab 工作区（**不**使用 Node-RED 流程画布）。
- **底栏**：Chat + CLI；改模型默认 **先列出命令再确认**。
- **顶层**：常驻菜单 + 可消隐、可换边 Toolbar（命令分层对齐 Solid Edge，而非整条 Ribbon 照搬）。

### 1.2 非目标

- 像素级复刻 Solid Edge 或任何商业 CAD。
- 一屏同时堆满 Ribbon、双树、流程图与大聊天区。

## 2. 主布局

```text
┌ 菜单栏 MenuBar（常驻）──────────────────────────────────────────┐
│ Toolbar（可消隐；可停上/下/左/右；可锁）                          │
├─────────┬──────────────────────────────┬────────────────────────┤
│ 左栏     │         3D 视口              │ 右栏 Tabs               │
│ 🔍 搜索  │     （主舞台）                │ 结构|属性|选项|显示|测量 │
│ 分类折叠 │                              │ （可拖宽 / 收起）        │
│ 命令库   │                              │                        │
├─────────┴──────────────────────────────┴────────────────────────┤
│ 底栏 Tabs： Chat | CLI          （可拖高 / 收起，宜留一行入口）   │
├─────────────────────────────────────────────────────────────────┤
│ 状态栏（一行常驻：提示 / 单位 / 重建状态）                         │
└─────────────────────────────────────────────────────────────────┘
```

### 2.1 区域职责

| 区域 | 职责 |
|------|------|
| 菜单 | 完整功能入口与设置；不消隐 |
| Toolbar | 高频动作；可消隐、换边、锁定 |
| 左栏 | 完整命令库：分类 + 搜索（Node-RED 调色板式架子） |
| 视口 | 几何结果与点选 |
| 右栏 | 结构（PathFinder 语义）、属性、命令/计划参数、显示、测量 |
| 底栏 | 对话计划确认 + CLI |
| 状态栏 | 常驻一行提示，不与底栏合并 |

### 2.2 刻意换位说明

Solid Edge 的 PathFinder 多在左侧。本产品左侧固定为命令库，故 **结构树放在右栏「结构」Tab**，避免左栏同时承担树与命令。

## 3. 菜单栏

对齐 Solid Edge 信息架构的精简集：

| 菜单 | 项（首期） |
|------|------------|
| **文件** | 新建、打开、保存、另存为、导入、导出（STEP/STL）、截图、退出 |
| **编辑** | 撤销、重做、删除、选择过滤器 |
| **视图** | 着色/线框、适应窗口、标准方向（正视/等轴等）、显示/隐藏 Toolbar、Toolbar 停靠边、显示/隐藏左/右/底栏 |
| **特征** | 常用特征入口（与左栏重复可接受，便于发现性） |
| **工具** | 选项、单位、测量、重建 |
| **智能体** | 查看待确认计划、清空对话；（预留）信任模式且默认关闭 |
| **帮助** | 快捷键、关于、开源许可说明（Apache-2.0） |

## 4. Toolbar

### 4.1 行为

- **消隐**：视图菜单或快捷键切换可见性。
- **换边**：可停靠上 / 下 / 左 / 右；拖到边缘吸附。
- **锁定**：锁定后不可拖换边。
- **布局记忆**：边与显隐写入 `QSettings`，下次启动恢复。
- **与底栏关系**：停在底部时，位于底栏 Chat/CLI **上方**，不得遮挡输入框。
- **与左栏关系**：停在左侧时，优先贴窗口最外侧，命令库在其内侧。
- **自动滑出**：可作为二期；首期手动显隐 + 换边即可。

### 4.2 最小图标集（约 12–17 个）

**文件与历史**

1. 新建  
2. 打开  
3. 保存  
4. 撤销  
5. 重做  

**选择与视图**

6. 选择  
7. 适应窗口  
8. 旋转观察  
9. 平移  
10. 窗口缩放  
11. 显示样式（着色 / 线框）  

**建模高频**

12. 拉伸  
13. 旋转  
14. 孔  
15. 圆角  

**智能体**

16. 待执行计划（有草稿计划时高亮）  
17. 确认执行 / 取消计划  

更多命令只进入左栏，避免 Toolbar 膨胀。

## 5. 左栏：命令库

### 5.1 交互

- 顶部：**搜索框**（过滤命令名称与关键词）。
- 下方：**可折叠分类**；项为图标 + 名称；双击或点击启动命令（复杂命令进入确认/选项流）。
- 可整体收起为窄条或隐藏（视图菜单）。

### 5.2 分类（首期）

| 分类 | 说明 |
|------|------|
| 草图 | 草图相关（首期可弱化，占位与少量入口） |
| 特征 | 主体创建类 |
| 修改 | 圆角、倒角、抽壳、布尔、阵列等 |
| 基准 | 基准面 / 轴 / 点 |
| 检验 | 测量入口等 |
| 视图 | 与 Toolbar 视图类可重叠，左栏更全 |
| 智能体工具 | 生成计划、解释模型等 |

## 6. 右栏：Tabs（对齐 SE）

### 6.1 默认 Tabs

| 顺序 | Tab | 对标 SE | 内容 |
|------|-----|---------|------|
| 1 | **结构** | PathFinder | 特征树；基准/草图/特征/实体分组；点击与视口联动 |
| 2 | **属性** | 选中属性 | 名称、可见性、特征摘要；无选中时文档属性 |
| 3 | **选项** | 命令参数面板 | 当前命令或待确认计划中选中步骤的参数表单 |
| 4 | **显示** | 显示配置 | 着色模式、基准/草图显隐等 |
| 5 | **测量** | Measure | 距离/长度/面积等；可先占位 |

默认常驻展示：**结构**、**属性**；**选项**在有命令或计划时自动展开；显示/测量可按需打开。

**不在右栏放置完整 Chat**（聊天在底栏）。

### 6.2 结构树分组

```text
文档名
├── 坐标系 / 基准
├── 草图
├── 特征
└── 实体 / 设计体
```

### 6.3 自动跳转

| 用户动作 | 右栏行为 |
|----------|----------|
| 选中视口或树节点 | 聚焦 **属性**（或结构内滚动到对应项） |
| 启动特征命令 | 切换 **选项** |
| Chat 生成待确认计划 | 切换 **选项**；点步骤可编辑参数 |
| 启动测量 | 切换 **测量** |

### 6.4 扩展约定

```text
register_right_tab(id, title, widget_factory)
```

## 7. 底栏：Chat 与 CLI

### 7.1 Tabs

| Tab | 作用 |
|-----|------|
| **Chat** | 多轮对话；展示计划卡片；执行 / 编辑 / 取消 |
| **CLI** | 精确命令与历史；与计划命令文案等价 |

可选后期：**Log**（重建错误、工具调用轨迹）。

### 7.2 计划确认交互（默认）

```text
用户：做一个法兰，外径 80，内孔 20，厚 8，4 个均布 M6，孔距 50

Agent 计划卡片：
  1. cylinder d=80 h=8
  2. bore / cut d=20
  3. hole_pattern d=6 count=4 pcd=50
  [执行] [编辑] [取消]
```

- 编辑：可改数字；与右栏「选项」同步后再次展示计划。
- 执行：整批提交 Command Bus；失败则事务回滚。
- 输入区：可统一输入框，以 `/` 或模式切换分流到 CLI（实现可选）。

### 7.3 伸缩

- 高度可拖；折叠后宜保留一行入口或芯片。
- 默认高度约主区分屏的 20%–25%。
- 建议快捷键切换底栏（实现时在帮助中列出）。

### 7.4 扩展约定

```text
register_bottom_tab(id, title, widget_factory)
```

## 8. 状态栏

常驻单行，例如：

- 当前命令或「空闲」
- 选择计数
- 单位（mm）
- 重建状态（就绪 / 重建中 / 失败摘要）

不承载多行 Chat 历史。

## 9. 视觉方向（初稿级）

- **气质**：工业灰蓝，接近专业 CAD，而非消费级紫色炫光风。
- **层次**：左右栏略深，视口区域更亮、更干净。
- **字体**：选用清晰的 UI 无衬线字体（实现时在 QSS 中固定，避免系统默认杂乱）。
- **手段**：PySide6 + QSS；图标首期可用开源图标集，风格统一即可。
- 本文件不规定像素稿；后续可另附视觉规范。

## 10. 实现提示（PySide6）

| 部件 | 建议 |
|------|------|
| 主窗 | `QMainWindow` |
| 菜单 | `QMenuBar` |
| 工具条 | `QToolBar`，`setMovable(True)`，四边停靠 |
| 左/右/底 | `QDockWidget` 或中央 `QSplitter`（底栏比例用 Splitter 更易控） |
| 右/底多页 | `QTabWidget` |
| 左栏列表 | `QLineEdit` + `QTreeWidget` / `QListView` |
| 布局持久化 | `QSettings` |

与 [技术路线](技术路线.md) 中 `ui` / `commands` 模块划分一致：面板只发命令或改计划，不直写几何。

## 11. 首期验收对照（UI）

- 上述主布局五区 + 菜单/Toolbar/状态栏齐全。
- Toolbar 可隐藏且可换边。
- 右栏具备结构/属性/选项（显示、测量可占位）。
- 底栏 Chat 能展示计划并确认后才改模型。
- 左栏至少包含 P0 命令的可发现入口（分类或搜索）。
