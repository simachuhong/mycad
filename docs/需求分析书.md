## 1. 产品定位

MyCAD 是面向 **Ubuntu 桌面** 的开源 CAD 建模软件，并内置 **智能体助手**。

核心主张：

- **可编程建模为先**：一切改模型操作最终落到可序列化、可撤销的命令。
- **人机协同**：智能体负责理解意图并生成命令计划；**默认先列出命令再由用户确认**，再执行。
- **桌面专业体验**：界面借鉴 Solid Edge 的命令分层与视口主舞台，左右侧栏借鉴 Node-RED 的可折叠分类检索与 Tab 式工作架（**不**引入 Node-RED 流程画布）。

本软件以 Apache-2.0 开源发布，便于二次开发与商业友好使用，同时保留专利授权与 NOTICE 义务。

## 2. 目标用户与使用场景

### 2.1 目标用户

- 在 Linux（优先 Ubuntu）上工作的机械/结构爱好者、工程师、学生。
- 希望用自然语言或 CLI 加速建模、又需要可审计命令记录的个人或小团队。
- 愿意接受「首期能力聚焦零件实体特征」而非完整商业 CAD 替代品的早期采用者。

### 2.2 典型场景

| 场景 | 描述 |
|------|------|
| 对话建模 | 用户描述法兰、轴套等零件；智能体给出命令计划；用户确认后生成实体并导出 STEP |
| 传统点选建模 | 通过左栏/工具栏启动拉伸、孔、圆角等；参数在右栏「选项」中填写 |
| CLI 精确操作 | 在底栏 CLI 输入与计划等价的命令，便于脚本化与复现 |
| 检查与导出 | 在视口查看结果，测量关键尺寸，导出 STEP/STL |

## 3. 范围

### 3.1 首期包含（In）

- 零件（Part）环境：常用实体特征（对齐 Solid Edge Part 高频子集，详见 UI 设计初稿命令清单）。
- 3D 视口：观察、选择、基本显示样式。
- 文档结构树（PathFinder 语义，置于右栏「结构」）。
- 属性 / 命令选项 / 显示 / 测量（右栏 Tabs）。
- 底栏 Chat + CLI；**改模型默认「计划 → 确认 → 执行」**。
- 统一 Command Bus 与 Undo/Redo（批计划按事务回滚）。
- 导入导出：**STEP**（主）、**STL**（网格/预览/打印向）。
- 目标 OS：**Ubuntu 22.04+**。

### 3.2 首期不包含（Out）

- 自研几何内核或完整约束求解器。
- 完整装配约束求解、大型装配性能优化、工程图（Draft）完整环境。
- Web CAD、云端多人协作、移动端原生 App。
- 默认「信任模式」跳过确认（可作为后期选项，**不得**作为默认行为）。
- 将 Node-RED 或其它流程引擎嵌入为建模主交互。
- Kivy 或其它非 Qt 主 UI 框架。

## 4. 功能需求

### 4.1 文档与文件

| ID | 需求 | 优先级 |
|----|------|--------|
| F-DOC-01 | 新建 / 打开 / 保存零件文档 | P0 |
| F-DOC-02 | 导出 STEP、STL | P0 |
| F-DOC-03 | 导入 STEP（只读或转内部特征策略在实现阶段细化） | P1 |
| F-DOC-04 | 会话内撤销 / 重做 | P0 |

### 4.2 建模与视口

| ID | 需求 | 优先级 |
|----|------|--------|
| F-MOD-01 | 提供 Part 高频特征命令（拉伸、旋转、孔、圆角等，见 UI 清单） | P0 |
| F-MOD-02 | 视口支持旋转、平移、缩放、适应窗口 | P0 |
| F-MOD-03 | 选择实体/特征并与结构树双向联动高亮 | P0 |
| F-MOD-04 | 着色 / 线框等基本显示样式 | P1 |
| F-MOD-05 | 基准（面/轴/点）创建与显示 | P1 |

### 4.3 界面壳（与 UI 设计初稿一致）

| ID | 需求 | 优先级 |
|----|------|--------|
| F-UI-01 | 常驻菜单栏 | P0 |
| F-UI-02 | 可消隐、可换边（上/下/左/右）、可锁定的 Toolbar | P0 |
| F-UI-03 | 左栏：搜索 + 可折叠分类命令库 | P0 |
| F-UI-04 | 右栏可伸缩 Tabs：结构 \| 属性 \| 选项 \| 显示 \| 测量 | P0 |
| F-UI-05 | 底栏可伸缩 Tabs：Chat \| CLI | P0 |
| F-UI-06 | 常驻一行状态栏（提示、单位、重建状态） | P0 |

### 4.4 智能体与命令确认

| ID | 需求 | 优先级 |
|----|------|--------|
| F-AGT-01 | Chat 根据用户意图生成**可读的命令计划清单**（含命令名、参数、影响对象） | P0 |
| F-AGT-02 | 用户须明确**执行 / 编辑 / 取消**后，计划方可进入 Command Bus | P0 |
| F-AGT-03 | 编辑计划参数时，与右栏「选项」及底栏计划列表保持同步 | P0 |
| F-AGT-04 | 确认后执行失败时，已执行部分可按事务 Undo，或整批回滚 | P0 |
| F-AGT-05 | CLI 提供与计划等价的命令形式，便于回放与学习 | P1 |
| F-AGT-06 | 左栏/Toolbar 触发的复杂改模命令，可与 Agent 共用同一确认管道（简单视图操作除外） | P1 |

### 4.5 结构与属性

| ID | 需求 | 优先级 |
|----|------|--------|
| F-TREE-01 | 结构树分组：基准、草图、特征、实体（及文档根） | P0 |
| F-PROP-01 | 选中对象显示属性；无选中时显示文档级属性 | P0 |
| F-OPT-01 | 当前命令或计划步骤的参数表单在「选项」Tab | P0 |

## 5. 非功能需求

| ID | 类别 | 需求 |
|----|------|------|
| NF-01 | 平台 | 以 Ubuntu 22.04+ 为一级支持；依赖安装策略见技术路线（conda-forge / 系统包） |
| NF-02 | 本地优先 | 建模与文档默认本地完成；LLM 可调用远端 API，但不得强制云端存模 |
| NF-03 | 可审计 | 计划与已执行命令可在 Chat/CLI/日志中追溯 |
| NF-04 | 性能（首期） | 中等复杂度单零件交互流畅；大型装配不作为首期指标 |
| NF-05 | 开源合规 | 发行遵守 Apache-2.0；保留 LICENSE 与 NOTICE；第三方归属随依赖补充 |
| NF-06 | 可扩展 UI | 左栏命令项、右栏 Tab、底栏 Tab 支持注册式扩展（见 UI/技术路线） |
| NF-07 | 安全 | Agent 生成的脚本/命令在受控环境执行；限制任意代码无限权限（实现阶段细化沙箱） |

## 6. 智能体确认流（产品规则）

```text
用户意图（Chat / 部分菜单）
    → Agent 生成命令计划（不改模型）
    → 用户确认 / 编辑参数 / 取消
    → 仅在「确认执行」后提交 Command Bus
    → 几何重建 → 视口与结构树更新
    → 失败则事务回滚并反馈错误
```

- **默认必须确认**；「信任模式」若未来提供，不得作为默认开启。
- 计划中每条命令至少包含：命令标识、参数、新建或修改的对象说明。
- 视图类操作（旋转、平移、缩放、纯显示开关）可不经确认管道。

## 7. 分期计划

| 阶段 | 目标 | 主要交付 |
|------|------|----------|
| 阶段 0 | 可编程 MVP | build123d/CadQuery 建模、简单预览、STEP/STL 导出、命令原型 |
| 阶段 1 | 桌面壳 | PySide6 主窗口按 UI 初稿落地；Command Bus + Undo |
| 阶段 2 | Agent 闭环 | 计划确认流、评测集回归、Chat/CLI 打通 |
| 阶段 3 | 特征加深 | 草图约束、更多修改特征；装配/工程图按需；热点路径可 C++ 下沉 |

## 8. 验收标准（基线）

满足以下条件视为首期基线验收通过：

1. 能在 Ubuntu 上完成「示例法兰类零件」建模（外径/内孔/厚度/均布孔等参数可改）。
2. 通过 Chat 生成计划 → 用户确认 → 执行成功，并导出有效 STEP 文件。
3. 撤销可回退该批计划；CLI 或日志中可见等价命令记录。
4. 主窗口布局符合 [UI 设计初稿](UI设计初稿.md)：菜单、可换边 Toolbar、左命令库、右五类 Tab、底 Chat/CLI、状态栏。
5. 仓库含 Apache-2.0 `LICENSE` 与 `NOTICE`，README 正确声明许可。

## 9. 假设与依赖

- 用户可安装 OCCT 及相关 Python 绑定（具体渠道见技术路线）。
- 智能体依赖可用的 LLM（云端 API 或本地推理）；无网络时 Chat 降级，CLI/GUI 建模仍可用。
- Solid Edge、Node-RED 仅为 UX 参考，与本项目无商标或代码从属关系。

## 10. 术语

| 术语 | 含义 |
|------|------|
| Command Bus | 统一命令总线；所有改模型操作的唯一写入入口 |
| 计划（Plan） | Agent 或系统生成的、尚未执行的有序命令列表 |
| 结构 Tab | 对标 Solid Edge PathFinder 的文档/特征树 |
| 左栏命令库 | 对标 Node-RED 左侧调色板的分类检索菜单（非流程图） |
