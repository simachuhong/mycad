# 机械三视图与工程图

工程图与平面草图分开。中央常驻 **平面草图｜工程图｜3D图**，切页保留未提交草稿、选择、缩放与三维相机。工程图引用当前三维零件；独立 `.my2d` 文档仍可自由绘图与空间预览，不生成实体工程视图。

## 生成与排版

1. 打开或建立有实体的三维零件，切到「工程图」。
2. 在右侧「设置」选择 A4/A3、横纵向、第一角/第三角、比例与标题。选择「基准与投影视图」；首张图纸会自动建立。第一次计算有进程准备时间，提示准备完成后再放置。
3. 在纸上单击放置基准视图，移动鼠标到其上、下、左、右预览投影视图，再单击放置。第一角法下，俯视图在主视图下方、左视图在右方。按 Enter 提交整组；Esc 放弃未提交组。每组可一次撤销。
4. 点击视图选择，使用移动、比例与对齐手柄直接调整。移动基准视图带动对齐的投影视图；子视图沿对齐轴移动。显式解除对齐后可自由放置，再恢复对齐。
5. 右侧「视图」可设置比例、继承与隐藏线/相切线。图形信息在右侧 Tab 内，设置区可浮动；底部信息、CLI、AI 和计划共用容器，AI 明确显示未连接。

删除父视图时，界面先显示其子视图和标注的删除范围，再由 Enter 或「确认删除」确认；一次撤销恢复整组。

## 标注与更新

使用工程图标注工具在图中点选几何，再单击放置文字。支持水平、垂直、对齐、半径、直径、角度、中心标记；拖动文字调整位置，双击进入右侧格式设置，可修改精度、前后缀。

工程图尺寸读取模型真实数值。例如模型长度 80 mm、视图比例 1:2，纸上长度为 40 mm，尺寸仍显示 80 mm。工程图标注为关联参考尺寸；修改实体请回到模型或草图。平面草图的新建尺寸仍默认驱动，并保留参考尺寸切换。

模型修改后视图会更新。更新中保留旧几何并显示状态；过期、失败或标注失关联时禁止出图。取消更新后可点击「更新视图」重试。切换文件、删除视图或连续修改不会接受旧任务的迟到结果。

首版关联采用保守的几何来源判定：唯一圆柱轴/材料侧、平面朝向/位置及投影曲线类型。可跟随已验证的长度、孔径、外径变化；重复的同轴同侧面、复杂拓扑变化可能产生多个候选或失关联，须选中标注并重新关联。不会按最近边或临时拓扑编号猜测。该机制不等同通用持久拓扑命名；用几何相同的新特征替换旧特征时，不能保证识别其语义身份变化。

## 保存与出图

图纸、视图与关联标注随当前 `.my3d` 保存，使用 v3 命令历史。原有审计时间戳保留，修改有追加记录。旧 v1/v2 档案可读；含工程图的 v3 文件应使用支持该版本的 MyCAD 打开。未提交草图或工程图预览需先提交或取消，才可保存/替换文档。

「导出 DXF」输出 R2010 纸空间图纸：视图块保留模型毫米坐标，插入比例对应纸张比例，标注输出测量文字与几何，便于交换但不声称是 AutoCAD 原生关联 DIMENSION。直线、圆弧、椭圆和有理 B 样条保留解析数据。图层分离可见线、隐藏线、相切线、中心线、尺寸与图框。

「导出 PDF」输出矢量纸张，嵌入字体；A4/A3 按毫米输出。打印请选择实际大小/100%，不要适应纸张。画布和 PDF 共用受误差约束的矢量曲线（纸面误差上限 0.01 mm），DXF 保留原曲线。两种输出先写临时文件，成功后原子替换目标，失败保留原文件。

推荐系统安装 Noto Sans CJK SC 中文字体。PDF 已验证中文与数字文本；DXF 字体替换取决于接收 CAD 的安装字体。本地使用 QtPdf、Poppler 和 ezdxf 独立渲染核对，尚未在 AutoCAD/Solid Edge 实机完成验收。

## 首版范围与性能

支持当前零件的基本正投影与多实体联合遮挡；不含剖视、局部放大、断裂视图、装配/BOM、GD&T、公差自动布局或外部模型链接。斜投影圆为椭圆，不作为真实直径圆自动测量。沉孔的同轴多候选会明确报歧义。

HLR 使用常驻独立进程，首次启动约 10 秒、子进程峰值约 600 MiB；准备状态可见。900 边样本的预热后三视图完整 DTO 流程曾测得 2.835 秒，机器负载会影响结果；最终验收数据见 [验收记录](../.omo/evidence/mechanical-three-views/acceptance.md)。性能数字仅代表所测样本，不保证任意复杂零件均在 3 秒内完成。
