# 机械三视图与工程图

中央常驻 **平面草图｜工程图｜3D图**，桌面按独立文档保存。平面草图和工程图各存 `.my2d`，三维零件存 `.my3d`；模型内部草图随所属零件保存，编辑时标题显示“内部草图”。切页保留未提交草稿、选择、缩放与三维相机。工具栏的文档选择器可切换多份同类文档，名称后的 `*` 表示仍有待保存内容。

## 生成与排版

先在「文档 → 选择工程图来源」中选择已打开的零件或独立平面草图；独立二维图可先通过「文档 → 将当前二维图用于建模」创建有来源关联的零件。工程图只采用确认时的来源版本，不会在打开或保存时隐式替换来源。关联草图实例只读；「文档 → 解除来源关联」后成为可独立编辑的模型内部草图。

零件中已完成的内部草图可通过「文档 → 将内部草图分离为独立二维文档」复制为待保存的 `.my2d`。副本保留几何、约束、图层及工作平面，脱离原模型支撑面；原模型历史和建模结果保持不变。关联实例需先解除来源关联。

打开引用文档时，状态栏显示来源路径缺失、身份不匹配或关联有效等状态；文档选择器的提示保留这些信息，也可用「文档 → 查看来源状态」重新检查。文件缺失仍使用已保存的采用版本，不能用同名异身份文件自动替换。另存到新目录会重新计算相对路径，包括当前未打开的来源。

1. 切到「工程图」，起始页和工具栏均有「放置草图平面视图」入口。在右侧「设置 → 草图来源」选取已完成的草图，设置纸张和比例，点击入口；首张图纸自动建立。移动鼠标预览，单击放置，Enter 提交、Esc 取消。一次放置一个平面视图，可重复选择不同草图放到同一图纸。来源为空时，先回到平面草图点击「完成草图」。
2. 有三维实体时，也可点击「从当前三维模型生成投影视图」。平面草图无需拉伸即可入纸；若需三视图，先到「3D图」拉伸或旋转建模。
3. 在右侧「设置」选择 A0–A4、横纵向、第一角/第三角、比例与标题。选择工具栏「从模型生成投影」或空白页的生成按钮；首张图纸会自动建立。第一次计算有进程准备时间，提示准备完成后再放置。
4. 在纸上单击放置基准视图，移动鼠标到其上、下、左、右预览投影视图，再单击放置。第一角法下，俯视图在主视图下方、左视图在右方。按 Enter 提交整组；Esc 放弃未提交组。每组可一次撤销。
5. 点击视图选择，使用移动、比例与对齐手柄直接调整。移动基准视图带动对齐的投影视图；子视图沿对齐轴移动。显式解除对齐后可自由放置，再恢复对齐。
6. 右侧「视图」可设置比例、继承与隐藏线/相切线。图形信息在右侧 Tab 内，设置区可浮动；底部信息、CLI、AI 和计划共用容器，AI 明确显示未连接。

草图视图采用源草图局部 U/V 坐标，保留直线、多段线、矩形、圆、圆弧及精确三次样条。构造线、隐藏或冻结图层不出图；锁定图层仍显示。源草图的驱动尺寸不复制到图纸，需要在工程图中另行添加参考标注。纸上位置、比例独立于源草图，可通过视图手柄调整。

删除父视图时，界面先显示其子视图和标注的删除范围，再由 Enter 或「确认删除」确认；一次撤销恢复整组。

## 标注与更新

顶部主工具条点击 **尺寸标注**，选择水平、垂直、对齐、半径、直径、角度或中心标记；也可在右侧 **标注** Tab 直接点击创建按钮。第二行提供带图标和完整名称的尺寸工具。选工具后在图中点选几何，再单击放置尺寸文字。支持水平、垂直、对齐、半径、直径、角度、中心标记；拖动文字调整位置，双击进入右侧格式设置，可修改精度、前后缀。

工程图尺寸读取模型真实数值。例如模型长度 80 mm、视图比例 1:2，纸上长度为 40 mm，尺寸仍显示 80 mm。工程图标注为关联参考尺寸；修改实体请回到模型或草图。平面草图的新建尺寸仍默认驱动，并保留参考尺寸切换。

源草图尺寸、几何或图层显示状态修改后，平面视图会更新；三维模型修改后投影视图也会更新。更新中保留旧几何并显示状态；过期、失败或标注失关联时禁止出图。取消更新后可点击「更新视图」重试。切换文件、删除视图或连续修改不会接受旧任务的迟到结果。

草图视图按草图 ID、图元 ID 和作者定义的分段序号关联；长度和方向变化可跟随，删除、替换图元后需要重新关联，改变折线顶点顺序或段数后应检查并重附着相关标注。

三维视图首版关联采用保守的几何来源判定：唯一圆柱轴/材料侧、平面朝向/位置及投影曲线类型。可跟随已验证的长度、孔径、外径变化；重复的同轴同侧面、复杂拓扑变化可能产生多个候选或失关联，须选中标注并重新关联。不会按最近边或临时拓扑编号猜测。该机制不等同通用持久拓扑命名；用几何相同的新特征替换旧特征时，不能保证识别其语义身份变化。

## 文本标注

主工具条点击 **文本标注**，再在图纸上单击位置，直接输入说明文字。Enter 换行，**Ctrl+Enter** 或编辑器内“完成”按钮提交，Esc 取消；没有图纸时自动建纸。右侧“标注”页也提供文本入口，“文本”页调整纸面字高。

单击选中文字，拖动可移动；双击文字在原图编辑，Delete 删除，撤销恢复。编辑器中的 Delete 只编辑字符。文字属于图纸，位置和字高使用纸面毫米，不受视图缩放影响；删除视图保留文字，删除图纸一并删除文字。支持中文、多行及纯文本 DXF/PDF 输出；未提交文字需先完成或取消再保存、出图或新建图纸。当前不含引线、富文本或旋转。

## 保存与出图

图纸、视图、标注、文字与来源关联保存到工程图自己的 `.my2d`，使用 v4 JSON 命令历史；独立草图 `.my2d` 和来源零件 `.my3d` 各自保存。`Ctrl+S` 保存当前编辑文档，`Ctrl+Alt+S` 或「文件 → 全部保存」处理所有修改；首次保存分别命名，路径不能与其他打开的文档冲突。有效草图会先提交再保存，未完成的图元或工程图预览需先完成或取消。

全部保存按来源依赖顺序执行，并记录相对引用路径；某项失败时，已成功的文档保持已保存，其余内容保留并报告。退出时可勾选要保存的文档，也可放弃或取消；取消、草稿提交失败或写盘失败都会保留窗口和内存内容。旧混合档案在隔离重放成功后拆分为独立待保存文档，原文件不改写，原始审计历史保留于新文件的 `migration_origin`。

「文档 → 更新来源引用」明确采用源文档的新版本，可撤销。未打开的来源需要定位并校验文件身份；同名的其他文件不能直接替换引用。工程图和模型保留所采用版本的重放数据，即使来源暂不可用也能显示已保存内容。另存为生成新文件身份，原文件及已有引用者保持原关联；复制全部依赖不属于普通另存为。

未来装配使用 `.masm` 保存组件引用、实例位置及约束，零件仍分别存 `.my3d`；当前版本尚未提供装配文件读写。保存调度已按通用依赖图实现，可扩展为“零件 → 子装配 → 总装配 → 工程图”。

「导出 DXF」输出 R2010 纸空间图纸：视图块保留模型毫米坐标，插入比例对应纸张比例，标注输出测量文字与几何，便于交换但不声称是 AutoCAD 原生关联 DIMENSION。直线、圆弧、椭圆和有理 B 样条保留解析数据。图层分离可见线、隐藏线、相切线、中心线、尺寸与图框。

「导出 PDF」输出矢量纸张，嵌入字体；A0–A4 与自定义模板幅面按毫米输出。打印请选择实际大小/100%，不要适应纸张。画布和 PDF 共用受误差约束的矢量曲线（纸面误差上限 0.01 mm），DXF 保留原曲线。两种输出先写临时文件，成功后原子替换目标，失败保留原文件。

推荐系统安装 Noto Sans CJK SC 中文字体（Ubuntu 可安装 `fonts-noto-cjk`）。PDF 导出会检查实际排版及回退字形，缺字时阻止导出、提示安装字体并保留已有文件。PDF 已验证中文与数字文本；DXF 字体替换取决于接收 CAD 的安装字体。本地使用 QtPdf、Poppler 和 ezdxf 独立渲染核对，尚未在 AutoCAD/Solid Edge 实机完成验收。

## 首版范围与性能

支持当前文档已完成草图的平面视图，以及当前零件的基本正投影与多实体联合遮挡；不含剖视、局部放大、断裂视图、装配/BOM、GD&T、公差自动布局或外部模型链接。斜投影圆为椭圆，不作为真实直径圆自动测量。沉孔的同轴多候选会明确报歧义。

HLR 使用常驻独立进程，首次启动约 10 秒、子进程峰值约 600 MiB；准备状态可见。900 边样本的预热后三视图完整 DTO 流程曾测得 2.835 秒，机器负载会影响结果；最终验收数据见 [验收记录](../.omo/evidence/mechanical-three-views/acceptance.md)。性能数字仅代表所测样本，不保证任意复杂零件均在 3 秒内完成。

## 草图中的 Delete 键

在平面草图构图时，点选或框选当前草稿图元，按 Delete 删除；引用这些图元的尺寸和约束同步移除。Ctrl+Z 一次恢复图元与约束，Ctrl+Y 重做。锁定、隐藏图层及正在进行的编辑预览不会被删除，数值输入框内的 Delete 仅编辑文字。在图形导航中选中尺寸或约束时，Delete 只删除该约束，保留其高亮引用的图元。已提交的背景图元仍通过历史编辑修改。


## 图纸模板

在「工程图功能 → 设置 → 选择 / 导入图纸模板…」打开「模板」页。新图纸默认使用 GB 国标机械图，也可选 ISO 机械图或“原有简单图框”。A0–A4 的横纵方向在「设置」页选择；第一/第三角同步决定内置模板的投影符号。GB 默认保留 25 mm 左装订边，A4/A3 其他边距 5 mm，较大幅面 10 mm；ISO 左边距 20 mm、其他边距 10 mm。

模板页可填写图号、材料、单位、设计、审核、日期、版本、质量等字段；图纸标题仍在「设置」页填写。比例和页码留空时自动取图纸设置。先「预览模板…」，再回到设置页「应用图纸设置」；新建图纸也采用当前模板。应用只改变图纸图框和字段，已有视图不会被移动或缩放，请检查新图框及标题栏是否覆盖现有内容。撤销/重做包括模板变更。旧图纸保持原有简单图框。

### 导入其他标准或企业 DXF 模板

1. 点击「导入 DXF 模板…」，选择空白图框 DXF。DWG/DWT 请先在源 CAD 中另存为 DXF。
2. 选择源模型空间或纸空间布局，设置实际纸张宽高、源单位及纸面原点偏移。支持毫米、英寸、厘米、米；未声明单位的文件必须明确指定。
3. 「生成预览」保留纸面尺寸，不自动拉伸或缩放到纸张。可在文字列表中修改默认文字，并为可填写位置指定字段名；ATTRIB 的 tag 和 `{{字段名}}` 文字会自动识别。多个位置可绑定同一字段。
4. 检查预览后「保存到模板库」，该模板会被选中。回到设置页「应用图纸设置」或新建图纸。取消导入不会修改当前图纸。

支持 XY 平面直线、无宽度二维多段线、圆/圆弧、普通 TEXT/MTEXT 与图块属性，图块可嵌套并作平移、旋转及可表示的缩放。图线采用 MyCAD 图框线样式；颜色、源图层和线宽不作为模板样式导入。非支持实体、外参/裁剪图块、复杂文字格式、自动折行、镜像/倾斜文字等会明确报错，请先在源 CAD 中转换。错误不产生不完整模板。单文件上限 16 MiB、图元上限 20000。

用户模板存放在系统数据目录 `MyCAD/drawing-templates/`（Linux 默认 `~/.local/share/MyCAD/drawing-templates/`），为可复制的 JSON 文件。应用后的完整模板快照写入工程图 `.my2d` 命令历史，删除源 DXF、移走模板库或换电脑不影响已有图纸重放。模板库有损坏文件时显示提示，其余模板仍可用。含模板的图纸需要支持 `drawing.sheet.create/update` v2 的 MyCAD 版本。

### 内置模板依据

- GB：GB/T 14689-2008（图纸幅面和格式）、GB/T 10609.1-2008（标题栏）。
- ISO：ISO 5457:1999 及 Amd 1:2010（图纸幅面和格式）、ISO 7200:2004（标题栏字段）。

当前标题栏为 MyCAD 的通用机械图布局；标准版本标识说明设计依据，不表示已完成标准全文逐条合规认证。ISO 7200 定义数据字段，不定义唯一标题栏网格。对有固定签审区、更改区或其他专用版式的单位，可导入已审核的企业模板。
