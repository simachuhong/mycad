# MyCAD

Ubuntu 桌面端开源 CAD 建模软件：以可编程几何、可确认的命令计划和传统桌面建模交互为核心。

相对坐标系预览时，可点击视口中的原点圆形热点，或点击“捕捉三维特征点”，然后点击实体端点、边中点或圆心；也可以从热点拖到目标点。捕捉直接采用点的三维坐标，确认创建仍需点击外层“确认”。如需平面上的投影点，使用“在平面上定位原点”及其一次投影选项。

## 技术栈摘要

- **几何内核**：OpenCascade（OCCT），经 build123d 暴露
- **桌面 UI**：PySide6（Qt6）——阶段 1 五区外壳已交付；Qt/GL 依赖属于可选 `desktop` extra
- **计划执行**：结构化计划经用户确认后由统一 Command Bus 执行；LLM 计划生成属于 Phase 3
- **目标平台**：Ubuntu 22.04+

详细说明见 [技术路线](docs/技术路线.md)。

### 当前可用流程

- **二维复制与粘贴**：选择草稿或已提交图元后，可通过编辑菜单、画布右键或 `Ctrl+C` / `Ctrl+V` 复制到同一图纸或另一张二维图纸；粘贴时指定放置点，Esc 取消。`COPYCLIP` 和 `PASTECLIP` 也可使用；目标图纸缺少的图层在放置时导入。完整位于所选图元内的本地约束和标注随图元复制；单独复制标注需同时选择其引用图元，跨草图相切关系不会自动复制。当前剪贴板格式供 MyCAD 二维工作区使用，三维对象尚未接入。
- **新建文档**：统一“新建”入口选择二维图或三维零件；装配体显示为规划中并禁用。取消选择不改变当前文档。
- **工作区布局**：二维仅保留右侧“二维功能”面板，绘图、UCS、修改、图形共用 Tab；面板可左右停靠、浮动、缩放与关闭，从“工具栏与面板”恢复。图形页按草图列出图元、约束与驱动/参考尺寸，与画布选择联动，双击尺寸继续在图中编辑。坐标输入和连线按钮移入绘图页，完成/取消草图位于顶部工具栏。底部共享“信息 / CLI / AI 对话 / 计划”容器，二维默认显示收起的标签栏，点击展开、再点当前标签或“收起”折叠；当前提示保留在状态栏，完整提示进入信息页。CLI 和输入草稿在二维/三维切换间保留；未提交草图时先完成或取消草稿再执行 CLI 写入命令。AI 窗口已提供，但尚未连接服务，发送按钮禁用，不会生成或发送消息。三维启动仍默认隐藏底部面板，可从“视图 / 智能体”打开。工具栏与右侧面板共同记忆布局；“视图 → 重置工作台布局”恢复默认。
- **二维绘图与草稿编辑**：独立 `drawing2d` 文档，在主窗口内嵌工作区绘制，绘图/修改/尺寸标注三个可独立停靠、悬浮的原生工具栏与 UCS 原点/方向；直线连续接段，Enter/右键/Esc结束、C或首点捕捉闭合。同平面已提交图形可选择、捕捉并参与受支持的二维编辑。XY/XZ/YZ 或选面工作平面；线、折线、圆、顺逆圆弧、椭圆、矩形、控制点式三次 B 样条和构造几何；精确局部坐标输入、正交、UCS原点/独立栅格捕捉、端点/交点/中点/圆心/切点/垂足捕捉。选择工具支持空白处拖拽或两次单击框选：从左到右蓝色实线框仅选完全包含的图元，从右到左绿色虚线框选包含或与框线相交的图元；Ctrl 加选、Shift 减选、Esc/右键取消。独立二维图的已提交图元在存盘重开后仍可点选、框选和高亮；隐藏图层与三维草图只读参照不参与选择。框选可用于草稿与同平面已提交图元的选择；混合操作在暂存候选中整体校验，并保留独立撤销步骤。未提交草稿可移动、复制、旋转、镜像、阵列、偏移、限定修剪/延伸/分割，并完整撤销/重做。 二维图纸工具栏“偏置”可直接选择对象并使用当前默认距离或通过点，移动鼠标预览后单击放置；也可先输入距离；默认距离为 0 时须先输入正距离或 T。命令 `O` / `OFFSET` 可输入距离或通过点，选择对象后指定偏置侧；支持连续、撤销、删除源和图层选项。数值偏置位于右侧“修改”面板。 多段线偏置支持部分线段收缩和闭合轮廓分裂；直线和圆弧闭合轮廓支持尖角、圆角及倒角。椭圆和椭圆弧可按距离或通过点偏置；椭圆弧可从工具栏绘制，或输入 ELLIPSE 后选 A，并以 CW/CCW 指定方向，结果为有界误差样条片段；开放样条可按距离或通过点偏置；可确定方向的开放多分支结果均予保留，结果为若干独立三次样条片段。连续偏置按完整路径计算，每次相对上一次结果的近似误差不超过 0.001 mm。移动/复制支持选择—基点—鼠标预览—落点，也可按住基点拖放；右侧参数面板“修改”页保留按 ΔU/ΔV 执行。旋转支持选择—中心—鼠标方向或键入角度（Enter 确认），可勾选参考旋转按中心—起点—目标三点操作；镜像用任意两点定义轴，默认保留原对象，可取消“镜像保留原对象”以替换。两者均支持预览、Esc 取消、撤销/重做，右侧“修改”页保留明确的数值执行按钮。正多边形支持 3–128 边、内接圆/外切圆模式，按中心—顶点或边中点绘制，保存为闭合多段线。二维点阵网格可用“网格 F7”复选框或 F7 显隐，隐藏不影响栅格捕捉；三维 XY 工作网格也使用点阵。直线连续修剪保留剩余线段的连通性。样条至少四个控制点，Enter/右键完成，支持控制点拖动、保存重放、原生 DXF SPLINE 输出和闭合轮廓建模；尚不支持拟合点/周期/有理样条和样条修剪/延伸。闭合路径/矩形按两个唯一交点修剪或拆成两条开放路径；复杂、退化或歧义结果明确拒绝。
- **图内尺寸标注**：智能、水平、垂直、对齐、角度、半径、直径、弧长、连续、基线、坐标共 11 个独立工具；在图中拾取端点/圆心/顶点/线段、随鼠标预览并点击放置，支持中键平移和滚轮缩放。新尺寸默认驱动，可关闭“驱动尺寸”切换为仅测量的参考尺寸；在尺寸旁输入数值、预览并显式确认；双击尺寸使用画布内数值框，拖动文字或尺寸线调整位置，Esc 取消。草稿和同平面已提交图形共用操作；新尺寸默认存入自动创建的 DIM 层，可在工具栏选择其他标注层或使用当前层；独立标注层不随引用几何隐藏。线性尺寸提供自动、固定起点、固定终点、中心对称；自动优先遵守已有固定/锁定关系，否则保持首点或圆心。固定方式为临时编辑定位，不增加永久固定约束；显示真实自由度并在画布标红冲突图形。标注位置、图层、投影方向、固定方式、小数位和比例随档案保存、撤销与重放。 标注选项的“符号”菜单可插入直径 ⌀、正负 ±、度 °、方形 □ 等；文字为空时自动生成如 `⌀<> mm` 的动态尺寸模板，已有文字时在光标处插入或替换选区。`<>` 始终显示实际尺寸值，符号与文字随保存、撤销和 DXF 导出保留。
- **二维公差（开发中）**：尺寸样式与单尺寸设置支持对称公差、上下偏差和极限尺寸；数值可通过“精确输入”使用科学计数法；`TOLERANCE` 放置可编辑的形位公差框，`DATUMLABEL` 放置独立基准；也可从“工具”菜单或绘图工具栏进入。基准可附着几何点、直线、矩形边、圆、圆弧、多段线和样条，失关联后选中基准并输入 `REATTACH` 可重新指定位置。公差框可编辑旋转和图层；未关联基准会提示，可双击公差框关联本图同名基准。导出 DXF 时可选择保留结构的默认格式，或选择“图形兼容”以便部分 CAD 显示，后者的公差框不可作为结构化对象编辑或无损恢复。DXF 交换与标准规则的已实现范围和待验证事项见[公差支持矩阵](docs/design/2026-11-18-geometric-tolerance-support-matrix.md)。
- **参数化草图**：受限 PlaneGCS 关系和长度/距离/角度/半径/直径/弧长，驱动与参考尺寸分开；显示自由度、冲突关系和图元位置，失败不能确认，分支变化需额外核对。已提交草图的数值尺寸可以修改，预览同时重建下游实体；确认后追加审计历史，撤销/重做和重开使用冻结解。锁定图层不能被直接或间接求解移动，参考测量仍可用。
- **二维文字与字体**：独立二维草图提供 `TEXT` 单行文字、`MTEXT` 多行文字和 `STYLE` 文档文字样式；从绘图工具栏或命令栏进入，点击插入点输入，`Ctrl+Enter` 提交、`Esc` 取消，双击编辑。文字特性支持字高、宽度因子、旋转、对齐、文本框宽度、行距和图层，支持选择、移动/复制/旋转/缩放/镜像、混合剪贴板、撤销重做与保存重开。系统设置的“字体管理…”可枚举系统字体并将 TTF/OTF/TTC 导入 MyCAD 用户字体库；图纸保留请求字体，缺失时提示替代和缺字。DXF 交换使用原生 TEXT/MTEXT/STYLE，支持纯文字文档；字体文件不嵌入 DXF。首批 MTEXT 为统一样式，SHX 绘制、局部富文本和复杂分栏仍属后续兼容范围；含暂存相切/关联阵列的草稿需先完成，再进行文字与几何的混合变换。开发与定向检查记录见 [文字与字体计划](docs/superpowers/plans/2026-11-17-drawing-text-fonts.md)。
- **二维 GROUP 与 BLOCK（人工验收待执行）**：独立二维图提供 `GROUP`、`UNGROUP`、`GROUPEDIT` 及组管理入口；几何、文字、尺寸、公差框、基准、图片和块实例可编组，支持重叠组、组选择开关及成员现有能力范围内的整体操作。`BLOCK`、`INSERT`、`BEDIT`、`BSAVE`、`BCLOSE` 和 `EXPLODE` 支持共享几何与文字定义、实例编辑和分解；实例支持移动、复制、旋转、正等比缩放及删除。块内关键点可捕捉，但不会建立块外持久关联。嵌套、属性、动态块、实例镜像与非等比缩放不在首期；进入块编辑前需完成或取消草稿。原生 `GROUP`、`BLOCK` 和 `INSERT` 交换、图片损失提示与操作步骤见 [验收清单](docs/design/2026-11-21-drawing-collections-manual-check.md)，AutoCAD 2023/2025 结果仍待人工记录。
- **图层与 DXF**：非模态图层表统一控制整张图纸的草稿和已提交对象，提供颜色、线型、线宽及独立的显示/隐藏、冻结/解冻、锁定/解锁。冻结层不参与显示再生、适配范围、捕捉和选择；关闭层仍计入适配范围；解冻保持原显隐状态，当前绘图层不能冻结。隐藏/冻结不解除驱动约束，旧尺寸可批量迁入 DIM；图层状态支持撤销、保存和 DXF 往返，以及线性、投影、角度、径向、弧长和坐标尺寸。DXF R2010 指定子集先显示实际输出字节的缩放/平移预览，再确认原子写入。未知单位要求输入；不支持的实体、带宽度或无法表示的多段线、外部无关联尺寸等通过报告披露；支持范围内的多段线保留 bulge 圆弧，不能误报完整交换。
- **草图驱动三维**：拉伸、旋转、孔和孔阵列，支持已公布的新建/合并/切除、正负方向、对称深度、到平面和盲深/贯穿模式。法兰、阶梯轴、长圆孔安装板有从空白 GUI 创建、修改、undo/redo、重开与 STEP 的自动流程证据。
- **多实体修改**：多边圆角/倒角，目标体与刀具体并/差/交及保留/消耗，移动/旋转/复制/镜像，通用线性/完整或部分环形阵列。实体树显示来源步骤、结果序号、输入关系，可打开历史预览；逐体显隐仅影响显示和拾取。对称支架和通用阵列改参有完整任务级证据。
- **视口交互**：固定逻辑像素 XYZ 方向标及原点标记，参数条位于视口外；中键自由旋转（可越过上下极点，不锁定世界 Z 轴朝上）、Shift+中键沿屏幕平面平移、滚轮缩放。自由视角与拾取投影保持一致，切换文档保留完整姿态，标准视图按钮可恢复正视方向。数值输入/方向手柄接受后，只有对应当前文档修订的最新有效预览能够提交；撤销、重做和其他写入使旧预览失效。

三维空场景默认在画布中心显示世界坐标系与原点；它始终对应模型空间 `(0, 0, 0)`，相机平移后会随之移动。放置实体时靠近原点可吸附到精确零坐标，按住 Shift 可临时绕过；“视图 → 全局 XYZ 坐标”可切换其显示。

打孔时靠近世界原点选择目标平面，可将孔轴对齐世界原点：孔心取世界原点沿目标面法线投影到该面的位置。按住 Shift 选择可临时绕过吸附，仍以点击处定位。

- **机械三视图与工程图**：中央常驻平面草图、工程图、3D 三页；A0–A4、内置 GB/ISO 模板与外部 DXF 模板库、第一/第三角投影、图中直接放置/对齐/比例手柄、可见尺寸菜单、图中多行文本及关联参考标注、模型更新状态与失关联提示、已完成草图直接作为平面视图入纸（无需实体）、独立工程图 `.my2d` 与来源零件 `.my3d` 分别存档、DXF/PDF 出图。草图尺寸驱动规则保持独立。首次投影有进程准备时间；首版采用保守来源关联，复杂拓扑修改需重新关联。见 [工程图操作指南](docs/工程图操作指南.md) 与 [验收记录](.omo/evidence/mechanical-three-views/acceptance.md)。

### 支持边界

直接画布几何编辑按用户选择仅限**未提交草稿**；已提交尺寸修订可用。完整 IntelliSketch、通用约束引用迁移、复杂偏移自动拓扑修复、闭合路径跨段拖动修剪、装配配合和完整同步建模不在本次能力声明内。实体来源是操作输入关系，不能当作逐面拓扑持久 lineage。失效或歧义几何选择器明确拒绝。

DXF/STEP 的目标 AutoCAD/Solid Edge 实机显示、字体、设备交互和平台表现仍由用户验收；自动测试与 XCB 自检截图不代表 Solid Edge 等价或人工验收通过。PlaneGCS 在 T2/aarch64 的构建未验证；缺少求解器时普通绘图仍可用，并明确提示求解不可用。

### 架构与既有能力

阶段 0 可编程内核和阶段 1 五区桌面外壳已交付；P2 F 三维工作台工程收口见 [F 记录](.omo/evidence/task-P2-F-closure.md)。

- **唯一写入路径**：Command Bus；undo 为删除命令后全量重放，批事务整体成功或回滚（[ADR-001](docs/adr/ADR-001-command-bus-and-history-replay.md)）。
- **文档与存盘**：桌面按独立文档保存，平面草图与工程图采用 `.my2d`、三维零件及其内部草图采用 `.my3d`。工作区切换保留其他文档，工具栏文档选择器支持多个零件；每份文档独立记住路径与修改状态。`Ctrl+S` 保存当前文档，`Ctrl+Alt+S` 全部保存，退出时列出所有未保存文档。全部保存先收集命名与覆盖决定，按来源依赖保存；部分失败会报告已保存和未保存项。另存为生成新文件身份，现有引用者继续指向原文件。新建二维文档使用 v8 JSON 命令历史，圆角初始半径和倒角初始角度均为 0；旧图纸保留其原有初始值。新建零件从 v4 开始，关联较新版本草图时目标文档也会升级；旧版 MyCAD 可能无法读取 v8 文件。旧 v1/v2/v3 档案可读并隔离迁移，原文件不改写，原始审计历史保留。`.masm` 为未来装配文档预留，当前拒绝读写。CLI 的旧批处理文件名及接口保持兼容；多文档桌面新建/打开/保存使用文件菜单。见 [工程图操作指南](docs/工程图操作指南.md) 与 [ADR-013](docs/adr/ADR-013-document-ownership-and-save-session.md)。
- **命令、格式和插件**：命令按 ID/版本绑定；CLI REPL、ASCII/JSON 计划、STEP/STL/DXF 格式提供方、entry-point 插件。`mycad commands` 列出实际已注册命令（[ADR-003](docs/adr/ADR-003-extension-points-and-plugin-api-versioning.md)、[ADR-005](docs/adr/ADR-005-format-provider-tiers.md)）。
- **球体基本元素**：`feature.sphere@1` 使用半径和世界球心，支持新建、添加和切除；新建会替换当前实体。桌面命令栏支持数值输入、工作平面定位和预览确认；球面不作为平面绑定来源。
- **命令实例身份基础（E2-A）**：开发接口可通过 Bus 的 `prepare_identity_upgrade()` / `apply_identity_upgrade(proposal)` 显式启用 v5，在每条命令记录中保存 `instance_id`；改参、撤销重做、隔离预览和另存保持已有实例身份。准备或放弃升级提案不修改文档，旧档普通读写保持原格式；v5 文件需要新版读取器。桌面默认仍为 v4。见 [ADR-014](docs/adr/ADR-014-command-instance-identity.md)。
- **绑定面孔（E2-B，开发 API）**：`feature.hole@3` 可在显式 v5 文档中绑定 box 六面或 cylinder 顶/底面，以来源局部坐标定位孔。支持有限 Boolean/孔演化、改参、保存重开和撤销重做；分裂、合并、删除或无法证明对应关系时明确拒绝，不以 rank 替代。既有查询/草图孔仍可在旧格式运行。GUI 升级确认、绑定选面及失效修复工作流仍待 E3，见 [ADR-015](docs/adr/ADR-015-bound-face-hole.md)。
- **桌面外壳**：文件生命周期、GL 视口、底栏 CLI、拾取/结构树双向高亮、计划卡片六态确认。所有模型写入均需用户显式确认。

## 快速开始：三条命令跑通法兰

Windows 测试安装包的本机构建、安装/卸载日志和升级验收步骤见
[Windows 安装包测试指南](docs/windows-installer-testing.md)。当前脚本与配置已准备，
Windows 编译和实机验收仍待执行，尚无已发布安装包。

```bash
uv sync
uv run mycad run examples/flange_script.txt
uv run mycad run --json examples/flange_plan.json
```

两条路径描述同一个零件（OD80 × 8、中心孔 φ20、4 × φ6 均布于 PCD50），
产出 `flange.step` / `flange.stl` / `flange.mc.json`（计划路径的产物位于
`examples/` 下，以计划文件名为基名）。体积真值为
`math.pi*8*(40**2-10**2-4*3**2)` ≈ 36794.333 mm³，由
`tests/test_acceptance_flange.py` 断言。

交互式使用直接运行 `uv run mycad`，输入 `help` 查看内建命令。默认安装保留 headless CLI。
需要桌面与草图求解时先运行 `uv sync --extra desktop --extra sketch-constraints`，再执行 `uv run mycad gui` 打开首页；使用 `uv run mycad gui 文件.my3d` 或 `文件.my2d` 可直接打开文档；
在 Wayland 桌面需要工具栏拖动自动停靠时，可用 `scripts/mycad-x11` 以 X11/XWayland 兼容模式启动当前项目；可在命令后附加要打开的文档路径。该入口使用项目现有 `.venv`，不影响普通启动方式。
无显示环境（CI/远程桌面/SSH）可设置 `QT_QPA_PLATFORM=offscreen`，但离屏测试不替代真实 GL 验收。

Linux 使用 Fcitx5 时，如果系统 Qt 输入法插件无法与 MyCAD 的 Qt 加载，而 Fcitx5 提供 IBus 门户，启动时会自动使用 MyCAD 自带的 IBus 输入上下文。可用的原生插件和其他输入法配置会保留。安装 Xvfb、D-Bus、Fcitx5 及相应输入法后，可用 `MYCAD_REAL_IME_TEST=1 uv run pytest tests/ui/test_input_method_bootstrap.py -q` 在隔离会话验证拼音和五笔拼音；未安装的输入法会跳过对应场景。

## 开发环境

仓库使用 [uv](https://docs.astral.sh/uv/) 作为 Python 工具链。安装 uv 后：

```bash
# 开发环境包含测试工具、桌面和可选草图求解器
uv sync --extra desktop --extra sketch-constraints

# 在项目虚拟环境中执行命令
uv run ruff check .
uv run ruff format --check .
uv run basedpyright
uv run pytest -q
```

CI 工作流定义于 `.github/workflows/ci.yml`，覆盖 `ubuntu-22.04`、
`ubuntu-24.04` 与 `windows-latest` 三个 runner。

### 国内镜像

若直连 PyPI 受限，可通过环境变量切到国内镜像：

```bash
# 清华源
export UV_DEFAULT_INDEX=https://pypi.tuna.tsinghua.edu.cn/simple
uv sync

# 或阿里源
export UV_DEFAULT_INDEX=https://mirrors.aliyun.com/pypi/simple
uv sync
```

仅安装 headless 运行依赖时使用 `uv sync --no-dev`；如需 GUI 运行依赖，使用
`uv sync --no-dev --extra desktop --extra sketch-constraints`。阶段 2 拆分与 wheel/glibc 边界见
[ADR-006](docs/adr/ADR-006-platform-tiering.md)。

也可以在 `~/.config/uv/uv.toml` 中固化该配置，避免每次临时设置。

> **注意**：切换索引后 `uv sync` 会把 `uv.lock` 中全部包的 `source` 与下载 URL 改写
> 为该镜像（hash 不变，完整性不受影响）。**不要提交这份改写**——CI 以 `--frozen` 安装，
> 一旦合入会把三个 runner 全部钉到该镜像。同步完成后执行 `git checkout uv.lock` 还原。

### 离线 / 无外网应急（conda / wheelhouse）

仅在完全无外网的环境下使用。conda-forge 上的 `build123d` 滞后于上游 0.9.1，
与本仓库锁定的 0.11.1 不兼容；wheelhouse 离线方案需要先用联网环境
`uv pip download` 把依赖下载到内网仓库。`pyproject.toml` 中锁定版本不可降级，
因此离线方案仅作为应急，不能替代正常的 `uv sync`。

## 插件与安全

- 插件经 Python entry-points 在**同一进程**内加载，等同完全信任其作者：
  没有沙箱、签名校验或权限强制（ADR-003）。
- manifest 的 `permissions` 字段在阶段 0 仅作声明展示，不做任何强制。
- 安装任何第三方插件前，请先审阅其源码。
- 最小示例插件见 [`plugins_examples/mycad_plugin_demo/`](plugins_examples/mycad_plugin_demo/)。
- 已加载与被跳过的插件可用 `uv run mycad plugins` 查看。
