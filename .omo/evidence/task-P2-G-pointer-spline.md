# 二维样条、连续修剪、鼠标移动/复制整改

状态：工程检查完成，待用户重启后人工复验。用户 GUI PID 352527 保持运行，本轮未关闭或重启。

## 四项反馈的处理

1. 样条：新增绘图栏“样条”图标，采用控制点式开放夹持均匀三次 B 样条，至少四个控制点。Enter/右键或“完成样条”结束；首尾点在曲线上，中间控制点决定形状。支持选择、控制点拖动、移动/复制/旋转/镜像/阵列、图层、撤销重做、保存重放、同平面已提交参照显示、原生 DXF SPLINE 往返，以及与直线闭合成轮廓后拉伸。几何使用 OCCT 原生 B 样条；core/UI 不导入 CAD 后端，中立采样与 OCCT 原生参数位置独立比对。
2. 连续修剪：原算法把所有剩余交点均拆成独立线段，导致下一次修剪的片段缺少内部交点。改为只删除所点区间，左右剩余区段各保持连续；同一条线两端连续修剪、两条不同目标线连续修剪均已验证。保留源身份、图层与撤销行为。
3. 复制：工具栏进入鼠标放置状态，不再直接用默认零位移创建重叠副本。选对象、基点、鼠标预览、目标点确认；复制后仅选中新副本。原对象保留，副本使用新身份。目标与基点重合时拒绝创建副本。
4. 移动：同样支持基点/目标点鼠标预览，也支持按住基点拖动后松开落点。预览不改草稿；Esc取消，确认一次记入草稿撤销。可预选，也可先点命令后选择对象，再用Enter/右键结束选择。隐藏/锁定层及用户约束的保护继续生效。

数值位移保留在左侧参数区“按 ΔU / ΔV 移动/复制”两个明确按钮中。未经确认的预览期间不能完成草图。直接几何编辑范围仍为未提交草稿。

## 范围

- 不包含拟合点输入、周期/有理权重样条、样条修剪/延伸/偏移。DXF 对不支持的样条类型明确报告，不能静默离散成折线。
- 样条端点/控制点可进入已有点约束系统，未宣称曲率/切向连续性约束或完整 Solid Edge/AutoCAD 样条工具集。
- 用户已确认的几何约束仍禁止普通整体移动直接改写；应先处理相关约束。复制不改变原对象约束。
- DXF 导出沿用原有局部二维坐标/mm 约定；外部 CAD 实机互通仍待用户验收。

## 人工复验

1. 新建二维图 → 样条 → 依次放置至少四个控制点 → Enter或右键：应出现平滑曲线，选择后能拖动控制点。少于四点应提示补点，Esc取消未完成曲线。完成草图后保存重开应保持形状。
2. 画两条竖向边界，再画一条两端都越过边界的横线。点修剪，依次点左侧、右侧外伸段：应只剩两边界之间的连续线，撤销逐次恢复。另用两条横线分别修剪，第二条同样应成功。
3. 先用“选择”点选对象 → “移动” → 点击基点 → 移动鼠标：应见预览，原位置淡显；点击目标点确认。也可从基点按住拖到目标点松开。Esc应保持原位置，确认后一次撤销恢复。
4. 同样使用“复制”：预览期间对象数量不变，落点后新增一份；原对象保留且不重叠。基点和目标点相同应拒绝创建。用“先点复制 → 选对象 → Enter/右键 → 基点 → 目标点”再试命令先行流程。
5. 左侧参数区设置ΔU/ΔV并使用独立数值按钮，仍应按输入精确位移；隐藏/锁定图层及用户约束保护应继续生效。
