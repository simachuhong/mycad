# 形位公差专业复核样例

本样例仅展示当前实现的结构与输出，不是合规样图，不代表任何符号、被测要素、M/L 或基准组合符合 GB/ISO。请专业人员使用项目授权标准核查并记录结论。多行样例仅为测试显示，不能将其视为复合公差的标准示例。

- `review-sample.my2d`：可在 MyCAD 打开及编辑的命令历史。
- `review-sample.dxf`：从同一文档生成的 DXF，包含原生公差框及基准图形块。
- `review-sample.svg`：根据导出的 DXF 字节生成的预览；`review-sample.png` 为其栅格化视图。
- `manifest.json`：各符号框位置、内部行字段、文件哈希与导出提示。
- `generate_sample.py`：样例生成脚本。保存命令历史有时间戳，重建时文件哈希可能变化。

符号从上到下、每行从左到右分别为：

1. 直线度、平面度、圆度。
2. 圆柱度、线轮廓度、面轮廓度。
3. 平行度、垂直度、倾斜度。
4. 位置度、同心／同轴度、对称度。
5. 圆跳动、全跳动。

底部单独排列 A、B、C 基准；其上的两行框分别显示直径、圈 M、圈 L 和有序基准引用。对照标准时请分别检查符号轮廓、各格分隔和顺序、M/L 及直径修饰符、基准标识和多行表达。对不适用的示例应记录原因，不应以当前图像代替标准规则。

已知互操作边界：LibreCAD 2.2 的打印路径未显示原生 `TOLERANCE`；基准在其他 CAD 中是图形块，不承诺结构化编辑。预览文字度量依据本机字体并留有余量，其他 CAD 的排版仍须实测。
