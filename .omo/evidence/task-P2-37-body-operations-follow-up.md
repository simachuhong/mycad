# P2-37 — 选择实体布尔、变换与通用实体阵列（实现记录）

日期：2026-10-25。状态：**实现中，尚未定向验证或人工验收**。本记录不表示 P2-37/P2 G 完成。

## 本轮实现

- 增加可重放几何 `BodySelector`：以体积、质心、包围盒和必要时的稳定排序 rank 定位当前实体；未匹配或歧义选择明确失败。
- 提供实体并集、差集、交集，要求用户从视口选目标体及刀具体，并明示布尔后是否保留工具体。
- 提供选中实体的移动、旋转、复制、镜像，以及线性/环形实体阵列；UI 参数先预览，再显式确认后经 Bus 提交。阵列生成独立实体，不冒充装配配合。
- Boolean 结果可包含多个实体；空结果拒绝写历史。输入目标/刀具选择器保留在命令参数中，使 undo、redo、修改历史和重放仍由原有 Bus 流程负责。

## 尚未完成

- 当前源码支持的布尔结果身份来自顺序化几何选择器和历史命令，不是跨拓扑修改稳定的装配对象身份，也未建立独立的持久 Feature/Body lineage 树。
- 重复相同或几何签名近似的实体可能要求 rank 消歧；拓扑变化后的重选提示、复杂布尔多结果及所有失败恢复组合尚需定向验证。
- 首份实现记录写入时尚未运行测试；2026-10-25 收敛后的全仓验证见下文。手工步骤和 Solid Edge 实机比较仍待用户验收。

实体布尔采用 Siemens `BooleanFeatures.Add` 的并/差/交与显式实体输入语义作为参照；该 API 只确认功能方向，不证明 MyCAD 的对象生命周期或界面等价。
