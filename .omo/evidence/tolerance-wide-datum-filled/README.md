# 基准宽字画布快照图形导出

`capture.py` 使用与原始问题相同的宽字基准，通过画布快照导出图形兼容 DXF。CADCraft 0.20.1 CLI 转换的 `cadcraft.png` 显示填充字形及内孔，基准框和引线保持可见。快照转换不可恢复为结构化基准，导出报告会提示。该证据仅覆盖此软件和样例；无画布快照的回退仍输出轮廓，AutoCAD 和真实桌面仍待验收。
