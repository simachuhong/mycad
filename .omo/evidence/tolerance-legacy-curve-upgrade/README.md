# 旧曲线点身份升级人工测试样图

`legacy-curves.my2d` 包含一条不带点身份的多段线、一条不带点身份的样条；基准 A 附着于多段线顶点 `(30, 0)`，平面度公差框引线附着于第一段中点 `(15, 0)`。样图仅用于操作及数据验证，不是 GB/ISO 标准示范图。

1. 在 MyCAD 打开 `legacy-curves.my2d`，先另存测试副本；必要时使用适应窗口。确认基准和公差框均可见且指向多段线。
2. 选择元素工具中点击多段线，按 Ctrl 点击样条，执行基准操作菜单“升级曲线点身份”或命令栏 `CURVEIDUPGRADE`。检查几何、基准和公差框指向位置不变。
3. 执行一次撤销，再重做；等待每次操作结束。保存、关闭并重开副本，检查两曲线及附着位置。可用原生 DXF 导出并导回，在导入报告中检查关联状态。
4. 单独选择已升级曲线再次执行，应提示已有身份。另用原样图副本，混选基准或其他非曲线对象，应提示仅选择曲线且不产生历史更改。
