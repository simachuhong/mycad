# P2-34 — 悬停结果预览与曲线边界延伸（开发续记）

日期：2026-10-25。状态：**源码已补充，尚未验证或人工验收**；不代表 P2-34/P2 G 完成。

## 本轮改动

- 直线与开放多段线首尾端点沿当前切线/端段方向，寻找最近的非构造有限直线段、整圆或有效圆弧交点。
- 圆弧仍沿自身有向扫掠方向延伸；有限弧切割器只在它的实际扫掠范围内参与计算。整圆目标、闭合路径和开放多段线内部段仍不作为延伸目标。
- 修剪/延伸悬停时，用淡化原图与高亮候选结果显示不写入草稿的预览；没有有效交点、目标被锁定或编辑会破坏用户约束时不显示可提交预览。
- 修剪工具按住 Shift 切换为延伸预览，释放后恢复修剪；单击执行仍走原草稿操作和 undo 边界。
- 相关手工验收边界同步到 `docs/design/solid-edge-interaction-acceptance.md`，README 与开发进度已更新。

## 参照与限制

按 Autodesk Trim/Extend 悬停预览与 Shift 模式切换、Solid Edge 端点延伸到指定/下一对象的交互方向实现。当前仍没有 Fence/框选边界、多段线 Ctrl 子段选择、连续拖动延伸、内部段/闭合路径延伸或 AutoCAD/Solid Edge 桌面级选择纠正；不宣称操作等价。

用户要求在 P2 G 功能补齐前暂缓验收。本轮没有运行测试、静态检查或 GUI，延伸交点方向、重叠候选、预览画面和按键焦点行为留待开发收敛后的自检与人工验收。
