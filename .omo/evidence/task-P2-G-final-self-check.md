## 仍需明确的支持边界

- 约束自动推断目前集中在重合、水平/竖直等基础关系；PlaneGCS 在 aarch64/T2 的真实构建与包分发未验证，求解结果分支不保证全局唯一。
- 草图直接拖动编辑只针对未提交草稿；已提交草图通过历史修订/重放维护下游特征，不提供任意已提交草图的自由画布编辑。
- 草图修剪/延伸/分割覆盖直线、圆弧和开放轮廓常用子集；Fence、闭合多段线连续拖动修剪和拖动延伸尚未支持。
- DXF 只承诺文档记录的 R2010/mm 图元和关联标注子集；未支持内容会报告，外部 DXF 标注语义与任意实体类型不保证往返。
- 实体间拓扑引用由几何选择器及历史序位重建；当前没有跨拓扑稳定的持久 Body lineage。重复或近似重合实体可能需要 rank 消歧。
- 已按 AutoCAD / Solid Edge 的公开工作流与 API 进行代码级对照，但未完成用户机器上的实机操作比较；本记录和自动测试不能表述为 Solid Edge 等价或人工验收通过。
