# 工程图入口与草稿 Delete 整改（2026-10-28）

工程图无视图时显示页面内的生成入口、来源说明及步骤；有实体可自动建纸并进入画布放置，无实体则引导完成草图后拉伸/旋转。提供草图、3D、新建和打开入口。窄窗口使用滚动内容，960×600 截图已检查。

Delete 删除当前草稿选中图元及其依赖约束，一次撤销/重做；锁定、隐藏层、进行中的几何预览及输入框受保护。导航中的尺寸选择会高亮相关图元，Delete 只删选中约束；导航树也可按 Delete。删除前取消未提交的尺寸编辑，避免旧预览复活。

范围：草图先建模后投影；未加入二维草图直接排到纸上的新来源类型。已提交背景图元仍须通过历史编辑修改。本轮未重启用户正在运行的 MyCAD。

验证：
- `entry-red.log` 与 `delete-red.log` 重现入口缺失及 Delete 无响应。
- `entry-regression.log`：工程图放置、Tab、框选、分层及初版删除，60 passed。
- `sketch-regression-before-navigation-fix.log`：草图编辑器、面板、入口及删除，84 passed / 1 failed；唯一失败是导航树 Delete 未被快捷键接收。
- `constraint-delete-red.log` 重现尺寸选择误删其高亮图元；修复为优先删除选中约束。
- `delete-navigation-green.log`：改用树的键盘事件过滤后，删除与面板26项全部通过，覆盖上述两个问题。

预览脚本使用独立 XDG_CONFIG_HOME，未覆盖用户界面设置。第一次脚本退出停在临时脏文档关闭流程，仅终止该预览进程；后续脚本标记临时文档为已保存，正常关闭。用户实例未被终止。
