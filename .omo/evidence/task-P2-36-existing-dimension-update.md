# P2-33 / P2-36 已有尺寸修改

2026-10-25。本轮新增已保存草图的尺寸修订，P2 G 整体仍 active。

## 交付

- `Sketch.with_updated_constraint` 保留尺寸身份、类型、引用、来源、顺序及其他约束；只允许修订已有数值尺寸，缺失身份或改绑引用被拒绝。
- `solve_sketch_constraint_update` 以当前几何为初始状态，替换待改尺寸后调用现有 PlaneGCS，保留后来增加的关系。修改长度、距离、角度、半径、直径均有用例。
- `sketch.constraint.update@1` 追加一条审计命令，保存原状态哈希、已求解几何、尺寸和求解器版本；不改写原历史或时间戳。复用隔离下游重建、Bus 回滚、撤销/重做与无求解器重放。
- 二维文档允许该命令；驱动尺寸与参考尺寸可以相互转换。参考标注在已接受几何上重测，新增驱动约束或修改尺寸后不会残留旧参考值。
- “特征 → 草图约束 → 操作”选择已有尺寸，显示数值/精度/比例/驱动语义并锁定类型及引用，先预览草图与实体，再按“确认修改”。使用原异步代次与文档 revision 保护。
- README、ADR-010、Solid Edge 交互基线与显式命令目录同步。

## 红绿与问题记录

核心/几何新回归先因缺少 `with_updated_constraint` 和 `preview_sketch_constraint_update` 失败；GUI 新回归先因缺少 `preview_update` 服务参数失败。实现过程中，带参考直径的半径修改曾被旧参考值触发残差失败，根因是非驱动标注尚未重测；现先重测参考值，再独立检查实际几何约束残差。旧版命令重放不调用求解器，@1/@2 原执行语义保留。

命令发布使内置目录由 15 项增加为 16 项；插件用例预期由 16 更新为 17，未削弱目录精确性断言。
