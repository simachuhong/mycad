# 公差框图标主题渲染

公差框首格由叉号改为位置度的圆与十字，后两格保留简化数值和基准字母。`themes.png` 左右分别为浅色和深色背景，上方为 24 像素原尺寸，下方为同一位图的 4 倍放大；通过 Qt 的项目图标引擎渲染。

该图是本软件图标的可见性证据，不是 AutoCAD 截图或对标结论；用户指定版本的视觉对照仍需人工验收。

`toolbar.png` 是 1400×900 窗口中从实际尺寸标注工具栏截取的深色主题图。针对 24×24 图标框内原公差框占高偏小的问题，增大图框和位置度符号；普通与紧凑工具栏的显示及动作定向测试通过。此截图来自 Xvfb，并非真实桌面或 AutoCAD 对照。
