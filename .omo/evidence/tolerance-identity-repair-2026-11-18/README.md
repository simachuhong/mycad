1. 打开未锁定样本，执行 `REPAIRANNOTATIONIDS` 或工具栏“修复标注身份”。确认修复后公差框、基准和参考尺寸可分别选择，公差框仍引用 A。
2. 撤销一次，确认恢复修复前的身份冲突；重做一次，确认三者再次可独立选择，基准引用仍在。另存并重开，重复核对对象和关联。
3. 打开锁定样本，执行修复，确认提示图层锁定且没有部分修改；解锁 `GDT` 后重试，确认成功。
4. 记录软件版本、操作系统、样本哈希、每步观察、结果及验收人。出现差异时保留操作后的副本和错误信息。

本样本不覆盖 M4 以外的几何附着、第三方 CAD 或标准符号复核。
