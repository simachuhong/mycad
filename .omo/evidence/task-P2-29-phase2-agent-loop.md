## 实现

- 新增明亮与暗色语义色板；默认明亮。主题写入 QSettings，切换只更新 Qt widget palette/QSS，不提交命令或改变文档历史。
- 五区 QMainWindow 继续作为主工作台。CLI/计划底栏默认收起，按需显示；提供命令库、结构属性、CLI/计划面板收起入口及重置布局。
- 工具栏为常用文件、撤销/重做、视图和建模动作提供中文标签、平台标准图标及快捷键提示；无实现的动作显示禁用原因。窄宽窗口低于 1000 logical px 时自动收起命令库，并在放宽后恢复原状态。
- 按已批准的明亮工作台设计方向实现视觉基线；未露出未实现的二维/草图功能。

## 验证

PySide6/xcb 实机截图覆盖 5 种状态（空文档、当前 3D、选中特征、计划确认、错误恢复）× 2 个像素尺寸（1920×1080、1366×768）× 4 个 Qt scale factor（100%、125%、150%、200%），共 40 张工作台截图，并为错误恢复另存错误对话框截图。矩阵与每个组合的实测尺寸、DPR、视口占比、面板状态和工具栏溢出动作见 [`render-check-matrix.json`](phase2-foundation/p2-29-workbench/render-check-matrix.json) 及同目录分辨率报告。

| 像素尺寸 / 缩放 | 常规视口占客户区 | 计划面板打开后 |
|---|---:|---:|
| 1920×1080 / 100% | 68.56% | 47.23% |
| 1366×768 / 100% | 57.00% | 31.11% |
| 1920×1080 / 125% | 61.36% | 36.94% |
| 1366×768 / 125% | 47.55% | 23.05% |
| 1920×1080 / 150% | 54.41% | 27.81% |
| 1366×768 / 150% | 56.73% | 26.48% |
| 1920×1080 / 200% | 58.68% | 29.34% |
| 1366×768 / 200% | 44.73% | 22.06% |

所有组合均捕获 5 种状态；150% / 1366×768 因设备像素取整得到 1367×768，其余与目标尺寸一致。125% / 1366×768 时“孔”和“圆角”进入工具栏原生溢出菜单，仍可访问。

相关回归：`tests/ui/test_theme.py`、`tests/ui/test_menus_toolbar.py`。主题、QSettings 往返、默认收起、计划/CLI 面板按需显示、布局重置、工具栏可用性及窄屏面板恢复均通过。P2-30 后续会修正当前 3D 截图中的剖分三角线；P2-31 后续会完成视口选择和导航状态。
