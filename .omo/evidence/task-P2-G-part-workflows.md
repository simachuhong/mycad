# P2 G 代表零件 GUI 流程与恢复路径

2026-10-25。范围是原 P2-32～P2-36 的任务级自检，未代替用户人工验收。

## 从空文档创建的自动 GUI 流程

`tests/ui/test_p2_g_part_workflows.py`：实际 Qt 按钮/组合框、坐标输入及鼠标事件创建几何；没有通过 Bus/CLI/JSON 预先创建代表零件。

- 法兰：鼠标外圆、数值同心内圆和种子孔 → 草稿四孔环形阵列 → 拉伸 8 mm → 撤销/重做 → 新增外圆 R41 驱动尺寸 → 修改同一尺寸为 R42 → 每次完整预览/确认及撤销/重做 → 保存重开/STEP 回读。
- 阶梯轴：XZ 闭合多段线 → 绕全局 Z 旋转 → 撤销/重做 → 保存重开/STEP。
- 安装板：两条直线/两段圆弧组成外边界及长圆孔，四圆孔 → 拉伸 6 mm → 撤销/重做 → 保存重开/STEP。
- 提交草图失败：故障注入确认草稿窗口、图元仍保留且可重试，随后同一草稿成功提交。

每个实体检查有效性、解析体积、实体数量、草图持久图元 UUID、保存重开与 STEP 几何体积。预览期间历史及提交模型不变。尺寸修改保持同一约束 UUID 和图元 UUID。

结果：**4 passed in 32.61s，exit 0**（`/tmp/mycad-part-workflows-dimensions-3.log`）。原基础流程加 geom/sketch_commands 已有 **15 passed**；核心新增推断重合验证可重放、错误几何拒绝。

## 实际发现并修复的问题

1. Canvas 产生合法的自动重合关系，而 `sketch.create@3` schema 漏列 `coincident`。完整法兰/圆弧安装板无法提交。补齐 @3 已有几何验证器支持的种类；@1/@2 未改。无效推断关系仍拒绝，测试已验证。
2. 异步提交失败后草稿窗口已关闭、用户无恢复入口。失败时恢复同一草稿窗口、清除提交结果、显示错误并允许修正/取消/重试；几何工作线程忙碌时禁止再启动新草稿。
3. 孔阵列 UI 强制把点击位置作为阵列中心，环形面中心在孔洞里无法点选。新增“点击位置 / 面形心”，默认保持点击位置；后者复用已支持的 `position.kind=center`，取所选面的面积中心。不是任意自动几何圆心识别。

## 孔阵列与改参

`test_annular_face_hole_pattern_can_use_face_centroid` 在预置环形实体上通过 GUI 选面、设面形心、R25 阵列四个 Ø6 通孔；直径 200 mm 预览失败且当前历史/实体不变，恢复 Ø6 后提交。通过特征树历史编辑框将孔径/数量改为六个 Ø8 孔，核对体积、有效性和原时间戳/追加 amendment。此前无中心选项测试明确失败。该特定测试设置预置实体，不冒充上述从空文档创建的流程。

结果：定向恢复用例 **1 passed**；随后完整 toolbar + modeling interaction **54 passed in 58.07s，exit 0**，Ruff/format/basedpyright 全通过。

## 身份契约与边界

BodyId 是重放代际内的运行时身份，撤销/重做后应过期；不能用相同 BodyId 断言持久实体身份。当前交互选择器包含体积/形心/包围盒谓词，尺寸变化后其值应更新；保存重开比较的是修改后的谓词。草图图元和尺寸使用持久 UUID。这里不宣称稳定装配实体 UUID。

这些结果是自动 Qt 事件路径及精确内核检查；真实用户视感/手感、Solid Edge 对照和外部 CAD 手工兼容仍待最终统一交接。剩余 P2 G 完成度以 requirements-audit 为准。
