## 改动与行为

`BuildKernel.apply` 每次成功都保留快照，包括完全切除后的 None；空快照输出空网格，
保持后续快照序号正确。中立端口文档明确“无历史”与“成功但空结果”的区别，不改 DTO/schema。
UI 检测当前空网格，清除实体、线框、高亮和选择，并请求重绘；空当前模型不拾取历史旧实体。
绑定空文档也会清掉旧高亮，不把旧模型残影留在新会话。
