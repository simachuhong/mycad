# 二维窗口选择 / 交叉选择

日期：2026-10-25

## 行为

- “选择元素”工具：在空白处按住左键拖拽，或两次单击指定选框对角点。
- 从屏幕左侧向右侧：蓝色实线窗口，仅选完全包含的图元。
- 从屏幕右侧向左侧：绿色虚线窗口，选完全包含或与框线相交的图元；接触边界计入。
- Ctrl 框选加选，Shift 框选/点选减选；普通框选替换选择集，与现有普通点选一致。
- Esc/右键取消当前选框并保留原选择。切换工具、中键平移或滚轮缩放时清理未完成选框。
- 移动/复制的命令优先流程支持累积框选；Enter 完成当前选框后结束对象选择，再指定基点与目标点。
- 隐藏图层与只读背景参照不参与；锁定图层沿用现有可选择、不可修改的规则。
- 保留现有控制点拖动、点选、Ctrl 点选切换、草稿撤销/重做。

## 几何判定

线段使用有限线段与选框裁剪；多段线包含隐式闭合边；矩形按轮廓处理。
圆和圆弧使用解析极值与圆/框线交点，圆弧按有向扫角过滤。
样条使用画布相同的采样路径，选择与当前显示形状一致。
闭合轮廓内部空白不作为曲线交点，避免包围盒/填充导致的误选。
选择本身只更新 UI 选择集，不改变 Document，也不新增几何撤销步骤。

## 人工回归跟进：存盘重开后对象不可选

根因：独立二维图重开后将全部已提交草图投影到 `background_entities`；之前的点选/框选只检查未提交 `entities`。上一轮验证未覆盖 GUI 保存/打开完整生命周期。

当前行为修正：独立 `drawing2d` 的可见已提交图元参与点选、窗口/交叉选择、Ctrl 加选、Shift 减选及高亮。三维草图只读参照保持原规则。选择不会复制图元到新草稿，不写命令、不改变脏标记。已提交几何仍通过现有历史编辑修改，混选时明确拒绝部分修改。

刷新提交上下文时清理失效选择，并取消未完成选框；草稿 undo/redo 也过滤已不存在的已提交身份。
