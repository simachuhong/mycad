   既有计划卡片仍走六态机；新增 AI 不在本阶段实施。

   在对应任务中提交 ID/版本/schema 清单并更新 ADR-003 保留表；无清单不得占用。
4. 当前修复只涉及公开数据边界和既有显示语义，不解除无网络/无线程/无缓存限制。
   P2-07～10 启动时再按任务决策替换阶段守卫；长期 layering 测试不削弱。

   不换几何/显示后端、不引求解依赖。本批修复均不需要这些后续决策。
6. Phase 3 接口在 P2 CAD 契约之上扩展；P2 不提前实现空数据库/provider 框架。

### P2-36 版本补充（2026-10-25）

释放 `feature.extrude@3`，只在已用 command ID 上新增版本：保留 @2 的 profile、distance、mode schema，追加可选 `extent_mode: "one_sided" | "symmetric"`（默认 `one_sided`）。对称模式把正的 `distance` 解释为总深度，草图/XY 截面基准面两侧各延伸一半；面拉伸明确拒绝对称范围。@1/@2 schema 与既有命令历史语义不变。精确契约同步记入 ADR-003 §9 和 P2-36 证据。

再释放 `feature.revolve@3`：保留 @2 全局轴分支，增加与之互斥的草图构造直线稳定引用分支，仅接受 `LineEntity(construction=true)`，经草图平面映射构造偏置回转轴。@1/@2 schema 与存档重放不变；建模栏仅列出当前回转轮廓草图中的构造线。此切片按 Siemens Solid Edge Ordered Revolve 的草图中心线轴工作流自检，跨草图/模型棱边轴选择和到面终止仍在范围外。精确契约记入 ADR-003 §9 与 P2-36 证据。
