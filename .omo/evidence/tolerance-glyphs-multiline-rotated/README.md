# 旋转双行公差图形和适应窗口样例

`capture.py` 在隔离 Xvfb 中创建双行、37° 旋转、字高 5.5、宽度因子 1.8 的公差框，包含数字、直径、材料条件 M 和中文基准文字；执行适应窗口并截图，输出图形兼容 DXF。CADCraft 0.20.1 CLI 将 DXF 转为 SVG 和 PNG；图示中双行框格、填充文字、数字内孔、修饰符圆圈和右侧引线可见。画布的“基准未关联”是刻意使用的未绑定名称提示，此处中文只用于字体交换测试，不代表标准制图。该单一样例不代表 AutoCAD 或所有字体的结果。
